導覽的現用態不是被標示出來的——它是被多印了一塊版。

圖版室工作準則・一九五九年二月訂

數翅膀，
不要數羽毛。

這句話不是我們發明的，是查理・哈波說的：「我看一隻鳥的時候，我不看牠翅膀上的羽毛，我只數牠有幾片翅膀。」他把這種畫法叫做極簡寫實（minimal realism）。我們把它變成三條可以驗算的規矩，因為地下室那台機器不接受意見，只接受版。

THREE RULES

三條規矩

一　數翅膀，不要數羽毛

同一組重複的形狀——六隻腳、五顆斑、四片翅、兩隻耳朵——要嘛全部留下，要嘛全部刪掉。留三顆斑刪兩顆，那不是簡化，那是漏印。引擎的判準：對每一個群組 g，|留下∩g| 必須等於 0 或 |g|。

二　識別鍵不能刪

每一張圖版有二到三塊形狀被標成識別鍵：浣熊的黑面罩、紅雀的尖冠、山雀的黑頭巾、蜻蜓的四片翅。拿掉它，畫面上剩下的東西可能還很好看，但它不是那隻動物了。這一條也順帶決定了另一件事：一塊形狀被刪掉時，掛在它身上的東西一起走——刪掉頭，面罩就沒有地方可以掛。

三　刪到不能再刪

前兩條都沒犯，但留得比館方那一版多，一樣退。理由寫在版邊上：這是插畫，不是圖版。插畫可以慢慢看，圖版要在三十呎外被一個走過去的人認出來。館方版的塊數不是隨便定的，它是我們自己刪到最後、還敢送印的那個數字。

三條規矩都不扣分、不排名、不給星等。版只有兩種結局：收版，或退版重來。退版不會失去任何東西——這是圖版室，不是考場。

THE NUMBERS

HOW IT IS PRINTED

這批圖版怎麼做出來的

五種形狀

圓、橢圓、等腰三角、半圓、圓角矩形。刀片只有這五把，剩下的靠疊。這不是限制，是因為一塊版上刻得出來的東西就只有這些。

四塊版、固定的套印偏移

芥末 +1.5/−1.1、磚橘 +1.3/+1.4、鴨青 −1.6/+1.0、墨 0/0。墨是套準版，其餘三塊都對不準，而且我們不修。油墨還會肥出來一點——版上刻多細，紙上都會粗一點。

墨線只給識別鍵

這裡沒有描外形這回事。形狀的邊界就是顏色的邊界。墨版只印三種東西：識別鍵、眼睛、和牠站的那根枝。

留白至少二成八

圖不准碰到版框。你在刪形台每刪掉一塊，剩下的形狀就會被重新裝框放大到剛好留下這個白邊——版的尺寸是固定的，所以少一塊，其他塊就變大。這是這間圖版室唯一的獎賞。

TECHNICAL NOTE

技術附記

SVG feMorphology + feComposite。圖版上的油墨肥邊由一支濾鏡承擔：先 operator="dilate" radius="0.62" 把整張圖脹一圈，再把原圖 feComposite operator="over" 疊回去，於是每塊形狀底下都墊著一圈自己的顏色，相鄰兩塊接觸的地方會透出那一圈。MDN 標示 feMorphology 為 Baseline Widely available（2015-07 起跨瀏覽器）。濾鏡只掛在首頁與刪形台各一張大圖上（目錄的十二張縮圖不掛），不支援時整支濾鏡被忽略，形狀與版面完全不變。

CSS Grid subgrid。圖版目錄每張卡片內部的五列——圖、中名與編號、學名、塊數與版數、年份印量價格——用 grid-template-rows:subgrid 掛到外層網格上，因此不論學名多長，整排卡片的每一條橫線都會對齊成一條直線（一九六三年的目錄頁就是這樣排的）。caniuse／web.dev：subgrid 自 2023-09-15 三引擎齊備（Firefox 71、Safari 16、Chrome/Edge 117），2026-03-15 起列為 Baseline Widely available。@supports not 時退回一般網格，卡片內容完全一樣，只是橫線不跨卡對齊。

規則引擎。三條規矩是三個可驗算的述詞，純 JavaScript、無瀏覽器 API 依賴。「下限」由識別鍵的依附閉包＋群組補齊求得，並以窮舉全部 2^n 子集驗證（十二張圖版全部相符）。建置階段跑完全部窮舉的時間約數十毫秒，執行階段每次交版只做一次線性掃描。同一組刪法恆得同一個版號（FNV-1a 雜湊），?p= 網址可完整還原。

無 JavaScript 時。四頁的全部文字、表格、十二張圖版與首頁那張原稿，都在建置階段以同一支形狀引擎算完並寫進 HTML，關掉 JavaScript 仍是完整的網站；失去的只有「刪」這個動作本身。
