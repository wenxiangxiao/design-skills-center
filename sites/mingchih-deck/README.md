## 五個不可省略的視覺特徵

1. **編號取代名稱**——編號一律比名稱大 2–8 倍，很多時候只有編號沒有名稱。
2. **資訊被扣住：色碼作為定址語言**——四段等寬色段編出層、區、步數、但書；牌面不寫字。
3. **借來的圖**——全站唯一的圖是三十日在場車輛數的疊線層析圖，無座標軸、無圖例，圖說是一句不解釋任何事的襯線斜體。
4. **不可協商的十二欄格線**——欄線印在背景上，所有版塊用 `subgrid` 掛在同一副欄上，欄間距 0。
5. **裝飾只能從工地與交通來**——45° 危險斜紋、反光釘、地面標線、分區色塊。

## 動效四式

- **ambient**：日光燈管不規則閃爍（`steps(1)`, 7.2s）＋危險斜紋帶整格位移（`steps(7)`, 5.6s）＋首屏色碼帶的白框掃描每 0.5 秒硬跳一段
- **input**：導覽「倒車進格」`transition:height 140ms steps(4)`；指到任一格，右側解碼尺即時讀出該格四段（`transition:none`）
- **transition**：進頁時黑色遮罩以 `clip-path:inset()` 由左掃出，`steps(6)`, 620ms
- **signature**：**逐段讀碼 gate-read**——送標時色碼四段依序點亮，每亮一段就把對應欄位硬跳寫進收據，四段讀完柵欄才抬起

四式皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。

## 核心功能：一一五年八月標售

規則三句話、九十秒玩得完：

1. 從四層四十八格裡挑一格——牌子上只有編號和色碼，沒寫它在哪、離電梯多遠、有什麼毛病。
2. 填一個月租價，不得低於該格底價。
3. 送標——同格的既有標單當場一起開，最高者得，同額者以收件序決定。

**兩道會擋人的規則**：未指定標的即退件；低於底價即退件並報出底價。

## 認領的首創

**以色碼作為站內唯一的定址語言，且核心功能要求使用者先學會這套設計語言才能操作（chromatic addressing as the product's only address space）**

全館第一個站，其產品的規格不是用文字列出來的，而是編成一組顏色印在牌面上——使用者在標售台上看到的每一格只有一個編號和四塊顏色，他必須先讀懂第一段是層、第二段是區、第三段是離電梯幾步、第四段是這格有什麼毛病，才知道自己在標什麼。這是 Peter Saville 在《Blue Monday》封套邊緣印色碼、把鑰匙藏在另一張唱片背面那一手，被做成一個真的要用的東西。

- 與 `namsek-lights`（燈質時間編碼）的差別：那是把時間序列編成閃光節奏，被編碼的是**訊號本身**；本站被編碼的是**一件商品的規格表**，而解碼的動機是要花錢買它。
- 與 `khoaibeng`（介面自身的幾何作為被優化對象）的差別：本站沒有最優解、沒有成本函數，只有「你讀不讀得懂」。
- 與 `beian`（訪客重排資訊架構）的差別：那是使用者改變介面；本站是介面不肯翻譯自己，使用者必須改變自己。
- 破格但不難用：每一枚色碼旁必有視覺隱藏的文字全譯，標售台上常駐可展開的解碼卡，`code.html` 是完整對照表，全部四十八格的規格另有一份不需 JavaScript 的靜態表格。
