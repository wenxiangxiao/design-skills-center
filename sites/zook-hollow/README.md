### 認領首創

**「規矩本身即驗收條款，且驗收數字用感知色空間算」**——全館第一個把一個歷史流派的成立規則（Ordnung）直接寫成使用者要通過的四條檢查，而其中兩條的門檻是 OKLab 的感知明度差 ΔL，讀數即時顯示在介面上。使用者玩這個功能的過程，就是在親手驗證「深色包著亮色」為什麼必須成立——功能的驗收標準就是風格的規格書。

另一項並存的首創：**絎縫的立體感由 SVG 光照濾鏡的高度場產生，而光的方位由訪客本地時鐘驅動**（`azimuth` 198°→258°），因此整床被的浮雕陰影一天之內會換邊。

## 核心功能：換布

規則三句話，九十秒玩得完：

1. 用蜜換布。八戶人家，每戶只換一次，她要哪一種蜜、要幾罐，牌子上寫著。
2. 把布放到被的四個位置：中心菱形、角三角、內框、角石。外框固定用蜂場自家的茄紫。
3. 過 Ordnung 四條才算一床被——不上白、菱形要浮出來（ΔL ≥ 0.110）、角石要跳（ΔL ≥ 0.090）、連外框最多四種色。

窮舉數據：255 種換布組合中 **143** 種在十一罐蜜的預算內換得成；這 143 種裡 **84** 種（58.7%）至少存在一個過得了 Ordnung 的擺法，全部可成被的擺法共 **1,612** 個。剩下 41.3% 需要跟莎拉要一塊茄紫——只要換過至少一戶，加上那塊布就一定湊得出來，所以沒有走不下去的局，只有要不要欠人情。

成被後：被記編號、針距、義賣落槌價（全數歸義消隊）、可分享還原的 `?q=` 碼，以及「縫上繃架」——首頁那床被會換成你配的那一床，針從第一行重新走。
