EL TALLER · 絹印工坊

TRES LATAS,
UN PAPEL

工坊在放映隊的院子後面，兩張桌子、三塊木框、一把橡膠刮刀、三罐墨。海報不是宣傳品，它是村裡唯一一張告訴大家「這週五晚上有事做」的紙。所以它必須在二十公尺外、在下午四點的太陽底下、被一個不識字的人一眼認出來——這就是為什麼它只能是大剪影、大字、三個顏色。

CÓMO SE HACE · 五道工序
1

EL ORIGINAL｜原稿

Mirta 把片名與圖直接畫在三張描圖紙上，一張一色。畫的時候就要決定哪一塊形歸哪一塊版——因為形沒有輪廓線，一個形不能被兩塊版共有，否則邊會糊。

2

LA EMULSIÓN｜曬版

三塊 43T 尼龍網、木框 70×50，塗感光膠，正午拿到院子裡曬十一分鐘。陰天曬十六分。曬過頭的版洗不開，細的地方會塞死。

3

EL REGISTRO｜對版

把橘版放平當基準，綠版與黑版對著它推。推到最後永遠差那麼一點——這台架子用了二十三年，綠版固定往右上跑 3.5 與 2.2 個點，黑版往左下跑 2.8 與 3.1。

4

EL RASERO｜刮印

橘、綠、黑，一色一刮，一刮一張。刮完一色要等四十分鐘乾透才能上下一色，所以一張三色海報要做一整天。

5

EL CONTEO｜點數

印三十五張，挑掉糊掉的通常剩三十一二張。前二十張當天貼出去，剩下的擺在工坊賣，一張六十比索。

LAS CINCO REGLAS · 五條規矩

SI QUITAS UNA,
YA NO ES ESTO

這五條不是風格建議，是這間工坊的物理條件。拿掉任何一條，印出來的東西就不是古巴絹印海報了——它會變成別的東西，可能還很好看，但不是這個。

1

TRES LATAS｜三罐墨，其餘全部疊出來

一張海報只有三個專色加一張紙的顏色。第四、第五、第六個顏色不是調出來的，是兩塊版壓在同一個地方疊出來的。這條規矩的檢查方法很機械：把樣式表裡出現的色值列舉出來，只准有五個——紙面 #E9DCBC、紙上網目的谷 #DFD0AA，加上三罐墨。第六個值就是第四罐墨，而我們沒有那罐墨。

上面那八格裡，只有第二到第四格是墨（第一格是紙）。後四格是把前面幾格疊起來壓出來的——樣式表裡沒有它們的色碼。

做法是把每一塊版包成一個 multiply 圖層，並且用 isolation:isolate 把混色關在這張紙裡面，不讓它跟頁面背景亂疊。

.hoja{ isolation:isolate; background:#E9DCBC } .plancha{ mix-blend-mode:multiply } .p1{ color:#DD5B21 } /* naranja */ .p2{ color:#8AA627 } /* verde */ .p3{ color:#17130E } /* negro */
2

SIN CONTORNO｜沒有輪廓線的剪形

所有的形都是實心平色剪影，零描邊。形的邊界就是顏色的邊界。一加輪廓線，它立刻變成木刻、變成漫畫、變成別的流派——因為輪廓線意味著「先有線再填色」，而絹印是先有色塊，線是後來才有的東西（而且線也是色塊，只是很窄）。

左邊是對的，右邊是錯的。錯的那一片你會開始覺得它是插畫；對的那一片你只會覺得它是一片葉子。

在 SVG 裡這件事要寫死，不能靠自律——把整塊版底下所有元素的 stroke 一律關掉，這樣任何人後來加進來的圖都不可能帶線。

.plancha svg *{ stroke:none } /* 形只用直線與圓弧接成： */ <path d="M0 0 L40 0 A20 20 0 0 1 40 40 Z"/> /* 不要： */ <path stroke="#17130E" stroke-width="3" .../>

附帶結果：兩個形之間如果要有「線」，那條線其實是第三個形——一條很窄的實心長方形。這也是為什麼這個流派的線看起來永遠比插畫的線重。

3

EL REGISTRO｜固定的套印偏移與單色月牙

手工套版對不準。這台架子的綠版固定往右上跑 3.5 與 2.2 個點，黑版往左下跑 2.8 與 3.1 個點——二十三年都是這樣，修不掉，也不必修。它的結果是：任何一塊疊色的邊緣，一定露著一條只有單色的月牙。那條月牙是這張紙是人印的證據。

左邊有月牙（真的）。右邊完美重合，看起來像電腦做的——這個流派裡它才是錯的那一個。

把偏移量寫成變數，全站共用，並且讓它可以被一個 0 到 1 的數推回去。這樣「分版」與「套準」是同一條式子的兩端。

@property --reg{ syntax:'<number>'; inherits:true; initial-value:1 } .plancha{ transform:translate( calc((var(--rx)+var(--ox)*(1 - var(--reg)))*1px), calc((var(--ry)+var(--oy)*(1 - var(--reg)))*1px)) } .p2{ --rx:3.5; --ry:-2.2; --ox:35; --oy:-22 } .p3{ --rx:-2.8; --ry:3.1; --ox:-28; --oy:31 }

拉開的量正好是殘餘偏移的十倍，所以把版拉開時看到的歪法，跟成品上那個歪法是同一個方向。

4

PLANO ABSOLUTO｜絕對平色

一塊色就是一塊色，從頭到尾同一個值。絹印不會漸層（那是噴槍的事），不做網點（那是製版相機的事），不打陰影（那要多一塊版而且沒人會為了陰影多花一罐墨）。整張海報的空間感全部靠「誰蓋住誰」與「誰比較大」。

Degradado 漸層
Trama 網點
Sombra borrosa 模糊陰影
Brillo 發光
Gris intermedio 中間灰
Esquina redonda 大圓角

要一個灰？沒有灰這罐墨。灰只能是綠壓黑，或者把黑的形做小一點、讓紙露出來。

這條規矩最容易破功的地方是陰影。想要層次就把形錯開，不要打陰影。

/* 對 */ .caja{ border:4px solid #17130E } /* 錯 */ .caja{ box-shadow:0 8px 24px rgba(0,0,0,.2); border-radius:16px; background:linear-gradient(...) }

附註：連「按下去的硬陰影」也不要——那是紙盒與網頁的語言，不是絲網的。這裡的按鈕就是一個四像素的實框，按下去換成整塊反色。

5

LETRAS MORDIDAS｜咬合的手繪展示字

片名是被「畫」出來的，不是被「排」出來的。所以字與字會互相咬進去（負字距）、會被壓扁拉長、會為了填滿一塊空白而歪一點。字腔是封死的——看起來像被剪刀剪下來的整塊。而正文用的是完全相反的另一套字：規矩、窄、只負責說清楚事情。這個對比越大越好。

AGUA DE POZO
AGUA DE POZO

上面那行是對的（咬在一起、逐字微調）；下面那行只是把同一個字體照預設排出來——它立刻變成一張投影片。

做法：負字距 + 逐字的微幅縮放與旋轉。不要用在正文，只用在展示字。

.cartel-t{ font-family:"Titan One"; text-transform:uppercase; letter-spacing:-.055em; word-spacing:-.06em; line-height:.84 } .cartel-t span:nth-child(2){ transform:translateY(.055em) scaleY(1.1) } .cartel-t span:nth-child(3){ transform:rotate(-2.4deg) }

西班牙文全大寫是這個流派的常態——因為手繪大寫比手繪小寫快，而且二十公尺外讀得到。
