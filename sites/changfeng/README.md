## 首創

**跨頁的實體運送（in-transit object with real travel time across pages）**——
使用者送出的子彈不是一段轉場動畫，它是一個帶發送時刻的物件：
它沿著每一頁頁首的同一段管前進，換頁、重新整理、開另一個分頁都在同一條時間軸上（`localStorage` 時間戳＋`BroadcastChannel`），
而且送出以後不能取消、不能取件。頁與頁之間的距離因此是真的。

## 動效四式

| 類型 | 內容 |
|---|---|
| ambient 環境 | 管內氣流點列持續流動（每頁頁首）＋首頁立管的鏡面光源以 22 秒來回掃過整根管 |
| input 輸入 | 站台 hover／點選即亮橘並打通那一支，其餘變死路（<100ms）；轉轍葉片 hover 預轉 |
| transition 轉場 | 換頁時內容由管口方向以 `clip-path` 推入（460ms），不用淡入 |
| signature 簽名 | **在途 in-transit**：子彈在你不看它的時候繼續走 |

四種皆有 `prefers-reduced-motion` 降級：氣流靜止、光源停在定點、推入改為直接到位、在途改為每三秒更新一次位置與剩餘秒數的文字，資訊零損失。

## 技術

1. **SVG `feSpecularLighting` ＋ `fePointLight`**（A 渲染層）——一體成形的塑膠光澤，由殼體自己的 alpha 生成。
2. **SVG SMIL `animateMotion` ＋ `mpath` ＋ `SVGSVGElement.setCurrentTime()`**（B 動效與時間軸層）——子彈沿真實管路曲線飛行，並在換頁時把時間軸 seek 到「它已經飛了多久」。
3. **`localStorage` 時間戳 ＋ `BroadcastChannel`**（E 資料與生成層）——跨頁、跨分頁的飛行狀態。

支援度查證、fallback 行為與效能實測值見 `SKILL.md` 第十二章。
