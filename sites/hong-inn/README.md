# 方圓菓子舖 HŌEN WAGASHI — 長安西路的和菓子

臺北市大同區長安西路 74 號的和菓子店（虛構）。1966 年秋周振芳從金澤學徒回臺開店；1971 年女兒周以寧把十二個月的菓子重畫成只有圓、方、三角的圖，從此店規是「沒有第六種形」。現在店裡有六十一枚木型，周以寧做圖、賴文雄師傅做菓子。
