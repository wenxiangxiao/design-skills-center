# 日月堂・けん玉道場 Nichigetsu-dō

> 昭和年間開到今天的けん玉（劍玉）道場兼玩具店。整間店做成一支けん玉：首頁的技演台不是示範影片，是你自己的手——拉球、放手、屈膝接玉，接進大皿、中皿、小皿或けん先，看你放手的力道與收球的時機。

## 品牌設定

- **產業**：けん玉道場／玩具店（雜耍・技巧玩具的近親，但核心是「三皿一尖」的接玉技術，與拋接、繩結、陀螺皆不同）
- **地點（虛構）**：東京都台東区谷中三丁目八番地
- **二代目**：桐生玄一，握了四十年木玉
- **調性**：熱血直球的職人道場。不賣「療癒小物」，賣一支能陪你練到手起繭的傢伙。牆上掛級位認定表，週末開連段擂台。
- **玉は陽、皿は月**——玉為陽、皿為月，日月相接，故名日月堂。

## 首創（_first_registry）

**弦繫木玉的拋接—屈膝收球物理作為核心互動（string-tethered ball toss with knee-cushion catch as interaction，nichigetsu）**：全館第一個以「けん玉的接玉」為核心技術的站。放手速度決定拋高（h ∝ v²）、玉落回皿口的相對速度＝落速−屈膝速度，屈膝（膝を使う）在接觸瞬間讓皿與玉同向下沉、把相對速度壓進該面的容許值內即「のった」，否則「叩」一聲彈開；四個接玉面（大皿／中皿／小皿／けん先）容許值遞減，故けん先最難、且需先把玉拋低才有屈膝的容錯。與 sanqiu（siteswap 拋接：多顆自由拋物、無繩、無接玉面、以落點雙射判合法）、jinsheng-glove（verlet 提線操偶：牽線操演布袋戲偶、非拋接接玉）、grip-station（攀岩牆面路線＋IK 人體）皆不同：本站的互動對象是一顆被線約束、被拋起、要用時機接進特定皿面的木玉，判定的是「這一下接不接得住」。同一支けん玉引擎渲染技演台、三十式技鑑、logo、favicon 與報名印記，全站無一張圖是「畫」的。
