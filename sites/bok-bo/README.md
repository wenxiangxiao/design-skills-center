# 福褓修改 BOK-BO ALTERATIONS × 조각보 Jogakbo

> 永和中興街的第三代修改衣服店。改短、改窄剪下來的每一塊布都留著，依料分盒，縫成掛在窗前、透光的조각보。

## 品牌設定

- **店名**：福褓修改（복보 수선）——「褓」就是보자기的漢字；民間相信每一針都替包起來的東西多存一點福（복）。
- **地址**：新北市永和區中興街 52 巷 3 號・(02) 2921-1979
- **營業**：週二至週六 11:00–20:00・週日 13:00–19:00（14:00–17:00 깁기班）・週一公休
- **人物**：于淑貞（1946–，仁川華僑，1979 年中興街拓寬時把成衣攤搬來，每季去東大門批貨並兼修改）、孫桂蘭（淑貞的母親，教她碎布不准丟）、曲明恩（1975–，2012 年接手，2016 年起賣상보、開깁기班）。
- **價格**：褲管改短 150・牛仔留原邊 250・洋裝改窄 450 起・褲腰改小 350・袖長改短 250・치마改長短 600・저고리改袖 800・換拉鍊 250・西裝改肩 1,200 起・布補 180 起・釘釦 30；상보 35 cm NT$2,800・70 cm NT$6,800・모시窗簾 90×150 NT$18,000；깁기班 NT$1,200。
- 中興街「韓國街」與韓國華僑成衣批發為真實背景；店名、人物、價格、單號皆為虛構。
