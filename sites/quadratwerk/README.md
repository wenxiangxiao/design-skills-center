## 為什麼是「格柵半身」

分離派有兩個身體。一個是印刷的——《Ver Sacrum》正方開本、黑白棋盤格帶、平的金（本館的 [`fangtsun` 方寸釦廠](../fangtsun/index.html) 講這一半）。另一個是鍛出來的：一九〇三年以後 Hoffmann 把方格帶進建築金工，於是整座維也納的樓梯間裝進了鍛鐵格柵——升降機柵門、護欄、通風格。

本站只做後面這一半，並且明文不用棋盤格帶、不用一點金。判準是三秒辨識：遮掉文字，首屏要能被認出是分離派的格柵。

## 核心功能：停層檯 Bündigstellen

規則三句：按住把手車廂上升，每一層樓面前一公尺有**減速凸輪**，車廂會自己降到爬行速度；在爬行段放手，車廂地板與樓面差三公分以內柵門才拉得開；停不準可以微動一公分一公分挪，但挪過的那一趟不算平層——**三趟連平**才發手執照。

沒有量表、沒有模擬引擎、沒有參數可調——回饋是門檻上看得見的那一道**階**，以及柵門拉不拉得開。

凸輪不是裝飾：全速放手的時間窗只有幾十毫秒，那不叫難。凸輪把放手速度壓到 25 cm/s，±3 公分的窗因此是 **240 毫秒**（模擬實測 224 毫秒），一整輪約 **27 秒**。另有「逐格」按鈕：第一下開到凸輪、之後一下兩公分，完全不靠手感也能拿到同一張執照（已模擬驗證）。

## 認領的首創

**`state-as-misalignment` 錯位即狀態**

全館第一個站，其「你在哪裡」完全不靠顏色、底線、粗細或大小表示，而是靠一個 **1/4 模矩的垂直錯位**。

在一個所有長度都是同一個模矩整數倍、所有東西都咬在同一條網線上的版面裡，錯開四分之一格比任何換色都響——而這個錯位不是裝飾，它就是這座梯的毛病：手動梯停不平。導覽的現用項上移 1/4 格、它底下那條髮絲線因此斷開；車廂停在樓層時也停低 1/4 格。

然後核心功能把同一個語彙**反過來用**：在停層檯裡，錯位是失敗，你要做的事就是把它消掉；消不掉，柵門就拉不開。

因為錯位是一個位置而不是一段動畫，`prefers-reduced-motion` 下它**原樣保留**——這是全館第一個在降級時簽名動效完全不消失的站。

附帶技術紀錄（非首創認領，但經建置期驗算）：四頁樣式表與行內樣式共 **645 處**模矩衍生長度、**0 處**自由絕對長度。全站只有一個長度單位，字級也是它的倍數——不像常見做法另開一個與格分離的字級單位。

## 技術

1. **Wang 磚邊緣匹配拼砌**（E 資料與生成層，全館首次）——73 枚磚，一枚只有在左邊條件等於左鄰右邊、上邊條件等於上鄰下邊時才准放；因此線不可能斷在半路。決定性，不用亂數，同型號永遠同圖樣。接縫驗算全站 0 處不合。
2. **Web Animations API 群組時間軸**——車廂行駛用同一個 `Animation` 物件 seek 與 `reverse()` 做 hover 預覽，不是每次新建動畫。
3. **CSS `shape-outside` / `shape-margin`**——正文沿格柵母題的 L 形缺角繞排。
