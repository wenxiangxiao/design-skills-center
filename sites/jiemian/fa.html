法 — The Three Laws

泡沫的三條定律

這一頁不需要開啟任何互動就能讀完。看槽之前先看它，或看完槽再回來對照，都可以。

第一律 — Plateau (1873)

壁只用一種方式相交

槽裡看得到的每一個轉折，都是這兩種事件之一。壁不會平移，胞也不會「滑開」——只有換鄰居（T1）與消失（T2）。

第二律 — von Neumann (1952)

一個胞的命運寫在它的邊數裡

dA/dt = κ ( n − 6 )

A 是胞的面積，n 是它的邊數，κ 是與氣體穿膜擴散速率有關的常數。式子裡沒有面積、沒有形狀、沒有位置——一個胞長大還是縮小，只取決於它有幾個鄰居。

這條式子有一個立刻可以驗證的推論：因為平面上的胞平均有六個鄰居（尤拉公式的結果），所以任何時刻都同時有一群在長大、一群在縮小，總面積不變。槽裡的氣體不會增加，也不會漏掉，只會換手。

在〈槽〉裡把「內部平均邊數」這個讀數看久一點：它會一直在 6.00 附近晃。貼著槽壁的胞不算在內——它們的邊數被壁截斷了。

第三律 — Laplace (1805)

小泡的壓力比較大

Δp = 2γ / r　（單面膜）　　Δp = 4γ / r　（兩面都是液–氣界面的皂膜）

曲率半徑越小，內外壓差越大。所以小泡裡的氣體壓力高於大泡。膜不是完全不透氣的——氣體會順著壓差，從小泡緩慢擴散到大泡。

這就是第二律的動力來源。粗化不是泡在「破」，是氣體在搬家。整槽泡沫從頭到尾可能沒有任何一張膜破過，胞數卻一直在減少。

顏色 — Thin-Film Interference

顏色是膜快沒了才有的

光在皂膜的前後兩面各反射一次。兩束反射光走的路程差了 2nh（n=1.33 是皂水的折射率，h 是膜厚），加上前面那次反射多出的半個波長相位翻轉，某些波長相長、某些相消：

I(λ) ∝ sin² ( 2π n h / λ )

膜厚一改，被加強的波長就換一組，顏色就換一次。下面這條色帶是把 h 從 0 掃到 1000 奈米直接算出來的，不是畫的：

最左邊那一段是黑膜：膜薄到約十奈米以下，兩束反射光幾乎完全相消，膜什麼也不反射，看起來是黑的。實驗室裡看到黑膜出現，就知道那張膜快撐不住了。

往右一點是厚膜區：路程差大到各個波長的極大值擠在一起，顏色互相抵消，看起來就是一般人印象中「白白的泡沫」。所以濕泡沫是白的，乾泡沫才有顏色，再乾一點就變黑。

在〈槽〉裡拖動「抽液」，讀數列會同步顯示槽中線的膜厚。壁的顏色就是用上面那條式子逐段算出來的——同一個 h，同一個顏色。

誠實聲明 — What This Model Is Not

本館的模型做了哪些簡化

  • 壁是直的。真實泡沫的壁是圓弧——Laplace 壓差讓壁朝壓力低的那一側凸出。本館的胞由 Laguerre（power diagram）解出，壁一律是直線段。這對邊數、拓樸事件與 dA/dt 的定性行為沒有影響，對壁的形狀有。
  • 槽壁採鏡射簡化。貼著槽壁的胞，本館把每一段壁計為一條邊。真實容器的壁接觸角是 90°，嚴格處理要把整槽鏡射展開。所以讀數列的「內部平均邊數」刻意排除了貼壁的胞。
  • 反射率被放大了。皂膜的實際反射率約 4%，直接照算在螢幕上幾乎看不見。本館把它放大約十二倍，色相沒有改，亮度改了。
  • 時間被壓縮了。真實的乾泡沫粗化以小時計。本館的 κ 調到讓一槽泡沫在數分鐘內走完一生。「時間 ×3」是再壓縮一次，不是把物理換掉。
  • 膜厚是位置的函數，不是逐張膜獨立計算的。本館用「抽液程度 × 高度」給出膜厚（重力使上方先變薄），沒有模擬每一張膜自己的排液歷程。
Glossary

名詞

胞　cell
泡沫裡的一個泡，在二維切面上是一塊多邊形。
壁　film
兩個胞之間那一張膜。
Plateau 交界　Plateau border
三面壁交會處那一小攤液體。泡沫裡的水幾乎都待在這裡，排液排的就是它。
T1 事件
兩個胞之間的壁縮到零長，鄰居關係互換。四個胞的邊數同時改變兩個。
T2 事件
一個三邊胞消失。周圍胞的邊數各減一。
乾度　dryness
泡沫的液體體積分率。液體越少，膜越薄，Plateau 交界越細，粗化越快。
粗化　coarsening
胞數減少、平均胞面積變大的整個過程。不需要任何一張膜破裂。
