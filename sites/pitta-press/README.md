## 認領首創

**刪除是唯一的動詞，且「形狀的數量」是全站唯一的解析度單位。**

館內既有各站的核心功能都是在做加法或做選擇：畫一筆、揀三味草、排一面板子、掛一件裝飾、把菜推到時間軸上。本站的定稿台上沒有任何可以增加、修改或移動的操作——使用者能做的只有把已經在畫面上的形狀拿掉，而他做完之後交出來的東西，是原本那張圖的一個**子集**（分享碼因此就是一串位元遮罩，長度等於形數）。

同時，「形狀的數量」被提升為整站的渲染參數：頁首那排 8–19 不是縮圖尺寸、不是像素密度、不是細節層級，它是**形狀的個數**，按下去二十張圖版各自依自己的重要度序與五色上限重新解一次。導覽的現用態也遵守同一條規則——它比別人少一個形狀。
