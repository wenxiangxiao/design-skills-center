## 首創

**讀者分版套印 commentator-as-plate**：全館第一個把套印的每一塊色版做成獨立、可抽離的 DOM 圖層，並讓「顏色＝讀者」——墨版是寫的人、朱版是謝老師、藍版是林老師、黃版是你；版架可以把任何一位讀者從紙上拿走、再放回並重新落版對位。附帶首創：**雙行夾注 warichu 跨行求解器**（CSS 尚無 warichu，本站以兩小字一格的行款計算切斷並接續到下一行頂端）與**以原生 text-emphasis 實作完整評點符號系統**（圈、點、密圈、藍點、藍三角）。
