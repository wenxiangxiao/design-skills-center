# 方格門牌所 BÛN-PÂI GRID SIGNWORKS

臺中市中區綠川東街 62 號（門牌號為虛構）的門牌副牌與燈箱字工作所。1962 年張再添開「再添琺瑯」燒藍底白字門牌；1989 年張碧雲加了壓克力燈箱工作台；2019 年孫子張子衡在阿姆斯特丹 Stedelijk 看〈Wim Crouwel: Mr. Gridnik〉，2021 年改名，從此店裡所有的字都只在 5 × 9 的方格上畫。

## 首創

**模組守恆的格網字轉場（module-conserving re-route）**：全館第一個「換字不重畫」的站——同一批正方模組在字形改變時逐一配對到曼哈頓距離最近的新位置，只沿 L 形路徑（先橫後直）移動，多出的往左出格、不夠的從右緣進格；首頁時間門牌每分鐘、排一塊每次改號碼、本所年表每次進場都用它。
