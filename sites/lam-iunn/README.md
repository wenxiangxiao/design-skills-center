# 南洋水族 LAM-IUNN AQUARIUM

**產業**：熱帶魚水族館（臺北市中山區中山北路二段 77 巷 9 號・1964 年起：熱帶魚按份賣・竹框缸組・配缸・到府清缸 NT$900・開新缸 NT$1,500・魚病出診 NT$600・週二週五傍晚到貨・(02) 2581-1964）
**風格**：玻里尼西亞流行風・提基 Tiki / Polynesian Pop（美國 1933–1970s：Don the Beachcomber 好萊塢 1933–34、Trader Vic's 奧克蘭 1936–37、Mai-Kai 勞德代爾堡 1956；Sven Kirsten《The Book of Tiki》Taschen 2000 命名的「Polynesian Pop」）
**語言**：繁中（拉丁字一律 Hanalei Fill）

## 品牌設定

1962 年，十八歲的陳金水在中山北路一家叫「呼拉小屋」的提基酒吧當雜工，專門照顧吧檯後那面六百公升的魚牆。1964 年他在隔兩間租下店面賣熱帶魚，照著酒吧菜單封面用相思木刻了第一尊提基當招牌。1979 年美軍協防司令部撤離、酒吧收掉，老闆把竹吧檯、三根圖騰柱和兩盞河豚燈留給他。1998 年女兒陳月霞接手並開始到府清缸；2019 年孫子陳柏宇學會刻提基，開始「配一缸」服務。

> 中山北路一帶在 1950–70 年代有大量服務美軍的酒吧、1979 年美軍協防臺灣司令部撤離，皆為真實背景；店名、人物、地址、電話、價格皆為虛構。店內河豚燈是椰殼與藤編，本店不販售任何動物標本。

## 首創

**全館第一個「游標即光源」的浮雕站**：每一尊提基（首頁兩根圖騰柱、缸底小雕像、魚單繞排柱、左側導覽四顆頭）都是程式生成的 Float32 高度場——木塊、耳、頂冠三角刻痕、眉脊、凹眼凸瞳、喇叭鼻、齜牙嘴、頰溝、斧痕刀面、木紋十種原語疊成——由 Sobel 取法線後逐像素 Lambert 打光；光源是游標上那支火把（位置＝光源、火焰明暗＝光強，每 90ms 閃一次），所以刻痕的影子會跟著你的手走。也是全館第一個 Tiki／Polynesian Pop 流派站，第一個以 CSS `offset-path` 讓每條魚各走一條去回等長迴圈、在 50% 以 `steps(1)` 翻面的站。
