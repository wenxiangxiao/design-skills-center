# 太平町洋傘 THÀI-PÎNG-TING PARASOL

> 銘仙・大正浪漫 Meisen × 銘仙日傘與修傘（臺北大稻埕）

大稻埕延平北路，日治時期的太平町二丁目。1928 年陳阿綢從銀座的洋傘店學成回來，用伊勢崎與足利運來的銘仙縫八骨日傘；第二代陳金標在尼龍傘時代改做雨傘與修傘骨，把閣樓裡沒賣完的 63 反銘仙用油紙包好；第三代陳怡安 2015 年拆閣樓找到那包布，現在一反做兩支日傘，傘骨刻反物番號，剩 22 反。

- 銘仙日傘 NT$6,800・晴雨兼用 NT$5,200・換傘布 NT$2,400・傘骨修理 NT$180 起・取り置き訂金為傘價兩成
- 臺北市大同區延平北路二段 163 號 騎樓・(02) 2553-1928・10:30–19:00・週二公休
- 每週日 15:00 騎樓前傘回し，免費

店家、人物、門牌、價格皆為虛構；大稻埕、延平北路（太平町）、永樂市場、迪化街、捷運大橋頭站、銘仙五大產地與ほぐし織技法為真實背景。

## 首創

**印經ほぐし渲染管線（printed-warp hogushi pipeline）**：全館第一個把「先把圖印在經線上、再織入緯線」這道真實製程寫成渲染管線的站——同一張圖有「印好未織」與「織上」兩個狀態，Canvas 2D 以 3px 為一束經線、9 參數 `drawImage` 逐欄上下錯位產生ほぐし絣的かすれ（橫邊梳齒、直邊銳利、零模糊）；signature〈織り下ろし〉讓一條緯線帶著杼由上往下走、走過處才錯開；游標掠過布面即「梳齊」經線、離開後鬆回。同一支渲染器也是傘面材質、型錄、圖解與遊戲的唯一圖像來源。附帶：招牌級文字以 `unicode-bidi:bidi-override`＋`direction:rtl` 做大正右横書き，DOM 保持正向語序。
