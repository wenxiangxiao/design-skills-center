# 新月貨運行 Naya Chand Goods Carrier

**產業**：長途貨運行（跨省夜線託運，車主兼司機的一人車行）
**風格**：印度／巴基斯坦卡車藝術 Truck Art（Phool Patti）— 取自 `_style_catalog`「在地與文化視覺」，非自創
**線上**：<https://wenxiangxiao.github.io/design-skills-center/sites/nayachand/>

一台 1978 年的 Bedford TJ，一個車主，二十九年。白天睡覺，太陽下山才發車。
整個網站是這台車的**車尾**：資訊不是排上去的，是漆上去的。

## 核心功能：〈夜線一趟〉

規則三句話——一、選一條夜線；二、每一站只能挑一件掛件，**掛上去拆不下來**，同一個部位也只掛得下一件；
三、20:50 發車，05:14 天亮（504 分鐘），車越重跑越慢，上件也要花時間。約九十秒跑完一輪。

- 三條線（幹線 300km／山線 210km／沙線 294km），各五個停點，每站三選一或不停。
- 兩道會擋人的規則：後軸限重 250 公斤；一個部位不能掛第二件。
- 結局**不給分數、不給星等、不排名**：只給一份到港紀錄（到港時刻、載重、部位覆蓋、側傾角）、
  由狀態決定的三到五條紀事、烏斯塔德的一句話、車號與車尾詩。
- 產出物是這個網站本身：按「把這台車貼到全站」後四頁的車尾板都換成你那一台（`localStorage`），
  並給一串可分享還原的 `?r=` 碼（同碼恆得同車）。
- 窮舉驗證（1024 條路徑／線）：準時抵達 91.5%／92.1%／97.1%；
  「五個部位全掛滿又準時」在三條線上分別只有 2、5、6 種解——那是這一夜真正的好結局。

## 認領首創

**質量作為互動貨幣，且版面姿態由它求解**（mass-as-currency, layout-pose-as-consequence）。

全館第一個把「重量」設為唯一資源的站：使用者每一個選擇都不是花錢也不是花點數，
而是把一份質量掛到車體的某個掛點上；引擎每幀以 Σm 求彈簧壓縮量、以 Σm·x 求側傾力矩，
直接寫進版面容器的 CSS 變數——整個網站在你逛的過程中真的越坐越低、越歪越明顯，而且掛上去拆不下來。

- 與 `foldpoint`（剛性摺疊運動學作為版面容器）的差別：那裡的摺角由使用者直接控制、連續可逆、與內容多寡無關；
  本站沒有任何一個控制項在控制姿態，姿態是內容累積的**副產品**。
- 與 `gluhwerk-glass`（canvas 物理模擬作為被觀看的模擬台）的差別：本站的物理不在一塊畫布裡，它在 layout 本身。
- 與 `gatemark`（不可逆作為互動範式）的差別：那裡不可逆的是**工序與順序**且系統拒絕評分；
  本站不可逆的是**重量**，而重量的代價是被看得見的物理姿態，不是被記在報告裡。

## 五個不可省略的視覺特徵（詳見 SKILL.md 第二章）

1. **分區滿版**：車體被金屬邊條切成頂冠／門牌／腰帶／尾板／裙鏈五塊，每塊填滿，留白 <12%
2. **墨線＋白線雙描邊**：任兩色永不直接相鄰（2.5px 墨在外、2px 白在內）
3. **中軸鏡射的花瓣貼花**：水滴瓣、偶數瓣、內縮第二色、瓣尖一點白
4. **鍍鉻字牌**：字是一塊有金屬底與四角鉚釘的牌，金屬底以 `conic-gradient` 程序化生成
5. **垂掛物與車尾詩**：畫面下緣必須有鏈、鈴垂下來並且會動；車尾要有一句給後車看的話

## 動效四種

- **ambient**：路面雜訊持續激振懸吊；鏈簾各自以不同固有頻率擺；頂冠風車 11s 一圈；尾燈 `steps(2)` 閃
- **input-driven**：滑過／按下鏈簾即改該擺角速度（延遲一幀）；滑過金屬件 conic-gradient 轉 38°（90ms）
- **transition**：拉帆布 `clip-path:inset(0 100% 0 0)→inset(0)`，260ms
- **signature**：載重壓吊 load-sag

四種皆有 `prefers-reduced-motion` 降級，降級後姿態改為靜態平衡解，數值與敘事完全一致，資訊零損失。
