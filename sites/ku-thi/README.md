## 〈三石〉怎麼玩

從石置場拖三顆石頭進尺二淺盆。不能排成等邊或一直線、整組不能放在正中間、三顆要分得出大中小、不能太擠。按「請師傅看」，林添福師傅會指出第一個問題；他點頭，苔就從三顆石頭底下長出來，這一盆可以選苔、看價錢、預約取盆（21 天後，遇休園日順延）。鍵盤：Tab 選石、Enter 放入／取出、方向鍵挪、[ ] 轉。

## 技術

1. 原生 WebGL 片段著色器（GLSL ES 1.00、無函式庫）：地、石、影、苔、雲、露（A 層）
2. 同一個 Ashima simplex 噪聲在 JS 與 GLSL 兩端逐式移植：版面多邊形與像素邊是同一條邊（E 層）
3. CSS `shape-outside: polygon()`：文字沿石與苔的真實輪廓繞排（C 層）
4. （轉場）cross-document View Transitions「霧散」

## 首創

**同一條不規則邊，同時是版面與像素**：全館第一個讓 CSS 文字繞排邊界（`shape-outside`）、點擊區（SVG 多邊形）與 GPU 著色器畫出的形，三者由同一個噪聲函式在 CPU／GPU 兩端分別求值而得的站——文字繞的那條邊，就是你看到的那顆石頭的邊。
