# 三面葉百葉工場 SANN-BĪN-HIO̍H LOUVRE WORKS

新竹市北區北大路的直立簾與鋁鰭片工場，1968 年起。每一片葉子烤兩面不同的漆：從火車站那頭走來是一種顏色，回頭是另一種；兩片之間的縫，是兩色加起來的第三色。三代人：鄭水木（1936–2011）做檜木固定百葉門；鄭秀琴（1961–）1983 年改做鋁直立簾，1987 年在一本法文畫冊裡看到 Cruz-Diez 的 Physichromie，替北大路 88 號阿桂豆花做了第一扇雙面簾（N° 0001，西面鉻黃、東面竹綠白相間）；鄭宇辰（1992–）2018 年接手，做建築外牆鋁鰭片。

- 地址：新竹市北區北大路 212 巷 6 號　電話：(03) 523-1968
- 週一至週六 08:30–18:00・週日休・週六 10:00「走一趟」工場導覽（免費，限 12 人）

## 首創

**視點即色 Physichromie（viewpoint-as-colour）**：全館第一個以真 CSS 3D 雙面鰭片（`preserve-3d`＋`backface-visibility`）做主視覺、並把觀者的位置（游標、手指、行人滑桿、閒置路人）直接寫進 `perspective-origin` 的站——每片鰭西面一色、東面一色，你看到哪一面完全由透視幾何決定，不是 2D 漸層或預算好的圖；鰭與鰭之間的縫以 `color-mix(in oklab)` 即時算兩鄰面的加色，東面以相對色語法 `oklch(from …)` 暗一階做背光。同站〈走過去〉讓使用者替 24 片葉的兩面分別塗色，拖著騎樓下的行人從西走到東，看自己配的店面翻色，再出估價單並以 49 碼 `?p=` 分享。
