# 掌語 手語典藏所 ZHǍNGYǓ

> 產業：手語典藏／手語詞典館　·　風格：**手勢掛圖／掌形骨架風 Handshape-Chart**
> 架空品牌 · Design Skills Center 館藏 Vol.02

一座把手語當作「有形態的語言」來典藏的線上圖書館。核心主張：手語不是靜止的圖片，而是空間裡的動作，可以像替語音標音一樣，替每個詞標出四要素——**手形、位置、動作、掌向**。

全站沒有一張外部圖片，也沒有一張是「畫」或「拍」的插圖：**每一隻手都由同一具手部關節骨架引擎即時擺出**（logo、favicon、詞典縮圖、指拼字母、教學掛圖、報名手印皆然）。

## 首創（全館第一次）

**手部關節骨架程序擺位引擎作為全站唯一圖像來源，並以「打手勢查詢（query-by-gesture）」為互動範式。** 二十餘自由度的手骨架（五指各節屈曲＋拇指對掌＋張開＋掌向）由參數即時前向運動學求解成 SVG；首頁不是選單選字，而是讓你**拖動手指關節、真的擺出一個手形**，典藏庫再依手形參數距離把最相近的詞排到你面前——先做出手，才查到詞。

## 頁面

1. **index.html** — 首頁。掌形直開場：首屏即可調關節的手骨架工作台＋打手勢查詢台；四要素解說、今日展櫃、來所資訊。
2. **dian.html** — 手語詞典。**核心功能＝資料庫查詢與多條件篩選**：依手形／位置／動作／分類多選交叉檢索＋關鍵字＋即時計數，二十四個典藏詞。
3. **pin.html** — 指拼字母生成。輸入英文詞，引擎逐字母描出示意指拼手形，可逐字播放、分享手形碼（第二功能）。
4. **ru.html** — 借閱證／共學報名。三步驟表單（選項目→驗證稱呼≥2、手機 09 十碼、Email 選填格式→生成 SY-YYMMDD-NNN 留位號與雜湊手印，第三功能）。

## 風格關鍵字

手勢掛圖、掌形骨架、四要素標形法、教育海報、錆青底、珊瑚朱作用色、粗圓描邊手圖、Space Mono 編碼、不對稱刊頭、底部手形導覽。

## 八維配方

- **開場原型**：handshape-first 掌形直開場（新原型）
- **導覽原型**：handsign-dock 手形底座導覽（四頁為四個手形，現用頁那隻被描亮；新原型）
- **插畫技法**：handshape-skeleton 掌形關節骨架（新技法，全站圖像單一引擎生成）
- **色彩氛圍**：mid-tone 錆青中間調底（petrol #2E6B68 大面積地色配骨白面板、珊瑚朱作用色、土金刻度）
- **核心功能**：資料庫查詢與多條件篩選
- **era**：1970s（教育掛圖年代）｜**locale**：台灣本土｜**voice**：溫柔療癒｜**texture**：墨／紙掛圖｜**density**：中等

## 技術

- 每頁單檔 HTML，CSS／JS 全 inline；頁面間相對路徑互連，共用底部手形導覽與 footer。
- 字體：Google Fonts（Noto Sans TC + Space Mono）。零外部圖片、零音檔、無 Three.js。
- favicon 為原創 inline SVG data URI（手形）。
- reduced-motion：指拼播放降為逐步、去除轉場；RWD 至 ≤560px 不破版。
