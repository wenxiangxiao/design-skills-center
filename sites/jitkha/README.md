# 日頭跤寫生會　Ji̍t-thâu-kha Plein-Air Society

> 戶外寫生會（週末現場油畫・畫箱畫具租借・海港寫生）× **油畫厚塗 Impasto**
> 基隆市中正區正濱路 116 巷 7 號 2 樓（虛構）

一個在正濱漁港畫了四十七年的寫生畫會。每週日 05:40 集合，07:10 收工，九十分鐘一張，回家不准修，每個人只帶八管顏料。

這個站的全部圖像——海港寫生、每一場的色記、八管顏料的色樣、四種工具的筆程、logo 與 favicon——都由同一支**厚塗筆觸引擎**即時算出：顏料有厚度（高度場→法線→斜光著色）、濕中濕會拖色（筆上的顏色沿筆程被底色汙染）、載量用完就出現飛白。零外部圖片、零照片、零濾鏡。

## 首創

**觀看距離作為版面的自由度（viewing distance as a layout dimension）。**
全館第一個把「你站多遠」做成版面本身的變數：三個距離帶各有各的內容（25 公尺帶只有畫會名與集合時間，2 公尺帶才有哪一筆沒顏料了），而距離軌會把同一塊板實際縮到該距離的視角，並當場量出「這個距離還分得出幾塊顏色」與「顏料的浮凸還剩多少」。這不是縮放，是把角尺寸與人眼解析度（1 弧分）算進版面：板的實際寬度 60 公分、緩衝區 1000 px，於是渲染解析度恰好等於人在兩公尺處的視力極限。

## 動效預算

1. **ambient** 調色盤結皮——昨天剩的八塊顏料由外而內結出乾皮再被刮掉，48 秒一輪，零輸入。
2. **input-driven** 筆程顯影——游標移到板上即讀出該點的顏料厚度、濕度與顏色（<100ms）。
3. **transition** 罩布——換頁時一塊沾了顏料的布斜推過畫面。
4. **signature** 退後看。

四種皆有 `prefers-reduced-motion` 降級：結皮靜止在濕的狀態、罩布不動、距離軌改為離散四段並全部同時顯示，資訊零損失。
