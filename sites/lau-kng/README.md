# 漏光噴砂玻璃 LĀU-KNG — 噴砂玻璃行 × 伊勢型紙

新北三重的噴砂玻璃行〔品牌虛構〕。創店的林清標十六歲在大稻埕染坊當型付け學徒，1974 年染坊收掉，他用一個月工錢換回三百一十二張伊勢型紙；1976 年開玻璃行，發現噴砂要遮罩，就照型紙的規矩彫——每一塊被圍住的紙都要有繋ぎ。整站是一張拿起來對著窗看的型紙：褐色的渋紙是墨，所有圖和大字都是孔，光從孔裡漏進來。

## 核心功能〈噴一扇窗〉

三句規則：挑一把刀在型紙上彫——錐點一個孔、梅壓一朵花、突拖一道線、縞點一列拉一條；被圍住的紙如果沒有繋ぎ接回紙身就會掉下來，那一塊玻璃也會整片霧掉；按「噴砂」再「揭型」，看光從你彫的孔漏進來，拿一張估價單（FNV-1a 單號 LK-XXXXX，存 sessionStorage，〈對光〉頁會出現「你剛才彫的那扇」）。另有行儀、梅散らし、萬筋三張現成的型；鍵盤可完整操作（方向鍵、Enter、1–4）。約 40–90 秒一輪。
