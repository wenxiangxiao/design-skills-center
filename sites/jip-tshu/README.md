# 好入厝搬家 HÓ JI̍P-TSHÙ

> 搬家行 × 花磚（日製馬約利卡浮凸彩釉磚，1915–1935）

新竹市北區北門街 92 號的搬家行。1928 年曾祖父陳水木是北門街替街屋立面貼日本花磚的土水師；1979 年孫子陳德明開了搬家行，第一位客人周家阿婆要他把舊家門口的四片花磚撬下來、貼到新家門上，從此成了店規：**每搬一戶，新家門楣送四片**。倉庫收了 3,214 片拆屋留下的古磚，2012 年起女兒陳怡君照最常見的六款在鶯歌開模復刻。

## 首創

**流釉 glaze-pour＋接縫吉語 seam-rebus**：全館第一個以「透明色釉在浮凸高度場上的厚度」逐像素算出顏色的站——同一罐釉在深凹處濃、在隆起處淡、在浮凸線上近乎胎色，顏色是 `胎色 × 釉色^(釉厚/0.45)` 的結果而不是被宣告的色票；簽名動效「流釉」就是把釉面高度從 0 升上來，所以最深的地先上色、浮凸線最後。也是全館第一個讓「意義只存在於元件之間的接縫上」的站：一片磚的四角各是四分之一朵花，吉語由四片交會處的角碼與中心圖共同查表成立，單看任何一片都讀不出來；轉一片 90° 就換掉交會處的花。
