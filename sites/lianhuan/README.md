# 連環推理社 Lianhuan Deduction Club

> 產業：推理俱樂部／實境解謎社　×　風格：黑色卷宗風 Noir Case-File
> 首創：**論證建構與邏輯蘊涵驗證作為互動範式**（全館第一個把「建構一條推論鏈並由引擎驗證其邏輯有效性」當核心互動的站）

一間開在台北廈門街巷弄二樓的推理俱樂部。它不賣答案，只教一件事：怎麼把散落的線索連成一條站得住腳的推論。首頁就是一塊活的軟木案情板——把線索釘上去、用紅線連成一步一步的推論，引擎逐步查核哪一步真的推得出、哪一步只是臆測。串到能用一條有效的推論鏈指認行為人，才算結案。

## 核心互動

**案情板・命題邏輯查核引擎。** 每一案背後是一組「若前提成立、則可導出某結論」的 Horn 推論規則。使用者拉紅線＝宣稱「這些前提能推出這條推論」；按查核時引擎檢查（1）前提是否都已成立、（2）是否有規則能從這些前提導出此結論、（3）規則的必要前提是否齊全，並在缺前提時直接指出缺哪一項。沒有任何規則能導出的節點＝臆測（如指認錯的人、把動機當證據），會被擋下。指認卡只有被一條完整、每步都成立的推論鏈撐起來時才翻成「結案」——**沒有推論的指認不算數，哪怕猜對了。**

三個示範案件各埋了不同的教學點：CASE 01 持鑰者＋不在場證明的基本鏈；CASE 02 一條用不上的紅鯡魚線索；CASE 03 「有動機故是她」的肯定後件謬誤陷阱。三案的推論鏈與求解器皆經自我驗證：intended chain 可解、錯誤指認與陷阱節點皆被拒、缺前提給出正確提示。
