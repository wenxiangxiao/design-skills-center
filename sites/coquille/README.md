## 〈轉台〉怎麼玩

1. 選花嘴（貝殼擠／C 卷／珍珠垂綵／珍珠點）與顏色，在蛋糕上按住就擠、放開就收嘴。
2. 按住時轉台會轉；可換外緣／中圈／內圈疊擠。外緣繞滿就請師傅看。
3. 師傅要洛可可的不對稱：左右份量差兩成以內，但花樣鏡像相似度要低於七成五。

鍵盤：焦點在轉台時空白鍵按住＝擠、← → 轉台、1–4 換花嘴、R 換圈。

## 技術

1. **SVG 打光濾鏡**（feDiffuseLighting＋feSpecularLighting＋單一 feDistantLight）——所有金框與糖霜的立體感；燈由燭光擾動與游標共同驅動。
2. **曲率斜坡卷紋文法**（自寫，FNV-1a→mulberry32 種子）——全站每條卷紋、每個卷紋框、logo、轉台上的 C 卷擠花。
3. **跨文件 View Transitions＋mask-image**——換頁時新頁從扇貝邊卷紋框開窗；不支援時以同一段 keyframes 在 body 上執行。

## 首創

**曲率斜坡卷紋文法＋轉台擠花**：全館第一個讓所有裝飾由同一條「曲率朝兩端以六次方急升」的卷紋文法即時長出、再擬合到任意兩點與任意元件尺寸的站；也是第一個以「轉台」為直接操作範式的站——按住即從固定花嘴擠出糖霜，物件在手下旋轉而燈不轉，所以浮雕的高光永遠停在同一側。評審把洛可可的核心概念 contraste（份量相等、形狀不鏡像）寫成可計算的兩個門檻，風格的定義就是功能的合格條件。
