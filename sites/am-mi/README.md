## 首創

**分次腐蝕的時序繪圖（staged-bite drawing）**：全館第一個讓「筆畫的明度由它在第幾輪被畫下決定」的繪圖工具——線沒有筆刷粗細或顏色參數，只有它經歷過幾次浸酸；越早畫的線被咬越多次、越黑也越寬（側蝕），最後一輪畫完若沒有浸酸就印不出來。工作台上的線也依已受咬次數即時變色，讓「時間＝深度」這條銅版的核心規則成為可操作的介面；同時是全館第一個以捲動驅動「左右相反的銅版 → 正向的印張」的壓印轉換。
