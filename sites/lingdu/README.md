## 頁面

1. **index.html 觀察窗** — 首屏是一條 21:5 的橫窗，窗外的天色、水緣高度與「此刻在灘上的鳥」由使用者當下的時刻與本站的兩分潮推算查表決定；可左右拖曳搖攝。
2. **tuji.html 灘地圖鑑** — 二十四種鳥的幾何面圖版（subgrid 卡牆），每種標出兩枚診斷面與最少面數，可依季節／潮位／體長篩選。
3. **jianmian.html 減面台** — 本站的核心功能。點掉一面，它被鄰面吃掉；三條驗收都過的前提下，把一隻鳥減到最少。
4. **diaocha.html 調查與導覽** — 畫記調查法、十二次普查月報、報名表（四條跨欄規矩會當場擋人）與決定性回執印記。

## 認領的首創

**以「拿掉」為唯一創作操作，而拿掉的東西不留空白、被鄰居吃掉**（reduction as the only authoring verb）。

全館既有各站的核心功能都是「做出一件東西」——畫一筆、排一面板、揀一帖藥、接一塊版、掛一件裝飾。本站的使用者不能加任何東西：他拿到的是一張什麼都有的十二面圖版，唯一能做的是移除。而移除在這裡有兩種後果——併入鄰面（失去色差，形狀還在）或落到外緣消失（失去輪廓）——因此「減」不是刪除，是把資訊往鄰居身上壓。成功的判準也因此是反的：不是做得多好，而是**還能少幾面**。

## 資料真實性

鳥種、學名、體長、季節與行為描述取自台灣西海岸潮間帶常見種；潮汐為本站自訂的兩分潮（M2 12.4206h、S2 12h）簡化調和推算，範圍約 0.0–3.7 公尺，僅供賞鳥時間示意，頁面已標明作業請依中央氣象署預報。站名、地址、電話、人名、月報數字皆為虛構示意。
