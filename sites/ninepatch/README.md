# 九拼互助社 Nine Patch Aid Society

賓夕法尼亞州蘭開斯特郡白鴿鎮的社區互助保險社（虛構）。沒有保單、沒有業務員、沒有理賠部——
出了事的那一家缺多少，月會上議一個攤法，九戶全部點頭才算數。
社務所後棟那一副被架上，掛著本年度的帳：受理一件事就縫上一塊布，事情結了就把那一塊壓線壓完。

- **風格**：阿米什拼布 Amish Quilt（Lancaster County，1880–1940）
- **產業**：社區互助保險社（mutual aid society）
- **線上**：`sites/ninepatch/`

## 核心功能：議定（一致決提案）

規則三句話：**挑一種攤法加兩條但書；九戶要全部點頭；錢還得補得滿缺口。** 一輪約九十秒，議三輪。

- 三種攤法（按田畝／按人口／按保額）× 六條但書取二 = 每案 45 種組合，三案共 **135 種**。
- 窮舉實測：通得過的只有 **6 種**（4.4%）——案 A 三種、案 B 一種、案 C 兩種。
- 搖頭的人會講出他要什麼，所以三輪之內找得到；三輪議不出來就交給主教。
- 議定後產出一床**議定被**：九塊布一戶一塊，每一塊的顏色就是把那一戶說服的那張牌；
  壓線母題由輪數決定。可以按「貼到全站」把它掛回被架（`localStorage`），也可以複製 `?p=` 分享碼還原。

## 認領的首創

**裝飾層錨定在頁面而非元件（page-anchored ornament / seam-blind quilting）。**
全館第一個把裝飾層與內容層的座標系分開的站：壓線不屬於任何一個元件，它屬於整張頁面。
版面重排、篩選、換頁、議定被生成時，底下的拼片動了，壓線**留在原地**，重新橫越新的接縫。
這正是阿米什被子的雙層邏輯——拼是各家的事，壓線是整床被的事。
