# 曝日電業 PHA̍K-JI̍T SOLAR

**產業 × 風格**：太陽能安裝 × 離網單線風 Off-grid One-Line

台南安南區的太陽能承裝業。曝日（pha̍k-ji̍t）是台語「把東西搬去給太陽曬」。本站的核心概念只有一句：**這個官網不吃台電**——主機（虛構地）掛在自家屋頂兩片 60W 退役模組與一顆 640Wh 電池上，訪客看到的每一瓦都有帳。

## 首創（已登記 _first_registry）

**站體能源預算與卸載階梯（load-shedding site）**：網站自身是一套離網光電系統，瀏覽行為即負載。太陽仰角公式（台南 23.05°N）×決定論天氣（日期雜湊，全球訪客同天同天況、「明日預報」誠實地 100% 準）驅動即時發電；電池 SOC 不存伺服器，每次開頁從 240 小時前逐時重建（收斂），故晴天午後與連雨深夜來訪看到的是兩個網站。SOC 跨五檔門檻觸發**文件化的卸載階梯**：先卸裝飾動畫（原位留「已卸載 −0.3W」籤）、再把插圖降為文字存根、再全站轉單色墨階＋系統字體、最後進入純文字「待日模式」附日出倒數——內容永遠不關，關的是妝。訪客另有「省電閘」可自願降檔，個人傳輸耗電記在自己的錶上（localStorage 跨訪次累計），共用電池不記估計值——帳要分清楚。與 patchframe（損毀—校正，品質值是待修復的故障）、leung-kee（真實時刻驅動的是街景顯示、無資源預算）、jiemian（單向損失、無補充機制）的差別：本站是一個**會充電也會見底的循環資源系統**，網站的臉面即電池的餘額，且整套規則同時就是這家公司賣的東西（防災儲能的保電清單、離網系統的負載排序）——風格皮膚拿掉之後，剩下的是「網頁的每個元件都有電費」這件事本身。
