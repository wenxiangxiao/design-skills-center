# 速鳴速錄所 Suming Stenotype Institute

**產業 × 風格：** 速錄學院／議會速錄傳習所 × 和弦速錄譜風 Chord-Steno Score
**風格代號（SKILL）：** `chord-steno-score`
**首創：** 和弦速錄鍵入作為互動範式——全館第一個以「同時擊下數鍵＝一個音節」的注音和弦擊鍵為核心互動的站。

## 品牌設定

架空在台北市中正區濟南路二段、近立法院一帶的一間和弦速錄傳習所。整站不放示範影片，首頁就是一台你真的能按的速錄機：沿用台灣標準「大千式」注音配列，但差別是把一個音節要用到的鍵**同時壓下、一起鬆開**，機器在你鬆手那一刻把整組鍵解成一個字。左手按聲母、右手按韻母、拇指按聲調，一擊一字，跟著議事報讀把整段發言寫下來，速度與正確率即時換算速錄級位。

品牌性格：嚴肅職人的道場語氣。地域台灣本土、時代錨定 1970–80 年代辦公機械。文案行話全從速錄本身長出（聲母／介音／韻母／聲調、空韻、一擊一字、一場不漏、級位認定）。

## 頁面清單

- **index.html — 速錄機**：核心互動。聽寫譜直開場，選單字／詞語／議事句講稿，學習模式亮出該按的和弦、測驗模式只剩速度與正確率；實體鍵盤同時壓下和弦於鬆手落字，手機點鍵後按「擊出」。
- **ci.html — 詞鑑**：二十四式常用詞（稱謂／議事／數字／日常／術語），每字附程序生成的和弦譜，依類別／字數／難度／關鍵字即時篩選。
- **fa.html — 速錄法**：完全靜態、不需 JavaScript 即可讀完的鍵位全圖、四位置拆音規則與三個特例（空韻／介音收尾／純韻母）。
- **ru.html — 報名**：十週和弦速錄班三步驟報名（選梯次含額滿鎖定→留資料驗證→完成），生成 `SU-YYMMDD-NNN` 留位號與由資料雜湊決定的速錄印記。

## 「拿掉風格皮膚後還剩什麼？」

一台你真的能用鍵盤和弦「彈」出中文的機器：按對一組同時壓下的鍵，一個字就落在譜上；跟著報讀把整句寫下來，速度與正確率即時算成級位。以及一套「亮起來的鍵＝一個和弦」的記譜法，全站每張圖都由它生成。這不是換配色的表格，是別站沒有的輸入範式。

## 技術備註

- 每頁單檔 HTML（CSS／JS 全 inline），頁間相對路徑互連，共用拇指鍵導覽與 footer。
- 鍵位採台灣標準大千式注音配列；和弦拆音為本所**簡化教學模型**，非特定商用速錄機（如亞偉中文速錄）之實際碼表。
- 零外部圖片與音檔、零 3D／WebGL／第三方函式庫；僅 Google Fonts（Bitter＋Noto Serif TC＋Noto Sans TC＋Space Mono）。
- favicon 為原創 inline SVG data URI；logo 於 `assets/logo.svg`。
- `prefers-reduced-motion` 降級；核心互動由使用者事件驅動，不依賴自動動畫；各頁附 `<noscript>` 指向靜態速錄法與電話。
- 店名、人名、地址、電話、費用、名額與級位標準皆為虛構教學示意；報名僅在瀏覽器本機運算，不送出任何資料。
