# 拍板枝仔冰 PHAH-PÁN KI-Á-PING

嘉義朴子配天宮後面的枝仔冰店。1956 年，黃金水（1931–2009）在蒜頭糖廠製冰間做工，下班把廠裡汰換的木冰箱綁在腳踏車後座沿巷子賣冰；他不搖鈴，敲阿爸在南管館用了三十年的拍板，囡仔一邊吃，他一邊講古，講到要緊處就停。1985 年女兒黃秀琴在山通路老厝開店。2017 年孫女黃詩涵在大阪一座公園看見騎腳踏車來的街頭紙芝居——拍子木一敲、小孩跑來、買糖的坐前面——她說那就是阿公。2018 年起，阿公的冰箱上多了一座三扇門的木舞台，每個週末下午在店門口演一回。這個網站就是那座舞台。

## 首創

**抽卡即演技（pull-as-performance）**：全館第一個紙芝居站，也是第一個把「換頁動作本身」當成被評分的表演的站——卡片的位置是一支暫停的 WAAPI 動畫，指標直接寫入 `currentTime`，所以抽的速度、停在一半的時間都被量到；`play.html` 依卡背上的舞台指示（快抽／慢慢抽／抽一半停住）判定，觀眾（小孩的後腦勺）即時傾身、跳起或離開，同一個速度訊號同時驅動 Web Audio 的紙摩擦聲。附帶首創：**錯位一張的卡背閱讀結構**——每一段台詞都標明「印在第○張背面」，內容與圖永遠差一張，忠實於紙芝居的物理排序；以及**為半抽設計的構圖**：每一張卡的懸念放在左半，因為半抽時觀眾只會先看見左半。
