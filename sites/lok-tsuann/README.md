## 首創

**傾角隱像（angle-coded imagery）**：全館第一個把圖像只寫在「每一片的表面法向量」裡的站。藏起來的圖形在顏色、亮度分布、鋪排方向上都與周圍金地無法區分（鋪設演算法刻意對它們視而不見，所以連 andamento 都不會繞著它們彎）；它唯一的差別是那一群金片傾向同一個方向。光向一對上，整塊同時反光，圖形才出現。這是拜占庭金地之所以斜按的那個物理事實，被直接做成資訊的載體與遊戲規則。

**鋪設工序即進場轉場**：畫面不是淡入，是按鑲嵌師真實的順序一片一片按上去——先每個形狀的深色輪廓列，再由外往內分階填身體，再金地繞形兩排，最後金地橫向成排。
