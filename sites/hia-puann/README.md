# 瓦盤 HIĀ-PUÂNN — 日曬鹽田 × 硬邊抽象・Ellsworth Kelly 單色接板

臺南北門井仔腳旁三格私人瓦盤結晶池〔品牌虛構〕。從瞭望台往下看，鹽田是一格一格的顏色：低鹹度的水被杜氏鹽藻染綠，高鹹度的鹵被嗜鹽古菌染成粉紅與紅，水乾後是碎陶片鋪的黑盤，最後是白的鹽。店主吳秀蘭每天照水面刷一塊板，掛成一面 64 格的「鹵色牆」——這就是 Kelly〈Colors for a Large Wall〉（1951，64 塊畫布、一塊一色、以機運排色）的鹽田版。

## 核心功能〈撈鹽花〉

三句規則：下午三點，黑色瓦盤上浮起白色鹽花、被風吹著漂；拖曳（或方向鍵）推動紅色鹽耙，把鹽花推進右下角的鹽堆；九十秒＝一個半小時，四點半以前撈到的排成你自己的鹽花牆。收成會變成一件 Kelly 式接板作品：每片鹽花一塊板，寬度＝重量、顏色＝撈到的時刻（三點白、三點二十黃綠、三點四十赭、四點粉、四點一刻紅），附一張牆上標籤與總公克數。
