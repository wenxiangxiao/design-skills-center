# 字像社 JI-SIONG CHARACTER PORTRAITS

> 臺中繼光街的電腦人像攤（1982 年中華路夜市起家）× ASCII Art・純 ASCII 半身（Knowlton／Harmon 1966 → Atari Compugraph 1976 → Usenet／FIGlet／jgs 1990s）

整個網站是一張不撕斷的綠條報表紙：左右兩條走紙孔、每三行一道淡綠條，所有的圖、框、按鈕、標題都只用 0x20 到 0x7E 這 95 個印字字元打出來。首頁的石膏頭像是活的——九針頭先一行往右、一行往左把它打出來，然後店裡那盞燈開始繞，游標或手指移到哪，光就從哪裡照下來，每一幀重新挑字。核心功能〈坐一張〉：開相機、放一張照片或用手指畫，監看螢幕即時把你轉成字（字形或密度兩種讀法），按「印」——你的人像、名字大字橫幅與這個月的月曆被雙向列印在報表紙上，可存成 .txt，取件單跨頁帶到〈到店〉。

## 四種動效

- ambient：石膏頭像的燈沿真實時間持續繞行，每幀重新打光、重新挑字；底部 .sig 列游標閃爍；頁首 job 時鐘
- input：游標／手指即時移燈（<16 ms 一幀）；監看螢幕在相機、手繪、滑桿調整時即時重算；連結 hover 由 `[ x ]` 換成 `[>x<]`（寬度不變）
- transition：換頁＝走紙——整張紙以 `steps()` 一次一行地往上送出，下一頁從下方一行一行送進來
- signature：〈雙向擊印〉九針頭是文字本身 `[#]`，單數行往右、雙數行往左把圖打出來
