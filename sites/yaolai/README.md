## 首創（_first_registry）

**打孔紙帶手搖音樂盒作為互動範式，且打孔圖樣同時是可演奏的內容與全站唯一圖像引擎**（punched paper-strip hand-cranked music box as interaction paradigm）：全館第一個以「在一條紙帶上打孔＝作一首可搖柄演奏的曲子」為核心互動、且第二個真正發聲（繼 tide-signal 之後）的站。孔位＝音高×時間，搖柄捲過黃銅音梳的讀取線時每個孔撥動對應梳齒、以 Web Audio 加法／衰減合成撥齒音發聲；同一支打孔譜帶引擎渲染演奏台、曲盤圖鑑、logo、favicon 與訂製印記。與 tide-signal（Web Audio 合成潮汐環境音、非樂音、無記譜作曲）、qizhong（排列群換鐘、無空間音高記譜與打孔介質）、sanqiu（siteswap 拋接記譜、無聲）、suming（和弦擊鍵解成一個注音字、對象非樂音、無時間軸打孔介質）皆不同：本站互動對象是一條被打孔編碼、被搖柄捲過梳齒而發出樂音的實體紙帶。

## 技術

單檔 HTML（CSS/JS 全 inline）、頁面相對路徑互連、共用音梳導覽與 footer、favicon 為原創 inline SVG data URI。零外部圖片與音檔、零 3D／WebGL／第三方函式庫，僅 Google Fonts。聲音一律 Web Audio 即時合成、只在使用者手勢後啟動。RWD（≤820px 導覽落底部 dock）、`prefers-reduced-motion` 下靜止但核心玩法不減。店名、人物、地址、電話、價格皆為虛構示意；預載〈小星星〉與曲盤室六首為公版童謠。
