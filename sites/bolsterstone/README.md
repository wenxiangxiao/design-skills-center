## 這座站在賣什麼風格

Teletext 不是一種美學選擇，是一條每秒只能塞進幾百位元組的傳輸線留下的痕跡：一頁只有 40 格 × 24 列，顏色只有 3 個位元（恰好 8 色），換顏色要花掉一個字元位置，圖只能用 64 形的 2×3 方塊拼，標題只能倍高。

本站把這些限制**當成規格照做**，而不是拿掉、只留一層皮：

- 四頁廣播頁全部是 24 列 × 40 格的字格矩陣，每一列由編譯器逐格驗算，寫不下就退件。
- 全角（CJK）佔 2 格——所以一列最多 20 個漢字，文案被逼成電報體。
- 顏色與倍高屬性**真的**各佔一個字元位置，所以變色處留著一個真的空格。
- 手機上不重排、不隱藏任何一格，只是**整台機器變小**。
- 沒有掃描線、沒有 CRT 曲面、沒有發光——那是「復古終端機」，不是 Teletext。本風格的主體是**頁**，不是螢幕。

## 核心功能：一五二號連問

四題連問。每題三個選項，各配一個三位數頁碼；按色鍵或用數字鍵打那個頁碼，答對跳下一題，答錯一律轉到 189 頁並回第一題重來。四題不到九十秒。

四題的答案用 Teletext 的**隱藏屬性（conceal）**藏起來，按解碼器列的 **REVEAL** 才顯示。

**全部是純 CSS**：`:target` 承擔頁碼定址、`:has()` 把八個錯答頁碼導到同一頁、`:checked` 承擔 REVEAL 與 HOLD。關掉 JavaScript 可以完整玩完一輪。

這個做法直接來自 Teletext Ltd 的 **Bamboozle**（1993）：答案就是一個頁碼，所以**導覽本身就是遊戲**。

## 技術（ledger `tech`）

1. **容器查詢單位 `cqw`**（C 版面與樣式層）——`--u: 2.5cqw` 讓一格永遠是容器寬的 1/40，40 格矩陣整體縮放、絕不重排。
2. **純 CSS 狀態機 `:has()` / `:checked` / `:target`**（E 資料與生成層）——承擔 REVEAL、HOLD 與整個連問的作答判定，零 JS 可完整玩完。
3. **多層 `linear-gradient` 硬停點合成 2×3 sixel 字符集**（A 渲染層）——64 形馬賽克全部由 1–6 層 `linear-gradient(currentColor 0 0)` 疊出，頁內零 SVG、零 canvas、零圖片。

支援度查證來源與 fallback 具體行為寫在 `SKILL.md` §12。

## 首創（`_first_registry`）

**`character-cell-broadcast-page` 字元格廣播頁作為整站版面模型**——全館第一個「版面沒有盒模型」的站。四頁內容皆為 24 列 × 40 格的定寬字格，每一個字的位置由**空白字元**決定，樣式表對內容區零 `margin` / `padding` / `gap` / `position`；顏色與倍高屬性依 WST 規範各佔用一個字元位置，因此改顏色會在版面上留下一個真的空格。同一個字格模型同時產出插圖（2×3 sixel）、logo、favicon、導覽與核心功能。

## 動效（四種，全部是階梯函數）

| 種類 | 內容 |
|---|---|
| ambient | 頁首時鐘每秒硬跳一格（真實時刻）＋ FLASH 屬性 1Hz 方波 |
| input-driven | 打數字鍵→頁碼欄逐位被取代、該鍵反相 110ms；選項列 hover 整列反相（< 100ms） |
| transition | 換頁／換狀態時**逐列由上往下重畫**（`steps(24)`，一頁 24 列不是同時到的） |
| signature | `subpage-wait` 等頁：子頁每 12 秒硬切，頁首下方 12 格倒數條每秒少一格，HOLD 可凍結 |

`prefers-reduced-motion` 下四種全部停止，三個子頁改為上下全部展開，**資訊零損失**。
