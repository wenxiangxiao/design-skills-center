# 媒帖紅線風 Red-Thread Ledger

## 一、設計哲學

這套風格處理的是**關係**，不是內容。它假設頁面上真正要給人看的東西不是某一則資訊，而是「甲和乙之間有沒有一條線、那條線現在繃著還是斷了」。

三個立場：

**一、關係是物件，不是裝飾。** 一般網站畫連結線是為了「表示有關聯」；這套風格裡，線是**主角**，兩端的卡片反而是線的錨點。所以線有粗細、有張力、有鬆弛、有斷掉之後留在原地的痕跡，而不是一條 1px 的灰色 SVG。

**二、狀態要用物理表達，不要用顏色表達。** 「這條關係還在協商」與「這條關係已經成立」的差別，不靠標籤文字、不靠綠燈紅燈，而靠線的形狀：鬆的（垂下去的）是提出中、繃的是持有中、垂在下面褪色的是被退回的、打了結的是定了的。使用者不必讀圖例。

**三、底色要中間調，紙只出現在被寫過的地方。** 全站底是一片帶灰的藕荷紫（不是米白紙，也不是深黑），紙色只出現在「有人寫過字的東西」上——帖、表格、裁定書、印記。紙一旦鋪滿全頁，帖就不成其為帖了。

**去AI化的具體效果**：這套語言沒有 hero、沒有圓角卡片牆、沒有紫藍漸層、沒有淡入進場（線是彈進來的不是浮進來的）、沒有跑馬燈。首屏直接是一面工作用的榜，使用者第一個動作就是點人送帖。

## 二、色彩系統

| 用途 | hex | 佔比 | 說明 |
|---|---|---|---|
| 藕荷灰（大面積底色） | `#6B5560` | 40% | 帶灰的紫紅，介於絹布與舊漆之間。整站的地。**不可換成米白或純黑** |
| 藕荷灰・暗（次級面板） | `#5A4650` | 6% | 極少用，只在需要兩層深淺時 |
| 深藕（工作條、面板） | `#47353F` | 18% | 功能區、操作列、表格容器 |
| 玄藕（頁首尾、深底塊） | `#2E222A` | 10% | 店招條、footer、記事欄底 |
| 帖紙 | `#EADFC6` | 18% | 卡片、裁定書、表單、說明匣。**只給「被寫過字」的東西** |
| 帖紙・次 | `#DBCBAC` | 3% | 卡片左緣厚邊、順序格底 |
| 墨 | `#241E20` | — | 帖紙上的文字 |
| 淺文字 | `#EFE4D8` / `#C6B2B8` | — | 藕荷底上的正文／次要文字 |
| 紅線硃 | `#C8302B` | ≤7% | **只給三種東西**：線、現用態、不可回復之事（退帖、私奔、錯誤） |
| 金線 | `#C9A227` | ≤2% | 只給「已定案」的那一種狀態，其他地方一律不准出現金色 |

硬規則：
1. 硃紅是本風格唯一的高彩色，且它有語意——看到硃紅就等於看到「一條關係」或「一個不可逆的判定」。拿它去做按鈕底色、標題底線裝飾即破功。
2. 金色只在最終狀態出現一次。若一個頁面有三處金色，就沒有任何一處是最終狀態。
3. 底色紋理：兩層 `repeating-linear-gradient`——橫向 6px 一條 `rgba(255,255,255,.035)`、縱向 9px 一條 `rgba(0,0,0,.05)`，疊起來是很淡的織物感。不可用雜訊圖或外部貼圖。

```css
body{background:#6B5560;
  background-image:repeating-linear-gradient(180deg,rgba(255,255,255,.035) 0 1px,transparent 1px 6px),
                   repeating-linear-gradient(90deg,rgba(0,0,0,.05) 0 1px,transparent 1px 9px);}
```

## 三、字體系統

- 中文：**Noto Serif TC**，字重 400／700／900。標題一律 900，正文 400。這套風格不用黑體——帖與名冊是寫的，不是印的。
- 數字與英文：**DM Mono** 400／500，開 `font-feature-settings:"tnum"`。所有名次、案號、金額、帖數一律 mono，且**永遠直接跳字，禁止數字滾動動畫**。
- 字級：正文 15–16px／行高 1.9–2.0；帖上姓名 19px/900/letter-spacing .08em；章節標題 20–23px/900/letter-spacing .10em；小標與欄名 11.5–12.5px/letter-spacing .1–.24em（拉開字距，像蓋在表格上的欄位名）；mono 標籤 10.5–11px/letter-spacing .1em。
- 字距：中文標題一律加 `letter-spacing`（.06–.12em）。這是這套風格「像名冊、不像網頁」的關鍵之一，不可省略。

## 四、版面與網格

**主結構是三欄的榜**：`grid-template-columns:1fr 190px 1fr`。左右兩欄是對望的卡片，中間 190px 是**空的**——那是留給線的空間，不放任何內容，只在頂端放一個字距很寬的小標（例：`紅　線`）。行動版縮成 `1fr 74px 1fr`，線的空間可以窄，但不可以取消（取消了兩欄就變成一般的雙欄卡片牆）。

其餘規則：

- 一律無圓角。所有卡片、按鈕、表格、輸入框 `border-radius:0`。
- 陰影只有一種：`box-shadow:2px 2px 0 rgba(0,0,0,.28)`（硬投影，無模糊）。選中態把陰影換成 `2px 2px 0 var(--red)`。禁止任何 `blur` 陰影。
- 卡片用**單邊厚邊**表示歸屬與方向：左欄卡片 `border-left:4px`，右欄卡片 `border-right:4px` 且文字靠右對齊。兩欄的文字向中間收，視覺上就會朝著線。
- 長文頁最大寬 790px，圖鑑頁最大寬 1120px。工作條（`.bar`）永遠貼在店招條下方、內容之上，深藕底，裡面是狀態文字＋按鈕，不置中。
- 頁面順序：店招條（深底細長，含 logo mark／地址／電話／營業時間）→ 工作條 → 主體 → 說明段落 → footer。**不設 hero，不設大標開場。**

## 五、元件配方

### 5.1 帖（卡片）
```
[編號 mono 10.5px　年齒　職業]      ← #7A6A54
[姓名 19px/900]                     ← #241E20
[「一句他自己說的話」11.5px]        ← #7A6A54
[順序格 ■■■■■■]                   ← 6 個 19px 方格
```
順序格是這套風格的招牌零件：一排等寬小方格，每格一個字，代表這個人心裡的排序。四種狀態——底 `#DFD2B4`（未動）、硃紅填底（現持有）、灰字加硃紅刪除線（已退）、金色填底（已定）。行動版縮成 15×17px。

### 5.2 線（核心元件）
兩點之間的三次貝茲，控制點水平外推 0.34×Δx，鬆弛量 `sag=(1-k)*min(96, Δx*0.34+30)` 加在兩個控制點的 y 上。`k` 是張力參數（0＝完全鬆弛、1＝完全繃緊），由彈簧積分驅動，不是 CSS transition。

```js
function d(a,b,k){var dx=b.x-a.x,s=(1-k)*Math.min(96,dx*0.34+30);
  return "M"+a.x+" "+a.y+" C"+(a.x+dx*.34)+" "+(a.y+s)+" "+(b.x-dx*.34)+" "+(b.y+s)+" "+b.x+" "+b.y}
```
線的四態：**提出中／持有中** 2.4px 實線、不透明度 1、k→1；**被退回** 1.2px、不透明度 .34、k→0，且**留在畫面上不刪除**（這是本風格的記憶機制：畫面下半部逐漸累積的褪色垂線，就是「你試過幾次」）；**已定案** 3px 紅線＋下層 5px 金線＋中點一個 r=5.2 的空心圓（結）；**衝突** 1.6px `stroke-dasharray:4 3` 暗紅＋中點一個 ✕（兩條 2px 交叉線）。

### 5.3 按鈕
主鈕：帖紙底、墨字、`border-bottom:3px solid #B9A882`（實色厚底邊，非陰影）。危險／決定鈕：硃紅底、`#FFF3EA` 字、底邊 `#8E1F1C`。切換鈕：透明底＋1px 帖紙色框，`aria-pressed="true"` 時整顆反白成帖紙底墨字。全部 `padding:7px 13px`、13.5px/700/letter-spacing .05em。**禁止按壓時的位移＋硬陰影效果**（那是別的風格的招牌）。

### 5.4 表格
`border-collapse:collapse`，只有橫線，`1px solid #C9BA9C`；表頭 11.5px 拉字距、下緣 1.5px 墨線。數字欄一律 mono。表格一定放在帖紙底上，不可直接放在藕荷底上。

### 5.5 表單
輸入框：`#F6EFDE` 底、`1px solid #B9A882` 框、15px serif、focus 時 `outline:2px solid var(--red);outline-offset:-2px`。標籤 12.5px 拉字距在上方。錯誤訊息硃紅 12.5px/700，**用完整句子寫，並且要說明「為什麼館裡要問這一欄」**——這套風格的表單是有人格的（見 §7 文案）。

### 5.6 導覽（紅線繫帖）
右上固定一支線軸垂下的紅線，線上四張小帖＝四個頁面。現用頁那一張**被線穿過**（帖加寬使線落在帖身上）並在其下打一個結；其餘三張只是靠在線邊。語意是「這條線此刻繫在哪一頁」。≤900px 攤平為頁首下方的四格橫列，現用格反白＋下緣一個硃紅小環，頁尾另備完整連結。

### 5.7 印記
圓形雙圈硃紅印，**紋路必須由該頁的資料算出來**：節點沿圓周排列，弦＝資料中的配對關係，中心壓一塊帖紙色圓底寫兩個字＋mono 編號，整枚旋轉 −3°～+3°（由雜湊決定）。同資料恆得同印。不可畫成通用徽章。

## 六、動效規則

**本風格唯一的動效是線的張弛。** 其他一切都是瞬時的。

| 事件 | 做法 | 參數 |
|---|---|---|
| 送出一條線 | 線以完整長度出現在鬆弛位置，彈簧拉緊 | `v+=(1-k)*0.14*dt; v*=0.80^dt; k+=v*dt`，初速 +0.16 |
| 線被切斷 | 目標 k→0，給負初速造成回彈抖動 | 初速 −0.22～−0.26，同一組彈簧常數 |
| 已定案 | k 停在 1，金線淡出現＋結出現 | 無補間，直接切 |
| 面板／裁定書出現 | **直接顯示**，不淡入、不上滑 | — |
| 數字變化 | **直接跳字** | — |
| hover | 底色換一階（`#EADFC6`→`#F5ECDA`） | 無 transition 亦可 |

明文禁止：淡入進場、滾動揭示、視差、數字滾動、`stroke-dashoffset` 描繪（線是被拉緊的，不是被畫出來的——這是本風格與所有「畫線動畫」的分野）、跑馬燈、載入骨架屏。

`prefers-reduced-motion:reduce` 時：彈簧整支關掉，`k` 直接設為終值（1 或 0），線瞬間就位；其餘互動與資訊完全不變、零損失。實作上偵測一次 `matchMedia` 存成常數，在動畫迴圈入口 return。

## 七、文案與敘事

- 敘事者是**做這一行很久的人**，不是品牌。他會說「這一條寫在委託書第四項，簽字前請看清楚」，不會說「我們致力於提供最優質的服務」。
- 台語漢字只用在**人物說出口的話**與少數行業用語（帖、退帖、掛榜、謝媒），說明與判定一律用標準書面中文。整頁台語會變成表演，反而不真。
- 錯誤訊息與拒絕訊息要給理由，而且理由要對敘事者有代價（例：「這一欄不能空，館裡不替人瞞這件事。」）。
- 允許（而且鼓勵）寫出對敘事者自己不利的內容：制度性的不公平、做錯過的案子、退還的委託金。這是這套風格可信度的來源。
- 禁止：「EST. 19xx」徽章、「把 X 變成 Y」標題句式、老街屋改建開場、驚嘆號、emoji。

## 八、Logo 與 Favicon

Logo＝**兩張直立的帖＋一條穿過去打了結的紅線**。標準比例：帖 22×60，間距 30，線從左帖右緣 y=1/3 處出發、以一個 S 形彎到右帖左緣 y=2/3 處，線寬 4，中點一個 r=6.4 空心圓（結）。可再加兩顆 r=2.6 的硃紅小點在左上與右下（帖的釘孔）。

Favicon 是同一個圖形的 32×32 版本：藕荷底、兩塊 8×20 帖紙、2.4px 紅線、r=2.6 的結。inline SVG data URI 寫在 `<head>`，不另存檔。

## 九、插畫與圖像

**全站不得有任何一張「畫出來的」插圖。** 所有圖像都必須是同一組資料在不同尺度下的渲染：

1. **紅線二部圖**（thread-graph）：兩排節點＋線。大尺寸即主榜，小尺寸即案例縮圖（170px 寬，實線＝成立、.28 不透明度細線＝退回、虛線加 ✕＝衝突）。
2. **圓印**（seal）：同一份配對資料換成極座標。
3. **順序格**：一維的排序資料。

新增任何圖像時先問：「它背後的資料是什麼？」答不出來就不要畫。這條規則使整站的美術與功能永遠一致，也是這套風格最省工的地方——一支渲染器供全站使用。

## 十、Do & Don't

**Do**
- 首屏就是可以操作的榜；使用者第一個動作是點兩張帖。
- 線負責表達關係狀態，文字只補充細節。
- 把規則、公式、反例全部寫在頁面上，讓使用者可以自己複核。
- 失敗狀態要具體：指出是哪兩個、為什麼、根據哪一條。

**Don't**
- 不要把中間那一欄拿去放內容。
- 不要讓被切斷的線消失（記憶會跟著消失）。
- 不要用綠色表示成功、紅色表示失敗——本風格的硃紅是「關係」而不是「錯誤」。
- 不要加陰影模糊、圓角、漸層、玻璃感。
- 不要用這套風格做「內容瀏覽型」網站；它是給**有狀態、有關係、有判定**的頁面用的。若你的頁面只是文章列表，這套語言會空轉。

## 十一、頁面骨架

```html
<body data-p="index">
<div class="sign"><div class="wrap">[logo mark]<b>店號</b><span class="mono">EN NAME</span><span>地址　電話　營業時間</span></div></div>
<nav class="tie">…線上四帖…</nav><div class="tierow">…行動版四格…</div>

<div class="bar"><div class="wrap">
  <div class="case">本案　<b>狀態摘要</b></div>
  <button class="btn ghost" aria-pressed="false">切換</button>
  <button class="btn">主要動作</button>
  <button class="btn red">決定</button>
</div></div>

<div class="wrap">
  <div class="board">
    <div class="colhead">左欄名</div><div class="midhead">中欄小標</div><div class="colhead">右欄名</div>
    <div class="col l">…帖…</div><div class="midhead">操作提示</div><div class="col r">…帖…</div>
    <svg id="threads"></svg>   <!-- position:absolute;inset:0;pointer-events:none -->
  </div>
  <div class="note"><h4>記事</h4><div id="noteBody"></div></div>
  <div class="verdict">…裁定書（帖紙底）…</div>
  <div class="sect"><h2>段落標題</h2><div class="en mono">SECTION</div><div class="cols">…三欄短文…</div></div>
</div>

<footer><div class="wrap">…地址／頁面／公休／免責…</div></footer>
</body>
```

線層的座標一律用 `getBoundingClientRect()` 相對 `.board` 換算，`resize` 與 `document.fonts.ready` 時各重算一次；`viewBox` 跟著 board 的實際寬高設定，不要寫死。
