怎麼判斷一步推論站不站得住

案情板不是猜兇手的遊戲。它只認一件事：你連上的推論鏈，每一步是不是真的成立。這一頁把規則、常見的假推論、以及三個示範案件的完整解答都寫清楚——不需要開啟 JavaScript 也能讀完。

一、什麼是「一步有效的推論」

偵探小說給人一種錯覺：靈光一閃、指著某人說「就是你」。真正的推理不是這樣。一步推論要成立，得同時滿足兩個條件：

條件一：前提為真。你拿來當根據的每一條線索，本身都要是已確認的事實（在案情板上就是「已成立」的卡片）。
條件二：前提蘊涵結論。就算前提都為真，也得是「這些前提合起來，非得推出這個結論不可」，而不是「這個結論聽起來跟前提有點關係」。

兩個條件缺一，這一步就不算推論，只是臆測。案情板的查核就是機械地檢查這兩件事——所以它有時會擋下一個「其實猜對了」的指認：因為你還沒把它推出來。

二、案情板怎麼查核

每一案的背後，是一組「若前提成立、則可導出某結論」的推論規則。你拉紅線，等於宣稱「這些前提合起來能推出這條推論」。按查核時，引擎做三件事：

1.　前提都成立了嗎？只要有一條前提本身還沒被查核成立，這一步就先被擋下——你得先把前提推出來。

2.　有規則能從這些前提導出這個結論嗎？有，就成立、蓋上「查核 ✓」；沒有任何規則能導出它，代表這是臆測（例如指認一個現有線索根本推不到的人）。

3.　規則的前提齊了嗎？若某規則指向這個結論、但你少連了一條必要前提，引擎會直接告訴你缺哪一項。多連了不相干的線索不會讓推論成立，但也不會扣分——它只是沒有用。

指認卡是最後一關。只有當它被一條完整、每步都成立的推論鏈撐起來時才會翻成「結案」。這是刻意的設計：沒有推論的指認不算數，哪怕你猜對了。

三、四種最常見的假推論

下面這幾種在案情板上都會被擋下。它們的共同點是：結論「聽起來合理」，但前提其實推不出它。

肯定後件AFFIRMING THE CONSEQUENT
「兇手一定有動機。他有動機——所以他是兇手。」有動機的人很多，動機不是行為的證據。CASE 03 的威脅信就埋著這個陷阱：袁樂快被換角（動機），但這推不出信是她寫的。
以偏概全HASTY GENERALIZATION
「他上週遲到，所以那晚一定不在場。」用一兩個例子跳到全稱結論。案情板要的是覆蓋當下這個時段的證據，不是性格印象。
訴諸巧合POST HOC
「他一出現東西就不見了，所以是他拿的。」先後發生不等於因果。時間相鄰只是需要進一步查的線索，不是結論。
訴諸權威APPEAL TO AUTHORITY
「鑑定師說是真的，所以一定是真的。」權威的說法是一條需要被檢驗的線索，不是免驗的結論——尤其當那位權威正好是嫌疑人時。

四、三個示範案件的完整解答

下面是案情板三個案子的推論鏈。想自己解的話，先別展開。

CASE 01・畫室・失竊的《觀音山晨霧》 — 展開解答
鑰匙只有兩把 ＋ 窗由內反鎖 → 能進出的只有持鑰者 能進出的只有持鑰者 ＋ 館長有不在場證明 → 當晚在場的持鑰者是周敬 當晚在場的持鑰者是周敬 ＋ 松節油手套（僅周敬合穿） → 指認：周敬取走了畫 ●

陷阱：直接指認館長「監守自盜」推不出來（沒有規則支撐）；「館長謊報行蹤」也是臆測——不在場證明有三位人證，你沒有任何線索否定它。

CASE 02・茶室・被換掉的帳本 — 展開解答
保險箱新密碼（只告知陳雨蘋） → 能開保險箱的只有陳雨蘋 夜間盤點班表 ＋ 工讀生九點早退 → 夜裡仍能接觸帳本的只有陳雨蘋 能開保險箱的只有陳雨蘋 ＋ 夜裡仍能接觸帳本的只有陳雨蘋 ＋ 鋼筆墨水相符 → 指認：陳雨蘋掉包了帳本 ●

紅鯡魚：「紅茶進貨單」和換帳無關，連進來也不會讓推論成立。學會不把干擾線索當前提，跟學會找對前提一樣重要。

CASE 03・劇場・首演夜的威脅信 — 展開解答
打字機缺角字模（全團一台） ＋ 道具間鑰匙副本（柯與三主演） → 能進道具間打字的：柯與三主演 能進道具間打字的：柯與三主演 ＋ 技術彩排點名（唯袁樂離席） → 案發時段唯一能離席去打字的是袁樂 案發時段唯一能離席去打字的是袁樂 ＋ 左手折信痕（袁樂左撇子） → 指認：袁樂寫了威脅信 ●

陷阱：「換角傳聞」是動機不是證據。用它去撐「有動機故是她」會被擋下（肯定後件）；就算把它連到正確的指認卡，那條規則也不需要它——真正撐起指認的是機會（能進、能離席）與習慣（左手）。
