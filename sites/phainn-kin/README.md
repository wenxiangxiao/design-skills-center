# 揹巾所 PHĀINN-KIN

**嬰兒揹巾行 × 爪哇蠟染 Batik Tulis・梭羅宮廷 sogan 半身**

桃園市中壢區新興路 128 號 1 樓，中壢火車站後站步行 4 分鐘。店主蘇莉 Siti Nurjanah 生於梭羅 Laweyan（布商區），母親替布商畫了三十年蠟；1995 年來中壢做看護，2006 年在後站騎樓擺攤，2014 年開店。賣的是梭羅手繪蠟染揹巾（kain gendong）——由表姊 Bu Warsini 在 Laweyan 的工坊畫蠟，中壢這裡縫邊、試揹、教揹法。

## 首創

**染缸歷史即顏色（resist-history compositing）**：全館第一個「使用者從不選顏色」的繪製功能——每一筆蠟、刮蠟、銅印都以 SVG `<mask>` 克隆寫進四張遮罩（藍缸可見／藍缸被護／褐缸可見／褐缸被護），畫面上的四個顏色由「這一點在每一缸時有沒有蠟」以遮罩交集算出；同一套規則（C／B／U 三種角色）也在建置期產生全站每一張靜態布樣。蠟裂紋亦依歷史成立：每一缸各自生成一張 Voronoi 裂紋網，只出現在那一缸時被蠟蓋住的地方、染成那一缸的顏色。

## 動效

- 環境：晾布竿上三塊布各以不同週期擺動；〈畫一塊〉蠟鍋持續冒煙。
- 輸入：成品布上的「看蠟底」透鏡；canting 筆寬依筆壓（或速度）即時變化、停太久會滴蠟；紋樣頁五道工序切換。
- 轉場：換頁時一道梭羅向 parang 斜紋布幕斜掃覆蓋／掀開；入缸時染液由下而上淹過布、再由上往下退。
- 簽名：煮蠟 nglorod——蠟由下往上一團團融開、氣泡上浮、鉛筆稿淡去，被護住的顏色與裂紋同時出現。
