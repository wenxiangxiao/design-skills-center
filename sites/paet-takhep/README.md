# บาตรแปดตะเข็บ — 八縫缽鋪

**產業 × 風格：** 手打僧缽鋪兼金漆作 × 泰式廟宇金漆 ลายรดน้ำ（洗金漆畫）

曼谷 Pom Prap Sattru Phai 區 Ban Bat 里，一條寬兩公尺的巷子。拉瑪一世朝在城裡分了三個打缽的村，剩下的是這一個。本鋪第四代：八片鐵、八道縫、二十一天一口缽；另外半間屋子做 ลายรดน้ำ——缽蓋、缽座、寺裡經櫃的門板。

## 本站首創

**`resist-reveal-gilding`——把「整面貼金再沖水」這道工序做成頁面的狀態機。** 全館第一次讓一個網頁的圖像不是被畫出來、淡入或描繪出來的，而是**先把整個畫面蓋滿，再洗掉一部分才顯形**：`<mask>` 幾何由 SVG SMIL 推動，遮罩內容套一層靜態 `feTurbulence → feDisplacementMap` 讓水線與金箔的邊是撕的。第四頁的接紋檯讓使用者自己接出那塊要被洗出來的紋。
