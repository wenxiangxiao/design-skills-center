# 三刮印房 SANKUA — 滑板店 × 網版印刷 Screenprint

臺南康樂街上的滑板店兼絹印房。店裡只有三罐墨、一支刮刀，和牆上那排曬好的網版。
**這個站不是載入的，是被你刮出來的**——首屏是一張空白的芥末卡紙，按住往下拉，黑版才落到紙上。
而你刮的那一下有多抖，決定了整站的粉版要偏多少：刮得穩就套得準，抖了，你逛完四頁看到的粉紅色都會偏那麼多。

## 認領的首創

**`user-pulled-registration`**：全館第一個把「使用者的一次手勢誤差」變成整站持續套用的視覺參數的站。
使用者刮刀下拉時的速度標準差 σ 被換算成 `--reg-x / --reg-y / --reg-rot`，寫進 `sessionStorage`，
**套用到四個頁面的每一個粉版與藍版**——標題、套準十字、插畫、色塊同步偏移同一個量。
這不是隨機抖動效果，也不是一次性的進場動畫：它是一個由使用者產生、在整個 session 裡穩定不變的識別參數。
你印壞的那一版，就是這個站接下來的長相。

## 動效預算

- **ambient**：紙的翹曲（19s）＋ 濕墨反光（11s，只在已上墨的大色塊上）
- **input-driven**：刮刀跟手、墨隨速度變厚薄（單一 rAF）；圖卡 hover 三個版分開
- **transition**：換版 — 舊版沿刮刀軸抬起、新版落下（View Transitions）
- **signature**：**〈套不準〉** — 見上方首創

四種皆有 `prefers-reduced-motion` 降級，降級後整頁直接印好，資訊零損失。

## 技術與相容性

`<feTile>` 為 Baseline（2015 起）；CSS Custom Highlight API 2026-03 起 Baseline widely available；
`getCoalescedEvents()` **不是** Baseline（Safari 未支援），取不到時退回單點取樣，功能完整。
完整查證來源、fallback 行為與效能實測值寫在 `SKILL.md` 最末章「技術實作與相容性」。
