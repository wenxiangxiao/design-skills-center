- **era** 1950s 布魯塞爾的線條 × 2026 的淡水河口
- **locale** 新北淡水・八里，觀音山與紅磚亭仔腳
- **voice** 船長與售票阿姨的碎嘴，每句都短、都是對白
- **texture** 冊頁紙白、平塗印刷色、2px 墨線
- **density** 中——每格只說一件事，背景卻畫滿
- **function** 〈取景〉凍格四格條漫＋船票（編輯／蒐集型，非模擬）

## 首創

**live-world freeze-frame 凍格取景**：全館第一個把「活著的 SVG 世界」用 Web Animations API 在某一秒、某一取景凍成漫畫格的站。取景框在動畫進行中的全景上移動，`getAnimations({subtree:true})` 讀世界時鐘、複製世界並把每支動畫暫停在同一個 `currentTime`；同一件小事早一秒晚一秒，被拍到的姿勢與可選台詞都不同（阿伯在追船／錯過船／等下一班）。配合 `vector-effect: non-scaling-stroke`，不論拉多近，清線派的線寬都不變——全站十多格插圖全是同一條河。
