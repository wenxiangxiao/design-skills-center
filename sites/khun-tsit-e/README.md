## 首創

**孔陣即顯示（grille-as-display）**：全館第一個「聲音只從喇叭孔裡看得見」的站——五種白噪音（粉紅、褐色、電扇、冷氣機、細雨）與起床鈴全部以 Web Audio 即時合成，經 AnalyserNode 取頻譜，同心環孔陣的每一環對應一段頻帶（內低外高），孔的口徑隨能量張開；沒有聲音時以每分鐘 6 次的靜息呼吸慢慢開合。併同：說明書面板的引線以 CSS anchor positioning **兩端都綁錨點**（零件右緣 → 說明左緣），撥盤讀數綁在以 `sin()/cos()` 算出的指針尖端。
