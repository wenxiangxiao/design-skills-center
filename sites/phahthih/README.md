# 拍鐵仔摔角團 PHAH-THIH PRO WRESTLING

三重舊鐵工廠二樓的獨立摔角團。一九九八年冬天發仔把機具推到牆邊、鋪三層舊床墊開始，到現在第一七九場。

**產業：業餘職業摔角團（獨立摔角，小場地巡演）**

## 認領的首創

**自我剪貼的排版（self-cannibalising ransom-note typesetting）**

全館第一個「標題的每一個字元都必須是站內既有文字的一片實體剪片，並可回溯出處」的站。

1. 站上沒有任何一個標題是排版出來的。建置期先把四頁的全部內文切成字元索引（61 句語料），每一個標題字元再從索引裡「剪」一片下來，帶著它的出處（哪一頁、哪一段、原句前後九個字）。滑過任何一個字，它會告訴你自己是從哪一句剪來的。
2. 剪不到的字（某些數字與符號）不會被偷偷換成字型——它變成空心的麥克筆補字，在版面上一眼看得出來。這使「這個網站的標題是用它自己的內文剪成的」成為一個**可以被讀者當場證偽**的主張，而不是一句設計說明。
3. 這條線一路接到核心功能：你在麥克風那一分鐘講的那句話，會被當場拿去剪成下個月宣傳單的標題——功能的產出物就是這個風格本身。
4. 與 `yongzi-foundry`（字形合成引擎：改的是字的骨架）、`baicaochun`（包絡熔字：改的是裝字的容器）的差別是——本站一個字的造形與容器都沒有改，改的是**字的來源**：每一個字元都必須先在別的地方被印過一次，才有資格出現在標題上。與 `khoaibeng`（揀字：從一面固定的字盤裡取字，取完還在）的差別是本站的剪片會在原文留下記錄，而且來源是**這個網站自己**，不是一套外部字庫。

## 核心功能：麥克風一分鐘

規則三句話：

1. 從上禮拜發生的三件事裡挑一件。
2. 決定誰拿麥克風、對誰說、說哪一種話（挑釁／認錯／背叛／點名觀眾）。
3. 觀眾照牆上那張規則表當場算帳，然後下個月的單子當著你的面重剪一次。

一輪約九十秒。沒有分數、沒有排名、沒有暗底、沒有量表、沒有物理模擬、沒有可拖的參數滑桿。引擎就是頁面上那張十條的規則表，明文印著，可以自己照算一遍（`<noscript>` 亦已說明）。

會咬人的地方：挑釁自己的隊友等同背叛；正派一背叛就轉反派並吃掉對方一半人氣；反派向自己害過的人認錯，觀眾反而買單；人氣掉到 0 的人下個月的單子上不會有名字。

## 動效預算（四種，皆有 `prefers-reduced-motion` 降級且資訊零損失）

1. **ambient**：影印機指示燈的方波閃爍（`steps(2,jump-none)`，1.4s 循環，不需輸入）。
2. **input-driven**：剪片被滑過時抬起 3px、轉角放大 1.7 倍並顯示出處（`steps(2,end)`，70ms）。
3. **transition**：出紙——結果與回執由上而下逐段刷出（`clip-path:inset` + `steps(14,end)`）。
4. **signature**：**再影印一次**——進紙動作（`steps(3,end)`）＋世代 +1，門檻位移、碳粉擴張、細節掉失。全館唯一。
