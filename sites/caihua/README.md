# 採話所 CAI-HUA SUO｜臺灣口承文藝採集會

架空的民間故事採集機構，設在彰化縣員林市三民街 46 號 2 樓（樓下是鎖店，門鈴壞了直接推門）。民國六十三年由施秋煌等七人發起，四十餘年間在彰化、南投兩縣採錄口述故事二千一百餘則，建檔話型一百三十四種。

## 這個站在做什麼

全館第一個核心互動是「**看一段文字在人嘴裡被規則性地改掉，再從改壞的版本反推它原來的樣子**」的站。

站上有一則「虎姑婆」的母本（十三個母題）與六位有名有姓的講述者，每一位都帶著兩種口傳變異癖性（省略、合併、增飾、三疊、在地化、數字放大、角色置換、教訓附加——民俗學歸納的八條法則）。你把故事交給誰講、再交給誰講，決定它變成什麼樣子：話帶上的記號格會即時被抽掉、併掉、翻牌長出來，散文同步被改寫，右邊的變異記錄逐條寫下誰在第幾棒做了什麼、哪些東西**不可回復**（刪掉的母題，後面的人再怎麼講也長不回來）。

核心功能是下半頁的**復原課題**：三個異本（甲、乙、丙）、七個岔口，你要判斷母本原來的讀法。陷阱寫死在資料裡——甲乙同出陳阿葉一個人，所以它們的「兩本一致」其實只有一票；逐題多數決會在七題裡錯兩題，而且錯得很整齊。交卷時若你的七個答案剛好等於多數決，系統會直接指出這件事。同時，獨立的丙本也不乾淨，它自己在另外兩處改過——「沒有一個異本是乾淨的」是本會校勘的第一句話。

## 首創（全館未有）

**口傳變異作為互動範式，且文本本身即全站唯一的圖像引擎。** 使用者不模擬物理、不解謎、不創作，也不編輯既有素材——他決定的是「這個故事接下來交給誰講」，然後看八條真實的民俗學變異法則把文本改掉；接著要在明知每一本都被改過的前提下，用共同錯誤法（同源異本折算為一票）、變異方向性（在地化單向、數字只放大、教訓只增添）、難讀者優先三條判準，把母本判回來。同一組母題序列同時是可讀的故事、可比較的資料、以及 logo／favicon／圖鑑／表單回執的圖像來源，全站無一張圖是「畫」的。

## 技術

單檔 HTML／CSS／JS，零函式庫、零 3D、零外部圖片與音檔，外部資源僅 Google Fonts。`fa.html` 完全不含 `<script>`。全部動效在 `prefers-reduced-motion` 下停用，內容與判定不受影響。所有品牌、人名、住址、電話、年代、採錄編號與故事異本均為虛構示意。
