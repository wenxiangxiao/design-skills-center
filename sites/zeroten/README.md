## 首創

**風格法則作為即時執行的版面約束。** 至上主義的三條成文規則被直接編譯成一支持續運行的鬆弛求解器，而這支求解器就是本站的版面引擎——形的位置、字的位置、卡片縮圖、劇目幕圖、logo 全部是它的輸出。任何拖曳、視窗縮放或字體載入造成的違規（相接、與畫框平行、相鄰形互相平行），都會在同一幀內被就地解掉。因此本站沒有「版面」這個檔案，只有一組法則與一個解。

與 `xiulu` 的波函數塌縮（WFC）約束傳播的差別：那是離散鑲嵌的一次性收斂，輸出一張圖然後結束；本站是連續位形空間上永不終止的鬆弛，被求解的對象是活的 DOM 版面本身。
