## 核心機能：銘をつける（命名）

規則三句：**一、札を一枚か二枚選ぶ。二、二枚なら「の」で繋ぐ。三、主人に見せる。**
主人が検めるのは家法四条——

1. **一条** 形・色・材を直に言ふ札は使へぬ（〈白〉〈紅〉〈餡〉〈丸〉）
2. **二条** 季を違へぬ（当季の季の札を必ず一枚、一枚だけ）
3. **三条** 三音以上、九音以下（「の」も一音）
4. **四条** 銘帖に既にある六十の銘とは重ねられぬ

通れば木札に書かれ（簽名動效「銘が入る」）、**掛詞と見立てが同時に立てば朱印**。點數・星等・順位は一切出ません。

**全 8,208 通りの実測**：通過 6,804（82.9%）／退け内訳＝一条 1,152・三条 210・四条 48。
朱印（掛詞＋見立て）1,071（通過の 15.7%）、片方のみ 3,126（45.9%）。
二十四の節気すべてで朱印に到達可能（最低 冬至 3.9%／最高 春分 30.8%）。
