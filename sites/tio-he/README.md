# 昌記釣蝦場 TSHIONG-KÌ TIÒ-HÊ

新北三重仁義街的釣蝦場。老闆吳文昌 1972 年十六歲進光明印刷所當學徒，1979 年跟師傅學會「拆墨斗」——用兩塊鐵楔把圓壓機的墨斗隔成三格，粉、橘、黃一次上機，歌廳秀、工地秀、野台戲的螢光窗卡都這樣印。1989 年印刷所收了，他用遣散費和一台 1962 年西德圓壓活版機開了釣蝦場；1990 年因為窗卡貼在台電電線桿上一直被撕被罰，乾脆在門口自己立一根杉木桿。2014 年兒子吳承翰回來接手，每週一印一張、週三釘上桿。2026 年是第 1,912 號。
