# 沃貝尼耶堡 Château Vaubernier

**葡萄酒莊 × 凹版雕刻鈔券風 Intaglio Line-Engraving & Guilloché**

法國 Gironde 省 Médoc 產區 Bégadan 村的家族酒莊。四塊地，九點〇五公頃。本莊不賣瓶，賣一張**可轉讓的窖單**——券在誰手上，酒就在誰名下，酒仍睡在窖裡。

一八六一年曾祖父的手寫提酒條被仿了三次，第四年他去找了做匯票版的雕版師 Lucien Pouget，請他在條子中央車一朵玫瑰紋。一百六十五年後，Pouget 的第五代 Henriette 還在版房裡，只是車床換成了一組演算法。

## 認領的首創

**裝飾即簽章（ornament-as-signature）**

全館第一個站，其裝飾紋樣不是「被生成的裝飾」，而是**一份資料的密碼學摘要本體**。券面中央的車床玫瑰紋，其十個車刀參數全部由 `SHA-256(莊名·地塊·年份·瓶數·券號·開立日)` 的 32 個位元組切出；因此驗證這張券不是比對字串，而是**把兩張紋疊起來看它們重不重合**——改動任一字元，整朵紋會換成完全不同的形狀、瓣數與莫列圖樣，肉眼立刻看見雙影。

與館內既有首創的差別：
- 與 `ruixing-zhizha`／`yongzi-foundry` 等「由 seed 生成圖樣」的站不同——那些是「用亂數長出好看的裝飾」，seed 本身沒有語意，也沒有人需要驗證它；本站的紋樣是**可被第三方離線複算的承諾**，而且複算的**動作本身就是核心互動**。
- 與 `ngan-lun`（排版材料是會用完的消耗品）、`kirkbraes`（空白即商品規格）不同——那兩者是「某個量被消耗／被量測」；本站沒有東西被消耗，被建立的是「這張圖 ≡ 這份資料」這條等式，而且等式的驗證是可逆的、可重複的、離線也成立的。

## 三樣技術

| 技術 | 層 | 承載什麼 |
|---|---|---|
| SHA-256（Web Crypto ＋純 JS 逐位元相同備援） | E 資料與生成 | 特徵 I 車床玫瑰紋的全部參數；「裝飾即簽章」首創 |
| `paint-order: stroke fill` | C 版面與樣式 | 特徵 V 刀口白線（凸版觸感） |
| `@starting-style` ＋ `transition-behavior: allow-discrete` | B 動效與時間軸 | 券的開立與作廢轉場（`display` 也一起轉場，不用雙 rAF） |

支援度查證、fallback 具體行為與效能實測值，見 `SKILL.md` 第十二章。

## 四種動效

1. **ambient**：兩層底紋以 244s／311s 反向緩轉，莫列波紋整天漂移。
2. **input-driven**：雕版放大鏡（游標／觸控／方向鍵三路），鏡內 6× 才讀得出微縮文字，延遲 < 100ms。
3. **transition**：券的開立／作廢（`@starting-style` + `allow-discrete`）。
4. **signature**：**車紋 rose-engine turning**——玫瑰紋一圈一圈被車出來，每加一圈整張的干涉圖樣重新解一次（不是 `stroke-dashoffset` 描繪）。

四者皆有 `prefers-reduced-motion` 降級，且降級後資訊零損失。
