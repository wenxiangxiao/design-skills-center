# 結作行 GIREH-BANDĪ｜伊斯法罕．鑲嵌磚作行

> 伊斯蘭幾何（Girih／Islamic Geometric）× 鑲嵌磚作行（手工切磚鑲嵌與古蹟磚作修繕）

一間開在伊斯法罕舊城哈魯尼耶巷的磚作行。它做兩件事：把一面新牆切出來，把一面舊牆還回去。
全站沒有一張外部圖片，也沒有一張描摹古蹟的插圖——牆、樣紙、碎磚、logo、favicon、回執印記，
全部由同一支**尺規星紋引擎**即時算出來：底鋪 → 邊心射線 → 交點 → 面 → 面二著色 → 帶的上下關係。

線上：<https://wenxiangxiao.github.io/design-skills-center/sites/girehbandi/>

## 首創

**交錯結（alternating link）的上下交替條件，同時作為圖像引擎的生成規則與使用者操作的驗收條件。**
帶的每一個斷點都不是畫的：引擎把成圖當成一張 4-正則平面圖，先對「面」做二著色，
再由面的顏色決定每個交點誰在上——因此同一條帶在每個交點必定與上一次相反（實測 2,236 次通過，違例 0）。
而使用者在補磚台補上去的每一塊，驗收條件就是同一件事：帶接不接得起來。
