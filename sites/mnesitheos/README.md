## 開場・導覽・動效・技法

- **開場 frieze-first 一周帶直開場**（新原型）：首屏是一條環繞的肩帶，主軸是**周角而不是長度**；每一景印著自己的角度（0°–320°，景距 40°），走到底是 360°＝0°，回到雅典娜。瓶上沒有第一格，也沒有最後一格。
- **導覽 filled-to-the-line 注滿**（新語意）：四頁＝四只一模一樣的賞瓶剪影，變的只有「它裝了油沒有」——現用頁那一只灌到肩線。語意是**容器裡有一個量，而那個量看得見**。
- **插畫 slip-and-incision 泥漿與刻痕**（新技法）：零外部圖片、零 `<img>`、零 canvas。三條原語——只有兩態的實面、寬度恆定的刻痕或浮線、側面剪影＋正面眼＋地線。
- **氛圍 oxidation-reduction 氧化與還原**（新 mood）：陶土 44%／釉黑 38%／添白 ≤8%／添紫紅 ≤6%／生泥 ≤4%；明度階恰好是零。
- **簽名動效〈刻 incision〉**（全館唯一）：試片上拖曳就下刀，刮出寬度恆定的土色刻痕；**放開不消失、換頁回來還在**——皮革硬的胚體上刮掉的泥漿補不回去。刊頭與頁尾刻不動，因為它們已經燒過了。
- 另外三種動效：足部射線的氧化／還原輪替（環境）、肩帶上 hover 出現讚辭 ΚΑΛΟΣ（輸入）、換頁與換技法時依離窯口遠近錯序到位（轉場）。四種全部有 `prefers-reduced-motion` 降級且資訊零損失。

## 認領的首創

**全館第一個「技法切換 technique-switch」的站**：〈二法〉頁上只有一組路徑資料，按鈕切換的不是主題、不是配色、也不是圖地反相，而是**同一批輪廓經由不同的遮罩合成順序，輸出兩種在美術史上互斥的製作工序**——而且細節線的物理性質跟著換人：黒絵的刻痕是把泥漿刮掉、露出底下的土色（減法），赤絵的浮線是堆在土色上的泥漿（加法）。頁面不會載入第二張圖。
