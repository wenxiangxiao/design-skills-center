# 響銅鑼仔 HIÁNG-TÂNG — 手錘銅鑼工坊 × Calder 吊件

> 「重的靠近吊點，輕的伸遠一點——風一來，它會自己敲。」

彰化縣鹿港鎮埔頭街 52 巷 7 號〔門牌虛構〕的銅鑼店。1964 年施炎山開店打北管鑼與廟會開路鑼；打好的鑼要掛到天花板的杉木樑上試音，鑼的對面得吊一片鐵片撐平。1988 年兒子施振宗接手回火與調音，拿廟裡剩的四桶漆替鐵片塗色分辨（紅＝店、黑＝師傅、黃＝廟、藍＝戲班）；2019 年孫女施佳穎拆下一段試音樑，做成可以帶回家的「吊鑼」。

品牌敘事出自產業本身：鑼掛著試音、對面吊配重、風吹過會互相碰響——這本來就是一支 Calder 式的聲響吊件。

**資料皆為虛構示意**（人物、地址、電話、價格）。Calder 的 mobile／stabile 命名、〈Red Disc and Gong I〉1940、〈Red Gongs〉1950（The Met 55.181.1a–f）為真實背景。

## 首創

**聲響吊件（sounding-mobile）**：全館第一個把吊件做成樂器——巢狀 CSS 3D `rotateY` 的階層式扭擺物理由空氣與游標風驅動，色片與鑼在 3D 空間真的碰撞，撞擊那一幀以 WebAudio 合成該面鑼的非諧波分音（小鑼上揚、大鑼下沉），同時牆上的平面投影跟著轉。附帶：第一個由「力矩求解」決定配重片大小與吊點的訂製器；第一個「橫桿往你所在頁面傾斜」的天秤導覽。
