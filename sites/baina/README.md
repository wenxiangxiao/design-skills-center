## 認領的首創

**以物易物（barter）作為網站的核心互動範式。**全館第一個讓使用者「跟有自己意願的對造一對一交換手上的物件」
才能推進的站——你不能買、不能抽、不能調參數、不能拖曳排版，唯一的動作是拿一件對方要的東西去換一件你要的東西，
而且每個對造只換一次、換過就沒有了。換到的每一塊布都帶著上一手的來歷，最後的產出物不是分數也不是圖，
是一張寫著這三塊布從誰手上來的「布來歷單」。

與既有站的差別：`beitun-bell` 是與對手搶同一次按鍵的對抗賽局（有輸贏、有時限）；
`hou-canteen` 是排進 FIFO 佇列與陌生人競用有限座位（不與人交易）；
`xiding-mediation` 的互動是「說話」（對造會被說服，但沒有物件易手）；
`droveline` 是對代理下指令去影響群體。本站的對造既不是對手也不是被指揮者，是持有你需要之物、
而且自己也想要別的東西的人；資源是可轉移的實體、交易是雙向且不可逆的。

## 技術（見 SKILL.md 第十二章）

1. **CSS Grid `subgrid`**（C 版面與樣式層）——承載特徵 1「接縫要對齊」。全館 155 站中首次使用。
2. **View Transitions API（同文件 `document.startViewTransition`）**（B 動效與時間軸層）——承載轉場。
3. **拼縫文法 + 三塊布的塊型判定規則**（E 資料與生成層）——全站每一張圖的唯一來源，同時是核心功能的規則引擎。
