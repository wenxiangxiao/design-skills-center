## 風格

**卡帶未來主義 Cassette Futurism**（既有流派，取自型錄「數位與螢幕原生」類，全館第 1 站）。外部參照：1975–1992 年的類比機構器材（Nagra、Tandberg、Sony TC 系列）、蘇聯與東德的量測機殼、《異形》(1979) Nostromo 艙內介面、語言實驗室的教師控制檯。與 Y2K 的分界：Y2K 是鉻與銀，本流派明文零金屬；與復古終端機的分界：那講螢幕裡面（磷光、掃描線），本流派講螢幕外面那一大塊不發光的塑膠。

五個不可省略的視覺特徵（詳見 `SKILL.md` 第九章）：

1. **注塑殼**——拔模斜度、一條固定高度的分模線、一層由捲積核算出來的消光皮紋，三者同時在場
2. **方圓角**——`corner-shape: superellipse()`，不是 `border-radius`
3. **字只有三種存在方式**——絲印、模刻、Dymo 壓印膠帶，沒有第四種
4. **機械鍵**——`0 3px 0` 的實體鍵程，陰影永遠不模糊
5. **唯一的光**——琥珀顯示窗，面積上限 5%，永遠坐在一圈 3px 斜邊的凹孔裡

## 認領的首創

**`linear-medium-as-index` 線性媒介即索引。**全館第一個把首頁的全部第一層資訊放在一條**單向、不可跳躍的時間軸**上——沒有目錄、沒有選單、沒有錨點、沒有捲動揭示。而這條時間軸不是比喻：帶位、看得到哪一則、兩個盤的半徑、以及機械計數器上的三位數，是**同一個量**的四種顯示。要看第七則就得讓帶跑過前面六則；要回頭，就倒帶。

技術面另認領 **`corner-shape: superellipse()` 全館首次使用**（經查 `ledger.json` 與全部 263 站原始碼，零出現），以及 **SVG `feConvolveMatrix` 全館首次使用**（同樣零出現）。

可用性保底：卡座下方永遠有一張十則全在的靜態表；關掉 JavaScript 時卡座停在第一則，表格照樣完整，資訊零損失。

## 技術

| 層 | 技術 | 承載什麼 |

| E 資料與生成 | 自寫等線速度雙盤解算器 | 簽名動效、機械計數器、帶位索引、分秒↔公分換算——全站唯一的長度／時間來源 |

支援度查證、fallback 具體行為與效能實測值見 `SKILL.md` 第十二章。

## 四種動效

- **ambient**：顯示窗的燈 2.6s 極輕微呼吸；帶在跑時兩盤持續反向轉動
- **input-driven**：機械鍵沉 3px（70ms linear）、量表 120ms、拖曳換面點即時重算，延遲 <100ms
- **transition**：帶倉——離站 `rotateX(-18deg)` 彈開 200ms，到站從 `-16deg` 闔回 260ms
- **signature**：**等線速度雙盤**——兩盤半徑由帶長守恆解出、角速度 ω = v／r，收帶盤越轉越慢，而機械計數器接在收帶盤上，所以它的跳字速率一直在變

四種皆備 `prefers-reduced-motion` 降級，降級後盤的半徑仍然正確（半徑是資訊，不是動畫），資訊零損失。
