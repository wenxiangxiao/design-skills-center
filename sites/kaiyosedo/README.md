## 八つの決まり（設計上の位置づけ）

- **opening**：`byobu-first` 折屏直開場（新原型）
- **nav**：`seal-stamp` 落款鈐印導覽（新原型）——現用頁の色紙形にだけ朱文方印が捺してある
- **signature**：`otoshikomi` 落込滲出——押したところに一滴落ち、拡散を解き直し、五本の潮目が外から順に現れる。**形は一格も変わらない**
- **illust**：`katagami-tarashi` 型紙と溜まり構成（新技法）
- **mood**：`gilt-ground` 金地箔押（新增）——大面積の金は動かない。金だと分かるのは光ではなく**継ぎ目**
- **tech**：縦組み（`writing-mode`／`text-combine-upright`）／格子拡散＋marching squares／跨文件 View Transitions
- **first**：型紙と水の分離——輪廓是可重複使用的資產、內部是不可重複的事件；而遊戲的判準是「滲」而不是「形」

## 首創（`_first_registry`）

**型紙と水の分離（stencil-vs-water separation）**：全館第一個把「同一個形狀被重複使用」寫成明示的美學與商業規則的站。型紙只有五枚、二百年沒有增加，頁面上直接印出每一枚打了幾回；而每一次打出來的內部滲色都不同。核心遊戲因此把判準倒過來——盤上八枚地貝的**形狀完全相同**，能分辨的只有たらしこみ的潮目在割目上接不接得起來。與 khoaibeng（字盤佈局有成本函數與最優解）、rendong（接版：成功＝找不到版邊）、jiaobai（摺法決定對稱群）皆不同：本站的形不是被求解、不是被隱藏、也不是被群作用鋪滿，它是**被反覆使用的固定資產**，而變的只有一次不可重複的液體事件。
