# 藍莖草自然中心・圖版室 BLUESTEM NATURE CENTER — PLATE ROOM

**產業**：自然中心解說出版部（絹印圖版室）　**風格**：中世紀現代 Mid-Century Modern（Charley Harper 極簡寫實 × Girard 平塗限色）

一九五八年起，俄亥俄州洛夫蘭的藍莖草自然中心每個月印一張自然圖版。四塊版、一台二手對開平台機、一間會漏雨的地下室。館方的工作準則只有一句話，是查理・哈波說的：**數翅膀，不要數羽毛。**

這座站把那句話做成一個可以親手執行的動作：**你唯一能做的事是刪。**

## 首創（`_first_registry`）

**減法作為唯一的編輯操作，且產出物的優劣由「還認不認得出」裁定。**

全館第一個站，其核心功能只有一顆動作鍵：刪。使用者不能新增、不能移動、不能改色、不能調任何參數、沒有一根滑桿；他唯一能做的事是把已經在畫面上的東西拿掉，而每拿掉一塊，剩下的就自動變大——因為版的尺寸是固定的，留白率是硬規則。裁定的判準不是好不好看、不是分數、不是名次，是三條可驗算的述詞：同一組重複形狀要嘛全留要嘛全刪、識別鍵不能刪、留得比館方那一版多就是插畫不是圖版。

## 動效（四種）

- **ambient**　套印呼吸：三塊彩色版各自 ±0.9px 漂移（26s／31s／23s），墨版不動。
- **input**　抬版預覽：hover 零件列或形狀，該塊沿其色版方向抬起，其餘降到 24%（<100ms）。
- **transition**　過紙推移：進頁時四層內容依序 `clip-path` 推入，`steps(9)`，stagger 90ms。
- **signature**　**抽版重裱**：刪掉一塊時，那塊沿其色版的套印方向滑出畫面，整張圖同時依剩下形狀的邊界重新裝框放大。

四種皆備 `prefers-reduced-motion` 降級；降級後套印錯位仍停在錯位的位置（那是風格本體，不是動畫），資訊零損失。
