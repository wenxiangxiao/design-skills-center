## 認領的首創

**參考系作為互動對象，且辨識只能靠相對結構**
（the reference frame as the interactive object；xiangdui）

全館第一個站，使用者點選一個元素時被移動的不是那個元素，而是其餘所有東西：
選中者成為座標原點釘住不動，整個構成連同容器一起做剛體平移補償，
元素之間的相對關係一格都沒變、每塊自己的旋轉一度都沒動。頁面因此沒有
「絕對位置」這回事——同一個構成有無限多個等價畫面，而它們全是同一件事。

核心功能把這件事做成可被裁定的能力：認籤階段的九張牌每成一格就重轉一個
新的角度、重排到新的格位，因此位置記憶與圖像記憶全部作廢，玩家只能靠
四個人之間的相對結構去認。實測：不看籤亂點（不重覆）平均只成 1.49／5 格，
看過籤平均 4.98 格。

與既有各站的差別：yongzi-foundry 改的是字形骨架、baicaochun 改的是裝字的容器、
rendong 改的是平鋪的格子、nayachand 改的是容器的剛體姿態且姿態由重量求解——
那些被重算的都是「物件或容器本身」；本站的物件與容器一動都沒動，
被重算的是讀它們的那個座標系。

## 動效四式

| 類型 | 內容 | 降級 |
|---|---|---|
| ambient | 無地平線漂移：每塊平面各以 44–116s 獨立正弦漂 ≤11px，角度一度不動 | `animation:none`，停在起點，構圖完整 |
| input | 實心位移影子：hover/focus 時在 11px 外印出一枚同形朱紅實心塊，並顯示相對讀數（<100ms） | `transition:none`，瞬間出現 |
| transition | 跨文件 View Transitions：導覽條與主重量方塊在四頁之間只移動不重畫，新頁以 −40° 楔形 clip-path 推入 | 不支援或 reduced-motion 時為一般即時換頁 |
| signature | 換參考系 frame-swap | `transition:none`，瞬間到位，參考系照樣換得成 |

四種皆有 `prefers-reduced-motion` 降級且資訊零損失。
