# 金鶴繡學號 KIM-HO̍H

**產業**：學號刺繡兼制服行（台中市北區育才街 2 巷 11 號）

## 首創

**以「容量受限的磁碟」作為購物車的 Finder 拖放購物（disk-as-cart）**：全館第一個把購物車做成一張有容量上限（400K＝NT$4,000）的磁片——商品是檔案、價格是檔案大小、放不下就跳「磁碟空間不足」警告；刪除＝拖進垃圾桶、結帳＝把磁碟拖進垃圾桶退出，ImageWriter 以草稿模式逐行印出取件單。學號本身由使用者輸入的中文姓名即時柵格化成 16px 1-bit 字模、再依蛇行針序繡成一個可拖曳的 `.繡` 檔。
