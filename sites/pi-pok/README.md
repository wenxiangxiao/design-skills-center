# 嗶啵汽水廠 PI-POK Soda Works

> 彈珠汽水廠 × 義大利未來派・自由字半身 Parole in libertà（Marinetti〈未來主義文學技術宣言〉1912・〈無線想像與自由字〉1913・《Zang Tumb Tuuum》1914・Depero《Depero Futurista》1927 與 Campari Soda 錐形瓶 1932）

宜蘭羅東純精路的彈珠汽水廠（虛構）。1958 年游金水買下二手日製彈珠灌裝機，賣汽水給太平山伐木工人的福利社；2016 年第三代游哲宇在羅維雷托看到德佩羅的 Campari Soda 錐形瓶手稿，回來寫下〈嗶啵汽水宣言〉，把廠裡所有標籤、價目表、看廠單改成未來主義「自由字」排法——他說汽水廠本來就是一首噪音詩。

整站的圖幾乎都是字。首頁是一張滿寬的自由字版：灌裝線上每封一瓶，3 號機的嘴就噴出一串依馬里內蒂規則生成的字——暴力擬聲用最粗的黑體紅墨、快速感覺用 Bodoni 斜體、動詞原形用窄長藍字、連接詞換成 + × = >——每個字是一個剛體，飛出去、旋轉、撞開版上原有的字。

## 核心功能〈灌一班〉

瓶子從左邊來；瓶口對準 3 號灌裝機時按空白鍵（或點輸送帶）封珠，封得越準那一聲越大越重地砸進字版，漏掉的瓶子會碎；六十秒一班，班後字版定住，字仍可拖曳甩動排到滿意。類型：節奏遊戲＋生成字版（非模擬儀器、無量表、無參數滑桿）。
