卷貝糖霜室

Lambeth overpiped cakes · Taichung · sur commande

我們只做一種蛋糕：蘭貝斯疊擠花。奶油霜一圈壓一圈地擠上去，貝殼、C 卷、珍珠垂綵，像十八世紀巴黎客廳牆上的金框。今天換你上轉台。

  1. 選花嘴、選顏色，在蛋糕上按住就擠，放開就收嘴。
  2. 按住時轉台會轉；外緣繞滿一圈，請師傅看。
  3. 師傅要的是洛可可的不對稱——左右一樣重，但不能一樣。
花嘴 ・ la douille
擠花色 ・ la crème
蛋糕底色 ・ le fond
擠在哪一圈 ・ le rang
尺寸 ・ la taille

鍵盤：焦點在轉台上時，空白鍵按住＝擠、← → 轉台、1–4 換花嘴、R 換圈。

師傅的評語

師傅點頭

    ——葉蘊華，主廚。她在每一顆出門的蛋糕盒蓋內側，壓一枚只屬於那顆蛋糕的卷紋。

    帶這一顆去訂 →這顆的連結

    師傅看的三件事

    i.繞滿

    客人打開盒子，第一眼看的是蛋糕的邊。外緣那一圈要接上，轉台轉回原點時不能有缺口——缺一段，整顆蛋糕就像沒穿好的外套。

    ii.節奏

    貝殼擠是「擠、拉、收」三拍。每一擠的長度一樣，邊才會像一串念珠。長短差在三成以內，師傅就說你的手穩。

    iii.不對稱的均衡

    洛可可最早的意思就是不對稱：一七三〇年代梅森尼耶（Meissonnier）的裝飾版畫裡，卷紋從來不在左右兩邊照鏡子。我們的規矩是——蛋糕的左右兩半，糖霜份量差兩成以內；但花樣的鏡像相似度要低於七成五。一邊貝殼，另一邊就給 C 卷或垂綵。
