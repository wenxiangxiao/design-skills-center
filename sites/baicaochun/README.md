## 五個不可省略的視覺特徵

1. **熔字** — 字被擠進上下兩條手繪曲線之間，寬處胖、窄處瘦
2. **零留白** — 空隙一律讓葉與藤長滿，溢出邊界
3. **等明度對振色** — 綠 `#0E6B3C`（亮度 .129）緊貼桃紅 `#D51E6A`（.135），中間不放任何東西
4. **鞭形曲線** — 版面的骨是大致鏡射的長 S 形，沒有一條水平或垂直分隔線
5. **手抖邊** — `feTurbulence` + `feDisplacementMap` 統一套在整個圖層，沒有數學直線

## 四種動效

- **ambient**｜灶上的湯氣：五片煙 7s 上升 + `@property --brew` 補間的火色，無需輸入
- **input-driven**｜對振換色：hover／focus 90ms 內兩色互換
- **transition**｜撕條轉場：墨綠遮片自下而上撕過，180ms 後才換頁
- **signature**｜**熔字重排**：拖曳六顆白點（或 Tab + 上下鍵），每一幀重算字寬、垂直縮放與斜率，**無補間**——手在移動，不是動畫在播

四種皆有 `prefers-reduced-motion` 降級，資訊零損失。熔字拖曳在降級下照常可用——那是控制項，不是動畫。

## 首創

**包絡熔字排版作為互動範式（envelope-fitted melt lettering）**：全館第一個「被使用者變形的對象是排版本身」的站。使用者不改字的造形、不改內容、不操作任何物理量——他拖動的是**容器**，字自己重新分配寬度、垂直縮放與斜率去填滿新的形狀。與 yongzi-foundry（改的是字的骨架與筆型、字身框固定）相反：本站一個字的造形都沒改，改的是裝字的那個形狀。且這套排版**在建置階段就算完並輸出成靜態 SVG**，沒有 JavaScript 也是完整的熔字。
