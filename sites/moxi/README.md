# 墨汐 MOXI 流墨紙坊 Marbling Atelier

大稻埕的手工流墨紙工坊。整站就是一槽**真的會流動**的墨水面——不是把顏料畫在紙上，而是讓墨浮在稠稠的膠礬水面：滴一顆墨，先前的花紋被往外推成環；梳一道耙，整面被拖成正弦尾流；轉一個渦，紋路捲成夜鶯巢。你在水面上作畫、撈起獨一無二的一張紙，再選成藏書票、書衣或裱框原作下單。核心信念：**墨的走向由表面張力與你的每一次擾動決定，沒有兩張會一樣**——撈起的每一張都是 1/1，撕不回、印不出第二張。

## 首創（claim）

**流體表面平流墨流大理石紋引擎作為互動範式與全站唯一圖像引擎**：全館第一個以「在一槽會流動的液面上以位移場作畫」為核心互動的站。使用者不畫線、不填色塊、不調儀表——而是對水面下四種擾動：滴墨（徑向外推位移，把先前的墨擠成環）、單針（沿拖線方向、位移隨垂距指數衰減）、梳耙（整幅沿一軸位移、量隨另一軸正弦起伏＝波梳）、渦流（繞心旋轉、角度隨距離衰減）；墨的走向由這些平流位移決定，撈起即成 1/1 唯一的紙。同一支引擎把「一段 ops」渲染成全站每一張圖（水槽、24 式圖鑑、選購格、購物車縮圖、logo、favicon、訂購印記），ops 可序列化重播故可留存與轉移：撤回＝pop 後重播、撈紙＝存 sessionStorage 帶去購物車下單。與 jiaobai（摺疊對稱群作用於防染基本域、離散鏡射）、gluhwerk-glass（熔融玻璃旋轉對稱剖面五力演化）、shaft-eight（經緯浮沉織法矩陣渲染平面布料）、xiulu（WFC 約束傳播）皆不同：本站的互動對象是**連續液面的二維平流位移場**，一張紙就是一段對水面的擾動序列。
