## 首創

**`solved-headline` 求解式標題**

全館第一個站，其**所有標題的三個排版變數（級數／寬度軸／字距）都不是作者決定的**，
而是由一支求解器對「欄寬」這唯一的硬約束即時解出來；
而且當某一行解不出來（撐不滿欄寬）時，**未達成的差額會被當作內容印在版面上**
（規格行轉紅，印「差 N 字」），網站不改標題、不改欄寬、也不置中假裝沒事。

站上第二版的〈距離除以時間，就這樣〉與第五版大樣裡那一行，就是這個狀態的實例。
