## 認領的首創

**橫向全景作為章節軸，且整站的資訊架構可被訪客親手重排並成為他自己的入口。**

館內既有的「訪客接管識別」（yongzi-foundry：改鑄字形）與「貼到整站」（rendong：換一塊花版）改的都是**外觀**；本站讓訪客改的是**這個網站有哪些內容、誰重要、依什麼順序出現**——磚的取捨、尺寸與次序就是這個站的資訊架構，排完之後第一頁的看板整個換成他排的那一面，並可用板號還原給別人看同一面。同時，本站是全館第一個以**橫向全景（panorama）**作為章節軸的站：章節不往下疊、往右躺，標題被畫布右緣切斷是版式規格而非意外。

## 三項核心技術

| 層 | 技術 | 在本站承載什麼 |
|---|---|---|
| C 版面與樣式 | **CSS Container Queries ＋ 容器查詢單位 `cqi`** | 特徵 3「大小＝資訊密度」：每塊磚依自己的寬度決定顯示到哪一層資訊 |
| B 動效與時間軸 | **FLIP 版面轉場** | 拖曳重排時每塊磚從舊位置平滑滑到新位置；一 read 一 write，無 layout thrashing |
| D 輸入與感測 | **Pointer Events 自寫拖曳排序**（非 HTML5 Drag & Drop） | 核心功能的主要輸入；另備「←／→」鍵盤等價操作 |

支援度查證、fallback 具體行為與效能實測值見 `SKILL.md` 第十二章。

## 四種動效

1. **ambient** 值班色帶——依訪客本地時鐘判斷是否為開放時段（06:00–09:00、16:00–19:00），色帶上一格亮塊持續掃過；非開放時段轉灰。
2. **input-driven** 按壓傾斜——磚朝按壓點傾斜（≤±16°），放開彈回，延遲 <100ms。
3. **transition** turnstile 旋轉門——換頁時整個版面以左緣為軸旋出，新頁元素以 26ms 階梯依序轉正。
4. **signature** 對角波前接力翻面——磚陣沿 45° 波前依序翻到背面的另一份資料，每 7.5 秒一輪。全館唯一。

四種皆有 `prefers-reduced-motion` 降級且資訊零損失（自動翻面停用後改為點磚即翻，並在板下明寫）。
