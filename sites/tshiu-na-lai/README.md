# 樹林內觀葉苗圃 TSHIŪ-NÂ-LĀI — 觀葉植物苗圃 × 盧梭素人叢林（Henri Rousseau Naïve Jungle）

屏東長治的觀葉苗圃。溫室後牆四十公尺，是前國道收費員黃金德畫的叢林——八隻動物躲在以牠們為名的植物後面。首頁整面是那張畫：用手把葉子撥開，找到八隻，收齊八張通行券換一盆小苗。

## 首創

**撥葉尋獸 part-the-foliage hidden-object**：全館第一個「內容藏在一層物理植物後面、必須用手撥開才看得見」的站——約 180 片葉各是一支獨立的阻尼角彈簧，推力來自游標到「葉片線段」的垂距，所以只有手碰到的葉子會讓開；停在動物上半秒即找到，遮住牠的葉子永久收向兩側、牠的瞳孔開始跟著你，一張以牠命名的植物通行券從畫上飛進券軌。滑鼠、觸控、方向鍵三種輸入同一套規則。
