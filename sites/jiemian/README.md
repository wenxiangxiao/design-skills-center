# 界面館 JIEMIAN INTERFACE HALL

泡沫科學展演館 × 皂膜干涉風 Soapfilm-Interference

架空在台南市安平區安平路 802 號的一座小型科學展演館。整館只有一件常設展品：〈第一槽〉——一團 2019 年 4 月 3 日封槽、之後再也沒有補進任何氣體的二維泡沫。它從封槽那天起就在變少，而且沒有停下來的方法。

## 本站在做什麼

首頁不是介紹頁，是那一槽泡沫本身。它在你到達之前就已經在粗化，你不動它也會繼續：

- **粗化是真的算出來的。** 每一個胞的面積依 von Neumann 定律 `dA/dt = κ(n−6)` 演化——邊數少於六的在縮小、多於六的在長大、正好六邊的持平。胞元幾何以 Laguerre（power diagram）每一幀重解，邊帶鄰居標籤，所以邊數、共壁長度、鄰居更替都是量出來的而不是假裝的。讀數列的「內部平均邊數」會一直待在 6.00 附近——那是尤拉公式的結果，你可以自己盯著看。
- **顏色是膜厚算出來的。** 全站的介面只有兩個色（皂水青灰、墨青）。畫面上任何一抹彩色都必須是某個膜厚 `h` 經 `I(λ)=sin²(2πnh/λ)`（n=1.33）算出來的。拖「抽液」桿把水抽掉，膜變薄，白色的壁依序走過金黃、洋紅、青、藍，最後薄到約十奈米以下時反射互相抵消——**黑膜**。
- **想看見顏色，就必須讓它死得更快。** 抽液同時提高擴散常數 κ。這不是懲罰機制，是同一個物理量的兩個後果：膜薄了，光才有顏色，氣體也才穿得過去。
- **你吹進去的每一分面積，都是從別的胞身上拿的。** 槽的總面積固定。吹一顆大泡，它邊數多、會長大、活得久——代價是旁邊那些胞縮得更快。
- **本館替被命名的泡開籍。** 命名一顆泡吹進去，系統追蹤它每一刻的邊數、換過哪些鄰居、活了多久；它消失時出具一份泡籍：生於槽齡幾分幾秒、最多長到幾邊、一生換過幾個鄰居、面積被誰併走。籍存在瀏覽器裡，收在〈譜〉。

沒有分數，沒有星等，沒有「完成」。這個系統沒有穩定終態——唯一能被稱作結局的狀態，是只剩下一個胞。

## 首創

**薄膜干涉作為全站唯一的色彩來源，且色彩與死亡由同一個參數驅動**——`I(λ)=sin²(2πnh/λ)` 把膜厚 `h` 直接算成螢幕上的顏色，而 `h` 由「抽液」控制；抽液同時提高粗化常數 κ。想看見顏色就必須把膜抽薄，抽薄即加速整槽泡沫的消失，而薄到極限的黑膜正是最後一個狀態。**併同二維泡沫粗化（von Neumann 定律）作為互動範式：系統沒有穩定終態，使用者吹進去的每一顆泡最終都會被鄰居併走，唯一的「完成」是只剩一個胞。**

## 技術

- 四頁單檔 HTML，CSS 與 JS 全 inline，頁面間相對路徑互連。
- 零外部圖片、零外部音檔、零 3D、零函式庫；外部資源只有 Google Fonts。
- 胞元引擎為原生 Canvas 2D + 自寫的帶邊標籤 Sutherland–Hodgman 半平面裁切，O(n²) 每幀重解 40 胞。
- 靜態頁（〈法〉全部、〈譜〉的二十四幅圖鑑）在建置時以同一支引擎烘成 inline SVG，不跑 JavaScript 也看得到。
- `prefers-reduced-motion: reduce` 時主視覺不自動開始，改由「推進 10 秒」逐段推進，並在控制列說明原因。
- 泡籍簿存於 `localStorage`，不上傳、無副本。
- RWD：≤900px 導覽收為頂部四格 sticky 橫列、左緣直排刊記隱藏；≤760px 讀數列折為兩欄。
