## 首創

**捲動驅動的「墓室畫工三道工序」**：同一組 `<use>` 形狀疊成三層 SVG（紅赭打稿層、礦物上彩層、黑線定稿層），以 CSS `view-timeline` 讓每一欄壁畫依捲動進度依序「上彩、定稿、收格」，`animation-timeline` 不支援時退回 IntersectionObserver 定時播放；同一機制在〈辦宴〉被反向使用——編輯中的宴會整面退回紅稿，封甕才畫完。另以 Unicode 埃及象形文字＋`writing-mode: vertical-rl` 直欄排字，並用象形數字（𓆼𓍢𓎆𓏤）寫價格。
