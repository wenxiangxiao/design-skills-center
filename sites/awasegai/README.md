## 核心功能：合貝（あわせがい）

規則は三句。**一、貝を二枚起こす。二、絵が続いていれば一対、続かなければ伏せる。三、六対そろえば終い。**

同じ絵を二枚描く記憶遊びではありません。**一幅の絵が中線で二枚に割ってある**ので、合う相手とだけ枝や花が一本につながります。合った瞬間、中線が消えて継ぎ目に金の照りが一度走り（簽名動效）、右の貝の上の句と左の貝の下の句が一首に戻ります。歌は『古今和歌集』『百人一首』所収の古歌（公有領域）。

終いに出るのは点数でも順位でもなく、工房の帳面と同じ書式の **手控（てびかえ）** です — 貝桶番号、手数、一発で継いだ対、最初に継いだ意匠、手こずった意匠。盆は `?k=` で共有・復元できます（同じ番号なら必ず同じ十二貝）。

## 首創

**接續配對（continuation matching）を互動範式にした全館初の站。** 照合の判定基準が「同じかどうか」でも「好みが噛み合うか」でもなく、**二片の絵が一幅として続くかどうか**（幾何学的連続性）である站は本站が最初です。さらに、サイト上のすべての図像が「一幅の絵を割った半分」であり、割れた歌（上の句／下の句）が絵の継ぎと同時に戻ります。

- `khan-sing`（穩定配對媒合）との違い：あちらは選好順位による安定マッチング。本站は幾何学的連続性。
- `xiulu`（WFC 隣接規則）との違い：あちらは制約伝播で解を作る。本站は既にある一幅を割り、使用者が復元する。
- `qizhong`（排列群）との違い：あちらは群の元を鳴らす。本站は分割と復元。

## 動效（4 種）

1. **ambient**：光源が 38 秒周期の弧を描き、六つの扇の明るさと箔の粒が別々に変わる。
2. **input-driven**：ポインタ座標（または端末の傾き）がそのまま光源。追従遅延 <100ms。
3. **transition**：貝を起こす Y 軸 3D 反転（.40s）。
4. **signature**：**継ぎが照る** — 合った瞬間に中線が消え、継ぎ目を金の照りが一度だけ走る。

4 種とも `prefers-reduced-motion` で降級し、判定・記録・共有コードは一切変わりません。
