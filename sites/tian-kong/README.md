# 電光三太子團 TIĀN-KONG SAM-THÀI-TSÚ

高雄鳳山的電音三太子陣頭，2003 年成團。第二代鄭雅婷在利馬 Comas 區的絹印海報行當過兩年學徒，回來後把團的出陣單改成 chicha 海報：黑紙、螢光墨、每一行撐滿。後來她發現海報上的字可以排成鼓譜——寬的字打、窄的字休息。這個網站的首屏就是那張海報，按「起鼓」它就會打。

## 核心技術

1. 可變字型 `wdth` 撐滿求解器（拉丁行實際量寬換字級；中文行以平體／長體 scaleX 直接算）——特徵②、導覽、輸入魚眼與簽名動效
2. SVG 濾鏡：`feGaussianBlur`＋`feColorMatrix` alpha 閾值把字角磨圓；`feTurbulence`＋`feDisplacementMap` 做牆上漿糊皺——特徵②⑤
3. Web Audio 合成＋lookahead 排程：大鼓、鈔、銅鑼、五聲電音貝斯全部即時合成，零音檔；畫面拍點掛在同一個音訊時鐘上

## 首創

**字寬即節拍 rhythm-as-width**：全館第一個把排版本身當音序器的站。每一行字是一樣傢私、每一個字是一拍；開＝寬體、休＝窄體，行寬求解器讓整行永遠撐滿版寬。打到的那一拍字會瞬間撐寬、同行其他字被等比擠窄（總寬不變），聲音與字寬由同一份資料、同一個音訊時鐘驅動。
