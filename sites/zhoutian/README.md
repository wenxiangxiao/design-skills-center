# 周天軌道郵政 CHOU-TIEN ORBITAL POST

軌道郵政／太空郵便所 × 星曆公文風 Ephemeris-Bureau

架空在基隆港務大樓頂樓的「交通部郵政總局第七一支局」——一間 1968 年就開辦軌道郵務的另類史郵局。寄一件包裹，不是填地址，是親手飛一條轉移軌道；從業守則第七條寫著全站的核心悖論：**「欲追上前方之郵件，應先減速。」**

## 本站在做什麼

首頁不是形象頁，是寄件台。你的包裹已經在天上繞，時間不停，但系統純週期——不點火，它永遠準時回來：

- **軌道是真的解的。** 包裹狀態向量以 RK4 積分推進，每一幀由 `vis-viva` 與離心率向量重解軌道要素（a、e、近地點、遠地點、週期），預測橢圓即時重繪。你按住點火鍵的每一刻，那條橘色圓錐曲線都在連續變形——放手瞬間，軌道定格為新星曆。
- **不點火時完全不能轉向。** 這不是限制玩法，這就是玩法：軌道力學的全部張力在於「你只能在對的時機、對的方向燒對的量」。
- **三宗任務三堂課。** 同步帶投遞（霍曼轉移：抬遠地點→滑行半圈→收圓）、前方會合（相位追逐：想追上前面的站，得先逆行減速切進內側快車道）、返還再入（在遠地點輕輕一口，把近地點壓進 50–290 km 窗口；壓過頭就燒毀）。判定各有物理條件，燒太多會脫離地球引力、郵件遺失。
- **每一米每秒都算錢。** ΔV 預算即燃料條；完成任務開立「執行證」——證上的橘線就是你實際飛出的轉移軌道，面值以 ΔV 計，同任務飛得更省證會換新（sessionStorage）。
- **資費表就是物理。** 〈資費帶別〉的每格票價＝霍曼兩式解出的 ΔV × 費率；二十四枚「轉移郵票」由同一支圓錐曲線引擎印製，票面即郵路。〈寄件申請〉四步表單含驗證，收執的發航印由申請資料 FNV-1a→mulberry32 決定性生成。
- **〈軌道之法〉不需 JavaScript 即完整可讀**：活力公式、開普勒三律（郵務版）、霍曼轉移、相位追逐原理、再入窗口，附本所模型的誠實聲明（二體、共面、有限推力、示意比例尺）。
