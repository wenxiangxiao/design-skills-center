# 油水皂房 IÛ-TSUÍ Soap & Light

> 手工冷製皂房 × 迷幻液態光秀 Psychedelic Liquid Light Show（Seymour Locks 1952–53・Bill Ham 1965–66 Avalon Ballroom・Joshua Light Show 1968–71 Fillmore East）

臺北中山區雙城街 18 巷的手工冷製皂房（虛構）。1969 年，十九歲的阮秋月在中山北路的「藍天鵝」俱樂部顧後台的高架投影機，替週末通宵的樂團打液態光：兩片錶玻璃、一瓶嬰兒油、一盒食用色素。1972 年俱樂部收店，投影機折價抵薪水給了她；1978 年她在雙城街開皂房——她說做皂跟打燈是同一件事，都是油、水、顏色，差在皂要等二十八天。2015 年起，每週五 20:30 鐵門拉一半、燈全關，女兒阮以澄開三台投影機，吳宗翰彈電子琴，阮秋月壓玻璃，客人跟著拍子滴色，散場前那一池倒進模子。

整站只有一種圖像：黑牆上的圓池，池裡是彼此不相溶的色油與水。首頁三台投影機的圓疊在一起，是 WebGL2 片段著色器即時算的相場——每個像素只屬於一相，色界外側一圈彎月面亮線、色油相碰處一條暗縫，燈心亮、邊緣暗、圓緣一圈紅色色散。游標是攪棒，按住空白鍵或長按＝壓錶玻璃。

## 技術

1. WebGL2 片段著色器不相溶相場（附同式 CPU 備援）
2. Web Audio 合成＋AnalyserNode：歌是瀏覽器即時合成的，大鼓低頻回灌成壓玻璃，評分對照 AudioContext 時鐘
3. CSS @property 型別化自訂屬性：光圈半徑與色輪角度補間

## 首創

**一場可以帶回家的光秀**：全館第一個以「不相溶相場」渲染的站——每像素只屬於一相、相界自帶彎月面亮線與油油暗縫，而不是 blur/threshold 的 goo；也是第一個把一段跟著瀏覽器合成音樂的即時演出（滴的拍點、顏色、位置）決定性地凝固成一件可訂購的實物（皂的剖面）並整串寫進網址的站：同一條連結、同一池、同一塊皂，到〈油水夜〉頁的取件單還會重倒一次。
