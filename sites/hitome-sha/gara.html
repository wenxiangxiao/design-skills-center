柄帳　／　GARACHŌ　／　十六柄

柄の名は、二本の数列の名である

左の縁の並びと上の縁の並び。この二本だけで柄は決まる。下の数列は繰り返しの単位で、0 はずらさない、1 は一目ずらす、という意味。目数はどの柄でも同じ千六百四十目（四十目角）で、変わるのは輪の数だけである。

十字花刺しjūjibana 行 01　列 01　輪 0 二本の針目が交点で十字に出会わない、いちばん静かな柄。稽古着の背に最も多い。
米刺しkome-zashi 行 0　列 0　輪 400 行も列も一つも移さない。交点のすべてが角になり、輪が最も多く立つ。
角亀甲kaku-kikkō 行 0011　列 0011　輪 200 二目ずつ移す。六角に見えるが、引いてある線はすべて直線。
柿の花kaki-no-hana 行 0101　列 0011　輪 0 行は一目おき、列は二目おき。縦長の花が並ぶ。
風車kazaguruma 行 00101　列 01101　輪 65 周期の異なる二本。回っているように見えるが何も回っていない。
分銅つなぎfundō-tsunagi 行 000111　列 010　輪 85 三目ずつの行と一目おきの列。胴当ての裏によく使う。
竹の節take-no-fushi 行 000101　列 0　輪 140 列を一切移さない。節のような横の帯が出る。
井桁igeta 行 0011　列 01　輪 0 行だけ二目、列は一目。井の字が斜めに連なる。
銭刺しzeni-zashi 行 001　列 001　輪 121 三の周期。丸くないのに銭に見える、古い呼び名。
山形yamagata 行 00011011　列 0101　輪 0 袖口の補強に使う、密に見える柄。
稲穂inaho 行 0001　列 0111　輪 100 羽生の水田から採った名。穂が片側に倒れる。
二重十字nijū-jūji 行 011　列 011　輪 121 十字花刺しの二倍周期。面に厚みが出る。
網代ajiro 行 00110011　列 00001111　輪 200 行と列の周期が四と八。編んだように見える。
変わり石畳kawari-ishidatami 行 0110　列 0110　輪 181 移しの向きが交互に返る。畳の目のような柄。
麻の葉くずしasanoha-kuzushi 行 0010111　列 0100　輪 80 正式な麻の葉ではない、一目刺しで寄せた崩し。
一つ目hitotsume 行 01　列 0　輪 0 行だけを一目おきに移す、いちばん短く教えられる柄。

「定理」の列は、その柄にできたすべての輪が〈幅も高さも奇数・長さは 8 で割って 4 余る〉を満たしているかを、頁を作った時点で一本ずつ数えた結果である。十六柄すべて適合した。十字花刺しと柿の花に輪が一つもないのは、この二つが閉じない柄だからで、誤りではない。

※ 柄名は当舎の柄帳のもので、地方によって別の名で呼ぶものもある。麻の葉くずしは正式な麻の葉ではなく、一目刺しで寄せた崩し柄である。

どの柄を選ぶか

稽古着の背にいちばん多いのは十字花刺しで、これは最も静かで、汗で貼りついても柄が目に障らないからである。米刺しは輪が四百も立つので面が賑やかになり、子ども用や胴着の裏に向く。角亀甲と分銅つなぎは面に厚みが出るので、肩と襟に使う。

迷ったら〈印付け台〉で縁の点を押してみてほしい。当舎の十六柄に当たればその名が出るし、当たらなければ無名の柄として控えに残す。無名でも仕立てる。
