# 圈舞堂・手牽手土風舞聯誼社

**產業 × 風格**：土風舞／民俗舞蹈聯誼社 × 隊形走位圖風（Formation-Choreography）
**slug**：`quanwu`　**語言**：繁中　**Vol.**：本卷新增

一座台中社區活動中心二樓的土風舞聯誼社。核心互動是**呼舞台**：你站上台當呼舞者，呼一個圖形，八個舞者就在木地板上走位成隊形；一支「跳得回家」的舞，走完要讓每個人回到原位——而網站能即時判定回不回得了。

## 首創（全館第一次）

**呼舞編排作為互動範式（call-driven formation choreography）**：一組舞者是被 named-figure 幾何變換統治的隊形系統。使用者不操作單一對象，而是當呼舞者逐一呼點，引擎把整組舞者沿該圖形的**地板走位路徑**動畫，並以「排列合成是否回到單位排列」即時驗證整支舞是否**回原位（resolves home）**。全站圖像由同一支隊形引擎生成（舞者 token＋走位跡），零外部圖片。

與既有站的區別：droveline 是各自跑規則的自主群體（boids），本站舞者是**確定性、被口令統治、無自主性**；siteswap（sanqiu）畫的是物件在空中的拋物弧，本站畫的是**身體在地板上走的隊形路徑**且帶舞伴／角色語意；hejie 是有對手的對弈，本站是**合作、確定、可即時驗證回原位**；qizhong 換鐘是排列群鳴奏、無空間走位與舞伴幾何。
