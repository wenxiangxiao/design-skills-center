# 綰結所 WǍNJIÉ Knot Studio

淡水河口的繩結研習所。整站是一張編結墊——你一個交叉一個交叉地把繩打過去，編結台讀出你的 **over／under 交叉序列**，辨識你打成了什麼結，並照真實規則告訴你它**成結**還是**會滑脫**。核心教材是全所的信念：一個結會不會鬆，寫在它交叉序列的**奇偶性**裡，跟繩多粗、繩什麼材質都無關。

## 開場 / 導覽 / 動效簽名 / 插畫 / 氛圍

- **opening**：`knotbench-first 編結台直開場`（新原型）——首屏即一張編結墊與一段待打的繩，內容從你打的結長出，無大標 hero、無宣傳標語、無按鈕組。與 workbench-first 的差別是那呈現一台待操作的機器面、產出物在別處；本原型那條繩同時是工具與產物，頁面內容（結名、成結／滑脫、交叉序列）直接從你打出的那串交叉長出。
- **nav**：`cordloop-rail 繩耳側桿`（新原型）——桌機左緣一段垂下的繩，四頁是繩上四個繩耳（bight），現用頁那個繩耳被「收束成一個小平結」並翻陶土色，其餘為鬆開的開口繩耳。與 yoiwan lantern-string rail（垂掛提灯、現用態發光）的差別是它是繩本身的繩耳、現用態以「收束成結＋翻色」標記而非點燈；行動版落為頂部 sticky 橫向捲動列。
- **signature**：繩股引擎照 over／under 交叉序列即時把結畫成 laid cord（z 序即上下、疊印自動生成交叉），並以「同交叉、反奇偶＝平結成結／假結滑脫」為核心判定；逐手選 over／under 建構交叉序列、引擎判成結與否。刻意避開揭示淡入／數字計數／按壓硬陰影／dashoffset 四項過載語彙，無跑馬燈、無自動輪播、無自動播放，天生 reduced-motion 友善（互動由使用者觸發、無補間依賴）。
- **illust**：`cordage-crossing 繩股交越圖`（新技法）——全站沒有一張外部圖片、沒有一張描外形或拍攝的插圖；logo、favicon、結譜縮圖、比較器縮圖、研習印記全由同一支 `renderDiag(交叉序列)` 把繩畫成疊股 laid cord（深邊＋色身＋斜向 lay 高光），over／under 由繪製 z 序自然產生，換一串交叉就換一張圖。與 thin-lineart 的差別是每條線是有粗細與纖維質感的繩股、且交叉的上下編碼了真實結構（是哪一股壓在上面），非等寬裝飾外框。
- **mood**：`pastel-soft`（霧鼠青 #C9D2C6 為大面積地色＋麻棕 #E9E1CF 面板／繩身，陶土 #C67C58 為作用色／滑脫警示／CTA，樹皮墨 #3A362E 為字與繩股外緣，丹寧 #8FA3AB 為次級文字與另一股繩。刻意用帶灰的冷霧鼠青為底而非米白紙感，且為粗描邊粉彩而非糖果撞色——脫離近期高彩撞色與暗底儀器台兩端。）

## 首創（claim）

**繩結交叉序列拓樸引擎作為互動範式，且全站圖像皆由交叉序列渲染、成結／滑脫由真實奇偶規則判定**：全館第一個把「結」拆成 over／under 交叉序列、以序列本身判定成結或滑脫的站。核心教材是平結（reef）與假結（granny）——同樣兩個交叉，第二個交叉換手（奇偶相反）就互鎖成結、不換手（奇偶相同）就平行滑脫，與繩粗繩材無關；使用者逐手選 over／under 建構序列，引擎判斷成不成結並指出錯在哪一步。同一支繩股引擎把每一串交叉畫成 laid cord，渲染全站每一張圖（logo、favicon、結譜縮圖、比較器縮圖、研習印記）。與 grip-station（攀岩牆面拖放岩點自組路線＋IK 火柴人爬行、對象是牆上路線與人體運動學）的差別：本站的互動對象是**繩本身的交叉拓樸**，判定的是這串交叉會不會鬆脫，不涉牆面路線與人體。
