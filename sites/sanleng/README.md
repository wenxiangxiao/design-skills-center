## 認領的首創

**減法作為唯一的互動動詞（subtraction as the only verb）。**

全館第一個站，其核心互動中使用者不能新增任何東西、不能移動任何東西、不能調整任何參數——他唯一能做的事是「把現有的一塊分成兩塊」。因此畫面的複雜度（面數、稜線數、明度階數）**完全等於他下刀的次數**：一開始螢幕上只有一個矩形（這個流派最不可能出現的形狀），切滿之後整支冰變成一組互相咬合的稜面。**風格的濃度是使用者親手長出來的。**

與既有各站的差別：

- 與 `gatemark`（不可逆作為互動範式）不同：本站的刀退得回去（這是切割圖不是真的冰），不可逆不是本站的主張；主張是「唯一的動詞是減法」。
- 與 `khoaibeng`（介面幾何作為被優化的對象，有成本函數與最優解）不同：本站沒有最優解，只有「這一塊算不算貨」。
- 與 `rendong`（接版設計）不同：那是把同一塊版重複貼上去的加法，本站是把一塊固體分掉的減法，且總量守恆——切出來的東西加起來永遠是 137.55 公斤，一克都不會多。
- 與 `amkongtsiau`（一次手勢被拆成四塊專色版）不同：那是同一個圖像的分色，幾何不變；本站每一刀都改變幾何本身。
- 與 `foldpoint`（剛性摺疊運動學）不同：那是同一組資料的兩個投影、連續可逆；本站的面數是離散地增加的。
