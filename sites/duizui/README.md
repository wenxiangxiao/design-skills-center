# 對嘴配音室 DUÌZUǏ DUBBING ROOM — 配音工作室 × 動態字體 Kinetic Typography

臺北長安東路地下一樓的華語配音室（虛構）：動畫、影集、遊戲語音、有聲書，Booth A 租借，週六「對嘴一小時」體驗課。配音導演鄧雅筑在蒙特婁的配音公司當了十年寫帶員，回臺北後把法國／魁北克的 **對嘴帶 bande rythmo** 帶進棚裡——台詞手寫在一條和畫面同速度往左跑的帶子上，字碰到紅色讀帶桿那一刻開口，字寫多長、音就拖多久。

風格是型錄「當代網頁與品牌」類的 **動態字體 Kinetic Typography**，型錄條目首站。與館內早期的 kinetiq（「動態加重 Motion-Heavy」，SaaS 暗底＋電光綠、粒子與跑馬燈）分界：那是「網頁上加很多動畫」，本站是「字本身就是時間軸」；兩站 mood、主色相（電光綠 vs 錄音紅＋琥珀）、開場原型皆不同。這個產業和這個流派是同一件事的兩面：kinetic type 是「字跟著時間演出」，對嘴帶是「把時間寫成字的寬度」。全站沒有一張圖，只有字；字的大小、粗細與寬窄就是聲音。

## 核心技術

1. **可變字型軸動態**（C 層）：Noto Sans TC `wght 100–900`、Anybody `wdth 50–150 × wght 100–900`；字重承載音量與準度，字寬承載時長。
2. **Intl.Segmenter**（E 層）：`zh-Hant` 詞粒度切詞——片頭、名片快切、對嘴計分與結果字卡都以「詞」為演員單位。
3. **跨文件 View Transitions**（B 層）：`@view-transition{navigation:auto}`，點下的導覽詞放大成下一頁的標題，整頁以讀帶方向的 clip-path 推入；對嘴台換場與出結果用同文件 `startViewTransition`。

## 首創

**對嘴帶（bande rythmo）時間即寬度的同步互動＋按壓時長回寫成動態字卡**：全館第一個把配音業的對嘴帶做成可玩的介面——台詞每個音節依毫秒長度被拉成那麼寬，帶子以固定 px/ms 通過讀帶桿，使用者以按住的時間去對；計分以 Intl.Segmenter 切出的詞為單位，結果再交回同一套 snap-rotate 字塊拼版引擎，讓「你按了多久」直接變成字的寬、「你多準」直接變成字的重。
