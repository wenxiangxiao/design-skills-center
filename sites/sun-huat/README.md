# 順發魚行 LOTERÍA DEL MAR（sun-huat）

**產業**：港邊魚行（高雄前鎮漁港魚市場東側第 4 攤；週六晚上喊樂得利牌）
**風格**：墨西哥樂得利牌 Lotería Mexicana・套色卡牌（Clemente Jacques 1887／Don Clemente 牌組傳統）

## 品牌設定

陳順發（1951–）1976–1988 年在高雄籍延繩釣鮪船上工作，每四個月靠岸墨西哥馬薩特蘭一次，碼頭工人 Rigoberto Osuna 教他在酒館喊 lotería。1989 年上岸，在前鎮漁港開魚行；1993 年請鹽埕大統印刷照墨西哥牌的套色法印了一副自己的 32 張「海的樂得利」——十四張魚、八張蝦蟹貝與怪魚、十張港邊物件，每張配一句台語叫牌詩。今天由女兒陳玉梅（1979–）顧攤與叫牌。

- 時間：週二至週日 05:30–13:00；週六 19:00–21:00 喊牌夜；週一休市
- 電話：(07) 821-1989

## 核心功能〈喊一盤〉

三句規則：叫牌人一張一張翻牌、唸一句詩（Web Speech 出聲，可關）；你的牌板上有叫到的，點它放一顆豆子；湊滿選定花樣（一排／四角／中心）就喊 ¡Lotería!——要比阿嬤和蔡師傅快。贏線上的四張牌變成你今天的袋子（九折、碎冰送），帶到〈來魚行〉開取貨牌。約 40–90 秒一輪；`?t=1–99` 可分享同一張牌板；方向鍵移格、Enter 放豆、L 喊牌。
