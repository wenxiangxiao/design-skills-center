# 通格有線 THONG-KEH CATV

嘉義市東區民族路 406 號〔門牌虛構〕的有線電視與弱電配線工程行。1984 年蔡永通〔虛構〕在東門圓環旁五樓頂架起一支碟形天線，把同軸線拉進對面公寓十四戶——那時叫「第四台」；1986 年在機房牆上用道路標線剩下的螢光漆畫線路圖，一戶一格、一條線一條直線，停電時拿手電筒一照就知道哪一格沒亮；1993 年有線電視法通過後把頭端交給合法系統台，自己留下來做工程協力。現在由蔡怡君〔虛構〕經營、林冠宇〔虛構〕當線路班長，做室內配線、老公寓弱電整理、光纖到府代施工與颱風夜搶修。

第四台在 1970 年代出現、1980 年代快速擴張（1991 年《天下》估計約每十戶就有一戶接著）、1993 年 7 月《有線電視法》通過為真實背景；品牌、人物、地址、電話、價格皆為虛構。

## 首創

**訊號灌色 signal pour**：全館第一個讓「畫面上每一塊的顏色由網路連通性決定」的站——整站圖像是一棵只准水平垂直邊的樹，顏色只有兩種狀態：從訊號源 BFS 走得到就是 Day-Glo，走不到就是灰泥。斷一段管，下游的顏色退回上游、格沉回下緣；接回一段，顏色沿著管長累計的延遲往下游流、每一格從管接進來的下緣灌滿。〈颱風夜〉把這個機制做成派工遊戲：Dijkstra 決定師傅怎麼沿管溝走過去，斷點上的數字是它切斷幾戶，玩完得到一張以 Halley 命名法題名的「今晚的畫」（例：*Seven Lit Cells with Two Broken Conduits*）。
