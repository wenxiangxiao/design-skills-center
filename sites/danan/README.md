# 大湳保溫被廠　DANAN QUILTED JACKETS

桃園八德的可拆式保溫被工廠。做閥件、法蘭、彎頭、人孔的保溫被，兼做窯爐門被與冷凍庫門簾。
**產業 × 風格：保溫被工程行 × 阿米希素色拼布 Amish Plain Quilt（1870–1940，賓州蘭開斯特）。**

> 為什麼配得起來：一件閥件保溫被攤平之後，功能區剛好是五塊——閥體、法蘭四方、閥桿環帶、螺栓角方、搭接裙；
> 而素色拼布的「框中菱 Diamond in the Square」也是五塊。而且兩邊的核心規矩是同一條物理：
> **壓線間距決定棉會不會塌**。拼布師傅說「不能大過一個手掌」，施工規範寫「空區內接方不得超過 4 吋」。

## 認領的首創

**「材料守恆的即時浮雕」**：全館第一個把版面的立體感當成一個**要被求解的狀態變數**而不是畫上去的裝飾——
每一塊布能鼓多高由「它最大的未壓空方」決定，被壓扁的棉不會消失而是被分配給還有餘裕的布塊，
所以使用者在一塊布上多縫一條線，**另一塊布會當場鼓起來**。
凹凸不是資產，是解；而且它可以整層關掉——關掉之後畫面完全平，資訊零損失。

（與 `shunchang` 斜光浮雕風的差別：那裡的浮雕是固定的實體刻紋、使用者能改的只有光的入射角；
本站光也會動，但那不是簽名——本站的簽名是**浮雕本身被重新解出來並重新分配**。）

## 動效預算（四種）

1. **ambient**：斜光巡行——`feDistantLight` 的方位在 96°–168° 之間往返，帶幀時間看門狗自動降頻；另有真實時刻驅動的壓線進度。
2. **input-driven**：手電筒——樣片上的光源方位與仰角由游標位置決定，方向鍵亦可（延遲 <100ms）。
3. **transition**：翻被角——換頁時右下掀起一塊三角，露出背面的素裡布與線頭（clip-path，420ms）。
4. **signature**：棉的位移（見上）。

四種在 `prefers-reduced-motion` 下全部降級且資訊零損失：光固定 132°、手電筒改由方向鍵、翻被角直接切換、棉的位移不補間直接跳到新解。
