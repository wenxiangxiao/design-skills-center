## 核心功能：本季目錄

規則三句話、九十秒玩得完：

1. 這一季倉裡發生了十八件事，號碼只有十二個；揀一件就發一個號，**至少發滿八個**。
2. 其中**至少一個要發給不佔空間的東西**（事、制）——只編得出貨品的，是庫存清冊，不是目錄。
3. **同一類別不得連續三號**——連著三個同類就不是目錄，是分類帳。

抽掉一件，後面全部往前遞補：這份目錄的號不是打上去的，是它自己數出來的（CSS counter）。
編完之後，你的第一號會被漆在 A 棟外牆上，這個網站的刊頭跟著換；整季目錄可貼回首頁的十二個空號位，
並發一個季號與可還原的 `?c=` 分享碼（同一組選擇與同一個順序恆得同一個季號與同一張封面）。

**實測（20 萬組隨機揀選與排序）**：成季 83.7%；退件全部來自「同類連續三號」16.2% 與「沒有無形之物」0.1%。
n=8 通過 87.2%、n=12 通過 80.1%。刻意只揀「物」與「地」（庫存清冊心態）的玩法必定被第二條擋下。

## 動效四式

- **ambient**：警示帶推移（24s linear infinite）＋門禁時鐘（每 15 秒由真實時刻重算開閉與倒數，無輸入亦持續變化）
- **input**：列反白＋色碼方塊翻出自己的字母＋黑版前排剖線上抬（全部 .09s linear，<100ms）
- **transition**：捲門 shutter（`clip-path` 620ms `steps(14)`，逐段延遲）
- **signature**：**遞補波 counter-cascade**（增刪或移序時，其後每一列的號碼被重新數出來並以 300ms `steps(6)` 推過去，每列延遲 index×26ms）

四種皆有 `prefers-reduced-motion` 降級且資訊零損失。
