## 首創說明

**顏料褪色作為時間介面（pigment fade as the time interface）**

全館第一個站，其畫面上「現在是幾月」這件事不是用數字顯示的，而是用**顏料還剩多少**顯示的——
而且四塊石版以不同速率消失（洋紅 210 天半衰、藤黃 430、花青 950、炭黑 6000），
所以顏色的**偏移方向**本身就是日期：一張粉桃色的美人，到臘月會變成一張青灰色的美人。

- 與 `leung-kee`（真實時刻晝夜引擎）的差別：那是**可逆**的——時間走過去，天色會再亮回來；
  本站是**單向損耗**，而且損耗率因顏料而異，掛過的日子拿不回來。
- 與 `patchframe`（損毀—校正式站體）的差別：那有一個隱藏真值等著被調準修復；本站沒有真值、沒有修復，
  時間過了就是過了，竹尺只讓你「看」不同天數的樣子，鬆手它回到今天。
- 與所有「懷舊濾鏡」的差別：濾鏡是整張一起變黃；本站是分顏料的，且損耗量與同一支算式同時驅動
  核心功能的〈三年後〉對照、相簿廿四件的「紙況」欄，以及首頁的四支剩餘量條——同一本帳，四處共用。

## 動效（四種，皆備 `prefers-reduced-motion` 降級且資訊零損失）

1. **ambient**　紙受潮微捲（46s，只動 `transform`；降級停在定角，捲角仍在）
2. **input**　曆格壓印（hover／focus <100ms，同步把該日農曆／節氣／干支寫進讀值列；降級取消位移、讀值照常）
3. **transition**　掀紙 sheet-lift（換頁與換月，520–560ms `rotateX` 掀起；降級直接是最終畫面）
4. **signature**　掛久了 pigment-fade（六個 CSS 變數，不重繪幾何；本來就是狀態不是動畫）

## 技術與可行性

- **`Intl.DateTimeFormat` + `ca-chinese`**：Baseline Widely available（2017-09 起）。建置階段先算出丙午年全年靜態表（5.6 KB）寫進 HTML，
  執行時先試 `Intl` 並自檢，失敗退回年表；讀值列會標示來源。二十四節氣以視太陽黃經 15° 求根自算，與公開曆書 2026 年 24 個節氣日期全數相符。
- **`writing-mode` + `text-combine-upright: all`**：分別為 96%／96.68% 全球支援（caniuse，2026-08 查）。不用支援度差的 `digits`；不支援時數字逐字轉正，仍可讀。
- **SVG `feTurbulence` 濾鏡**：Baseline Widely available（2015-07 起）。不支援時濾鏡整個被忽略，造形與顏色零損失。
  只套在炭底那一組 `<g>` 上、一頁一次，且不動畫 `baseFrequency`。
- **效能**：單頁 58–88 KB（含全部 inline CSS／JS／SVG，預算 350 KB）；零外部圖片、零音檔、零函式庫，僅 Google Fonts。
