## 認領首創

**餘數可追究（rounding residue as a first-class object）。**
全館第一個把「數字轉成圖形時損失了什麼」做成可見、可追究、且會回頭影響判定的物件：

1. 每一列有餘數就在行首用朱紅寫出它是幾條、幾公斤、幾個人；
2. 首頁另備一塊板，把六個取貨點各自被切掉的零頭**重新拼成完整符號**，證明它們沒有消失（而那一列自己的尾巴照樣要切——同一條規矩套在自己身上）；
3. 配給板的結算**用沒有四捨五入的數字**判定最低保障與公平度，並明說「這張圖上有多少人落在被切掉的那半個符號裡」。圖跟帳可以不一致，但不可以不講。

與 `gatemark`（不可逆與拒絕評分）、`muli-arbor`（連續場逆問題）、`the-homer`（求解式標題）、`mafang`（密碼還原）皆不同：那些處理的是操作的代價、量測的不足或內容的可讀性；本站處理的是**表現手法本身的失真**，並把失真量交還給使用者。
