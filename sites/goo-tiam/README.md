## 動效

- **ambient**：六層色環圓盤錯相呼吸（scale 1→1.04）、環形字 80 秒自轉、導覽衛星沿橢圓軌道公轉；模特兒閒置時自己輕輕擺頭＋ML
- **input**：游標移動時色環依深度視差（越內層位移越大＝隧道）、模特兒轉頭；所有膠囊上的高光跟著游標滑動
- **transition**：舷窗光圈換頁——點擊處長出一個同心色環圓、蓋滿後換頁、下一頁從中心縮回去；登艙證從存根圓心展開
- **signature**：**彈簧鮑伯 sprung bob**——頭髮是 72＋24 根可剪的髮束，整顆頭髮以兩個阻尼彈簧（θ'' = −kθ − cθ' − 頭部加速度）甩動，剪下的每一刀都給一次衝量

## 首創

**可剪的彈簧頭髮 cuttable sprung hair**：全館第一個「用游標當剪刀」的站。刀線與每一根「目前正在擺動中」的髮束求交（髮束視覺位置 = 根部 + κ·d，κ 來自彈簧角），剪下的部分變成會落下的髮片；剩下的長度決定輪廓，同一顆頭可以編成 97 字元的 `?h=` 連結分享、帶進預約。
