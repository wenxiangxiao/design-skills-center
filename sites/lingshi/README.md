## 認領的首創

**席位視點單應（seat-vantage homography）** — 全館第一個以「使用者選定的實體座位」為唯一參數，把同一組舞台形體重投影成該座位專屬視像的站；也是全館第一個以「選位售票」為核心互動、且交付物（票根）與可分享網址就是那個視像本身的站。

至上主義主張形體漂浮在沒有透視的空間裡；劇場則把九十六個人分配到九十六個視點。這個站把兩者放在同一個畫面裡：那面幕在每一個座位上都是一塊不同的四邊形，而票價就是那塊四邊形算出來的。

## 核心技術

| 層 | 技術 | 承載 |
|---|---|---|
| A 渲染 | CSS `matrix3d()` 平面單應變換 | 席位視點重投影（SVG 只有仿射變換，做不出投影梯形） |
| B 動效與時間軸 | 真實時刻驅動的場燈狀態機（`Intl.DateTimeFormat` + `Asia/Taipei`） | ambient 動效：日間／進場／演出中／散場四態，演出時段整頁反轉為墨底 |
| E 資料與生成 | URL 狀態序列化（`URLSearchParams` + `history.replaceState`） | 票根即網址，可分享、可重開、可還原該座位的幕 |

支援度查證、fallback 具體行為與效能實測值見 `SKILL.md` 第十二章。

## 四種動效

1. **ambient** — 衛星形體失重漂移（49–91 秒互質週期，位移 ≤ 11px、旋轉 ≤ 0.4°）＋ 真實時刻驅動的場燈
2. **input-driven** — hover 形體傾斜換色、點選座位即時重投影整面幕（實測解算 0.0076 ms）
3. **transition** — 對角掃幕（一塊 240vmax 的墨色平面以 −45° 姿態滑出，露出頁面）
4. **signature** — 日落 sun-strike：一枚墨方沿 45° 滑入蓋住全站唯一那枚黃圓，狀態寫入 `localStorage` 跨頁生效，頁尾提供「復日」還原

四種皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。
