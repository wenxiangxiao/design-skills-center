# 秀枝繡號 SIÙ-KI

臺南市中西區大埔街 47 號的繡學號店，兼用巴拿馬 Guna 族 mola 的反向貼布法，把名字剪進兩到五層布裡；牆上寄售 Ailigandí 島婦女合作社的真 mola，店裡不抽成。

> 店名、人物、地址、電話、價格皆為虛構示意。

## 品牌設定

- **起源**：林秀枝（1956–）1979 年隨夫到巴拿馬 Colón 自由貿易區做成衣批發；1983 年 Ailigandí 島的 Olowaili Pérez（1948–2016）教她剪第一塊兩層 mola——一條魚。1986 年在 Colón 開 Bordados Siu-Ki 繡字店；2017 年臺巴斷交後，2018 年回臺南開店。
- **人物**：林秀枝（手剪、收邊）／陳以靜（1984–，生於 Colón，店長、設計、合作社聯絡）／黃淑芬（1970–，電腦繡學號機台）
- **價目**：繡學號一行 NT$40、兩行 NT$70；剪層名牌 12×8 cm 兩層 NT$680／三層 1,180／四層 1,880／五層 2,680（2／4／7／10 天）；加圖案 +200；嵌色每色 +150；週六「兩層一條魚」體驗 NT$900；合作社 mola NT$3,200–12,000
- **營業**：週一至週六 10:00–20:00，開學週（8/25–9/5、2/10–2/20）到 21:30；週日公休・(06) 213-1983
- **立場**：只教剪法、不教圖樣；Guna 氏族與儀式圖樣不剪、不賣、不仿。
