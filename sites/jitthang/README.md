## 品牌設定

基隆市中山區中和路 187 巷 6 號，仙洞公園口。民國六十三年開場，先做廢紙，民國七十一年才加收金屬。
負責人吳日成，刻版陳月理（民國九十六年來的，原本在中山區做印刷），司機黃阿田。
週一至週六 06:20–17:40，週三下午整理場地不收。電話 (02) 2428-3196。

店名的意思是「每天一面新的窗」。每天早上六點二十，陳月理刻一塊新的價錢版貼到窗上——
因為紙價一天一個樣，寫在紙上比喊來得清楚。一塊版刷得出幾張，就決定這面窗貼得到城裡第幾條街。
城裡二十五個窗口全部貼滿要 208 張；一塊版最省的刻法只刷得到 101 張，最好的刻法可以到 252 張。

## 認領的首創

**型版可切性作為互動與驗收條件**（stencil-cuttability as the interaction and the acceptance criterion）。

全館第一個站，使用者操作的對象是**形狀的拓樸連通性**——他不改形狀的外觀、不改顏色、不改版面、不調任何物理參數，
他決定的是「哪些封閉區域要被接回外界」，而這件事的後果不在螢幕上而在物理上：沒接住的那塊紙會掉下來，那一版報廢。

- 與 `rendong`（接版設計：被操作的是一個平移群，成品無邊界、成功的定義是看不見接縫）的差別：本站被操作的是一個**連通關係**，
  成品有明確邊界，成功的定義是「每一塊都還連著」，而且失敗會讓畫面上真的少一塊東西。
- 與 `khoaibeng`（字盤佈局最佳化器：有成本函數與最優解的排列問題）的差別：本站不是排列問題，
  是「割開或不割開」的二元選擇，而且它有兩個互相對抗的門檻（掉島／斷字），不是單一最小化目標。
- 與 `jiaobai`（摺疊對稱防染：摺法決定有限對稱群）、`xiulu`（WFC 約束傳播）的差別：那些解的是幾何或約束滿足，
  本站解的是**圖的連通分量**——每一座島是一個節點，每一根橋是一條邊，成不成版取決於它們跟「外界」在不在同一個分量裡。
- 與 `shidong`（把觀看者的視網膜當成輸出媒介）的差別：本站的後果完全在螢幕上，而且可以下載、可以分享、可以重現。

## 動效預算（四種，皆備 `prefers-reduced-motion` 降級且資訊零損失）

1. **ambient**：套印錯位（1.6s，`steps(1)` 四段）。朱版與赭版各自在四個離散位置間跳——你正在看第幾張手刷樣張。降級：停在對位準的那一張。
2. **input-driven**：三塊版當場分開（80ms，`steps(2)`）。hover／focus 任一格，朱版與赭版沿各自方向位移，同時浮出刀路細線。降級：瞬切，狀態仍成立。
3. **transition**：一格一格貼上去（320ms `steps(5)`，62ms stagger，`clip-path:inset` 由上而下）。降級：直接是最終畫面。
4. **signature**：掉島 island-drop（720ms `steps(6)`）。降級：島直接 `visibility:hidden`，露出的一樣是實心色版底。

全站沒有一條 `ease`／`cubic-bezier`。明文禁用：淡入式滾動揭示、視差、數字滾動、跑馬燈、按壓硬陰影、`stroke-dashoffset` 描繪、噴霧毛邊濾鏡。

## 無 JavaScript 時

- **首頁**：八格連環在建置階段就以同一支引擎算好並輸出成靜態 SVG 寫進頁內，關掉 JavaScript 仍是完整的一面窗；全部資訊為可選取的一般 HTML 文字。
- **牌價**：十二枚象形與二十四個品項全部靜態。
- **刻版**：`<noscript>` 區塊給出一塊已架好橋的示範版與它的實際數字（可刷 123 張、貼到第 10 個窗口），
  以及六塊版**全部組合窮舉**的結果表（成版率 26.6%–67.0%、張數 101–252），數字與互動算出來的完全一樣。
- **收運**：送出鈕預設停用（跨欄四條規矩需要當場算），改請打電話；四條規矩本身寫在頁面上。
