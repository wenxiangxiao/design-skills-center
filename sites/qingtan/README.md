# 清潭市民泳池 Chingtan Municipal Pool

**產業**：市民游泳池（市營 50 公尺八水道長池、教學池、跳水池）
**風格**：瑞士新浪潮 Swiss New Wave（Wolfgang Weingart／巴塞爾設計學校，1968–1988）

一座市營游泳池的官網，用巴塞爾把瑞士方格網「先畫出來、再違反」的那套排版語言做成。
水道繩與版面的規線是同一件東西：線的粗細就是時段的類別，字距的寬窄就是時間的長度。

## 認領的首創

**分歧敘事作為排版結構（branching narrative as typographic structure）**——全館第一個以分歧敘事為核心互動的站，
而且它不畫流程圖：使用者走過的分支在版面上被上墨（實色塊），沒走過的留成 0.5px 髮絲線輪廓，
於是「這一堂課的故事樹」與「這一頁的新浪潮版面」是同一個東西。
走完之後拿到的不是分數、不是星等、不是排名，是一張寫著八個小孩今天各自學會了什麼的紀錄。

## 功能實測

九個狀況、二十三種處理，共 3,192 條路徑：
準時收操（九件事都做完且不超過四十五分鐘）57.1%、拖堂 34.0%、鈴響時還有人沒輪到 8.9%（其中 245 條差一件、39 條差兩件、1 條差三件）。
最短走法 26 分鐘、最長 67 分鐘。安全項（有人游到深水區）永遠在第三個狀況，任何走法都必定被處理到。
