# 撿著了 KHIOH-TIO̍H 遺失物寄還社

> 臺北懷寧街的遺失物寄還社 × Jean Dubuffet〈L'Hourloupe〉浮路細胞排線（1962–1974）

## 品牌設定

- **名稱**：撿著了 遺失物寄還社（台語 khioh--tio̍h，「撿到了」）
- **地址**：臺北市中正區懷寧街 62 巷 3 號 2 樓〔門牌虛構〕，一樓是印章店
- **電話**：(02) 2311-1983〔虛構〕
- **時間**：週一至週六 10:00–20:00；週日只接電話 13:00–18:00
- **故事**：白秀鑾 1974–1982 年在（虛構的）北環客運總機接找東西的電話，左手話筒、右手紅藍兩支原子筆，邊聽邊把對方描述的東西畫在留言條上、一格一格塗滿條紋。1983 年她帶著那疊留言條出來，替客運、車行和附近店家收失物、找失主、寄回去，條紋顏色就成了分類：**紅＝車上撿到、藍＝店裡撿到、白＝路上撿到、黑＝證件**。2008 年女兒白亭妤接手。去年寄還 6,214 件。
- **價目**：自取與代尋登記免費（保管 90 天）；寄還小件 NT$90、中件 150、大件 260；離島 +120；海外 680 起；臺北市當日專人送還 420；證件、健保卡、藥免運。
