十二條梯子，每一階少一個形

一條梯子從七個形開始。每往下一階，引擎在圖上找出最像是同一個形的那一對——距離近、顏色同、其中一個比較小的那一對——把它們併成一個膠囊或一個圓。併出來的形，面積等於被併掉那兩個的和；同一種動物在七階裡的墨量完全相同（誤差 0，見下表「面積」欄）。

點任何一階，上面那張大圖就會走一次合形。梯格的邊長是 √(形數÷7)，所以格子的面積也正比於形數——梯子自己也遵守同一條規矩。你若做過少形測，你的下限會印在每一格的規格列上。

合形怎麼算

面積守恆的併形

每一個形先被量成三個數：面積、重心、二次矩（它有多長、朝哪邊）。兩個形要併，就把這三個數依面積加權合起來——這跟把兩團墨倒進同一個模子是同一件事。合出來的二次矩比決定它是圓還是膠囊、膠囊有多長；面積則直接被定死成兩者之和，所以併形不會生出新的墨，也不會少掉墨。

要併哪一對？成本最低的那一對。成本 = 重心距離 ÷ 兩者的等效半徑和，再乘上「顏色不同就罰 1.9 倍」，再除以「其中一個愈小愈該併」。眼睛與白斑另外給了 2.6 到 3.2 倍的保護係數——牠們是最後才被吃掉的形。

function merge(a, b) {
  const A  = a.A + b.A;                 // 面積直接相加
  const cx = (a.A*a.cx + b.A*b.cx) / A; // 重心加權
  const cy = (a.A*a.cy + b.A*b.cy) / A;
  const dx = a.cx-cx, ex = b.cx-cx;
  const dy = a.cy-cy, ey = b.cy-cy;
  return {                              // 平行軸定理
    A, cx, cy,
    mxx:(a.A*(a.mxx+dx*dx)+b.A*(b.mxx+ex*ex))/A,
    myy:(a.A*(a.myy+dy*dy)+b.A*(b.myy+ey*ey))/A,
    mxy:(a.A*(a.mxy+dx*dy)+b.A*(b.mxy+ex*ey))/A,
    col:(a.A>=b.A ? a.col : b.col)
  };
}
