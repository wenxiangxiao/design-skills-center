# 城中電話交換所 Chéngzhōng Exchange

> 一座還在拉線的人工電話總機。自動交換機來了以後，這種「人接的電話」被一台台拆掉；城中局把最後一座 A 型共電式塞繩台留了下來，改成講習科的教具。坐上接線台，來話亮燈時把塞繩拖進塞孔、扳鈴、接通，看你一輪能接住幾通。

## 品牌設定

- **產業**：電話交換所／接線生講習（人工總機博物館＋話務員養成）
- **地點（虛構）**：台北市城中區懷寧街 15 號二樓・城中局
- **年代**：民國五十年代（1960s）共電式全盛期
- **領班**：林秀珠，甲組，服務三十一年，「號碼請講」講過上千遍
- **調性**：溫柔而職人。快、準、輕聲，是這行的三件事
- **一句話**：整條線路，是你的手拉起來的。

## 頁面

1. **index.html — 接線台**：switchboard-first 總機直開場。首屏即一台正在運轉的塞繩式總機。核心功能＝**即時接線遊戲（call-routing）**：來話亮燈→拖後塞（應答）進塞孔→拖前塞（振鈴）進對方塞孔→扳鈴鍵振鈴→接通計時→掛機閃燈時拔線收場。班表由 seed 決定（純函數，可重播），計接通率／平均應答／未接／誤接。支援拖曳、點選、鍵盤三種操作。
2. **jixie.html — 機件**：塞繩台的機件解剖。點任一部位（塞孔／指示燈／後塞／前塞／塞繩／鈴鍵／監視燈），左圖亮出位置並說明它在線路裡的角色；附共電式三步原理。
3. **kecheng.html — 講習**：接線生六週課程表、「號碼請講」六字訣、學費與收費。**梯次選填**：點一個梯次看餘額，選定後可留一個練習報名序號（前端模擬）。
4. **yange.html — 沿革**：從民國十六年磁石式小總機、到共電式 A 座、再到自動交換機來臨後被留下的一座教具台。附領班側寫與參觀資訊。
