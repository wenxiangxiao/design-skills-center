## 首創（_first_registry 登記）

**拍頻聽感調律作為互動範式（beat-frequency aural tuning）**：以兩個相近部分音的干涉拍作為唯一被判定的知覺訊號；不諧和部分音 fₙ = n·f₀·√(1+Bn²) 使八度必須拉伸；平均律音程以「規定拍速」而非「無拍」為合格判準——五度交出無拍反而失敗。Web Audio 疊加部分音使拍自然湧現（非合成的顫音），拍表、里薩茹拍紋與判定引擎共用同一組頻率。
