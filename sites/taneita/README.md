## 這一站在做什麼

寄木細工的最小單位是**一根木條的木口**（切面）——你不能把它切得更細，所以文樣必須從單位本身長出來。ANSi Art 的最小單位是**一個字元格**——同樣切不細，圖案同樣必須從單位本身長出來。

這間工房把它的文樣型錄，用 1990 年代 BBS 畫家的流儀發行：每月一包、十六色、字元桝目，加上署名。**全站所有的圖（頁首的しるし以外）都是真的文字**——可以框選、複製，貼進記事本後顏色掉了，形還在。

四頁：

| 頁 | 內容 |
|---|---|
| `index.html` 工房 | 種板の三面図（逐格重畫開場）、今月の種板、四つの仕事 |
| `monyo.html` 文様 | 十二の文様（麻の葉・市松・矢羽根・亀甲・青海波・七宝・鱗・籠目・檜垣・風車・井桁・三崩し）と条数 |
| `iroha.html` 木の色 | 十六格に六十種の木を入れる。そして木では出ない六色の話 |
| `tejun.html` 手順 | 四回仕掛けの秘密箱（核心互動） |

## 八維配方

| 維度 | 值 |
|---|---|
| **style 風格** | ANSi Art — BBS 場景的 ANSI 藝術（既有流派。型錄「數位與螢幕原生」類「ASCII/ANSI Art」條目，全館第 1 站） |
| **industry 產業** | 寄木細工工房（箱根 畑宿：種板の仕込み・ヅク貼り・無垢彫り・秘密箱の仕掛け・修理） |
| **opening 開場** | `redraw-first` 逐格重畫直開場 — 首屏不是已經在那裡等你，是在你眼前一格一格由左上往右下畫出來的，順序不能改。1440 字元／秒（14400 bps ÷ 10 位元） |
| **nav 導覽** | `cursor-parked` 游標停駐 — 四行大小・位置・外形・字・明暗完全相同，變的只有反白停在哪一行（ANSI SGR 7 反顯）＋ 行首一個 456ms 閃爍的 `►` |
| **illust 插畫** | `halfblock-raster` 半塊柵構成 — 零 `<img>`／零 `<canvas>`／零點陣圖。只准三條原語：半塊切格・四階濃淡・框線字元 |
| **mood 氛圍** | `ega-sixteen` 十六色定盤 — 色盤不是設計者挑的，是 1984 年 IBM 燒進 EGA 基板的。零 opacity・零 rgba 第四位・零漸層・零 filter；背景只能用低八色 |
| **signature 簽名** | 〈屬性流〉 — 滑過任何一塊圖，亮起來的不是那個圖形，是**畫出它的那一段屬性**。高亮的邊界是檔案的邊界，不是圖的邊界 |
| **func 功能** | 〈手順〉四回仕掛けの秘密箱（解謎／手順型） |
| **tech 技術** | CSS Custom Highlight API（A 渲染層）／跨文件 View Transitions（B 動效層）／CSS `round()` ＋ `ch`·`em` 字元格單位（C 版面層） |

其他變數維度：**era** 1990–1997 的 BBS ／ 明治以来の畑宿・**locale** 箱根 畑宿・**texture** 零質感（文字模式沒有紙、沒有墨、沒有顆粒）・**density** 満（屬性不佔格，所以畫面可以塞滿）。

## 認領的首創

**全站彩色圖像零包裝元素（zero-wrapper coloured imagery）**

全館第一個把所有圖像的色彩完全交給 CSS Custom Highlight API 的 `Range` 來上的站。畫面上每一幅彩圖底下都**只有一個純文字節點**——沒有任何一個 `<span>`、`<i>`、`<canvas>`、`<img>`、`<svg>` 參與上色。（頁首那個 logo 是 inline `<svg>`，但它不是「圖」，是把同一套字元格寫成整數座標矩形的商標；站內的每一幅畫都不經過它。）所以「圖」可以被游標框選、被複製、被貼進純文字編輯器而原樣保留（顏色掉了，形還在）。

由這一點長出本站的簽名動效〈屬性流〉：因為顏色掛在「一段連續字元」而不是掛在圖形上，高亮的邊界就是**檔案**的邊界——它可能橫跨兩個不相干的形，也可能在一行中間斷掉，而且跨換行不中斷。這是把 ANSi 檔的 SGR 屬性流直接搬到網頁上的結果，不是視覺效果。

## 四種動效

| 種類 | 內容 | 觸發源 | 降級（`prefers-reduced-motion`） |
|---|---|---|---|
| ambient | 閃爍位 456ms 硬切（VGA 文字模式 70.086 Hz ÷ 32 ≈ 2.19 Hz） | 不需輸入 | 停在「亮」的那一半，資訊不變 |
| input-driven | **重放**：按一下任何一幅畫，它就從頭再流一次（1440 字元／秒）；以及**整格跳位**：秘密箱的板每 90ms 滑一格，沒有中間位置 | 點擊／Enter／空白鍵／鍵盤 1–6 | 重放直接一次到位；跳位本來就離散，照常 |
| transition | 清屏重畫：跨文件 View Transitions，`clip-path` 由上往下 240ms | 換頁 | 直接換頁 |
| signature | 〈屬性流〉：屬性段整段反白（用木做不出來的暗青 `#0000AA`） | 指標／方向鍵落在圖上 | 它是資訊不是動畫，照常顯示 |

## 核心互動〈手順〉

箱根の秘密箱は、板を順に滑らせないと開かない。四回仕掛け＝四枚。

規則三行：**箱の面を押す／順が合っていれば板が一枚ぶん滑り、合っていなければ全部戻る／四回で開く。**
わからなくなったら〈木口を見る〉——動く板の合わせ口に、**木では出せない色**（明紅 `#FF5555`）の筋が一本立ちます。

一輪およそ六十秒。量表なし・模擬引擎なし・調整パラメータなし。

## 技術與相容性（要旨）

- **CSS Custom Highlight API**：`::highlight()` は MDN で **Baseline 2026 · Newly available**（2026-03 以降）。`color` と `background-color` が使える。非対応時は `<span>` 包装に切替——**画面は同一、形と色は零損失**。
- **跨文件 View Transitions**：MDN で **Limited availability（not Baseline）**。非対応時は普通の瞬時遷移。情報の損失なし。
- **CSS `round()`**：stepped-value 関数は **Baseline 2024**（2024-05〜）。列高を整数画素に吸着させ、半塊のあいだに髪の毛ほどの隙も作らない。`@supports` で包んであるので非対応でも版面は変わらない。

詳細（查證來源・fallback 的具體行為・效能實測值）は [SKILL.md](SKILL.md) の「技術實作與相容性」章に。
