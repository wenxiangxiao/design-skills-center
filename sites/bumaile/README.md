# 不買了工具圖書館 BUMAILE TOOL LIBRARY

> Design Skills Center 館藏範例站 — **龐克剪貼 Punk Xerox × 社區工具圖書館**

一間開在新北三重后竹圍市場後門的社區工具圖書館：館藏 342 件，牆上輪展 24 件，年費 360 元，逾期不收錢、收你的時間。整個站的視覺語言是 1976–78 年英國龐克 fanzine 的影印機美學——勒索信剪貼字、二值化碳粉、膠帶與撕邊、大面積實黑塊、一個螢光專色。

## 頁面

| 檔案 | 內容 |

| `index.html` | **卡袋牆**（開場原型 pocket-first）：24 個卡袋，有卡＝在館、空袋＝在別人手上；點一格看卡背上前面的人寫過的字 |

## 核心功能：借一把，卡片再影印一次

三句話講得完、九十秒玩得完的**流轉型**互動（不是模擬器、沒有量表、沒有滑桿、沒有隱藏真值）：

1. 從卡袋牆挑一把還在館裡的工具——**一次只能借一件**（手上還有沒還的就會被擋下，並點名是哪一把）。
2. 卡片跟著工具走，你得在卡背寫一行給下一個人——**寫什麼都可以，除了「好用」**（敷衍詞會被規則二退回）。字可以打，也可以從頁面上任何地方圈選剪下來。
3. 還的時候老實講它的狀態，卡片就會**再被影印一次**：留言逐行變糊、卡片更歪、多一條膠帶、黑邊變厚。**沒有還原。**

第 6 次影印之後卡片作廢重打，上面六個人寫過的字——包含你剛寫的那一行——全部消失。逾期不罰錢，一天換修理日一小時（上限 8 小時），十五天以上停權一個月。狀態存在 `localStorage`，跨頁生效：你寫的那一行會出現在首頁卡袋牆的那一格上，並可用 `?c=` 分享碼還原。

## 八維配方

- **era 時代**：1976–78 英國龐克 fanzine 的影印機／2020 年代的社區共享
- **locale 地域**：新北市三重區，市場後門的一樓店面
- **voice 性格**：直白、拒絕客套、規則寫成命令句、對消費主義有意見但不說教
- **texture 質感**：碳粉、影印紙、膠帶、剪刀邊與撕邊
- **density 密度**：高，留白率 <18%，畫面永遠被貼滿
- **function 功能性**：借還檯（流轉型互動，非模擬）
- **opening 開場**：`pocket-first` 卡袋牆直開場
- **nav 導覽**：`generation-clarity` 世代清晰度導覽（現用頁是原稿，其餘依距離被影印 1–3 次）

## 首創（全館第一次）

**以「選取範圍」為主要輸入的站（selection-as-scissors）**：用滑鼠或觸控圈選頁面上任何一段字，放開的瞬間那段字就被剪下來、每個字換一種字體與底色、歪一個角度，貼到右下角的剪貼台，並可帶去借還檯貼進卡背那一行。館內既有各站的輸入是點擊、拖曳、鍵盤、壓感、捲動與捲軸時間軸，沒有一站以 `Selection`／`Range` 為輸入來源。原文一個字都沒有被改動——剪的是影本。

**簽名動效 `generation-loss` 影印世代退化**：歸還時一道白色掃描條由上往下掃過借閱卡，掃到哪一行，那一行的 SVG 濾鏡世代就 +1，字就糊一級；掃完卡片整體轉正 0.45°、黑邊加厚、多一條膠帶。這個劣化是狀態不是特效，寫進 `localStorage`、跨頁生效、單向遞減。

## 技術

| 層 | 技術 | 它在本站承載什麼 |
|---|---|---|
| A 渲染 | `feMorphology` + `feComponentTransfer` 二值化濾鏡鏈 | 影印退化本體：碳粉外擴 → 模糊 → 硬門檻 → 斷線 |
| D 輸入與感測 | Selection API（`getSelection` / `Range.getClientRects`） | 圈選即剪貼，與飛向剪貼台的動畫起點座標 |
| E 資料與生成 | Canvas `ImageData` + Bayer 8×8 有序抖動 | 全站紙面的碳粉髒污底紋（決定性、零外部圖片，實測覆蓋率 7.88%） |

支援度查證、fallback 具體行為與效能實測值見 `SKILL.md` 最末〈技術實作與相容性〉。
