# 共榮消費合作社 第七分社 KIONG-ENG CO-OP No.7

**產業**：社區消費合作社（基隆愛四路，共同購買與店頭零售）
**風格**：蘇聯 ROSTA 窗 Окна РОСТА（1919–1921）— 取自 `_style_catalog`「在地與文化視覺」，非自創
**線上**：<https://wenxiangxiao.github.io/design-skills-center/sites/kiongeng/>

一間開了六十四年的合作社。它不做廣告、不發傳單、不寄電子報——
社裡要講的每一件事都出成一面「窗」，六格圖加兩行押韻的話，貼在店頭玻璃上，一面壓一面。

整個網站就是那面玻璃。

| 檔案 | 頁 | 內容 |
|---|---|---|
| `index.html` | 今日之窗 | 第 2,317 號窗的六格；朗讀與指讀；刷次說明與一版三百張的排班；昨天那面窗；社務、價目、創社由來 |
| `chuang.html` | 出窗房 | 核心功能：對句開窗。另附六張事由牌的完整靜態全表（無 JS 可讀完） |
| `pan.html` | 版房 | 二十二塊模板象形字彙圖鑑、橋的規矩、三塊版的套印、刻版五道工序、ROSTA 窗的史料 |
| `she.html` | 入社 | 入社條件、股金、配送班表、本社年度帳、入社申請表（跨欄驗證＋決定性回執印記） |

## 核心功能：〈出一面窗〉

規則三句話——一、揀一件今天社裡要講的事；二、用漿糊桌上刻好的詞塊把下聯拼出來；三、四條都過就開窗。
約九十秒跑完一輪。

- 六張事由牌（高麗菜整車到／雞蛋限購／漁貨到岸／油品共同購買／明日停電／招新社員），
  上聯已由理事會擬好，下聯要訪客自己對。
- 四條會擋人的規矩，每一條都是刻版的實務而不是文學品味：
  **字數與上聯相同**（版面要一樣長）、**末字同韻且不得同字**（走過去的人才記得住）、
  **至少一塊是叫人做事的話**（窗不是報紙）、**不准把上聯的字搬過來**。
- 字數以 `Intl.Segmenter` 的 grapheme 計算；下聯以 word 斷詞，**詞縫就是刻版要留的橋位**，
  刻版員的回話會直接報「斷成 3 個詞，我留 2 道橋位」。
- 不給分數、不給星等、不排名。只給：一面真的排出來的六格窗、要刻幾塊版、
  照 Cheremnykh 的實際節奏（第一天 25 張、第二天 50 張）幾天能刷滿三百張、
  以及刻版員邱萬得的一句話。
- 產出物就是這個網站本身：按「貼到店頭」後首頁會記得你那一面窗（`localStorage`），
  並發一組可分享還原的 `?w=` 碼（同碼恆得同窗）。
- 窮舉驗證（最多四塊、不重複用塊、末字同韻且不同字、至少一塊祈使）：
  六張牌的相異解分別為 **13／60／16／14／38／24**。隨手亂拼多半拼不出來，要真的去挑末字。

## 八維配方

| 維 | 值 |
|---|---|
| **opening** | `serial-window-first` 連格窗直開場（新原型）——首屏即貼在玻璃上的今日窗：六格必須照序讀，全部營業資訊寫在格子裡，沒有大標 hero |
| **nav** | `paste-layer` 疊貼導覽（新原型）——四頁＝四張貼在同一塊玻璃上的紙條，現用頁那張貼在最上層、壓住其餘三張的角、多一枚圖釘。語意是層序 |
| **signature** | `impression-count` 刷次遞增——每一次瀏覽就是把這面窗再手刷一份，刷次跨頁累計並印在窗角，且決定這一份的套印錯位、吃墨漲量與缺刷位置 |
| **illust** | `stencil-cut pictogram` 模板刻版象形（新技法）——剪影／橋／錯位鬼影三種原語，二十二塊模板排完全站所有圖像 |

| **func** | 對句開窗（語言拼組＋韻律驗收，非模擬類） |
| **tech** | `feMorphology`（A）／Web Speech `speechSynthesis`（D）／`Intl.Segmenter`（E） |
| **era** | 1919–1921 的莫斯科，接到 1962 年起的基隆 |
| **locale** | 基隆愛四路・廟口市場後段 |

## 動效（四種）

1. **ambient**　日光掃玻璃（126px 硬邊光帶，24s 橫過整張紙）＋ 指讀棒每 3.2s 前進一格
2. **input**　指到哪格就讀哪格：該格翻洞白、指讀棒立刻跳過去（<100ms），ambient 暫停
3. **transition**　刷版 brush-pull：`clip-path` 由左而右 `steps(6,end)` 0.52s，三塊版 stagger 90ms
4. **signature**　刷次遞增 impression-count

四種皆備 `prefers-reduced-motion` 降級；降級後刷次照增、錯位與缺刷照樣不同（那是印刷差異不是動畫），
六格短句與上下聯本來就是可選取的一般文字，資訊零損失。

## 首創

**把「這是第幾份手工複製品」做成頁面本身的內容**（the page as a numbered hand-pulled impression）：
全館第一個站，其畫面差異不是「每次載入不一樣」的生成裝飾，而是**被計數的複製品序號**——
你是第 N 個把這面窗刷出來的人，N 印在窗角上，並決定了這一份的三塊版錯位、吃墨漲量與缺刷位置，
而頁面用整整一節文字明講這件事。附帶登記：全館 154 站中**第一個使用 Web Speech API** 的站，
且它不是配音效，而是這個流派的存在理由——ROSTA 窗是做給不識字的人看的，所以現場一定有人念，
本站把「念」交給瀏覽器，並讓語音的段落切換直接驅動畫面的閱讀動線。

## 風格血緣

既有流派，非自創。一九一九年二月起於莫斯科，Mikhail Cheremnykh 與記者 Nikolai Ivanov 在一家
空掉的糖果店櫥窗貼出第一面；Vladimir Mayakovsky 隨後接手寫了約九成的句子。
沒有印刷廠與紙，改用源自法國 pochoir 的模板手刷：刻版員第一天刷二十五張、第二天五十張，
幾天後滿約三百張，通常全家一起刷。一則前線捷報四十分鐘後就能貼上牆。
一九二一年 ROSTA 收攤後由 Glavpolitprosvet（GPP）接手一年。

產業配對取的是同一條線的下游：Mayakovsky 與 Rodchenko 的「Reklam-Konstruktor」（1923–25）
把這套手法從內戰宣傳轉用到國營消費合作社 Mosselprom 的日常廣告——
「除了 Mosselprom 哪裡都沒有！」本站就是那句話搬到基隆廟口。

## 去 AI 化檢查

- 零外部圖片、零音檔、零函式庫；外部資源僅 Google Fonts（Noto Sans TC、Archivo Black）
- 零漸層、零模糊陰影、零圓角（圖釘的圓除外）、零材質貼圖
- 無 hero 大標＋副標＋按鈕組、無三張圓角卡片、無跑馬燈、無視差、無淡入式滾動揭示
- 無 Lorem ipsum、無 emoji icon、無「EST. 19xx」徽章
- 四頁各自在關掉 JavaScript 時完整可讀：六格窗、六張事由牌全表、二十二塊模板圖鑑、
  價目與班表全部是靜態 HTML
