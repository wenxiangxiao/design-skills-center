**視覺家族**：F5 手工質材

---

## これは何か

黒漆の面に金粉を撒いてつくる蒔絵を、そのまま web の設計言語に翻訳した作例站です。
地色は「黒」ではなく**反射する面**で、光源は訪問者のカーソルそのもの。金は色ではなく**一粒ずつ撒かれた粉**で、
画面の 55％ 以上は何も置かれていない漆のままです。

核心機能は「**粉を蒔く**」——実際の工程どおり、五十秒で乾く漆を一枚渡されます。
下絵と粉を選び、湿っているうちに粉筒を振り、払う。**払ったあとに残ったものが作品**で、
残り時間は数字ではなく**面の艶そのもの**で示されます（乾くほど映らなくなり、粉も付かなくなる）。

## 技術（`tech`）

1. **原生 WebGL 片段著色器**（A 渲染層）— 圓筒法線＋Blinn–Phong＋付着量貼圖，承載特徵 1／3／4。無 WebGL 時退回建置時烘好的靜態 SVG。
2. **View Transitions API 跨文件**（B 動效層）— 被せ蓋の転場。Firefox 未対応のため漸進増強、非対応時は通常遷移。
3. **`writing-mode:vertical-rl` ＋ `text-combine-upright`**（C 版面層）— 銘・箱書・受付票の直排と縦中横。

## 首創

**乾いてゆく接受面を互動媒材とする**（a substrate that dries）——
使用者の入力は「空間に分布した落粉」であり、成果物は *落ちた場所 × その時点の湿り* で決まる。
そして「残り時間」は読み取り計器ではなく**面の光沢そのもの**であって、面が乾けば映らなくなり、同時に粉も付かなくなる。
時間は一度しか進まず、やり直しは新しい一枚になる。

## 五つの不可欠な視覚特徴（詳細は `SKILL.md` 第二章）

1. 鏡面黑地と単一の可動点光源（地色は黒ではなく「反射する面」）
2. 蒔粉——金は常に離散した粒であり、粒度と密度勾配を持つ
3. 平蒔絵と高蒔絵の二階（平らな金と、稜と実心の影を持つ金が同一画面に）
4. 螺鈿——直線で切った貝片、鋭い縁、光角で転ぶ干渉色
5. 餘白と切邊構図——紋様は偏心し器の縁で切られ、黑地 ≥55%、切金は一本の斜線上に
