## 〈猜線〉怎麼玩

畫面中央藏著一個字，你只看得到它最外面的回聲線。從四個字裡選一個；猜錯，線就往內退兩圈。五個字猜完，分數（滿分 15）換成同心券：13 分以上九折＋送一球、9–12 分九五折、其他送色卡。鍵盤 1–4 可作答。

## 技術

1. Felzenszwalb–Huttenlocher 歐氏距離轉換：字與物件的距離場（E 層）
2. Canvas 2D ImageData＋Uint32 查表逐幀上色：回聲線流動、游標合流、退圈（A 層）
3. CSS `@property <length>` 驅動 mask 半徑：同心環擦除轉場（B 層）
4. 無 JS／無 canvas 備援：建置時烘好的 SVG 疊層描邊
