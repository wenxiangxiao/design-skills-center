## 首創

**以圖像複雜度為代價的辨識（shape-budget identification）**：全館第一個把「我想再多知道一點」的成本直接寫成「畫面上多一塊形」的站——資訊量與圖像複雜度是同一個量，使用者買到的不是數值而是一塊看得見的造形。
並且，擬態被實作成同一組形的參數與疊序差異：六種蟲共用同樣九塊形，不新增、不刪除，只換位置、大小與誰疊在誰上面。

## 五個不可省略的視覺特徵

1. 極簡寫實：一個生物＝最少數量的平塗幾何形，只留分類學上的識別特徵
2. 零輪廓線、零投影、零漸層——深度全部來自兩塊色疊在一起相乘
3. 灰化的有限調色盤（五母色＋一記號色）＋一塊平塗的地色（不是白紙）
4. 質感只用等距的點與短線，且被身體外形裁掉、不跨越邊界
5. 幾何無襯線＋Girard 實心磚符號帶當分隔；圓角只有 0 或完整半圓，沒有中間值
