## 為什麼是這個配對

管委會公告是台灣都市生活裡**被影印最多次、被膠帶貼最多次、語氣最生氣**的一種印刷品。
它跟一九七六年那些在演唱會門口賣的影印刊物，用的是同一台機器、同一種紙、同一種火氣——
只是一邊在罵政府，一邊在罵沒有人繳管理費。

這座館裡已經有律師事務所、有市立圖書館、有調解委員會，但沒有人做過管委會；
而龐克剪貼在全館也是零站。把兩件都沒人碰過的東西放在一起，剛好互相解釋。

## 核心功能：排這次的議程

規則三句話，一輪約九十秒：

1. 從十二件住戶提案裡揀**三件**上議程。
2. 三件的經費合計不得超過公積金六十二萬元；規約列為**相斥**的兩件不得同次列入。
3. 按「開會」，四十一戶照名冊上的立場與到會習慣當場投票。

真正的機關在**分母**。到會規則是公開的：必到 9 戶每次都來；看議題 12 戶只要議程裡有他不是棄權的就來；
不到 20 戶只有議程裡有他反對的才會來——來投反對票。
所以你排的三件會決定誰出席，出席決定分母，分母決定門檻。
**排一件會惹人的案來把票衝高，很可能就是把自己另外兩件一起弄死。**
另一層是權利比例：一樓店面一戶 36‰，頂樓小坪數一戶 18.4‰，人頭夠了不代表權比夠。

窮舉全部 220 種三案組合實測：

| 結果 | 組合數 | 占比 |
|---|---|---|
| 相斥擋下 | 20 | — |
| 超出公積金擋下 | 3 | — |
| 一件都沒過 | 47 | 23.9% |
| 過一件 | 78 | 39.6% |
| 過兩件 | 50 | 25.4% |
| **三件全過** | **22** | **11.2%** |

出席 29–38 戶（中位數 34 戶），依本屆名冊任何合法組合都達開會額數，故不會流會。
單案通過率 12%–75%，沒有任何一件是穩過的，也沒有任何一件是死的。
結果可用 `?an=9-10-11` 分享還原，並可「貼進電梯」跨頁生效。

## 認領的首創

**介面的狀態＝材料的疲勞史（interface state as material fatigue）。**

全館第一個站，它的每一個介面狀態都不是被「加上去」的視覺標記，而是該元件**被複製了幾代**：

1. 這個站沒有 hover 底色、沒有現用色塊、沒有 focus 光暈、沒有 active 高亮。
   你翻開過的每一張紙，就是被多影印了一代——黑變胖、細線掉光、紙歪 0.9°／1.7°、
   左緣多一條沒蓋好的黑帶，右上角多一個「第 N 代」的鋼印。
2. 它是**累積的、跨頁的、不可逆的**（localStorage）。逛完四頁再回首頁，
   版面上最髒的那幾張紙，正好就是你自己讀最多次的那幾張——
   **這個網站最後會長成你的閱讀路徑的形狀。**
3. 復原的唯一辦法不在介面裡，而在敘事裡：到〈規約〉頁「向管理室索取新原稿」，全部重印。

與既有各站的差別：
與 `shidong` 的圖地反轉（同樣沒有高亮，但那是可逆的、瞬時的、與使用次數無關）不同；
與 `patchframe` 的訊號衰減（有隱藏真值待修復、劣化是待解的問題）不同——這裡沒有真值、沒有任務，
劣化不是問題，是紀錄；
與 `nayachand` 的載重壓吊（累積的是質量、被重算的是剛體姿態）不同——這裡累積的是**注意力**，
被重算的是**影像品質**；
與 `gatemark` 的不可逆工序（成本寫在報告裡）不同——這裡的代價直接寫在你正在讀的那張紙上。

## 三項核心技術

| 層 | 技術 | 承載 |
|---|---|---|
| A 渲染 | SVG `feMorphology` + `feComponentTransfer type="discrete"` | 一位元碳粉、細線掉光、第 N 代影印 |
| B 動效 | CSS `steps()` 逐格時間軸 | 掃描光棒（ambient）、抽紙（transition）——影印機沒有中間幀 |
| E 生成 | FNV-1a → mulberry32 決定性剪紙幾何 | 贖金字逐字參數、剪影撕邊與掉線；同輸入恆得同一張剪貼 |

全部支援度已於 2026-08-15 查證 MDN，fallback 行為與效能實測值寫在 [SKILL.md](SKILL.md) 第十二章。

## 四式動效

- **ambient**：掃描光棒 —— 9 秒一輪、`steps(46)`、掃完就沒了。
- **input**：hover／focus 預覽「再影印一次會變成什麼」＋膠帶翹角被拉開，無補間、<100ms。
- **transition**：抽紙 —— `clip-path:inset()` 以 `steps(6)` 從上緣一格一格吐出來。
- **signature**：世代磨損 —— 累積、跨頁、不可逆。

四種皆有 `prefers-reduced-motion` 降級且資訊零損失：世代由「第 N 代」文字標記表達，
現用頁由膠帶的實體差異（不透明、壓平、擺正、沒有翹角）表達，兩者都與動畫無關。

## 無 JavaScript 時

- `index.html` 的出紙疊以原生 `<details>` 實作，十二張公告全部可讀。
- 全站的贖金字在建置階段就以同一支函式算完、寫成靜態 HTML，沒有 JavaScript 也是完整的剪貼標題。
- `an.html` 的排議程需要 JavaScript，但頁面內明寫：四十一戶的立場、到會習慣與三級門檻全部靜態印在
  〈住戶名冊〉與〈規約〉頁上，**用紙筆算得出同一個答案**，算法三步驟印在該頁的 `<noscript>` 區塊裡。
