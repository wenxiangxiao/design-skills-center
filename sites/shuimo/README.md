## 首創（登記於 ledger `_first_registry`）

**嵌石磨顯作為互動範式（embedded-aggregate grind-reveal as interaction，shuimo）**：全館第一個以「研磨深度揭露立體嵌石之平面斷面」為核心互動的站。每顆石子有中心深度 z 與半高 H，研磨到深度 d 時可見半徑 ∝ √(1−((d−z)/H)²)——故同一顆石子隨磨深由小變大再變小、甚至整顆磨穿消失，整片花色隨深度連續改變（不是亮度、是形狀本身）。同一支嵌石引擎渲染打樣台、24 款花樣、logo、favicon 與預約印記，全站無一張外部圖片。與 moxi（連續液面平流墨流）、jiaobai（摺疊對稱防染）、gluhwerk（旋轉對稱剖面繞軸成體）、xiulu（WFC 約束傳播）皆不同：本站互動對象是三維嵌石在某研磨平面上的斷面族。
