# 八風號船釣 PAT-HONG × Portolan 海圖・一張皮

宜蘭頭城烏石港的船釣船家（虛構）。林添福船長三十年的針路簿只記三件事：從哪個港出、用哪一針、走幾浬。女兒林佩君照十四世紀地中海 portolan 海圖的規矩把它畫成一張皮——地名垂直海岸寫在陸地那一側、大港寫紅、海上只有從十七朵風花放出去的三色恆向線。

## 品牌設定

- **店名**：八風號船釣 PAT-HONG（船名取自《呂氏春秋・有始覽》的八風）
- **地址**：宜蘭縣頭城鎮港口里烏石港路 18 號・第 3 號碼頭〔門牌虛構〕
- **電話**：(03) 978-1987〔虛構〕・店面每日 03:30–19:00
- **出航**：半日近海 NT$1,600／全日外海 NT$2,800（13 歲以上）／夜釣小管 NT$1,500（5–9 月）／包船全日 NT$30,000、半日 NT$18,000；竿餌組 300。東北季風季浪高逾 1.5 m 停航。
- **人物**：林添福（1951–）1971 年上延繩釣船、1987 年買船、1993 年改娛樂漁船並開始寫針路簿；林佩君（1979–）2024 年接手訂位、畫成海圖。

## 首創

**轉皮讀字 turn-the-skin reading**：全館第一個讓「文字的朝向本身就是資訊」、而且必須把整張畫面轉過來才讀得順的站。22 個地名由建置期以海岸法向排字（垂直海岸、字尾貼岸），所以每段海岸的字朝向都不同；〈讀圖〉頁拖曳、方向鍵（一次四分之一個風 11.25°）或手機指北旋轉整張皮，字的螢幕角＝法向角＋旋轉角，轉到 ±28° 內就「站起來」加粗並記進已讀清單。搭配的簽名動效 **平行尺 parallel-rule walk**：選一個方向，一副銅色平行尺沿它的垂直方向掃過整張皮，17 條同向恆向線依等級顏色加粗——就是水手把方向從風花搬到船位的動作。
