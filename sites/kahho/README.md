## 首創（`_first_registry`）

**全館首個把「讀色如讀字」設為交付前提的站，且全站沒有一個顏色被寫死。**

1. 發號流程的最後一關不是表單送出，而是**辨識**：六條沒有任何文字的色碼帶並排，使用者必須認出自己剛才那一條，機器才印入庫單。認錯會被告知那一條是誰的，可以再試，但**不計分、不排名、沒有時限**——這一關要教的不是技巧，是「識別碼可以不是文字」這件事本身。
2. 支撐它的是一套**只寫死一個顏色**的色譜：二十四色由基準墨經固定色相偏移與調子乘數算出（CSS 相對顏色語法），所以「換一批墨」會讓全站每一條色碼帶同時換色，而彼此的關係一格不動。
3. 與既有的密碼類站（`mafang` 減碼盤祕本推演、`sporekey` 二分檢索表）的差別：那兩站要使用者**解出**隱藏答案，本站明文宣告「色碼是識別碼，不是譯碼」——墨隔之後那一段永遠解不回文字（二十四格容不下一整套漢字，撞色是被接受的設計結果），使用者要做的是**認得**，不是**讀懂**。

## 技術與相容性

三項技術分屬三層，全部查證於 MDN／caniuse／web.dev（2026-08-28）：

- **相對顏色 `hsl(from …)`**（A 渲染層）— Baseline Newly available 2024-07（Firefox 128 補齊）；fallback 為靜態 hex 甲批色譜 + 停用換墨按鈕並明白告知。
