SIMILARITY TRANSFORM一、套合的四個參數

把一張舊地籍圖套到今天的地面上，用的是二維相似變換：整張圖可以平移、可以旋轉、可以整體放大縮小，但不可以歪斜，也不可以局部拉扯。四個參數，兩個平移、一個旋轉、一個尺度。

x′ = a·u − b·v + Tx
y′ = b·u + a·v + Ty

其中　s = √(a²+b²)　為尺度因數，θ = arctan(b/a) 為旋轉角。(u,v) 是舊圖座標，(x′,y′) 是套合後的今地座標。

四個未知數，一個同名點提供兩個方程式（x 與 y），所以兩個點就解得出來——而且解得「剛剛好」，殘差必定為零。這正是危險的地方，見第三節。

加權最小二乘解

每個同名點可以給不同的權 w。權愈大，這一點對解的影響愈大；權為零等於不採用。閉合解如下（先求加權重心，再求兩個係數）：

ū = Σwᵢuᵢ / Σwᵢ　，　v̄ = Σwᵢvᵢ / Σwᵢ　，　x̄ = Σwᵢxᵢ / Σwᵢ　，　ȳ = Σwᵢyᵢ / Σwᵢ

a = Σwᵢ(Δuᵢ·Δxᵢ + Δvᵢ·Δyᵢ) / Σwᵢ(Δuᵢ² + Δvᵢ²)
b = Σwᵢ(Δuᵢ·Δyᵢ − Δvᵢ·Δxᵢ) / Σwᵢ(Δuᵢ² + Δvᵢ²)

Δ 表示各點與其加權重心之差。Tx、Ty 由重心回代求得。

套合台左欄的 0／1／3 就是這個 w。權重是人給的，不是算出來的——這件事本頁其餘各節都在講。

RESIDUALS二、殘差與中誤差

把解出來的變換套回每一個同名點，它落下來的位置與實測位置之間的差，叫殘差 vᵢ。殘差不是「錯誤」，是「這一組解沒有能力照顧到的部分」。

σ₀ = √( Σwᵢ·(vxᵢ² + vyᵢ²) / r )　，　r = 2n − 4

σ₀ 就是圖面右上角那個 ±xx cm。它的意思是：在這一組權重之下，一個同名點的位置大約有這麼多的不確定。它不是某一條界線的誤差，更不是某一戶的損失。

REDUNDANCY三、多餘觀測與可靠度

r = 2n − 4 叫多餘觀測數。它是「這組解裡面，有多少個方程式是多出來、可以互相檢核的」。

所以「只信四個老點」那一組不是本所的建議。它的 σ₀ 是 ±3.6 cm，四組裡最漂亮，但 r 只有 4——這張圖上幾乎沒有東西在檢核它。殘差小是因為沒有人反對它，不是因為它對。點少的解看起來比較有把握，那個把握是假的。

控制點的分布

除了數量，還有分布。若採用的同名點所圍出的多邊形（凸包）涵蓋不到測區的兩成，其餘範圍就是外插——外插區的界址位置沒有任何觀測在檢核。本所在外插區不作「越界／未越界」的判斷，成果圖以斜線標示，套合台也會直接拒絕請當事人到場。

PATTERNS四、殘差型態六類

殘差圖不是用來看大小的，是用來看形狀的。形狀會告訴你錯在哪一類，而錯的類別決定了要不要改用別的變換、或者去翻哪一份卷宗。

形狀成因處置
全部指同一邊整張圖平移：圖廓四角採錯一組圖根點，或複製時整張位移相似變換可完全吸收，界址相對關係不受影響
繞中心成環方位差：舊圖基準與今日座標系統的北方不同相似變換可吸收；但外圍位移量遠大於中心，須向邊緣地主說明
由中心向外放射紙張伸縮或複印縮放由尺度因數吸收；面積會一致偏差，見第五節
沿一軸規則變化局部歪斜：受潮變形、分幅描繪基線抓歪相似變換無法吸收，須改用仿射變換並於報告書載明理由
一根特別長粗差：樁被拔過、埋錯、或現場指錯點不是誤差是錯誤。剔除前必須有卷證支持，不得只因「它不合群」就剔除
被一條線切成兩半圖幅接邊差：測區跨兩張舊圖幅分幅處兩側分別套合，接邊帶另行協議

案卷室那二十四張縮圖就是照這六類畫的，可以拿來對照。

AREA五、面積為什麼會變

重測之後幾乎每個人的面積都會變，而且同一個街廓裡的人通常是一起變大或一起變小。原因不神祕：登記面積是當年照圖上的尺寸算出來的，而紙會縮。

和紙百年線性收縮　≈ 0.32%
面積為長度的平方　→　0.32% × 2 ≈ 0.64%

廣興段 21 地號：登記 209.78 m²　→　重測 211.11 m²　→　差 +1.33 m²（+0.63%）

這一點三平方公尺不是誰讓給誰的，它一直都在地上，只是紙上少算了。依地籍測量實施規則，這種情形辦理的是面積更正，不是土地增減，也不用繳稅、不用找補。

會吵架的從來不是這個。會吵架的是那條線離某人家的牆有幾公分。

ORDER OF DETERMINATION六、指界的順序

當地籍圖的線與地上的東西對不起來，法律有一套順序。土地法第 46 條之 2 規定，重測時土地所有權人未於期限內設立界標或到場指界者，地政機關得依下列順序逕行施測：

若當事人到場而無法達成協議，案件送不動產糾紛調處委員會；對調處結果不服者，得於接到通知後 15 日內向管轄法院訴請確定界址，逾期未起訴者，依調處結果辦理。

協議的效力與界限

  • 界址協議是當事人之間的合意，須全體到場、全體簽章；缺席者不受拘束，也不能用多數決通過。
  • 協議不得損害第三人（例如抵押權人、耕作權人）的權利。
  • 協議所定的界址若與測量成果不同，本所在成果報告書上兩者並列，不塗改觀測資料。

WHAT WE REFUSE七、本所拒絕做的事

  1. 同名點少於三點時不出圖。兩點解四參數，殘差恆為零。那個零不是精度，是沒有檢核。
  2. 控制不足的區域不作結論。凸包涵蓋不到測區兩成時，外插區的界址位置本所不宣稱，也不請當事人在上面簽名。
  3. 不以「不合群」為由剔除任何一點。要剔除，必須有卷證：工程接管清冊、施工紀錄、增建執照、或活著的人的證詞。純粹因為殘差大而剔除，等於用結論證明前提。
  4. 距離小於中誤差時，不說「未越界」。只寫「界線與構造物之距離小於本次測量之中誤差，爰依到場指界結果認定」。我們量不出來的事，不會寫成量得出來的樣子。
  5. 不在當事人缺席時決定界址。本所可以算到公釐，但那條線要不要成立，不是我們的權限，也不是最小二乘法的權限。
