# 樹厝客 TSHIŪ-TSHÙ-KHEH — 屋頂綠化工程行 × Hundertwasser 有機螺旋建築

新北三重的屋頂綠化工程行〔品牌虛構〕。創辦人潘玉枝焊了二十二年鐵窗花——三重的公寓每一戶都要不一樣的花樣——1992 年在雜誌上看到維也納那棟樹從窗戶長出來的公寓，才知道 Hundertwasser 早在 1958 年就把「住戶有權把自己的窗外漆成粉紅色」寫成了宣言。現在她把樹請進別人家的窗戶，叫它們「樹房客」。

## 核心功能〈樹房客入住〉

三句規則：點一扇空窗，再點一位樹房客；窗的樓層與方位決定日照和風——合得來，樹就用 L-system 從窗裡一段一段長出來、窗外暈開一臂的顏色，合不來它只長三成就垂頭，告訴你為什麼（例：「檸檬只受得了弱風，5 樓左窗是強風」）；住進三位，簽一張樹房客租約（FNV-1a 編號 TTK-XXXXX、樓層窗位、入住費合計與每月保養），帶到〈房客〉頁。約 40–90 秒一輪；可全程鍵盤操作（窗是 `role=button`，Enter／空白鍵）。
