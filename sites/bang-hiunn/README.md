## 核心功能：落牌檯（命名／登記型）

三句規矩：(1) 一張標只准一個物；(2) 兩罐墨，且不得與左右鄰居那兩枚用同一對；(3) 牌不得與該口岸已掛走的牌相同。
選物 → 選主版與色版 → 選口岸 → 送印。過了三關的牌直接落回本頁那一區的空格裡，並發一張〈牌號登記證〉。九十秒可玩完一輪，三個空格。

## 首創

**整版即資訊架構（uncut-sheet as information architecture）**——全館第一個站，其四個頁面不是四個版面，而是同一張未裁印刷版的四個裁切區：首頁顯示「還沒裁」的狀態（四頁的內容同時在場、同時可讀），內頁顯示那一區「被裁下來」之後的狀態，而兩者的套印偏移與裁切偏移由同一支決定論雜湊產生，因此對得上同一枚標。使用者不是在頁面之間移動，是在同一張紙上換一個裁切區。
