# 鐵門仔 THIH-MN̂G GATES

高雄市苓雅區光華一路 206 巷 9 號的鐵捲門行（1983 年起）：做鍍鋅捲門、換馬達、修彈簧，也在店家打烊、鐵門拉下之後，把整面門噴成店名 piece。只噴有同意書的門，一年內被亂塗免費補噴。
