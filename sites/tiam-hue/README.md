# 點火煙火 TIÁM-HUÉ FIREWORKS

臺南鹽水的煙火製造與施放，1961 年起。三代人：黃清水（1938–2009）做沖天炮與蜂炮炮城的炮管；黃志明（1962–）1984 年用二手 ZX Spectrum 48K 接八路繼電器點火；黃筱婷（1990–）2017 年考到爆竹煙火監督人員資格接手，秀單至今寫成 BASIC 行號。

- 地址：臺南市鹽水區康樂路 88 巷 6 號　電話：(06) 652-1984
- 店面 09:00–18:00・週一休；施放晚間依約；元宵前 14 天不接家宴
- 高空彈（每發）：牡丹 NT$650・柳 780・彗星 420・環 700・閃光 560・冠 880；施放基本費 NT$18,000
- 家用：仙女棒 NT$40・沖天炮一束 60・水鴛鴦 50・地面旋轉 80・噴泉筒 120・「36 發」組合 1,200

## 首創

**位址順序載入＋撞色計分（interleaved display-file load & clash scoring）**：全館第一個以真機記憶體模型（6,144＋768 位元組）模擬 ZX Spectrum 顯示檔、並讓圖像依真機位址順序（三分之一→掃描線→字元列、顏色最後灌入）載入、邊框同步磁帶條紋的站；煙火粒子寫進點陣時改寫所在 8×8 格的 INK，兩發不同色的星落在同一格就「撞色」——撞色格數被計算、成為〈今晚的單〉的勝負條件，放完以長曝光合成並讓撞色格 FLASH。與 tai-kiat（NES 16×16 三色方塊作為靜態版面法則）的差別：本站是即時粒子模擬中逐幀發生的撞色，被計數成勝負條件。另：全館第一個以 Spectrum 一鍵關鍵字（K／L 游標模式）為主要輸入的編輯器。
