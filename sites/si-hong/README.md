## 首創

**看起來一樣才算贏 apparent-match scoring**：全館第一個以「同時對比誘導模型」判定勝負的站——勝負不看兩個色號是否相同，而看它們放在各自的底上「看起來」差多少（OKLab：apparent = c + k·(c − s)，ΔE_OK）。第一題要讓同一張紙看成兩色（ΔE ≥ .20），第二題要讓兩張量起來差很多的紙看成一色（ΔE < .04），提示也由模型推出（「底越亮，中心越暗；底越暖，中心越冷」）。過關後的「色橋」把同一張紙剪一條鋪過去，模型說的錯覺當場被實物拆穿。
