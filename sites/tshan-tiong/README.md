## 首創

**一天就是一張 color script（color-script-is-the-schedule）**：全館第一個把 Mary Blair「同一張畫只換顏色＝換時辰」直接做成資訊架構的站——首頁同一張建置期 SVG 主畫以 CSS scroll-driven `view-timeline` 驅動 9 個 @property 顏色變數走過六張 color key；〈排一天〉的課表沒有時鐘、只有六段天色，活動卡是奶色底稿，放進哪段天色就被一把 42 根鬃毛的刷子遮罩刷上那個時辰；能不能放由規則引擎判斷（畫不畫得出那個天色、便當後不下水、年紀），並說出理由。
