## 動效（4 種，皆有 `prefers-reduced-motion` 降級）

1. **ambient**　三塊版各以不同週期（19s／23s／29s）漂移 ±0.17 使用者單位＝手工套印每一份都不一樣；缺墨斑以 `steps(5,jump-none)` 每 13 秒跳一組（模版印刷沒有中間態，所以不補間）。
2. **input-driven**　游標即刮刀：指到哪一格，那一格的墨就以 `feMorphology dilate` 肥一階（<100ms），移開後分四個 steps 退回。鍵盤方向鍵在六格之間移動刮刀。
3. **transition**　揭紙 lift-off：進頁時一張刷好的紙由下緣被掀走（`clip-path` + 2.4° 旋轉），露出頁面。
4. **signature**　**刷版逐張 pull-run**（全館唯一）：按「刷」，刮刀以 `steps(28)` 逐格橫過刻版台，一趟一張紙掉進紙堆，印樣的套印偏移逐張重算；越接近這張版的壽命上限，破掉的機率越高，破的那幾張當場畫叉抽掉。

## 首創（全館第一次）

**拓樸連通性作為創作的硬約束，且產出物的壽命由一個幾何量解出。**
使用者畫出來的東西會因為它自己的拓樸（有沒有浮島）而根本不成立；而它能存在多久（刷幾份就斷）由留紙的最細橋寬直接解出——耐久度是被算出來的，不是被評分的。

- 與 `foldpoint`／`shaft-eight`（引擎驗證一張表、一組摺線的結構合法性）的差別：那些驗的是「這個設計符不符合規範」，本站驗的是「這張紙拿去刷會不會自己解體」。
- 與 `rendong`（接縫可不可見，判準在觀看者眼裡）的差別：本站的判準在模版自己身上，跟誰看它無關。
- 與 `amkongtsiau`（一次手勢的統計量裁定美學條件）的差別：本站裁的不是美學而是可製造性，而且失敗是看得見的——浮島會掉下來、細橋會斷。
