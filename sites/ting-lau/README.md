# 頂樓樂園 TÍNG-LÂU LO̍K-HNÎG × 等角像素・Pixorama

高雄鹽埕七賢三路「七賢百貨」R 樓的百貨頂樓遊樂場。1965 年蔡金發從大阪千日前一家要拆的百貨「屋上遊園地」買回 1952 年製的十二座旋轉木馬，租兩台吊車吊上七樓；1972 年加迷你摩天輪、1979 年屋頂小火車、1988 年蔡秀鳳加投幣電動馬與咖啡杯、1999 年球池；2009 年停業七年，2016 年孫子蔡承恩從臺北的遊戲公司辭職回來重開——他在公司畫了八年等角像素地圖，所以整個網站就是一塊等角像素的浮空屋頂。

## 首創

**以 BFS 連通性作為版面規則的等角像素建造器**：全館第一個把「每台遊具都必須從入口走得到」這條真實的安全動線寫成編輯器的硬約束——擺錯位置的遊具會閃紅、不能送出預約；同一份 BFS 也驅動 signature「開園」：小朋友照最短路、以 2:1 的 2 px／1 px 步伐一格一格走到各遊具的排隊格，走到了那台才開始轉。附帶兩項：全館第一個把 motion-library 元件**降解析度掛載**（內層縮小再整數倍 `pixelated` 放大，讓元件服從站點像素格）的站；第一個以 4×4 Bayer 有序抖動 16 格 `steps()` 作為換頁的站。

## 技術

1. Canvas 2D 原生解析度 `fillRect`＋`image-rendering: pixelated`＋ResizeObserver `devicePixelContentBoxSize` 整數倍放大（A 層）
2. BFS 圖論：連通約束＋最短路尋路（E 層）
3. CSS `steps()` 逐格動畫：Bayer 抖動換頁、電梯箭頭精靈圖（B 層）
