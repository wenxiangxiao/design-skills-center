# 合順鈕釦行 HA̍P-SŪN

**鈕釦行（釦材批發・包釦加工・樣卡打樣） × 擬物設計 Skeuomorphism**

臺北市大同區太原路 138 巷，後車站鈕釦材料批發街上一間三代的釦料行（虛構）。
第一代李水木在 1968 年從迪化街分出來做制服釦，第二代開始收貝殼與角，現在由第三代李家瑋顧店。

全館第一個把**介面元件本身當成商品**的站：網站上每一顆可以按的東西，都是店裡真的在賣的一款釦子——
有料號、有號數（ligne）、有面材、有孔數、有單價、有庫存。
從樣卡上拆哪一顆下來，整站所有按鈕的**面材、厚度、按下去的位移深度與按下去的聲音**就同時換成那一顆。
按鈕的規格就是商品的規格，這不是比喻。

| **texture 質感** | 絨、卡紙、拉絲黃銅、貝母、玻璃、水牛角、棉線——每一塊面積都宣告材質 |

| **function 功能** | **包釦檯**：手作製造型互動（非模擬引擎、非量表）。90 秒可玩完一輪，規則三句話 |

### opening／nav／illust／mood／signature

- **opening** `cardboard-first` 樣卡直開場——首屏是一張實體鈕釦樣卡，24 顆用棉線縫在卡上，資訊印在卡的上下緣。沒有大標 hero、沒有標語、沒有按鈕組。
- **nav** `buttonhole-thread` 釦眼上線導覽——四頁＝卡上四顆釦，**現用頁那一顆是「已經被縫上去的」**（十字縫線、下沉 1.5px、落影收到 1px），其餘三顆只是放在卡上。語意是「被縫住／已裝上」。
- **illust** `material-strata` 釦材疊層構成——材質疊層／珠光虹彩帶／雙股棉線／壓印小字四種原語。判準：拿掉顏色仍讀得出幾孔、哪一層是面材、什麼針法。
- **mood** `felt-desk` 絨檯暖光——絨綠 34%／卡紙灰 24%／貝母 14%／黃銅 12%／墨 10%／鈷藍 ≤6%。光源固定左上 315°，**反射光**（不是 mankong 的透射光）。
- **signature** `material-swap` 換釦改介面——六個 `@property` 註冊屬性同時補間 520ms，逐元件 52ms 錯時，按鍵音色一併換。全館唯一。

### 四種動效

1. **ambient 珠光遊移**：14s 週期，只作用在會產生虹彩與折射的材質（貝殼、玻璃）；拉絲金屬的反光帶方向固定，樹脂、角與包布沒有光澤層，皆不動。
2. **input-driven 按下即凹**：85ms，位移 1×1.6px，內側亮暗邊上下對調，同步發出該材質的合成音。
3. **transition 翻面**：620ms `rotateY(180deg)`，看樣卡背面。
4. **signature 換釦改介面**：見上。

四種皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。

## 技術

| 層 | 技術 | 它在本站承載什麼 |
|---|---|---|
| A 渲染 | **CSS Houdini Paint API**（Blob URL 註冊 worklet，附全域 fallback） | 絨面纖維、卡紙紙紋、黃銅拉絲——以元件實際尺寸重算的不重複材質紋理。不支援時退回多層 `repeating-linear-gradient`，材質與明暗結構一致 |
| B 動效時間軸 | **CSS `@property` 型別化自訂屬性補間** | signature 的六個材質參數（面材／亮／暗／邊圈／厚度／光澤）平滑補間；沒有它換釦只會瞬間跳掉 |
| D 輸入感測 | **Web Audio 合成**（使用者手勢啟動、預設關閉） | 六種面材各一個即時合成的按下音色，零音檔 |

支援度查證、fallback 具體行為與效能實測值見 `SKILL.md` 第十二章。

## 認領首創

**商品即介面元件（product-as-widget）** — 全館第一個把「介面元件本身」當作可購買商品的站。
網站上每一個可按的東西都是店裡真的在賣的一款釦子，有料號、L 號、面材、孔數、單價與庫存；
使用者從樣卡拆哪一顆，全站所有介面元件的面材、厚度、按下位移與按下音色就同時換成那一款。

與 `yongzi-foundry`（訪客可接管網站的字形識別）的差別：那裡被接管的是視覺識別，元件本身不是商品、沒有料號與庫存；
本站的**商品目錄與介面元件庫是同一份資料**——買走一顆釦，就是買走這個網站的按鈕。
