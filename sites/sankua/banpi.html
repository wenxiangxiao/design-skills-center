RUN 02 ／ 板胚與圖庫

板胚．四張圖

店裡常備四張曬好的版。每一張都是三色分版——把游標移到圖上，三個版會分開給你看；滑開就對回去。分版是做出來的，不是效果：黑是輪廓與字，粉是最亮的那一塊，藍永遠在最後面。

板胚一律不上底漆。木頭的紋會從墨底下透出來一點點，深色墨看不出來，螢光粉看得很清楚——這是特色不是瑕疵，不接受的話我們可以先刮一層不透明白打底，加 NT$300。

三罐墨

RUN 01

黑 · 水性 · 不透明。輪廓、字、所有要讀得出來的東西。

RUN 02

螢光粉。CMYK 做不出來的那一種粉，只能絹印。必須走 43T。

RUN 03

鈷藍。永遠在最後面，永遠先刮或最後刮，看那天誰在。

粉疊在藍上面會變成一種爛掉的紫，我們叫它第四色。不是調出來的，是疊出來的——所以它只會出現在兩個版真的重疊的地方，面積由套準誤差決定。套得越準，第四色越細。
