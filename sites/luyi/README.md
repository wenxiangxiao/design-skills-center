## 認領的首創

**以即時聲音的響度統治整頁排版幾何（audio-reactive typography as the layout engine）。**

全館第一個站，**版面的字重與字寬是從喇叭裡來的**：六具程序合成的噪音機一響，`AnalyserNode` 每幀取回時域波形算出 RMS，直接寫成頁面上二十四塊自由文字的 `wght`（200–900）與 `wdth`（122→62）——聲音大，字就被壓窄壓粗；聲音一停，字回到力場算出來的基準值。

與 `tide-signal`（全館第一個有聲網站）的差別：那裡聲音是**輸出**，是氣氛與回饋；本站聲音是**輸入**，是版面幾何的一個參數。與 `qizhong`／`yoiwan-hanabi`／`shipai` 等以 Web Audio 發聲的站的差別：那些站的畫面與聲音是同一份資料的兩個並列表現，本站的畫面**由聲音本身的即時波形驅動**，而且被驅動的不是裝飾層，是文字排版本身。與 `baicaochun`（包絡熔字：使用者拖動手繪包絡，字被塞進去）的差別：那裡被改變的是一個靜態的幾何容器，改的人是使用者的手；本站沒有容器，字的角度與粗細來自一個連續向量場，而調變它的是一個沒有人在操作的即時訊號。

## 動效預算（四種）

1. **ambient**：鋁面反光帶 17s 掃過 ＋ 擬聲詞沿力線滑行（CSS Motion Path）
2. **input-driven**：拖曳時間軸上的菜塊 → 節目單的自由文字即時重排（rAF 節流，<16ms）；鋁片 hover 抬起
3. **transition**：斜刃推移 `clip-path` wipe（進頁與結果面板揭示，非淡入）
4. **signature**：聲場排版 tipografia sonora

四種皆有 `prefers-reduced-motion` 降級；降級後噪音機仍可播放、判詞與所有數值照常顯示，資訊零損失。
