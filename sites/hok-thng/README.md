## 首創

**會拾色的濕滾筒（wet-roller pickup blending）**：全館第一個「漸層不是 gradient，而是滾筒物理」的站——滾筒是一根 44 點的直軸，每一點各自帶色；滾過牆時把自己的顏色塗上去，同時從未乾的牆上拾回一點顏色，漆量遞減到三成以下會刷出斷紋。一帶一帶由上往下滾、每帶多沾一點白，天空的上濃下淡就自己混出來；藍裡沾一點朱會變成富士的深藍紫。併同：〈塗り替え〉以 position:sticky 讓歷年壁畫一層畫在一層上面。
