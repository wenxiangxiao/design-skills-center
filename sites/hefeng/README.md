## 五個不可省略的視覺特徵

1. 同心框，而且嚴格對稱（滾邊→外框→角塊→內框→中心菱形；四角必須同色）
2. 一塊布 = 一個顏色（零印花、零漸層、零陰影、零圓角）
3. 飽和的深色，而且**沒有白**（靛藍／酒紅／松綠／茄紫／芥末／青灰）
4. 壓線跨過所有拼縫，一針到底（每吋 8–12 針；拼縫在布之間，壓線在布之上）
5. 四邊一圈滾邊把它封起來

## 技術（ledger `tech`）

- **CSS Grid `subgrid`**（C 層）— 承載「縫必須對齊」。Baseline Widely available 2026-03-15。
- **SVG filter `feTurbulence` / `feDiffuseLighting` / `feMorphology`**（A 層）— 承載布面織紋與壓線浮凸；只用於 64px 循環貼圖與**永不改變**的壓線層，不對整頁即時套用。Baseline Widely available 2015-07。
- **`steps()` 作為全站唯一 easing**（B 層）— 針是離散事件，本站 CSS 裡沒有任何 `ease` 或 `cubic-bezier`。

## 四種動效

- **ambient** 曬被日影線（3px 實色亮線 26s linear 掃過整幅）
- **input** 色塊挑起 2px、一疊裡的被抽出 14px 並吐出讀數（`steps(2)`，<100ms）
- **transition** 掀被（`clip-path` 由下往上一列一列掀開，560ms `steps(9)`）
- **signature** **換布不換線**（新布沿縫份方向被推進去 220ms `steps(6)`，而壓線層一針不動）

四種皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。

## 本站首創

**不變層作為版面的座標系**（an invariant layer as the site's coordinate system）：全館第一個站，其畫面上有一層東西在所有狀態變化中一針都不動——換布、換色、換頁、修補，色塊全部改變，壓線層完全不動。它不是背景（背景會被內容蓋住），它壓在所有內容之上；它是使用者唯一無法直接編輯的層，只能透過「重新壓線」整段拆掉重走。既有各站的核心都是某一層被重算（排版幾何、分版、圖地、格子、顏色、姿態），本站的核心是**有一層拒絕被重算**——而它的固定性正是這門手藝的價值：壓線是最後才在整幅上走的，所以它證明了這些布確實是同一床被。這條規則同時是效能紀律（不變的圖層不需要重新光柵化）與功能的核心取捨（換整塊布＝看不出來的修法，代價就是剪斷那條線）。
