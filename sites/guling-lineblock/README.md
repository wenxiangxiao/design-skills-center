## 技術

1. SVG 零長度虛線點列（`stroke-dasharray:0 d`＋圓端點）
2. `:has()` × checkbox 的 CSS 狀態機＋CSS counters（無 JS 也能落墨）
3. 同一份貝茲資料 → path／clipPath／覆蓋格審查／`shape-outside: polygon()`
