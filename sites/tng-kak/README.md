# 轉角油漆 TŃG-KAK

嘉義市西區光彩街 212 號的油漆行，1972 年開店：刷白牆、賣調色漆，也把一條三色帶從這面牆拉過轉角、一路拉到地板上。

- **產業**：油漆行兼色帶大圖施工（白牆粉刷 NT$750／坪・色帶大圖 NT$520／㎡・展開圖放樣 NT$1,800／面・轉角對線 NT$800／角・調色漆 NT$420／L・週六「一面牆」工作坊 NT$1,200／人）
- **人物**：吳金水（1943–，創辦人）、吳佩真（1979–，店長・展開圖設計）、林志明（1968–，施工領班）、黃秀蓮（1950–，調色櫃台）
- **電話**：(05) 222-1972・週一至週六 08:00–18:00（調色到 19:30）・週日與國定假日休
- **風格**：超級圖像 Supergraphics（Barbara Stauffacher Solomon，The Sea Ranch 1966；C. Ray Smith 命名，*Progressive Architecture* 1967-11）

> 店名、人物、地址、電話與價格皆為虛構示意。

## 風格關鍵字

一個平面裝不下・過牆角・平行色帶 3:1・同心四分之一圓弧・被裁掉的巨字・箭頭與大圓・白牆＋三色＋紅杉＋水泥・零漸層零陰影

## 八維配方

- **era 時代**：1966 Sea Ranch × 1972 嘉義 × 2026
- **locale 地域**：加州 Sonoma 海岸 ↔ 嘉義光彩街
- **voice 性格**：老油漆師傅的短句與規矩（「只待在一面牆裡的叫壁畫」）
- **texture 質感**：乳膠漆平光、遮蔽膠帶的硬邊、紅杉木、水泥地
- **density 密度**：低——大片白，資訊集中在一塊面板
- **function 功能**：〈拉一條〉空間繪製工具＋材料估價＋預約（非模擬儀器台、無量表、無連續參數滑桿）

## 首創

**跨面投影引擎 net-to-room projection**：全館第一個「一份展開圖座標的圖形，以多個 SVG viewBox 視窗同時投影到 CSS 3D 房間各面」的站——牆角處的連續由幾何保證；同一份資料再以 Canvas 逐像素分色歸面，算出每面每色的平方公尺、漆公升數、被牆外切掉的面積與「是否真的過了轉角」，把超級圖像的定義（大到單一平面裝不下）變成可驗證的規則。附帶：**捲動驅動的 3D 房間鏡頭轉身**作為首頁簽名。
