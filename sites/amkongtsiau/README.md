## 這是什麼

一個六個人、一頂黃帆布帳篷、兩百一十個木長凳座位的團。一年只做一檔新戲。
團長林貞儀一九九〇年代在華沙美術學院的海報工作室待過五年，回台開團時把那裡的規矩一起帶回來：
**海報不准畫馬戲團。**

這是波蘭海報學派的本體。一九五〇到八〇年代，波蘭的電影與馬戲海報由畫家而不是廣告公司做——
Tomaszewski、Świerzy、Cieślewicz、Lenica、Młodożeniec 替國營的 Cyrk 畫了近三十年，
上百張馬戲海報裡幾乎找不到帳篷、找不到明星、找不到節目表。
這個團把那套規矩寫成門口的四條，二十七年沒有改過。

## 核心功能：一筆成海報

規則三句話：**選一個節目。在紙上畫一筆。師傅照團規四條驗，過了就上版。**
一輪約九十秒。

| 團規 | 量的是什麼 | 門檻 |
|---|---|---|
| 一・海報不准畫馬戲團 | 寫在每個節目的禁畫清單上，是設計約束不是判分項 | — |
| 二・一張海報只准一筆 | 筆離紙的次數 | 0 次 |
| 三・一筆要有輕重 | 筆壓第 85 與第 15 百分位的比值 | ≥1.9 |
| 四・紙要留白 | 沿骨架積分的墨覆蓋率 | ≤34% |
| （長度） | 筆跡長度 ÷ 圖像區短邊 | ≥0.55 |
| （偏心） | 筆畫重心距版心的距離 ÷ 短邊 | ≥0.075 |

通過後，那一筆同時決定四件事：構圖軸（主成分方向）、鉻黃撕邊色域的形狀與大小、
飛沫的密度與落點、以及標題的筆型（拉丁字的骨架用你自己的筆去描）。
成品可以另存 1000×1180 的向量 SVG、可以用 `?s=` 分享碼還原、也可以貼到首頁的牆上（localStorage）。
用觸控筆會讀到真正的筆壓與傾角；用滑鼠或手指時改以移動速度反推（慢＝重、快＝輕），介面會誠實說明現在用的是哪一種；
沒有指標裝置時，「請師傅代筆」按鈕以決定性合成手勢走完同一條流程。

## 動效預算（四種）

| 類 | 內容 | 降級 |
|---|---|---|
| ambient | 探照燈掃過胭脂牆面（26s，`mix-blend-mode:screen`，只照牆不照紙） | 停在定點靜止 |
| input-driven | 筆下即墨（<100ms 出墨）／海報 hover 時四塊版即時分離 3px | 分離即時切換，狀態仍成立 |
| transition | 上版 plate-on（Web Animations 群組時間軸，五塊版依序落定） | 不播，直接是最終畫面 |
| signature | 落筆即成版 stroke-to-plate | 直接呈現成品 |

四種都有 `prefers-reduced-motion` 降級，降級後資訊零損失。

## 破格與保底

- 沒有 JavaScript 時，首頁與節目頁的海報是建置階段就算好的靜態 SVG，全部文字資訊是可選取的 HTML；
  歷年海報牆改為完整的年份、劇目與繪師清單。
- 導覽在 ≤900px 攤平為底部四格橫列，頁尾另備完整文字連結。
- 圖像容器有 `role="img"` 與說明，導覽有 `aria-current`，驗收結果為 `aria-live` 區域。
- 零外部圖片、零音檔、零函式庫；外部資源只有 Google Fonts 兩個家族。
