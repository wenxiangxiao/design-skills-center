## 首創（已登記 ledger `_first_registry`）

**耦合振盪子群體的節奏牽引（Kuramoto 同步）作為互動範式**：使用者唯一的輸入是「什麼時候擊鼓」——時刻本身就是全部訊息。二十名槳手是各有固有頻率、跟從增益與技巧值的自主振盪子，被控制的變數不是任何個體，而是群體的序參量 R（推進力 ∝ R²）；一次變速超過 10% 的牽引窗即逐人擲骰跟丟。R 是逐幀量出來的，不是演出來的。
