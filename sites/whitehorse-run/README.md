## 首創

**設計空間被完整窮舉並可步行——使用者的作品不是被評分，是被定位（exhaustive, walkable design space as the feedback surface）。**

十二塊、每塊兩態，全部的可能是 2¹²＝4,096 種，小到可以一種一種算完。
本站在頁面載入時當場窮舉一次（實測約 7ms），因此製版檯不必猜、不必打分數、不必給星等，
它直接知道每一種塗法的下場：

1. **你的版被放進一個已知的空間裡**——4,096 種塗法中有 494 種（12.06%）通過四條律，
   你這一版是不是那 494 之一、卡在哪一條、以及**離最近的合律版差幾塊**（漢明距離），都是確定的答案。
2. **鄰居可以直接走過去**——十二個「翻一塊就到」的版全部畫在頁面上，合律的那幾個框起來。
   使用者不是在盲目試誤，他是在一個圖上走路。
3. **規則不是隱藏真值**。四條律連同各自的門檻、量法、正反例全部印在站上，
   使用者可以自己驗算，也可以刻意違反——工房照印，只是不收進票籍。

與 `nayachand`／`whitehorse-run`／`rendong` 等站把窮舉結果當成帳本上的一個統計數字不同，
本站把窮舉本身做成回饋介面：那個數字不是拿來說服人的，是拿來走的。

## 動效四式

| 類 | 名稱 | 說明 |
|---|---|---|
| ambient | 燭焰不定 ＋ 塵的位移 | 三枚燭焰以 9.7／11／13.4 秒互質週期 `steps(1,end)` 逐格跳動（連續補間會產生中間值，中間值就是灰的時間版本）；那一叢點 34 秒一輪整體位移 ±3px |
| input | 端點鼓起／刻線浮現 | 導覽端點 90ms 由 1 放大到 1.9；版上區塊 hover 浮現孔雀色虛線刻線，延遲 <100ms |
| transition | 刀口推移 | `clip-path:inset(var(--wipe) 0 0 0)`，100%→0%，460ms 硬邊、無淡入 |
| signature | **墨吞 mass-swallow** | 全館唯一。hover／focus 任一黑塊，該塊沿輪廓外長 3.4%（340ms），緊鄰的髮線細節被**覆蓋**而非淡出；黑塊與遮罩共用同一個 `@property` 變數，故圖地邊界永遠同步 |

四式皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。

## 可用性保底

* 四頁的圖版皆在建置階段以同一支引擎輸出成靜態 SVG 寫進頁內，**關掉 JavaScript 仍是完整的票**；
  律文、讀數、票籍二十四張、違例對照、委託單與工房資訊全部是一般 HTML 文字，可選取、可搜尋。
* 製版檯的十二塊除了在版上直接點，另備十二顆有名字的按鈕（鍵盤、觸控、讀屏皆可操作），
  版上的每一塊也是 `tabindex` 可聚焦的 `role="button"`。
* 委託單在無 JavaScript 時不當場核對，但五條核對規則完整印在同一頁，人工收件用的是同一套。
* RWD：≤900px 導覽攤平為頂部四格橫列並保留「現用態＝墨底反白」；≤560px 圖版改兩欄。
