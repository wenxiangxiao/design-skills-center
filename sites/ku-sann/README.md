### 五個不可省略的視覺特徵

1. 標題被切開、被切斷、被丟到版面上另一個不相鄰的位置
2. 一頁上至少三個閱讀方向，而且每個方向都載真內容
3. 影印世代：1-bit，沒有灰、沒有網點、沒有漸層，且畫面上寫得出「第幾代」
4. 頁碼比標題大，而且不照順序
5. 零方框、零圓角、零陰影；元素靠重疊與切斷定位，唯一的線是撕開的紙邊

## 開場・導覽・動效・插畫・氛圍

- **opening**：`spread-first` 對開內頁直開場——首屏不是封面也不是刊頭，是一本已經翻到中間的內頁
- **nav**：`stack-top` 疊壓層序導覽——四頁＝四張互相重疊的紙，現用頁那一張**在最上層**（不是被高亮）
- **signature**：`bleed-carry` 出血接續（全館唯一）
- **illust**：`xerox-blowout` 影印爆掉圖版——單一門檻的等值線，只有純黑與紙色兩個值
- **mood**：`toner-grime` 碳粉髒底（`#D6D2C4` / `#14120E` / `#EEFF00` / `#6E6B60` / `#E5007E`）
- **motion**：碳粉浮塵（ambient）／再印一次（input）／壓稿條 platen-wipe（transition）／出血接續（signature），四種皆有 `prefers-reduced-motion` 降級且資訊零損失

## 核心功能：換一件（約九十秒）

三句話：**一、描述你要投的那件。二、投進三號櫃。三、櫃子還你一件別人的——你不能挑。**

- 換值 ＝ 類型（外套 5／褲 4／鞋 4／上衣 3／裙 3／包 2）＋ 狀態（九成新 +3／堪用 +1／有痕跡 0／破了但補得起來 −2）＋ 年份（1990 以前 +3／1990–2009 +1／2010 以後 0）＋（有寫來歷 +2／沒寫 −2）
- **換值只決定你抽得到哪一帶，不決定你抽到哪一件。**候選 ＝ 庫存中換值差 ≤1 的（不足三件才逐級放寬），再由 FNV-1a → mulberry32 決定性抽出。實測：換值分佈 2–12、候選 6–16 件（中位數 13）、6000 次抽樣涵蓋全部 36 件。
- 唯一的退件條件：**不能穿**。不能穿的不退回給你，直接進補丁桶，你拿到的是修補單而不是換衣單——這不是失敗，是另一條出口。
- 不給分數、不給星等、不排名。你拿到的是一張換衣單和前一位持有人的一句話。
- 可用 `?x=` 網址還原（同碼恆得同件）；可把自己投的那件貼到「本期 31」的牆上。

## 認領的首創

**被切開的標題，且「完整可讀」是一個要靠互動去換取、放手就失去的暫時狀態**
（split headline / legibility as a temporary, earned state）

全館第一個站，其標題在版面上不是一段連續的字：每一個大標都被拆成兩截，分別長在版面上兩個不相鄰的容器裡，由一條共用的時間軸維持「它們是同一行」這件事。壓住任一截，兩截在五格之內併成一行；放開就散回去。

與既有各站的差別：

- 與 `mafang`（密電待譯：內容被加密，解出後永久可讀，且另有靜態明碼保底）不同——本站沒有加密、沒有待解，文字全程都在畫面上、可選取、可被螢幕閱讀器讀成完整一句；被換取的是**視覺上的合一**，不是資訊的取得。
- 與 `baicaochun`（熔字重排：字被擠進一條可拖的手繪包絡，但字始終是一行）不同——本站一個字的造形與字距都沒有被改，改的是**它在版面上被放在哪裡**。
- 與 `luyi`（聲音響度統治字重字寬）不同——本站的字重、字寬、顏色全程不動，動的只有位置，而且驅動它的是使用者的手不是訊號。
- 與 `khoaibeng`／`yongzi-foundry`（揀字成本、字骨架合成）不同——本站不生產字、不量測字。
