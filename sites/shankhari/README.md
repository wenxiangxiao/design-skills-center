## 核心功能：〈নাম-পাঁচালি〉名紋口訣檯

規則三句：**盤上會出現一條刻紋。從四個名字裡挑出它的名字。挑錯會把兩條並排給你看，然後繼續下一條——一共八條。**

八題約七十秒。答錯時把「你挑的那一條」與「正確的那一條」並排、各自附上它的一句判準（例如「魚骨：中線不刻——中線是留下來的骨」），所以錯一次就學會一次分辨。結束給 `কাঁচা হাত` 生手／`দোকানি হাত` 櫃檯手／`ওস্তাদ হাত` 師傅手三級。

非模擬引擎、非調參數、非量表：它要你**盯著那張畫看**，而那正是本風格要賣的東西。十二名紋的完整圖鑑永遠靜態地印在同一頁下方，關掉 JavaScript 一條也不少。

## 認領的首創

**形自解的光心**：全館首次讓插畫**每一個形的暈染亮核與半徑，由該形自己的最大內接圓（pole of inaccessibility）解出**，而不是由設計者指定、也不取外接矩形中心或質心——對本站大量使用的弧形與新月形（螺鐲、刻紋帶），質心與 bbox 中心都落在形的**外面**，暈會整個放錯位置。

（與 `po-khang` 的分界：那一站也用過最大內切半徑，但用途是「在釉域裡塞得下多大的文字矩形」，屬於版面排字；本站用它決定**顏料的明暗中心**，屬於渲染，而且是全站每一個形都經過它。）

## 技術（tech）

1. **（E 資料與生成層）自寫「脹縮輪廓 ＋ 形自解光心」雙輸出引擎** — 承載特徵 1 與 2。建置期跑完寫死成靜態 SVG，頁面端零幾何計算；101 個形一次產生 122 ms。
2. **（A 渲染層）`feComposite operator="arithmetic" k1="1"`** — 承載特徵 3：暈與紙色逐像素相乘，紙的溫度從每一個顏色裡透出來。MDN 標示 Baseline Widely available。
3. **（B 動效與時間軸層）跨文件 View Transitions（`@view-transition{navigation:auto}`）** — 承載轉場：四頁是同一張紙被帶到下一張工作檯。Chrome/Edge 126+、Safari 18.2+；Firefox 穩定版未開，不認得即忽略、退為普通導覽。

支援查證、fallback 具體行為與效能實測值，見 `SKILL.md` 第十二章。

## 四種動效

| 種類 | 名稱 |
|---|---|
| ambient | 〈রাং ধরা〉錫上一條硬邊亮帶每十三秒走過一次 |
| input-driven | 〈আর এক পোঁচ〉hover 即「再上一道」：暈整組換深（70ms）＋輪廓換成 1.42 倍寬那一條（0ms） |
| transition | 〈পাতা ওলটানো〉跨文件 View Transitions ＋ 題目切換的 260ms clip-path 抹過 |
| **signature** | **〈চার হাত〉四隻手**：畫分四層依序放上——রেখা 線（由左）→ ভাঙি 暈（由上）→ রং 色（由右）→ রাং 錫（由下），每層 420ms、間隔 180ms、零淡入 |
