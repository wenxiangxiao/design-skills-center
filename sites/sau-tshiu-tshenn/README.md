# 掃帚星洗車 SÀU-TSHIÚ-TSHENN

高雄市苓雅區三多一路 288 號的翹屋頂洗車場。1969 年，洪天助照一張洛杉磯咖啡店明信片焊出一片左低右高的斜屋頂，招牌是一顆星拖一把掃帚。隧道機洗 NT$250 起、手洗 NT$450 起、自助投幣格 24 小時十元一枚；招牌每晚在高雄日落前十分鐘自動點燈。
