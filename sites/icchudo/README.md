# 一炷堂 ICCHŪDŌ — 香道教室／組香席 × 源氏香紋風

架空在台北市大同區赤峰街 63 巷二樓的聞香道場。核心是一場**真的可以坐的源氏香之席**：五炉香依序焚，一炉只聞一次，靠記憶判斷哪幾炉是同一味，答案畫成源氏香之圖，對照五十二紋中的一紋。

## 這個站在做一件別站沒做過的事

網頁送不出氣味，所以本站不假裝送得出來。它改用**整個頁面的樣子**當作那一味香——按下聞香，這一頁的暖度、顆粒粗細、呼吸快慢與煙筋條數同時位移成那一味的樣子，六秒後散去，爐上結灰，不再打開。

選擇「頁面本身」而不是一張圖，理由只有一個：**圖可以並排，頁面不行。**你不可能同時看到這一頁的兩個樣子。於是視覺被迫變得跟嗅覺一樣——一次只來一個，過了就只在記憶裡。組香真正的難處（拿「現在」去比「記得」）被完整保留下來，而不是被畫成插圖說明。

答え合わせ是全站唯一把五炉並排的時刻：先失去，才給你看見。

## 首創（全館第一次）

**不可並列的感官狀態作為互動範式：頁面自身的渲染狀態即被記憶與比對的對象，且系統刻意拒絕讓兩個狀態同時存在。**

配合的第二件事：**集合分割（貝爾數 B₅＝52）作為答案空間與全站唯一圖像引擎**——使用者的答案不是一個數值或一段序列，而是「五個位置的一種分割」，恰好 52 種；同一支引擎把分割渲染成 logo、favicon、圖鑑 52 紋、記録紙上的即時答紋與留席票印記，全站沒有一張「畫」的圖。

與既有館藏的差別：`qizhong` 的互動對象是排列群與其生成集（換序、可鳴奏），本站是集合分割（同異、不涉順序）；`gatemark` 的不可逆發生在「動作與其代價」，本站的不可逆發生在「知覺本身」——你沒有做錯任何事，只是那六秒過去了；`patchframe` 的頁面劣化是待修復的故障且校正值持續生效，本站的頁面變化不是故障、不需修復、也不會留下。

## 技術

單檔 HTML（CSS／JS 全 inline）、原創 inline SVG logo 與 favicon data URI、零外部圖片與音檔、零 3D 與零函式庫，外部資源僅 Google Fonts（Shippori Mincho／Noto Serif TC／DM Mono）。煙筋為 canvas 即時繪製，`prefers-reduced-motion` 時退為靜止圖且判定不變。色覺線索不只顏色：每一味香的煙筋條數（2–5 筋）、呼吸週期（4.4–10.2 秒）與顆粒粗細皆不同，另有高對比開關。

出現率為實算：五種香木各五包共二十五包，取五包依序焚，某紋機率＝ P(5,味數)×Π P(5,各味包數)÷P(25,5)（五炉全異 5.88%、五炉全同 0.0094%，52 紋機率總和為 1）。
