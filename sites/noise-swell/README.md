## 核心功能：〈讀版〉

規則三句話，約九十秒：

1. 下面是這一期的跨頁，它被美編處理過。
2. 題目問你一件事，答案就印在那張跨頁上——**點它**。
3. 每答對一題，整本就再被影印一次，下一題更難讀。找不到就按「求救」，它會退回一代。

五題。不計時、不給分數。結果不是分數，是一句「你在第幾代還讀得到東西」。
沒有指標裝置也能玩：每題下方常駐一排六個候選詞，鍵盤可完成同一輪。

## 首創

**以介面自身的可讀性作為對抗性難度旋鈕**（legibility as an adversarial difficulty knob）：全館第一個因為使用者表現太好而**主動變得更難讀**的站，而且變壞的是整個網站（四頁、`localStorage` 持久），不是一個遊戲區塊。

## 無 JavaScript

四頁全部內容皆為靜態 HTML，版面的瓦解、疊層、出血與裁切在建置期就寫死。世代停在 0，遊戲不能玩，`<noscript>` 直接印出五題的答案。破壞是增強，不是前提。
