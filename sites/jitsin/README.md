## 核心功能：型版指派

規則三句：一、挑一份電報（內容已定，六件事不能改）；
二、每格挑一塊型版來演那件事，抽屜裡有的不用錢，沒有合的就現剪一塊（＋7 分鐘）；
三、**同一塊版在這扇窗裡只有一個意思**——兩格講同一件就用同一塊，兩格講不同的就不能共用。

開窗後給的不是分數，是一張工房的帳：現剪幾塊、重用幾次、用了幾塊版、刷幾遍色、工時，
以及**這扇窗最少要剪幾塊**——後者由「意 × 型版」的二分圖最大匹配算出：

> 最少現剪塊數 ＝ 相異的意的個數 − 最大二分匹配數

窮舉四份電報全部 2,124 種組合：合格 1,584 種（74.6%）；剛好剪到最少的只有 78 種（3.7%）。
其中電報 №216 的最少剪版數是 1——「桶要站正」與「鋼瓶」都只有 K02 演得出來，
「桶橫著放」只有 K12 演得出來，而 K12 雖然也演得出「鋼瓶」，它已經被佔走了。
這不是設計出來的難關，是型版庫的結構決定的。

## 認領的首創

**「取代」不存在於這個介面**（no-replacement interface：every superseded state stays on screen and is peelable）。
換頁不是換內容，是把新的一張紙貼到玻璃上；開窗、退件、回執，全部是再貼一張。
沒有任何一張被移除——被蓋掉的那些的邊緣永遠露在畫面上，游標或鍵盤移過去可以把角掀起來讀完，
而玻璃的厚度（層數）本身就是使用時間的可見指示。

與 `gatemark`（不可逆作為互動範式）的差別：那裡不可逆的是**紀錄**（append-only 的工序卷、無撤銷），
畫面本身照常被更新；本站不可逆的是**畫面**——舊畫面沒有離開過，它在下面。

## 四種動效

- **ambient**：街上的日光斜帶掃過玻璃，`steps(14,jump-none)` / 42s；另有套印錯位漂移 `steps(4)` / 17s。
- **input**：掀角 peel。滑鼠或鍵盤移到被壓住的紙邊，那張紙抬起 8–9px 並轉正，90ms，延遲 <100ms。
- **transition**：貼新蓋舊 slap-on，`260ms steps(3,jump-none)` 播一次。
- **signature**：累貼 paste-accretion。

四種都有 `prefers-reduced-motion` 降級且資訊零損失——特別是掀角在降級後**照常作用**
（那是控制項不是動畫），累貼是結構所以完全不受影響。
