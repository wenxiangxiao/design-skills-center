# 向陽蜂學所 Sunward Apiary

> 一座把「讀舞」當成主課的觀察蜂場。蜜蜂在漆黑蜂箱、直立的巢脾上跳搖擺舞，用直行段的角度講方位、用擺尾的時長講距離。這裡的首頁不是介紹影片，是一隻正在跳舞的偵察蜂——你把她的舞讀成田野座標，或反過來替一朵花編一支正確的舞，再派工蜂出巢看牠們找不找得到。

## 頁面

1. **index.html — 舞台**：waggle-first 搖擺舞台直開場。首屏即一面直立巢脾上正在跳舞的偵察蜂＋一具依當地時刻定位的太陽羅盤。核心功能＝**雙向換算（試算/計算器）**：
   - **解舞 DECODE**：拖直行角度＋擺尾時長（或拖巢脾上的直行段）→ 讀出花叢方位（含十六方位名）與距離，田野羅盤標出花叢與太陽。按「派 14 隻工蜂」看牠們帶著天生散布飛出去、計命中率。
   - **編舞 ENCODE**：拖花叢方位＋距離（或直接拖田野地圖）→ 算出此刻該跳的角度與擺尾時長，蜂就跳給你看。拖「當地時刻」→ 同一朵花的直行段自己旋轉，這就是太陽補償。
2. **fa.html — 舞法**：不需 JavaScript 也能完整閱讀的原理頁。8 字結構、角度＝對太陽方位、時長＝距離的換算表、太陽補償、圓舞 vs 搖擺舞、蜂種差異與教學近似聲明；附兩張由同一套原語畫成的靜態舞圖。
3. **mi.html — 蜜源**：枕頭山南麓 5 公里內的蜜源圖鑑（**資料庫查詢與多條件篩選**）。22 種蜜源，可依花期季節、距離帶、蜜源型（流蜜／花粉／兼具）與名稱交叉篩選、即時計數；每一筆都附上偵察蜂正午時該跳的那支舞。
4. **ru.html — 入所**：讀舞課程與觀察箱共學的**多步驟報名（含驗證）**。選場次（含餘額、額滿鎖定）→ 留資料（稱呼 ≥2、手機 `^09\d{8}$`、Email 選填格式、人數 1–6）→ 生成 `FY-YYMMDD-NNN` 留位號與一支由資料雜湊決定的專屬舞印。
