# 芳路調香所 PHANG-LŌO × 地鐵路線圖風 Schematic Transit Diagram

臺北大稻埕歸綏街的調香所。一九五三年陳添福在這裡收苗栗的香茅油與樟腦；孫子陳以恆在倫敦當調香學徒的兩年，每天在 Piccadilly 線的車廂裡看同一張 Harry Beck 式路線圖，回來後把店裡二十四罐臺灣香材照那個規矩重排：每條線是一個香調家族，同一種香材出現在兩條線上就是轉乘站，淡水河是酒精。整個網站就是這張圖——沿線搭三到七站，就是一瓶香。

> 店家、人物、門牌、價格與電話為虛構；大稻埕、歸綏街、捷運大橋頭站、北門站、淡水河與各香材產地為真實地名。地圖畫法向 Harry Beck 1933 年倫敦地鐵圖與 Vignelli 1972 年紐約地鐵圖致意，未使用任何交通機構的標誌或字體。

## 首創

**乘路即配方 ride-as-formula（以拓撲路徑為產品配方）**：全館第一個把「在一張八向拓撲圖上走出的一條合法路徑」直接當成產品配方的站——路徑的前／中／後段就是香水的前／中／後調；結果不是一張表，而是以**斜接平行偏移（parallel offset）**沿既有線並行鋪出的一條新線，並以 Web Audio 依每一段所屬線的音色奏出發車旋律。附帶：全館第一個地鐵路線圖（Beck／Vignelli）流派站；第一個以「車廂路線燈條」標記現用頁、且燈條上的小車會從上一頁滑到本頁的導覽〔car-line-strip〕。
