# 泥仔湯 NÎ-Á THNG × Bògòlanfini 泥染布

臺南白河關子嶺的泥漿溫泉湯屋。一九八七年阿滿姨開店；女兒林佩君二〇〇四年在馬利巴馬科學了 bògòlanfini，現在每位泡湯的客人都裹一條泥染腰布下池。整個網站就是一幅布：泥沿著筆序一格一格塗上背景，店名、營業狀態、價目和地圖上的路，全是泥繞過去、留下來的白。

> 店家、人物、價格、電話與門牌為虛構；關子嶺泥漿溫泉、白河蓮田、水火同源與馬利 Beledougou 地區的 bògòlanfini 為真實背景。

## 原型

- opening：`resist-cloth-first` 負染布開場（首屏就是一幅正在被塗泥的布，資訊是泥塗不到的地方）
- nav：`seam-strips` 縫幅導覽（四條窄布縫在一起，現用頁那條被塗了泥）
- illust：`resist-ground` 負形泥地（全站圖像皆出自同一支逐像素負染渲染器）
- mood：`mud-leaf-sodani` 泥黑・葉黃・漂白布
- signature：負染顯形＋sodani 漂白

## 首創

**負形塗佈作為主要互動範式（negative-space painting）**：全館第一個「使用者只能塗背景」的站——游標是泥刷，刷到的永遠是背景，店名、營業狀態、訊息、地圖上的路都是刷不到的地方；並且以同一支逐像素渲染器（ImageData）產出全站所有圖像。〈留一條布〉另以紋樣詞彙編碼訊息、收件者必須讀懂紋才能解出約定時段。
