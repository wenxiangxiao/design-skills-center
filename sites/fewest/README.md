## 核心功能：減形間

規則三句話，一輪約九十秒：

1. 點掉圖上任何一塊形，剩越少塊越好。
2. 三位編輯每次都再看一眼；有兩位認不出來，這塊就得裝回去，記一次退稿。
3. 退稿三次，或者再也拿不掉任何一塊，就收工。

這是一個**減法**互動：使用者不能新增、不能拖曳、不能調整任何參數，唯一的動作是把既有元素拿掉；而判準不是好不好看，是「拿掉之後還認不認得出來」。

判定引擎具有單調性，因此：底數（全域最小解）一定走得到，但**順序決定你卡在哪一個局部極小**。以 24 張圖 × 400 次隨機亂點模擬（9,600 局）：走到底數 8.2%、差一塊 20.1%、差二到三塊 47.2%、更差 24.4%，其中 34.9% 是被退稿三次而收工。

收工單會給你版號、拿掉的順序、這張圖總共有幾種收工法，以及一個可分享還原的 `?p=` 碼；按「貼到首頁」後，首頁那張圖版就換成你減出來的版本（localStorage 跨頁生效）。

## 首創

**全館第一個以「刪除」為唯一操作的站**——使用者不能新增、不能拖曳、不能調參數，只能把既有元素拿掉；而系統的判定不是好不好看，是「拿掉之後還認不認得出來」，等於把 PLAYBOOK §2.7.2 的**三秒辨識測試本身變成可玩的功能**。同一支引擎另外承擔：二十四張圖版、底數與收工法數量的窮舉、首頁的環境動效、logo、favicon 與入社回執的社員章。

與既有登記項的差別：`gatemark` 的不可逆是「做完之後不能還原」，本站是「唯一能做的事就是拿掉」；`shaft-eight`／`foldpoint`／`rendong` 都是加法式的編輯器，本站是減法。

## 技術

`oklch()` 五色等亮調色盤與 `color-mix()` 淺底（先寫 hex fallback 再寫 oklch）／`@starting-style` + `transition-behavior:allow-discrete` 的形塊脫落與上片轉場（附 `@supports not` 降級）／單調識別規則引擎與建置期窮舉。零外部圖片、零音檔、零 JS 函式庫；外部資源僅 Google Fonts。

## 無障礙與降級

- 四頁全部資訊皆為靜態 HTML，關掉 JavaScript 仍可完整閱讀；圖版是完整的，三位編輯的規則與算式全文印在編輯部頁，可以拿紙筆自己算。

- 四種動效各自都有 `prefers-reduced-motion` 降級且資訊零損失：色帶靜止、形塊直接消失、進場直接到位；首屏改為靜態顯示「本社示範的拿法」並逐一列出拿掉的順序。
