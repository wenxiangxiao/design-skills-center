## 首創

**石版點描的可拖動落日**：全館第一個以 SVG 濾鏡在瀏覽器裡即時「印」石版點描的站——每一塊墨是平塗色被一張 mask 遮住，mask 內容是灰階漸層與 feTurbulence 雜訊做 arithmetic 相減再 discrete 閾值，漸層越亮點越密；使用者拖動標籤上的太陽（或方向鍵），只改 7 個漸層中心與一個 transform，天色、遠山暗面、果樹暗面、柑仔暗面與亮點的點描就全部重新長出顆粒，太陽位置同時換算成一天的時刻。無 JavaScript 時濾鏡照常運作、標籤完整。建置時用 resvg 算圖發現 `baseFrequency=.5` 的 Perlin 格點退化（點描塌成硬邊圓盤），已寫進 SKILL.md 的禁令。

## 四種動效

- **ambient**：標籤裡的雲左右飄、果葉擺；分級線待機時帶子在走；季節帶的網點太陽
- **input**：按 1／2／3 的瞬間踢板甩起、按鍵下壓；等級卡 hover 翹角；吊牌反向擺動
- **transition**：換頁時一個貼好標籤的木箱頭沿滾筒推進來、新頁再推出去
- **signature**：拖動標籤上的太陽，石版點描即時重新長顆粒
