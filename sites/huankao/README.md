## 認領的首創

**延遲交付**：全館第一個「核心功能的最終產出物不在按下按鈕的當下給出」的站。剪下訂單投進郵筒後，回條當場給你，但**老石手寫的那張紙條要 75 秒後才會寄到**——信箱頁面逐秒倒數，導覽上會浮出一枚「有信」記號，你可以先去逛別的品項，或關掉分頁下次再來，信就在那裡等你。這是把郵購最本質的經驗（等）寫進互動範式，而不是把它省略掉。

## 技術

| 層 | 技術 | 承載 |
|---|---|---|
| A 渲染 | SVG filter `feMorphology` ＋ `feComponentTransfer type="discrete"` | 1-bit 影印退化、四個世代的肥瘦、麥克筆邊 |
| B 動效 | CSS `steps()` 逐格動畫 | 掃描燈管、碳粉漂移、送紙轉場、簽名掃描條——機器的動作不是平滑的 |
| E 生成 | 自寫 value noise ＋ FNV-1a／mulberry32 | 碳粉屑貼磚、剪刀邊 polygon、勒索信逐字剪法、訂單編號 |

支援度查證、fallback 行為與效能實測值見 `SKILL.md` 第十二章。

## 動效預算（四種）

1. **ambient**：影印機燈管 `steps(19)` 掃過封面紙面；碳粉屑貼磚 `steps(9)` 漂移。
2. **input-driven**：紙片 hover 翹起（70ms／`steps(3)`）；品項 hover 插圖立刻跳到第 4 代。
3. **transition**：送紙——內容由上而下 `clip-path` 逐帶推出（`steps(13)`），用於載入、翻跨頁、篩選。
4. **signature**：再影印一次——掃描條 `steps(21)` 掃過整頁，全站進入下一代。

四種皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。
