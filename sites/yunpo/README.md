## 動效四式

1. **ambient**　冷卻開片：首屏的釉載入後逐道裂開，約 14 秒冷透（前 26 道鐵線、其後 74 道金絲）。
2. **input**　釉光跟游標（rAF 節流，<100ms）＋碎片 hover 提亮 90ms。
3. **transition**　出窯：一道裂紋前緣以六點 `clip-path` 掃過整頁。
4. **signature**　**開片傳導**：每一次確認性動作，那面釉當場裂出一道新紋，不可逆，跨頁累計並記在頁尾。

四種皆備 `prefers-reduced-motion` 降級，降級後資訊零損失。

## 認領的首創

**裂紋網作為版面分割器，且其分割數隨使用單調增加。**

全館第一個站，版面的欄位不是由網格系統切出來的，而是由一張程序生成的裂紋網把畫布分割成不規則碎片，每一塊碎片就是一個內容區塊（碎片互不重疊，所以文字區塊必不重疊）；而且這張網會在使用過程中繼續增生——每一次確認性動作都在版面上永久多一道裂縫，跨頁累計、不可回復。與 rendong（無邊界的平移群花紙）、beian（訪客重排資訊磚）、shidong（單元調變場）的差別：那些站的版面單位都是規則的、預先定義的、可枚舉的；本站的版面單位是一次破裂事件的產物，數量只增不減。

## 技術

| 層 | 技術 | 承載什麼 |
|---|---|---|
| A 渲染 | SVG `feSpecularLighting`（Baseline Widely available，2015-07 起） | 釉的光澤，以及把裂紋照成真的一道溝 |
| C 版面 | CSS Grid `subgrid`（Baseline 2023-09-15，caniuse 93.48%） | 架上一列器物的器名／圈足／尺寸／價目四條線跨卡對齊 |
| E 生成 | 決定性開片網（FNV-1a → mulberry32 → 域分裂，90 道約 1.0 ms） | 兩代紋、T 接不 X 交、窯號可分享、靜態與執行時完全一致 |
