# 濁水蔭甕醬園 CHOSHUI YINWENG SOY

> 醬油釀造老廠 × 蔭甕墨階風 Shoyu Tone-Ladder ｜ 繁體中文示範站

雲林西螺的黑豆蔭油老廠。首頁不是形象頁，是一座甕埕：三十六口甕全部封著，而醬油的胺基酸態氮沒有辦法隔著甕量——**要知道就得開，開了就不能賣**。你有十六個檢驗工，下午要把這批醬的等級報出去。

核心互動是**破壞性抽樣檢驗**：三種手段（看甕 0 工不毀、拔栓取汁 1 工降級、開甕取醪 3 工報廢）換到不同精度的資訊，你據此估出批平均、下等級判定、出貨，然後收到一張結算單。結算單會告訴你這批實際是什麼、你的信賴區間有沒有蓋到真值、你犯的是生產者風險還是消費者風險——但它**永遠不會揭露任何一口你賣出去的甕**。唯一確知的甕，是你已經賣不掉的那幾甕。

## 首創（_first_registry 登記）

**破壞性抽樣檢驗作為互動範式**（destructive acceptance sampling as interaction paradigm）：全館第一個「量測會消耗掉被量測的東西、而被消耗的正好是你原本要賣的那一份」的站。使用者不能量他要出貨的東西，只能量他因此賣不掉的東西；知識與庫存互斥，且精度與破壞程度是同一條連續光譜（0 工不毀／1 工降級／3 工報廢）。系統以機率而非真值結案：走味率的 95% 上界在開四甕時停在 53%，要壓到 8% 需開三十七甕（比整批多一甕），故本站從不宣稱「這批沒有走味」。個別出貨甕的真值**永遠不揭露**，也不提供任何按鈕可以看見答案。

## 技術

四頁單檔 HTML，CSS/JS 全 inline。零外部圖片、零音檔、零函式庫，外部資源僅 Google Fonts。所有圖像（商標、favicon、甕埕、二十四張圖鑑、圖表、回執甕印）由同一支甕層剖面引擎輸出；`weng.html` 與 `fa.html` 的圖在建置時以同一支引擎烘成靜態 inline SVG，不跑 JavaScript 亦完整可見。決定性亂數為 FNV-1a → mulberry32，同一批號恆得同一批甕。`prefers-reduced-motion` 下取消全部過渡與動畫，流程不變。
