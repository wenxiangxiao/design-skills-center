## 首創（登記於 ledger `_first_registry`）

**地圖投影變換與 Tissot 變形指標作為互動範式，且全站每一張圖都是同一組球面座標在某投影下的解**（map-projection transformation + Tissot indicatrix distortion as interaction，ziwu）：全館第一個以「把地球攤平」為核心互動的站。使用者拖動攤平桿讓球儀在正射球儀與所選平面投影之間連續變形，同一組經緯座標經投影函數解出螢幕位置；每一點的變形橢圓由對投影函數取數值雅可比、求奇異值（即橢圓長短半軸）即時算出，故任何投影都能用同一支引擎量測面積與形狀失真，並據此替使用者的製圖需求評分排序。與既有站的差別：既非工藝工作台（無材料成型）、亦非量測反演或規則引擎，互動對象是「一個不可攤平之曲面的各種平面近似，以及每種近似所付的變形代價」。
