# 開始電腦班 KHAI-SÍ — 長青電腦班 × 9x 經典介面

> 「看不懂，就回到開始。」

新北市板橋區府中路 96 號 2 樓〔門牌虛構〕的電腦班。1996 年 3 月，前板橋農會會計鄭玉霞（1958–）花三個月薪水買了第一台電腦，學會之後發現沒有人教得慢，於是在麵線店樓上開了「開始電腦補習班」——名字取自那一年左下角那顆按鈕。第一期 11 人，最年長的是 71 歲的退休郵差。2008 年起開長青班，2019 年女兒鄭宜庭（1986–）接手，手機課比電腦課多，但第一堂還是先握滑鼠。

品牌敘事出自產業本身：1995 年的使用性測試發現第一次用電腦的人不知道從哪裡開始，於是那顆按鈕寫上「開始」；三十年後，長青電腦班的學員遇到的是同一個問題。

**資料皆為虛構示意**（人物、地址、電話、課程、學員數）。Windows 95 上市日（1995-08-24）、使用性測試與「開始」按鈕的由來為真實背景；本站不使用任何作業系統的商標或圖示。
