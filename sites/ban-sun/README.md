# 萬順當舖 BAN-SUN PAWN

**產業**：當舖（臺北萬華西園路一段・1979 年起：典當收當、流當品販售、六件流當品可現場喊價）
**風格**：Anti-design・瀏覽器預設即材料（型錄「當代網頁與品牌」Anti-design 條目，全館第 1 站）

一間不裝潢的當舖，做了一個不裝潢的網站。字是瀏覽器本來的 Times，連結是本來的藍，按鈕是本來的灰；一個 774px 的紅色「當」從左上出框，「PAWN」從右下撞過來，盒子歪著疊在一起，價錢旁邊有人用滑鼠畫的紅圈。右下角那條電線是這個網站的樣式表——拔掉它，整站變回瀏覽器預設的樣子，價錢、地址、電話一個字也不少。

## 八維配方

- era 時代：當代（2024 網站），血緣 2010–2020 Anti-design／Brutalist web
- locale 地域：臺北萬華西園路騎樓，柱子上的當舖傳單
- voice 性格：直、口語、不客套（「錢花在估價師，不花在燈」）
- texture 質感：螢幕原生，零材質，滑鼠線
- density 密度：高、疊壓，但保留一條可讀路徑
- function 功能：〈喊價〉一對一議價賽局（破綻→底價、耐心→翻臉、三口價→最後價）
- opening 開場：raw-html-first 裸 HTML 開場
- nav 導覽：blue-link-pile 藍連結堆

## 首創

1. 全館第一個 Anti-design 流派站。
2. 全館第一個把**作者樣式表做成可拔插的實體**：右下角插頭切換 `style#anti.sheet.disabled`，整站在「作者設計」與「瀏覽器預設」之間即時切換，兩種狀態都完整可用；首頁開場就是先給你看預設樣式、再把樣式表插上，插上時每個盒子從亂飛的位置撞回自己的歪位置。
3. 全館第一個一對一**喊價（議價）**互動範式：破綻會降底價、喊太低扣耐心、有誠意地往上加不扣、三口之後給最後價。
