# 白鷺埔選務講習所 PEH-LO-PO INSTITUTE OF ELECTORAL OFFICERS

嘉義朴子的選務講習所示範站。首頁不是形象頁，是一張**開票台**：一個票匭、五塊開票板。同一疊五十張序位票，用五種計票法同時唱票上板——相對多數、兩輪決選、逐輪淘汰、波達計分、兩兩對決——開出**四個不同的當選人**。核心互動是**反例構造**：照著四道挑戰改票堆，親手讓裂票、孔多塞循環、「多得票反而落選」（IRV 單調性違反）、「單挑全勝卻首選墊底」在板子上真的發生，引擎當場驗證，四關全過發修了證。
