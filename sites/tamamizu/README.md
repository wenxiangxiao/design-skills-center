## 認領首創

**「作品的正典視角不是攤平的那一個」— the canonical view is never the flat one。**

全館第一個站，使用者在 A 座標系（攤平）編輯，但驗收發生在 B 座標系（半開的前縮視角），
而且 A 與 B 之間的變換**會破壞作品本身**：角度被壓縮 t 倍、半徑不變，
每一條山摺會把跨過它的顏料撕裂，每一條谷摺會把顏料積得更濃。

- 與 `foldpoint`（剛性摺疊運動學：平面刀模與立體成品是同一組資料的兩個投影，兩者都合法、都完整）的差別：
  這裡攤平視角是**錯的**——它只是工作台，沒有人會那樣看一把扇；而且摺疊是**破壞性**的，不是可逆的姿態變換。
- 與 `jiaobai`（摺疊對稱防染：摺法決定對稱群，摺是生成規則）的差別：這裡的摺不生成任何東西，它只**切**。
- 與 `rendong`（無邊界的接版：成功的定義是找不到版邊）的差別：這裡的邊（摺線）是**看得見而且必須被利用**的——
  好的設計不是躲開摺，是把摺挑成谷摺。

## 誂え的規矩（三句話）

1. 選骨數與地紙（十一／十五／二十五間；金地／銀地／砂子地）。
2. 把三到五個母題擺到扇面上。
3. 摺一次——跨過谷摺會積色更美，跨過山摺會裂。

擋人的規則四條：母題數不在三到五之間／母題越過親骨或壓進要側十二以內／割れ超過六成／
一條摺都沒跨（「那是色紙，不是扇」）。加分四項：谷に二本以上、二つ以上の母題が跨ぐ、間（1.6 面ぶんの空金地）、重心の偏り。
