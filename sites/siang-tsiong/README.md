# 雙將鎖店 SIANG-TSIONG — 鎖店 × 中國木版年畫・朱仙鎮門神

新北市永和區竹林路 79 巷 2 號、竹林市場口的鎖店（虛構）。創辦人宋金福 1931 年生在河南開封朱仙鎮，十二歲在年畫作坊刷槐黃版；1949 年隨部隊來臺，包袱裡只有一塊秦瓊的墨線版。1961 年在市場口擺鑰匙攤，每年除夕前替那一年修過鎖的人家印一對門神。敬德那一塊沒帶出來，他 1962 年憑記憶重刻——所以店裡的門神左扇刀細、右扇刀粗。兒子宋國樑 1988 年起做二十四小時開鎖；孫女宋以禎 2019 年把五塊色版重新刻齊。

## 首創

1. **分版即圖層**：全館第一個把「一張圖拆成六塊印版」做成真實結構的站——同一個 `<symbol>` 被六張 `<svg><use>` 引用，靠 CSS 自訂屬性繼承進 `<use>` 影子樹，每張只替自己那一塊版上色、其餘填白；`mix-blend-mode:multiply` 下白色等於沒印，前景自然遮住背景、錯位時露出紙。
2. **一支註冊屬性驅動整場拓印**：`@property --t`（`<number>`）從 0 走到 6，同時決定六塊版的 `clip-path` 揭示、錯位從 6 倍收斂到 1 倍、與棕刷的 `left:mod(var(--t),1)`。
3. **諧音即介面**：導覽的現用頁以「斗方倒貼」表示（倒＝到）；門上的蓮、魚、蝠＋錢眼是可聚焦的資訊點，以 CSS 錨點定位把讀法貼在物件上。
