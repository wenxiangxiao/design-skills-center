# 輪班 SHIFT ／ 北門單車快遞合作社

**產業**：單車快遞合作社（台北北門，社員九人，無老闆）
**風格**：龐克影印同人誌 Punk Xerox／DIY Fanzine（既有流派，1976–1984 英美自製刊物）

一個沒有網路版的社刊，被做成了網站。合作社每個月最後一個週四開完會就去影印店，把當月路況、費率更動、投書塞進一張 A4 的八個格子裡，印兩百份，放到十一家願意擺的店。首頁就是**那張還沒摺的紙**——八格印在同一面，下排是上下顛倒的，因為摺起來以後它們會轉過來。

## 核心功能：一張紙的八頁刊

三句話：**揀五塊內容 → 排進紙上的八個格子（上排正的、下排顛倒的）→ 按「摺」。**

- 兩道會擋人的規則：八格沒填滿、或五塊裡沒有一塊是實用資訊，直接退件；封面／封底沒落在會變成第 1 頁／第 8 頁的格子也退件（「摺起來封面在裡面，架上沒有人看得到它」）。
- 通過後那張紙會摺起來變成一本可翻的八頁刊，而且**照你排的位置摺**——排錯不會被攔，只會在報告裡逐頁列出「你想讓人讀到的」與「摺出來實際讀到的」。
- 不給分數、不給星等、不排名。只給一句「讀的人會在第幾頁停一下」、一個由紙張決定的印量（螢光橘 1.7 元／張＝176 份，影印白 1.2 元／張＝250 份，預算 300 元），一個刊號與可還原的 `?z=` 分享碼。
- 排好的封面可以「貼到全站」（localStorage 跨頁生效），首頁那一格就換成你的第 24 期。

## 首創（全館第一次）

**落版（imposition）作為互動範式**：使用者編輯的不是版面，是「讀的順序」與「印的位置」之間的一個置換——同一張紙的八格裡有一半必須印成上下顛倒，而且排錯了當場看不出來，非得摺起來讀一遍才知道。

與 `foldpoint`（剛性摺疊運動學作為版面容器）的差別：那裡摺的是一個盒子的刀模，摺疊角是連續的幾何量、每一格都是右邊朝上的立體投影；這裡摺的是一本書，求的是**頁序**這個離散的置換——它不是幾何問題而是裝訂問題，答案由「八格構成一個環、翻葉與翻書背交替」推出來，可以用手在紙上驗算。與 `jiaobai`（摺疊對稱防染）的差別：那裡摺法決定的是對稱群，這裡摺法決定的是閱讀順序。

## 動效預算（四種，皆有 `prefers-reduced-motion` 降級且資訊零損失）

1. **ambient**：影印燈管掃描刊頭，`steps(21)`，8.4 秒一輪。
2. **input-driven**：滑過任何一塊紙就「再影印一代」（換濾鏡，<60ms，離開還原、不累積）。
3. **transition**：壓上玻璃——進頁時 `clip-path` 由上而下六格推開，不是淡入。
4. **signature**：`fold-read` 摺頁閱讀（見上）。

## 技術與相容性

三項技術的支援度查證、fallback 具體行為與效能實測值，寫在 `SKILL.md` 第十二章。摘要：feMorphology／feComponentTransfer 與 `steps()` 皆為 Baseline Widely available（2015-07 起跨瀏覽器，caniuse 全球覆蓋 97.26%）；濾鏡失效時畫面仍是 1-bit（因為 1-bit 是由配色與元件規則保證的，不是由濾鏡保證的）；落版求解為純 JavaScript，且無 JavaScript 時 `<noscript>` 直接印出答案表與完整摺法。四頁單檔大小 24–40 KB，遠低於 350 KB 門檻，零外部圖片與音檔。
