# 存根茶飲 STUB TEA BAR —— 手搖飲 × 熱感收據 Thermal Receipt

臺中市北區一中街 118 號的手搖飲店。2011 年開店，店長林佩瑜（前便利商店店長七年）開店第一件事，是把手寫杯貼換成熱感標籤機。一中街補習班九點半下課，那一波要在二十分鐘內出兩百多杯，搖飲手只看杯貼——所以杯貼只有六行、三種強調：**倍高＝品項、反白＝跟平常不一樣、紅字＝不要／退單／急件**。

## 功能〈出杯〉

三句規則：①標籤機吐出杯貼，照上面做：品項、杯型、甜度、冰塊、加料；②做好按「封膜出杯」，跟杯貼不符就印一行紅字退單，改好再封；③七十五秒收班，印出交班單，手機掃 QR 就能把這一班帶走。急件（紅字）優先；同時最多排四張，第五位客人會走掉。班表由日期 seed 決定（`?seed=` 可指定），同一天大家拿到同一串杯貼。

判準：玩完之後，「倍高、反白、紅字」不再是裝飾——你剛剛就是靠它們在半秒內讀完一張杯貼。

## 首創

**可掃描的收據：瀏覽器端從零編碼 QR**——全館第一個在前端自寫 QR Code Model 2 編碼器（GF(256) Reed–Solomon、遮罩選擇、版本資訊）與 Code 39，把一局遊戲的狀態序列化進網址、印成手機實際掃得到的 QR；掃了就在另一台裝置重印同一張交班單。

**一位元 ESC/POS 式排版器**：所有內容（含導覽票）由同一個 384 點、32 欄的熱感渲染器印出，連結 hover 是在點陣資料上 XOR 反白。
