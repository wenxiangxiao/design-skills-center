# 和昌號 南北貨 HÔ-TSHIONG — 南北貨行 × 膠彩畫 Tōyō-ga / Nihonga

迪化街一段 172 號的南北貨行（虛構）：烏魚子、干貝、花菇、紅棗、金針、蓮子、柿餅、蝦米、桂圓、黑木耳。店頭掛著一幅 1936 年臘月請一位剛入選第十回臺展的年輕東洋畫家畫的〈歲朝清供〉，落款只剩一個「秋」字；第四代陳品睿大學念膠彩，照原作重畫一幅掛在網站首頁，店裡所有價目卡也都是他用岩繪具畫的。

風格是型錄「繪畫與材質」類的 **膠彩／礦物顏料**條目，全館第 1 站。指的是日治臺灣的「東洋畫」——1927 年臺展開辦後由陳進、林玉山、郭雪湖（「臺展三少年」）等人發展、戰後改稱「膠彩畫」的那一支：墨線骨描勾形，礦石磨成的岩繪具和膠一層層上在絹或紙上，**同一罐礦物磨得越細就越淡**——淺色不是加白調出來的，是同一種石頭的更細粒徑。郭雪湖〈南街殷賑〉（1930，第四回臺展臺展賞，北美館藏）畫的正是迪化街霞海城隍廟口的南北貨街，這是產業與流派在歷史上真正的交會點。

## 核心技術

1. **SVG 濾鏡鏈**（A 渲染層）：`feTurbulence → feComponentTransfer(discrete) → feBlend multiply → 內緣 feGaussianBlur 相減成隈 → feDisplacementMap`，粗／中／細三支濾鏡就是三種番手；全站每一塊顏色都經過它。
2. **SVG SMIL `<animate>`**（B 動效與時間軸層）：首頁〈撒粉〉——遮罩由兩層不同週期的顆粒圖樣組成，每顆粒子各自在不同時刻 `opacity 0→1`，大粒先落、細粉後補；遮罩同時含整幅骨描，所以墨線永遠先在。
3. **Pointer Events 壓力／傾斜＋`getCoalescedEvents`＋`setPointerCapture`**（D 輸入層）：清供頁的筆刷——`pressure` 決定筆寬、`tiltX/Y` 決定筆尖橢圓的扁度與方向，每一筆寫進該品項該粒徑那一層的 SVG `<mask>`。

## 首創

**粒徑即明度的分層筆刷**：全館第一個把「膠彩的明度只能靠換粒徑、不能加白」做成可操作的繪畫工具——每一樣年貨有三層同幾何、不同番手的色面（五番最深最粗、九番、白最細最淡），各自擁有一個 SVG `<mask>`；使用者選粒徑、以 Pointer Events 的壓力與傾斜下筆，筆觸只進該層的遮罩，因此「疊上粗粒會變深」是物理而非調色。上彩覆蓋率以 `isPointInFill／isPointInStroke` 在品項自己的座標系取樣，達六成才列入年貨單——畫了才算買。
