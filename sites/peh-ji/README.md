# 白字瓷 PE̍H-JĪ PORCELAIN

> 具體詩 Concrete Poetry（Konkrete Poesie／Poesia Concreta）× 一件一字的白瓷工場（新北鶯歌）

臺語的「白字」是寫錯的字。1961 年簡阿水在鶯歌尖山埔路砌窯，替台菜餐廳燒白飯碗；1975 年一批「瓷」字貼花漏了一角，燒出來是「次」——瓷少了瓦，就是次品。1988 年簡素琴從德國 Selb 的轉印廠實習回來，帶回網版貼花的做法；2019 年簡以文接手，開始「白字」系列：碗、盤、杯、碟每件只印一個字，四個人十六件擺一桌，就是一首具體詩。

## 技術

1. **Web Audio 模態合成**（D 層）：四種器形四組非諧泛音比＋竹籤敲擊噪聲；同一個字永遠同一個音，空格是休止；「敲一遍」以 AudioContext 時鐘排程。
2. **Intl.Segmenter**（E 層）：中文斷詞＋字素切分——一個詞不跨列、放不下就換列留空；不支援時退為逐字。
3. **FLIP（Element.animate）**（B 層）：拖曳換位、鏡／轉／輪／散整桌置換，每個字從舊位置滑到新位置。

## 首創

**部件共鳴與讀法即旋律**：全館第一個具體詩站，也是第一個用「漢字構件」資料驅動互動的站——敲一個字，同字以全振幅共振、共用構件的字（瓷↔次、杯↔不、碗↔宛）以四成振幅延遲共振並追加一聲共鳴；同一個 4×4 字陣依「橫／直（右起）／蛇」三種讀法敲出三段不同旋律，空格即休止。附帶：全館第一個以「現在這頁是空格」標記現用頁的導覽。
