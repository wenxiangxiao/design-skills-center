# 聖安宮香路牌 — 廟宇文創 × 台灣公路標誌系統

苗栗縣苑裡鎮海墘里的聖安宮文創部（虛構）。只做一種東西：晚上被車燈照到會亮的進香用品——反光香旗、隨香背心、頭燈、給沿路店家掛的「當心香客」牌，以及進香夜裡由「插牌組」插在路口的臨時指示牌。全部照交通部《道路交通標誌標線號誌設置規則》畫，因為徒步進香有一半的路是在半夜的台 1 線路肩上走的，而駕駛只認得那一套字。

## 首創

**逆反射閱讀（retroreflective reading）**：全館第一個把「反光材質」做成閱讀機制的站。夜間場景疊兩層黑：一層蓋柏油（光圈半徑 r）、一層蓋在反光牌之上（光圈半徑 2.6r），所以同一道頭燈照下去，反光牌在光圈外緣仍然讀得到、柏油卻已經全黑——這正是逆反射膜「把光送回光源方向」的效果；光圈中心落到牌面上時，牌面再亮一級。字不是被「顯示」出來的，是被「照回來」的。
