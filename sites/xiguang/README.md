# 析光所 Xiguang Optical Demonstration Theatre

> 一間光學演示劇場。整座劇場是墨色的，唯一有顏色的東西是光——而顏色，是稜鏡讓白光現形的那一刻才誕生。

架空的光學暗室劇場：不賣眼鏡、不賣望遠鏡，只做一件事——把幾何光學搬上舞台，讓人親手擺一張光學檯，看光如何被鏡子折、被玻璃彎、被稜鏡拆成一道光譜。

## 首創（全館第一次）

**幾何光學光路作為互動範式與全站唯一圖像引擎**（geometric ray-optics：reflection ＋ Snell refraction ＋ prism dispersion 作為可玩的光路解謎，並作為全站唯一的圖像來源）。使用者在檯面上擺放與旋轉鏡、稜鏡、透鏡，把一束白光導到標靶；引擎逐段實算反射與折射、稜鏡按波長色散成光譜、超臨界角時全反射。**色散的勝負判定不只看光有沒有到屏，而看七色在屏上散開的幅度**——一束沒被拆開的白光直射不算通關。同一支光路引擎渲染全站每一張圖（logo、favicon、圖鑑縮圖、報名印記）。

與既有站的區別：`compositie-optiek` 是 Three.js 3D 眼鏡商品展示（非光線模擬）、`flicker-house` 是 CSS 3D 放映廳的視線幾何、`nordvarsel` 是 GLSL 極光著色器（非幾何光路）、`tide-signal` 是音訊合成——全館未曾做過幾何光線光學。

## 頁面

- `index.html` — **光學檯**（核心互動）：五關光路解謎。反射轉向、透鏡壓光、雙鏡繞板、稜鏡散光、反射後散光。拖動元件移動、拖外圈把手旋轉、方向鍵微調、`[ ]` 旋轉、觸控用旋轉滑桿。
- `guan.html` — **元件圖鑑**：15 件鏡／透鏡／稜鏡，依類別×材質×暗室需求交叉篩選＋關鍵字，即時計數；每張縮圖皆由光路引擎當場算出。
- `fa.html` — **光之原理**：反射定律、司乃耳折射、全反射與臨界角、色散、薄透鏡成像，含原創 SVG 圖解與折射率表；不需開啟互動即完整可讀，並誠實說明檯上採用的簡化模型。
- `yue.html` — **演示預約**：三步驟表單（選場次含餘額／額滿鎖定 → 稱呼≥2、手機 `^09\d{8}$`、Email 選填格式、人數 1–6 → 生成 `XG-YYMMDD-NNN` 留位號與由資料雜湊決定性生成的光路印記）。

## 配方（八維）

- **產業 × 風格**：光學演示劇場 × 墨光檯風 Ink Light-Bench
- **opening**：`lightbench-first` 光學檯直開場（首屏即一張可操作的光學檯，光已在跑、無大標 hero）
- **nav**：`diffraction-order rail` 光柵分級導覽（四頁為光柵的四道繞射分級 m0–m3，現用頁那道被點亮）
- **mood**：`mono-ink` 單色墨階——刻意的唯一例外：顏色只發給光，且只在光被稜鏡拆開時出現
- **illust**：`ray-schematic` 光路解算構圖（全站圖像皆為引擎算出的光路；方法頁另配手工原創 SVG 定律圖解）
- **signature**：即時光路重算——拖動／旋轉任一元件，光束逐段重解反射與折射、稜鏡即時色散成扇形光譜，`lighter` 加成混合讓白光與光譜同源
- **func**：光路解謎關卡（幾何光學謎題：擺鏡稜鏡透鏡把光導到標靶，色散關要求光譜散開；有輸入、有狀態變化、有命中回饋）
- **era**：近未來　**locale**：無地域感　**voice**：冷靜理性　**texture**：玻璃　**density**：極疏（大量留白）

## 技術

單檔 HTML（CSS／JS 全 inline）、原創 inline SVG logo 與 favicon、`prefers-reduced-motion` 降級（光路只在互動當下重繪、靜態呈現結果）、RWD（`≤900px` 導覽轉底部 dock）。**零外部圖片與音檔、零 3D／WebGL／第三方函式庫**——光路引擎為純 Canvas 2D 幾何求解，僅使用 Google Fonts（Noto Serif TC＋Noto Sans TC＋Space Mono）。

所名、人名、地址、電話、票價與場次皆為虛構之教學示意；光學檯之反射、折射與色散為**簡化的幾何光學模型**（二維線段、理想薄透鏡、色散刻意放大以利觀察），供演示與教學，非精密光學設計依據。
