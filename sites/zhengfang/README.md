## 核心功能：減到零

三句話規則：

1. 由上往下拆——結構件同跨上方還壓著東西就拆不動（介面會指名是哪幾塊）。
2. 顏色就是去向：朱紅進再生鋁廠、黑進廢鐵爐、赭去再研磨、冷白進碎解場。
3. 收工驗三條——**認不出**（殘留物象度 ≤15%）、**沒有格線**（剩下的平面兩兩不同跨、不同層）、**有主軸**（≥4 塊、質量加權主軸比 ≥3.00、偏離工地邊界 ≥18°）。

Z0 那塊純黑正方是依法不得拆除的工地公告牌，也是全站唯一永遠保持正交的東西。

窮舉實測：滿足「沒有格線」的合法收工佈局共 **840 種**，其中 **295 種（35.1%）**同時通過三條。通過後發出可列印的〈拆除完工證明〉、分項報價與可還原的 `?d=` 收工碼。**沒有分數、沒有星等、沒有排名。**

## 五個不可省略的視覺特徵

1. 無地平線、無地面、無影子的白場（白是空間不是背景；全站零貫穿線）
2. 角度只有兩族：正交族（物象與黑方）與斜軸族 −24.5°／65.5°
3. 六種形的封閉字彙：方、長條、圓、弧、十字、梯形——實心、零描邊、零圓角
4. 黑方的原點地位：純黑正方、面積最大或次大、唯一永遠正交、敘事上不可移除
5. 色的階級：面積嚴格遞減，任兩塊色平面相鄰不夾線、不留縫、不加陰影

## 四種動效

| 類型 | 內容 |
|---|---|

| transition | **斜切推移**：內容以主軸方向的 clip-path 楔形推入，`.52s steps(9)` |
| signature | **零度切口 zero-cut**：拆掉一塊，一條場色的全幅切線 `steps(7)` 掃過整個白場並**永遠留著**；拆到後來白場上留下一組交錯的白縫 |

四種皆備 `prefers-reduced-motion` 降級且資訊零損失。

## 首創

**減法作為唯一的創作動作，且合格條件是它不再指涉任何東西**（subtraction as the sole authoring act; success = unrecognisability）。

全館第一個站，其核心功能裡使用者**只能移除**——不能新增、不能移動、不能上色、不能調任何參數。他唯一能決定的是順序，而驗收標準不是「好不好看」也不是「藏不藏得住」，是「**它還認不認得出來原本是什麼**」。畫面的價值隨著資訊被移除而上升。
