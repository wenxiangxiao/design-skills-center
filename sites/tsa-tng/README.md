# 早頓煎台 TSÁ-TǸG BREAKFAST & WATCH

新竹市東區光復路一段 371 巷 2 號，1981 年開的西式早餐店（虛構）。林美珠在巷口擺一公尺鐵板賣蛋餅與紅茶；先生陳國雄在科學園區的液晶模組廠裝計算機與掌上遊戲機的玻璃，1983 年用報廢的時鐘液晶焊了收銀台旁的報時機。2016 年兒子陳柏翰接手煎台。

**風格：段碼液晶掌機風 LCD Handheld · Segment Display**（型錄「數位與螢幕原生」新增條目）——1980 年代初反射式 TN 液晶掌上遊戲機：每個姿勢預印成固定的黑色剪影、只能開關、熄滅段留殘影；灰綠液晶後面墊一張低彩印刷背景膜；斜七段數字；拉絲金屬面板、印刷橘框、朱紅圓鈕。

## 功能〈煎台〉

三句規則：◀▶ 移動鍋鏟、A 出手；生料冒滿三縷煙就翻面，翻過的那面再冒滿三縷煙就鏟起出餐，太慢會焦；焦三次或 90 秒到收攤，拿到取餐單（你點的早餐、成績與加料）。GAME B 是三格同時開火的尖峰。鍵盤、觸控、實體手把（Gamepad API）都能玩。

## 首創

**預印段碼殘影液晶 ghost-segment LCD**：全館第一個把整站狀態做成「預印、只開關」的段碼液晶的站——三頁四塊液晶的每個物件、每個位置在建置期就寫成 `path[data-s]`，熄滅段 5.5% 殘影、點亮 90%、以 `<use>` 位移重畫 1.3/1.7px 反射落影，液晶反應用 `steps(2,jump-none)`；換頁轉場是「ACL 全段測試」（所有段同時點亮）。也是全館第一個段碼液晶掌機流派站，以及第一個「點單內容即遊戲關卡、遊戲結果即取餐單」的點餐範式。
