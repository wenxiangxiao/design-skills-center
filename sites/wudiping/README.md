## 五個不可省略的視覺特徵

1. 虛空是主體不是背景（白 ≥55%，全站零邊框零分隔線零卡片）
2. 有限形狀語彙：長條・方・圓・十字・扇，硬邊平塗
3. 全站共享一個傾斜角 −33°（水平垂直保留給現用態與連續文字）
4. 三色律：虛空白 `#F2F2EF` ／墨黑 `#0E0E10` ／朱紅 `#E5301C`，＋鉻綠 `#0B7A4B` ≤2%
5. 尺度階層與孤立：一大二中三小，任兩個形不對齊

## 四種動效

| 種類 | 內容 |
|---|---|
| ambient | 小形以 `steps(16)` 逐格從畫面上方落下並旋轉（26s／41s 兩支） |
| input-driven | 拖動任一人時即時拉出朱紅測距線與「幾個身長」讀數（0ms）；導覽形 hover 換角度 |
| transition | 斜線推移 clip-path wipe（190ms），角度與 −33° 同族 |
| **signature** | **解散**：按下左上紅鈕，畫面上所有的形沿各自方位以 `steps(6)` 飛出畫面，只剩下白 |

四種皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。

## 認領的首創

**旋轉不變的相對關係作為唯一正確性判準**——全館第一個站，其核心功能的對錯完全不依賴絕對座標：使用者把四個形擺在虛空的任何地方、整組轉任何角度、放大縮小，只要兩兩之間的相對關係與目標同構就算對；引擎枚舉 24 種身分指派 × 閉式 Procrustes 對齊，並在錯的時候用「誰在誰的哪一邊」指出錯誤，而不是「你偏了幾度」。實測：八形兩兩互判 56 組零誤判、隨機亂擺 3,000 次通過率 0.00%、單次判定 5 µs。
