# 形數室・草湖市立動物園解說設計室

架空的市立動物園解說設計室。本室只決定一件事：**這隻動物要用幾個形狀畫。**

牌立在步道旁，觀眾平均在兩公尺半外看它一點八秒。一點八秒裡認得出來的東西跟畫得像不像沒有關係，跟形狀的顆數有關係。所以每一種動物都被畫成一條**化約梯**：從七個形開始，一階減一個形，減到只剩一個。減的方式不是擦掉，是**把兩個形併成一個，併完的面積等於原來兩個的和**——整條梯子從頭到尾，這隻動物身上的墨一克都沒有少（十二種 × 七階實測，各階面積總和誤差為 0）。

牌上真正用哪一階，由觀眾決定：園門口的**少形測**把每一種動物「還認得出來的最少形數」記下來，那個數字就是明年那面牌的規格。

## 開場／導覽／動效／插畫／氛圍

- **opening**：`ladder-first` 化約梯直開場——首屏沒有大標 hero、沒有標語、沒有按鈕組，只有同一隻動物的七個化約階並排，全部營業資訊掛在階與階之間。
- **nav**：`shape-count` 形數導覽——四頁＝同一個記號的四個複本，尺寸完全相同；現用頁那一個被畫成五個形，其餘只有兩個形。現用態不是被標亮，是**它被畫得比別人多幾個形**。
- **signature**：`shape-merge` 合形——面積守恆的形狀吸收。被吸收者滑進吸收者的重心並把半徑收到零，吸收者同時長大接住它；被重算的是「一張圖由幾個形構成」這件事本身。
- **motion**：四式齊備——ambient 母題帶翻色（時間）／input 梯格外推（游標）／transition 分形進場（導航）／signature 合形（狀態）。四式皆備 `prefers-reduced-motion` 降級，資訊零損失。
- **illust**：`hardedge-reduction` 硬邊化約構成——四種原語（正圓、膠囊、等腰三角、同心圓的眼），無描邊、無漸層、無陰影，白隙以「與地同色的描邊」實作。
- **mood**：`flat-cream` 無質感奶白平塗——奶白 34%、湖青 24%、柿紅 15%、芥黃 12%、墨綠黑 11%、灰粉 ≤4%。奶白是印上去的實色，不是紙。

## 技術

| 技術 | 層 | 承載 |
|---|---|---|
| CSS Grid `subgrid` | C 版面與樣式 | 特徵 5「字與形同格」：十二張卡片借用外層網格的五列，跨卡對齊到同一條線 |
| CSS `@property` 型別化補間 | B 動效與時間軸 | 簽名動效「合形」：補間的是 r、L、角度五個數，不是變換矩陣，膠囊在每一幀都還是膠囊 |
| CSS `sqrt()` 數學函式 | C 版面與樣式 | 梯格的面積正比於形數（邊長 = √(k/7)），梯子自己也遵守面積守恆 |

支援度查證來源、fallback 具體行為與效能實測值見 `SKILL.md` 第十二章。

## 首創

**面積守恆的形狀合併作為互動範式（area-conserving shape merge as an interaction paradigm）**：全館第一個站，其全部圖像來自同一支合併求解器，而「化約」在畫面上被實作成**併形而非刪形**——十二種動物 × 七階，每一階的面積總和與第一階完全相同（誤差 0）。使用者操作的不是參數、不是顏色、不是版面，而是**一張圖由幾個形構成**這個離散的量；而這個量同時是本站的設計規格、是牌的價錢，也是核心功能唯一要量的東西。
