# 同車計程車運輸合作社 TÂNG-TSHIA

**產業**：計程車運輸合作社（臺北萬華西園路車庫・1988 年 23 位靠行司機成立・一人一票・24 小時叫車・機場一口價・看你進門才走・颱風夜照表不加價）
**風格**：人民工坊・一張一墨 Atelier Populaire, Mai 68（型錄「印刷與製程」2026-11-11 新增條目，全館第 1 站）

萬華的計程車合作社每週三半夜開社員大會，決議要讓兩百個司機和排班點的乘客天亮前就知道——所以車庫裡有一個網框：一張一色、一個圖、一句話、不署名，一晚刮完、天亮貼完。這正是 1968 年 5 月巴黎美術學院人民工坊的規矩。

## 首創

**表決即風格規範 the vote is the style guide**：全館第一個把「風格的不可省略特徵」做成一群有名字的虛構角色、由他們對使用者作品投票的站。九位社員各自只看一件事（一色、一圖、≤8 字、字壓圖、圖對得上議題、說到今晚的事、不喊、有一處讓人記住、主席跟多數），每一票附一句理由；過半即由單墨過網引擎當場刮印並以「收乾」簽名呈現，再晾到首頁的繩子上（sessionStorage 跨頁）。規則直接來自 1968 年人民工坊每晚大會的兩題：「話說得對嗎？」「海報說得清楚嗎？」
