貳

這面被的來歷佮五件無法度提掉的物件

Gee's Bend（Boykin），阿拉巴馬

阿拉巴馬河一个大彎內底的黑人聚落，路只有一條，出去愛坐渡船。彼裡的查某人用工作服、麵粉袋、洗甲白的褲跤縫被，一縫縫四代——毋是為著好看，是為著寒天。無打版、無畫線、無型錄，手內底有啥物就縫啥物。

1966 年成立的自由拼布社（Freedom Quilting Bee）是全美國少數的黑人查某人合作社。1972 年伊佮 Sears 簽約做燈芯絨枕頭套，一做十外年、超過十萬件；賰的燈芯絨長條予社員提轉去厝，落尾攏縫入去被裡。所以彼幾年的 Gee's Bend 被特別厚、特別飽色，色也特別統一——因為彼是同一批貨的下腳。

2002 年休士頓美術館策的「The Quilts of Gee's Bend」佇惠特尼美術館展出，《紐約時報》共伊寫做美國做出來的現代藝術內底上奇的物件之一。

參照

  • Loretta Pettway（1942–）：《Lazy Gal Bars》《Housetop》，大都會博物館藏
  • Lottie Mooney（1908–1992）：《Housetop》四塊半木屋變體，約 1940，棉佮嫘縈
  • Arcola Pettway：燈芯絨《Lazy Gal／Bars》變體，1976
  • Mary Lee Bendolph、Lucy Mingo、Loretta Pettway：2015 年美國國家藝術基金會國家遺產獎
  • 製作條件：一色一塊布、手撕邊、目睭量、粗白棉線手縫壓線；材料是工作服、麵粉袋佮 Sears 枕頭套的燈芯絨下腳

咱佮參照的差別：原作是一床有邊的實物，色是「手內底有啥物」決定的。本站共這句話寫做兩條會運作的規則——(一) 版面逐一塊區域的色，是伊家己有偌懸決定的（無夠長就閣接一塊）；(二) 成品的色，是你佇補布市換著啥物決定的。設計者佮使用者攏無揀色權。另外加一條原作免處理的網頁紀律：長文一律排佇棉白布頂，對比 ≥ 9:1。

一・色塊直接相接

兩塊布之間無烏線、無白邊、無圓角、無漸層、無模糊陰影。唯一的界線是縫——一條 2px 的暗帶佮一逝白棉線。
CSS：布塊之間留 6px 縫隙，露出下底的 --seam #2A2024。無 border、無 outline。

二・目睭量的直線

逐塊布的四个角用 clip-path: polygon() 各偏 0.3%–1.6%，四條邊無一條平行。仝一个編號永遠得著仝一組偏差（FNV-1a → mulberry32）。

三・無夠長就閣接一塊

Lazy Gal：一條帶仔的長度是手內底彼塊布決定的。逐一塊區域的布是照伊的高度一塊一塊接落去的，接縫斜 0–11px、有白棉線。共視窗放大縮小就看會著伊當場閣接一塊。

四・對中央一圈一圈包出去

Housetop：一塊中心方塊，四條帶包一圈，閣四條帶包一圈。逐圈闊狹無仝、色無規律。首頁彼面招牌被佮補布市的成品攏是。

五・手縫壓線是唯一的線

粗白棉線，針目 5／3／6px 三種長度輪流、間距 5／6／6px，橫向偏 ±1.4px，行的路佮拼接無關係。閣有燈芯絨的直棱紋（repeating-linear-gradient ＋ mix-blend-mode）——游標囥落去，絨毛順逆會反過來，明度差約 6%。

袂使做的

袂使加描邊、袂使加圓角、袂使加漸層、袂使加模糊陰影、袂使用置中對稱的版面、袂使用細線幾何線描的插圖、袂使用半調網點。加任何一項，這就毋是拼布矣。

參

技術實作與相容性

本站的三項核心技術，各自扛一條無法度提掉的視覺特徵。支援度佇 2026-08-30 對 MDN 佮 caniuse 查過。

CSS Grid subgrid

扛啥物：「照仝一條線裁」。布目錄二十四張卡片的四逝內容（名、質地、來歷、價）愛切齊佇仝一條橫線，毋管字長短；首頁彼面招牌被的三圈布，愛用闊狹無仝的十二條格線（1.5fr／1.05fr／2.15fr…），巢狀網格家己複製袂出來。

現況：Baseline newly available，2023-09-15 起三支引擎齊全。Chrome／Edge 117+、Firefox 71+、Safari 16+、Opera 103+、Samsung Internet 24+。

備援：@supports not (grid-template-rows: subgrid) 時，卡片退轉去逐張家己排（字攏猶原讀會著，只是無切齊）、被面的圈改成直接複製仝一份格線清單（版面完全相仝）。資訊零損失。

mix-blend-mode 棱紋疊乘

扛啥物：燈芯絨。逐塊布頂懸疊兩逝 repeating-linear-gradient：一逝 multiply 的暗棱、一逝 screen 的光棱。滑鼠一囥落去，兩逝的 opacity 佇 90ms 內對換——絨毛順逆反過來，明度差約 6%。用單純的半透明白／烏做袂出這款效果，因為棱紋愛佮下底的布色相乘，才會綴色走。

現況：Baseline widely available，2020-01 起跨瀏覽器。Chrome 41+、Firefox 32+、Safari 7.1+、Edge 79+。

備援：無支援時混色被當做 normal，棱紋變做半透明的直線，布色佮版面完全無變。註：Safari 對 hue／saturation／color／luminosity 這幾種非可分離混色的彩度處理佮 Chrome 小可無仝；本站只用 multiply 佮 screen 兩種可分離混色，無這个問題。

規則引擎（純 JavaScript）

扛啥物：補布市。三个熟似人的規矩是三條會當驗算的述詞（質地同一性＋塊數倍率／破損排除＋面積差／色集合互斥＋塊數相等），提出來的手先過述詞，才輪到算面積、色數、質地數佮上大塊佔比。「問阿蕊指一手」是仝一支引擎跑一輪一手的窮舉：≤3 塊出 × ≤2 塊提 × 3 人，約 7,700 組，揀離目標上近的。

現況：無用任何瀏覽器 API，無相容性問題。決定性偽亂數 FNV-1a → mulberry32，仝一个種子永遠仝一堆布，所以 ?q= 分享碼還原會著仝一床被。

備援：關掉 JavaScript 時，補布市改做一頁靜態的規矩說明佮實測數字，其他三頁全部完整可讀。

四種動效

  • 環境・曝被：一塊硬邊的日光沿 84 秒對倒爿掃到正爿（screen 疊層，無漸層邊）。prefers-reduced-motion 時停佇下晡的定點。
  • 輸入・順毛逆毛：游標囥佇任何一塊布，燈芯絨棱紋 90ms 內反過來，磨白的邊同時浮出來。延遲 < 100ms。降級時瞬間切換，狀態猶原成立。
  • 轉場・攤被：換頁進來的時，內容對中線向頂下兩爿攤開（clip-path: inset(43% 0) → inset(0)，560ms）。降級時直接是攤好的畫面。
  • 簽名・無夠長就閣接一塊：任何一塊區域變懸（改視窗闊度、放大字級、篩選卡片、市場換一手），伊當場閣接一塊布落去——新彼塊用 steps(7) 一針一針縫落來。降級時無動畫，布照常接。
