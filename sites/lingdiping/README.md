# 零地平跳傘學校 ZERO HORIZON

**產業**：跳傘學校（定點跳傘與五人編隊訓練，潮州跳傘場第二跑道）
**風格**：**至上主義 Suprematism**（馬列維奇，1915–1927）— 取自 `_style_catalog`「現代主義與構成」，**非自創**
**線上**：<https://wenxiangxiao.github.io/design-skills-center/sites/lingdiping/>

從機門出去到拉開傘，中間是六十二秒。這六十二秒裡沒有地面、沒有天空、沒有上下——
這正是馬列維奇 1915 年拿掉地平線之後留下的那個空間。
**一個運動的實況，剛好等於一個流派的世界觀。**

## 核心功能：〈六十二秒〉

規則三句話——一、出艙以後只能改變身體姿態（游標／方向鍵／手機傾斜）；
二、依序飛到五個接手位，**停下來**穩住 1.4 秒才算接上；三、到 3,500 呎必須開傘，接不完就散場。

- 14,000 呎出艙、3,500 呎開傘、平均墜落率 170 呎／秒 → **62 秒**，功能的長度就是這件事的真實長度。
- 接手三條件都是幾何量：距離 < 2.6 公尺、相對速度 < 2.6 公尺／秒、穩住 1.4 秒。撞過去不算。
- 相對風 0.85 公尺／秒且方向緩慢旋轉，所以「停住」是一直在修正的停住。
- **不給分數、不給星等、不排名**：紀錄卡只列你接上了幾位、每一位的時刻與當時高度、教練的一句話。
- 產出物是一張**由這一跳生成的至上主義構圖**——接上的位置是實色，沒接上的留在淡藍白裡。
- 紀錄碼可分享還原（`?j=`），24 個隊形皆可指定（`?f=`）。
- 三層輸入保底：裝置傾斜 → 游標 → 方向鍵 → 「請教練代跳」（同一組物理的決定性自動跳）。
- 建置期以自動控制器實測：完成一輪約 36 秒（人類會更久），五個接手位的最長段 26 公尺，
  最高橫向速度 6.7 公尺／秒。

## 認領的首創

**姿態即輸入的無參照系操控（attitude-as-input in a reference-frame-free space）**——
全館第一個把裝置／游標的**姿態**直接當成使用者身體在一個沒有地面、沒有上下、沒有固定水平線的空間中的唯一控制量：
世界繞著使用者旋轉、使用者從不移動也從不旋轉，操控是螢幕相對的（世界加速度 = R(−θ)·a），
而唯一的深度線索是尺度。與 first-gear 的鍵盤駕駛（俯視路網上有道路與建築等絕對參照）、
tackline 的風場對抗航行（有風向與航向這兩個絕對參照）、amkongtsiau 的壓感手勢（輸入的是壓力不是姿態）
皆不同：本站沒有任何絕對參照，連「上」都沒有。

## 風格血緣

至上主義為既有流派，非自創。外部參照：馬列維奇 1915 年「0,10 最後的未來主義畫展」與同年宣言
《從立體主義與未來主義到至上主義》、《黑方塊》(1915)、《至上主義構成：飛機飛行》(1915)、《白上白》(1918)；
El Lissitzky 的 PROUN 系列；1919–1922 維捷布斯克的 UNOVIS 團體（Chashnik、Suetin）。
SKILL.md 第九章逐項寫出五個不可省略特徵，第十章的 Don't 特別區分**至上主義 vs 構成主義**與 **vs De Stijl**——
這三者最常被混為一談。
