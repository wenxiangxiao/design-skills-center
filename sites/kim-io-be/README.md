# 金搖馬 KIM-IÔ-BÉ — 投幣搖搖馬修理彩繪行 × Tingatinga 瓷漆硬板畫

臺中太平的投幣搖搖馬修理彩繪行〔品牌虛構〕。雜貨店門口那隻「十元搖一首」的獅子壞了就送來這裡：補玻璃纖維、換彈簧和投幣器、重新上漆。1988 年一張從達累斯薩拉姆寄回來的照片改變了這家店的畫法——當地畫師用腳踏車漆把出口過去的獅子重畫成 Tingatinga：先黑線，罐裡的漆不調，身上點滿點。

## 核心功能〈搖一首〉

三句規則：挑一台、投十元，音樂響、牠開始前後搖；牠每搖到最前或最後（燈亮的那一拍）按空白鍵或點牠——準的一拍點兩顆點、差一點點一顆；一首 32 拍（108 BPM，約 25 秒），點到 8／20／34 顆時腿、鬃毛、身體的圖案一層層長出來，唱完拿一張出車單（FNV-1a 券號 KIB-XXXXX，存 sessionStorage，另兩頁會顯示）。聲音、搖擺與判拍共用 Web Audio 時鐘；靜音或無聲音時改看燈號，規則不變。

## 首創

**節拍點紋 beat-dotting**：全館第一個「每按準一拍，就在動物身上點下一顆點紋」的節奏遊戲——Web Audio lookahead 排程的旋律、搖搖馬 `7°·cos(π·拍相位)` 的搖擺極點、±90／180ms 判拍三者共用 `AudioContext.currentTime`；點紋以 best-candidate 取樣均勻落在動物身上，累積到門檻時 SVG `<pattern>` 以 `patternTransform` 從 0.3 倍彈到 1 倍「長出」整片皮毛。玩完一輪，你親手把一隻平塗的動物點成了 Tingatinga。
