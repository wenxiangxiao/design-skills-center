## 這是什麼

一座賣百花蜜的山裡養蜂園。八つの山、重箱式巣箱 168 群、年產 1,240 公斤，其中 818 公斤裝瓶。桐箱三枡詰合せ的蓋子由五代目佐登一枚一枚蒔絵。

風格選的是日本漆藝的**蒔絵**——把金銀粉蒔（撒）進未乾的漆裡，再塗漆埋起來，最後用炭研磨把粉研出來。它與泰國金漆、Art Deco 的「深底鎏金」是兩件事：蒔絵的調子不是色階，是**粒子的粗細與面密度**。

因此全站的美術只有一條原語：**懸浮在半透明地裡的隨機粒子場**。沒有一條線、沒有一個塗滿的形、沒有一個漸層、沒有半調網點的格子。

## 首創（全館初）

**懸浮粒子場作為唯一渲染原語（suspended particle field as the sole rendering primitive）**

全館第一個站，其全部圖像——首屏・插圖・表の見本・導覽の紋・logo・favicon・功能の産出——既沒有 stroke、沒有填色的形、也沒有漸層與網點格子，而是由**粒度（丸粉一号〜十五号）× 面密度 × 埋没深度**三個量控制的隨機散佈離散粒子場產生。形的邊界不是線，也不是色塊的邊，是**密度的落差**；而粒子被一層半透明的地埋著，所以同一顆粒子的顏色與大小由它的深度決定，研げば出てくる。

與既有登記的分界：
- **色階量化器（orangepeel）**——那是一個連續場經 `feComponentTransfer type="discrete"` 切成 N 塊硬邊平色，畫面上全部是**面**；本站沒有任何一塊面，只有離散的粒。
- **粗網 coarse-screen（the-homer）**——那的點坐在規則的 85 lpi 網格上、點的大小就是調子；本站的粒不在任何格上（層化ジッター散布），而且調子由**數**與**大小**兩個量共同決定，同一個調子有無數種合法解。
- **形自解の光心（shankhari）**——那是連續的暈；本站沒有任何連續的明度變化。
- **一目刺し位元串（hitome-sha）**——那是兩條 0/1 數列完全決定的確定性正交圖案；本站是隨機散布，而且有第三個維度（深度）。

## 技術

| 層 | 技術 | 本站で何を担っているか |
|---|---|---|
| A 渲染 | `feGaussianBlur`(SourceAlpha) → `feSpecularLighting` + `fePointLight` → `feComposite` → `feMerge` | 高蒔絵の隆起。粉が厚く積もったところが本当に高くなり、点光源がその肩にハイライトを置く。光は指に付いてくる |
| B 動效與時間軸 | CSS scroll-driven animations（`animation-timeline: view()` / `scroll(root block)`、`@supports` ガード） | 署名動效「研ぎ出し」。四つの深さ層が 11%／35%／59%／83% の四段で順に出る |
| E 資料與生成 | 自作 粒子場エンジン（mulberry32 ＋ 層化ジッター散布 ＋ 粒度階梯） | 全站の画像。依存ゼロ・ビルド工程ゼロ・ES5・約 90 行 |

計測（Chrome 140 / M2 / 1440×900）：index 21.3 KB、首屏 JS 実行 14–19 ms、粒子 約 6,400、スクロール中 60 fps（fill の切り替えのみでレイアウトは動かない）。

## 動效（4 種・觸發源はすべて別）

1. **環境 ambient**（時間）：梨子地の三群が 5.4 秒周期で入れ替わり、光の当たる粒が変わる。さらに 3.5 秒誰も触らないと点光源が自分で回り出す。
2. **輸入 input-driven**（ポインタ）：首屏の面をなぞると `fePointLight` が指に付き、高蒔絵のハイライトが動く。rAF で 1 フレーム 1 回、遅延 <100ms。
3. **轉場 transition**（状態変化）：詰合せ台で蓋が変わるとき、飴色の一刷けが左から右へ渡って新しい面になる（`clip-path` の `nuri`）。
4. **簽名 signature**（スクロール）：研ぎ出し。

四つとも `prefers-reduced-motion: reduce` で停止し、そのとき粒はすべて**研ぎ上がった状態**で静止する（情報の欠落ゼロ）。
