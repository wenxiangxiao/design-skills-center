# 一紋烙印所 IT-BÛN BRANDING IRONS

臺中市中區的烙印鐵工房，1958 年起。用竹製分廻し與一把定規割り付け家紋，鋸成真鍮烙鐵頭，替銅鑼燒、檜木杯墊、皮件與柴屐烙上一個紋。三代人：林添丁（1929–2004）在綠川邊銅器行當學徒，自立後先做柴屐底的店號烙印；林美惠（1958–）1986 年把三十年的舊烙鐵拓成〈紋帖〉一千二百枚；林睿安（1990–）2015 年從岐阜的烙印工房回來，加做電熱柄、開週六「烙一枚」。

## 首創

**對稱扇區揭示（symmetry-sector sweep）＋紋名文法雙向引擎**：全館第一個以 `repeating-conic-gradient()` 遮罩配 `@property` 註冊的 `<angle>` 補間，讓 n 重對稱的紋以 360°/n 為週期「同時」畫出——分廻し只轉一個扇區，n 份就全部到齊，動畫本身就是這個紋的對稱群；n 由紋名文法引擎算出（三つ＝3、梅鉢＝5、九曜＝8、違い＝鏡像 2）。同一支引擎把「中陰隅切り角に三つ銀杏」這種紋名解析成外枠／排法／圖樣／陰陽四個部件，再只用圓弧與直線生成 SVG，反過來也能由部件組回紋名——紋名就是規格書。

## 動效

| 種類 | 本站自製 |

| ambient | 炭床十二塊炭的裂縫 steps(6) 明滅；鏡像對照的巴緩轉 |
