## 為什麼是這個配對

책가도（冊架圖）是朝鮮後期民畫的一支：**一架子的東西，而且每一件都是一句吉祥話的圖畫版**。它畫的是當時買得到的舶來品——中國瓷、西洋鐘、眼鏡、書——擺在一面用**逆遠近法**畫的架子上。一家一九七〇年代的清溪商街電子行，架上擺的正是那個年代的舶來品：真空管、電晶體、映像管。所以本站把十二種零件各配了一句吉祥話（真空管＝長壽、保險絲＝平安、烙鐵＝姻緣），架子照朝鮮的오방（五方）分格。

## 認領的首創

**把「看不見」做成規則（contrast-as-existence）**：全館第一個讓元素因為對比度不足而在功能上被判定為不存在的站。
每一格的地色由它的**方位**決定（不由設計者決定），放進去的東西若對該格地色的對比 <3:1，系統就退件並明說「它在這一格裡看不見」。同一支對比計算同時統治核心功能的裁示、全站的文字色選擇、〈부품〉頁「可用顏料」那一欄，以及 Logo 的用色。
建置期已窮舉驗算：四格的合法顏料數為 3／3／4／3，合法解共 **5 184** 組，無死局。

## 四種動效

| 類 | 內容 |
|---|---|
| 環境 ambient | 刊頭下的단청帶圖樣自走（40 s 循環）；〈부품〉頁 다이얼 的指針掃過刻度（22 s） |
| 輸入 input-driven | 點任何一件零件即換顏料，對比值與退件狀態同幀更新（無 transition，延遲 0 ms） |
| 轉場 transition | 進場時五格依「中→東→南→西→北」逐格把遠面推出去（`--f` 19%→3%，各延遲 90 ms） |
| 簽名 signature | **透視歸正**：游標或焦點落在任何一格，那一格從逆遠近翻成正遠近（`--f` 3%→31%，260 ms） |

四種皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。
