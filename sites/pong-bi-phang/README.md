## 首創

1. **hose-rig 定長橡皮管骨架**：全館第一個橡皮管動畫站。角色四肢是定長二次貝茲（二分法解弧長），手以彈簧阻尼追游標，管子拉長即變細；白手套沿切線轉向。
2. **聲卡時鐘＝全站主拍**：同一個 AudioContext.currentTime 同時驅動配樂、整頁 `--bob` 彈跳（on twos）與遊戲判拍（扣 outputLatency）；無聲時無縫換成 performance.now()。
3. **衝擊波 take 簽名**：一聲「碰！」以鍋蓋為圓心，頁面每個元素依距離延遲做卡通 take（預備蹲→彈起拉長→落地壓扁），每天 :00 :20 :40 在首頁自動發生一次。
4. **可分享的重演短片**：遊戲的 32 拍偏差以 10ms 為單位編成 32 字元 `?s=`，朋友打開連結會看到片頭卡〈某某的四鍋〉、碰仔照你的每一拍重演、劇終卡。
