## 功能〈盛付〉

三句規則：①先選盒子（一幕 4×3、二幕 4×4、全本 6×4），再點菜，每道菜佔固定格數；②盒子要剛好裝滿，一格不空、一格不多，擺法交給裝箱器——裝不下或形狀塞不進會直接告訴你為什麼；③選場次、填座位，送出拿到單號，這一盒會出現在首頁「你的上一盒」。

判準：玩完之後你會知道 Bento 的本體不是圓角卡片，而是「把不同大小的東西裝滿一個矩形」。
