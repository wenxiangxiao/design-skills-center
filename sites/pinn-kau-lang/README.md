## 核心功能〈猜你的牌〉

三句規則：心裡記住二十一張裡的一張；它在哪一欄就按那一欄（牌會重發）；連按三次，告示把你的牌排成最大的字、滾筒走過印上紅版。拿到「學這一招券」單號（FNV-1a），到〈學藝〉頁可看到同一張牌與拆穿手法。約 40–90 秒一輪。

## 首創

**滾筒第二刷 second-forme roller pass**：全館第一個「第二色要等一根上了墨的滾筒走過才印上」的站——每個紅版元素的 `mask-image` 由一條隨滾筒位置推進的線性遮罩與一張 SVG 噪聲木紋遮罩 `mask-composite:intersect` 疊成，所以紅是以「缺墨的方式」被一行一行壓出來，而且印上之後一直微微漂離對版。同時以可變字寬軸 `wdth`／中文長扁體 `scaleX` 實作「每行一副字撐滿版心」的排字規則，滑過一行就從字盤換一副字重新撐滿。
