# 鋪線簇絨 PHOO-SUÀNN TUFTING — 簇絨地毯工作室 × 維秋爾毛線畫 nierika

臺中市大雅區學府路 118 號（地址虛構）的簇絨地毯工作室。張麗卿（1953–）1972 年進大雅「華盛地毯廠」（虛構）用氣動簇絨槍打外銷地毯，廠裡的規矩是每一塊顏色先打外框、再往內一圈一圈填、底最後——老師傅叫它「鋪線」。1998 年廠收，她帶回兩把槍與三十七軸剩線；2014 年一位在東海大學教西班牙文的墨西哥老師（虛構）抱來一幅巴掌大的維秋爾毛線畫要配線補洞，她認出那是同一個順序。2019 年女兒林郁芳（1981–）開了這間工作室。品牌敘事出自產業本身：簇絨地毯與 nierika 都是「沿著形狀把線一圈圈壓下去」，不走「孫輩出國看展」橋段。

## 首創

**弧長即物料單 arc-length bill of materials**：全館第一個讓「畫面上每一條線的實際長度」直接成為訂單數量的站。鋪線引擎把每一區、每一圈等距線的弧長逐段加總，〈打一塊〉的用線單就是這些長度依線色分組後 × 9.6（每 cm 打 4 針、毛圈 1.2 cm）÷ 2.2（100 g≈220 m）——你換一區的顏色，畫面重鋪，克數與加軸費同時改變；首頁游標摸到哪一區，也讀得出「這一區鋪了 3.24 m 線」。同時是全館第一個以「形內等距線由外往內逐條生長」作為簽名動效的站（外框先、底最後，正在鋪的那一條以亮撚表示指尖壓著），與 tang-sim 的形外回音線（字形外的等距線持續外流）方向相反、且每條線是有長度的實體而非像素帶。
