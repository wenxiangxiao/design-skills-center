# 銀梭鋁殼拖車 GÎN-SO Trailer Works

> 鋁殼拖車整修與出租 × 流線摩登 Streamline Moderne（1930–1940 美國工業設計：Bel Geddes《Horizons》1932・Bowlus Road Chief 1934・Loewy 水滴削鉛筆機 1933・Dreyfuss〈20th Century Limited〉1938）

臺中清水中社路 61 號的鉚接鋁殼拖車整修所兼出租站（虛構）。1979 年清泉崗剩餘物資標售，學徒柯文德用三個月薪水 NT$4,200 標下一台 1956 年的 22 呎鋁殼拖車；1983 年開店替人換鉚釘，1994 年第一次把殼拋到鏡面，2011 年女兒柯以晴開始出租。

整站的視覺只有一個主角：一面會反光的鋁殼。首頁的側立面由 WebGL 著色器即時算出——殼面高度場求法線、反射一個固定的「天空／地平線／暖褐地面」環境，所以那條銳利的地平線不是畫上去的，是曲面自己映出來的；游標就是太陽。捲動或滑動越快，所有標題的可變字軸越寬、越斜，三道速度線越長，停下時以阻尼彈簧收回——流線的本質是「看起來很快」，本站把它做成真的會隨速度變形的字。

## 首創

**速度驅動可變字軸的「速度字」**：全館第一個把捲動與指標速度經阻尼彈簧（k=170, c=17）即時寫進 Roboto Flex 的 `wdth`／`slnt`／`wght` 軸的站——字在你動的時候被「流線化」，停下來回彈一次再站好；同一個速度值同時驅動三道速度線長度、CJK 標題斜切、WebGL 殼面映出的路面速度與輪轂轉速。也是全館第一個以「殼面高度場→法線→反射固定天地環境」產生鉻面地平線、並讓同一高度場在拋光頁以 uniform 切出氧化／鏡面兩半的站。
