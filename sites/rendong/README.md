## 首創

**「無邊界的產出物，而且成功的定義是你找不到它」**——全館第一個站，其核心功能交出來的東西沒有畫框、沒有邊、會自己延續下去（它是整個網頁的底），而系統裁定的不是它好不好看，是**使用者能不能找到自己剛剛做的那塊版**。既有各站的產出物都是有邊界的成品（一張海報、一塊布、一份判讀、一枚印記）；本站的產出物是一面牆，而版邊是唯一的失敗證據。接版檯把接縫可見度算成一個可驗算的量（縱向走廊、橫向節奏、跨版邊的枝、接版法本身的破綻），並附一顆「顯示版格線」讓使用者用自己的眼睛驗證引擎的判斷。

## 動效預算（四種）

1. **ambient**：日光移牆（68s，暖色徑向漸層掃過整面花紙）
2. **input**：同版共振（hover 版籤，全頁 SVG 只留那一塊版印的東西，<100ms）
3. **transition**：裱紙推移（進頁時內容一列一列被貼上，620ms `steps(7)`）
4. **signature**：翻版遷位（換接版法時整面牆的版滑到／翻到新格子，版格線閃現一次；版沒有重刻）

四種皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。
