# 拾遺窗 Sip-uî Thang（西門總站失物招領室）

**產業**：客運總站失物招領室（每日重貼的招領窗）
**風格**：蘇聯羅斯塔之窗 ROSTA Windows（Окна РОСТА, 1919–1921）— 取自 `_style_catalog`「在地與文化視覺」，非自創
**線上**：<https://wenxiangxiao.github.io/design-skills-center/sites/shiyi-chuang/>

失物招領室不准貼照片——證件上有人的臉，行李裡有人的家。
所以這面窗上的每一件東西都是**割一塊模板、噴一次漆**印出來的：能不能被認出來，全看那一刀割在哪裡。

## 核心功能：〈六格認領〉

規則三句話——一、一格一件失物，只給剪影和兩句順口溜；二、從四個答案裡指認它是什麼；
三、認錯，割版師傅當場補一刀讓它更好認，再問你一次。六格約九十秒。

- **補刀階梯**：刀 0＝純外框剪影 → 刀 1＝往裡割出結構（束帶、接縫、鏡片、指孔）→ 刀 2＝另開一塊朱紅版標出關鍵部位 → 仍認不出來即揭曉並記三刀。
- **誘答不是隨機的**：三個錯誤選項優先取自同一個剪影族（長桿／筒身／板狀／袋物／衣物／器物），實測每題平均 2.75 個同族誘答。零刀時保溫瓶、保鮮盒、瑜伽滾筒幾乎是同一個長方形——這正是本站要你看見的事。
- **計分即刀數**：六格總刀數 0–18，四級判詞（看窗的老手／常客／生面孔／明天多帶一把刀）。3000 局亂猜模擬：0–2 刀 0.7%、3–5 刀 9.0%、6–9 刀 46.5%、10 刀以上 43.8%，中位數 9——亂猜的人拿不到好成績，看形狀的人才拿得到。
- **產出物**：結果單把六格照「你需要的刀數」重印一次，那張紙就是你今天看窗的紀錄；並發認領號與可分享還原的 `?w=` 窗號（同碼恆得同六格）。你補過刀的那幾件，會出現在今日窗的〈明日補刀〉欄裡（localStorage 跨頁生效）。

## 動效四式

1. **ambient**：玻璃天光——一條硬邊高光帶 46 秒掃過整面窗（`linear-gradient` 硬止點，不是柔漸層）。
2. **input**：游標移入任一格，墨／朱／赭三塊版即時分開（90ms `steps(2)`），角落跳出版名。
3. **transition**：貼窗 paste-on——每張紙以 `-1.7°` 傾斜、左上偏移落定並過衝一次（300ms）。
4. **signature**：**補刀 re-cut**——認錯的瞬間，一把朱紅的刀由左至右 `steps(5)` 掃過那一格，舊的剪影被 `clip-path` 逐段抹掉、露出底下多割一道的新剪影；若補到第二刀，朱版由右上 16px 滑進套準位置並過衝 −2.6px。

四種皆有 `prefers-reduced-motion` 降級：天光停住、版直接分開、紙直接就位、刀不掃而直接顯示補完的剪影，刀數、判詞與所有文字完全一致，資訊零損失。

## 認領的首創

**讀者的誤讀作為圖像的生成參數（misreading-driven progressive re-cutting）**——
全館第一個站，其插圖的完成度既不是由作者決定、也不是由使用者的創作動作決定，而是由「使用者看不懂它」這件事驅動：
每一次誤判，割版師傅就在同一塊模板上補一刀，直到它被認出來為止；
而失敗使畫面**更完整**，不是更劣化（與 patchframe「隱藏真值決定劣化、調準即還原」方向相反）。
本站沒有隱藏真值、沒有正確畫面，只有「還不夠好認」與「夠好認了」兩種狀態，判定者是使用者本人的錯誤。
