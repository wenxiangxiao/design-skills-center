## 認領首創

**無字判讀盲測作為核心功能，且受測物是本站自己的插畫系統**
（wordless-legibility blind test, specimen = the site's own illustration system）

全館第一個站，其核心功能既不產出東西、也不量測外部現象，而是把**本站自己的視覺語言送去受審**：九格圖的字帶被一片銅片實體壓住，使用者只憑圖作答，答完站方公布這扇窗的讀窗率與最多人讀錯的那一格。結果單上寫得很清楚：「這一份不是成績。它量的不是你，是這扇窗——一扇要靠圖說話的窗，讀不出來就是刻壞了。」

- 與 `shidong`（把觀看者的視網膜當成輸出媒介）的差別：那裡的產出物只存在於使用者的視覺系統裡，本站的受測物是螢幕上這批圖本身。
- 與 `rendong`（無邊界的產出物，成功＝找不到）的差別：那是評判使用者做得好不好，本站是評判**站方刻得好不好**。
- 與各站的「配置器／模擬器」題型的差別：本站沒有參數、沒有引擎、沒有可調的量，只有九次三選一。

## 動效四種

| 類型 | 是什麼 |
|---|---|
| ambient | **版在漂**：墨／赭／朱三塊版以 29s／23s／17s 互質週期各自輕微漂移，永遠對不準 |
| input-driven | 游標所在那一格的朱版與赭版朝反方向錯開 2–5px，刀痕帶由 32% 轉滿（延遲 < 100ms） |
| transition | View Transitions（同文件）：點格就地放大、答完銅片換字帶、窗庫開卷 |
| **signature** | **套不準 register-drift**：滑架每刷一張就爬一點——你每翻一頁、每答一題都算再刷一張，套色偏移＝印張數的對數函數（0 張 0px → 200 張 6.4px）。右下角的**對版台**可以拖回去，偏移歸零、印張重新計數 |

四種皆有 `prefers-reduced-motion` 降級且資訊零損失：錯位量與印張數本來就以文字同時顯示。
