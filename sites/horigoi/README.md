# 彫鯉（ほりごい）HORIGOI

東京・谷中の彫物所（刺青工作室）× **浮世繪 Ukiyo-e（錦絵）**

刺青と浮世絵は同じ一本の刀から出ています。1827 年、歌川国芳の《通俗水滸伝豪傑百八人》が江戸で彫物の流行をつくり、版木に線を刻む「彫師」と、皮に線を入れる「彫師」は、以後同じ呼び名を使い続けました。この店はその血筋を一代だけ横へずらした設定です——初代は根岸で錦絵の版木を彫っていて、版元が店じまいした頃、小刀を持って人の背中のほうへ移った。

**本館で「浮世繪 Ukiyo-e」を型録名で名乗る最初の站**（既存の `kinrin-en` は自創名「錦絵風 Nishiki-e」、地色は青鼠の中間調・錦鯉の遺伝エンジン站で、本站とは mood・主色相・開場のいずれも異なります）。

## 首創

**全館第一個使用 CSS Houdini Paint API（`paintWorklet`）的站。**外部ファイルを一つも置けない制約下で、worklet のソースを Blob URL 化して `addModule()` で登録し、奉書紙の簀の目・繊維と、奥付の版木の年輪を**版ごとに違う乱数種で**描いています。対応しない環境（Safari・Firefox）では `repeating-linear-gradient` の fallback に落ち、明度・対比・読めるものは一切変わりません。

## 技術（ledger `tech`）

1. **CSS Painting API（paintWorklet／A 渲染層）** — 紙の簀の目と版木の年輪。caniuse 78.01%、Safari/Firefox は fallback。
2. **`@starting-style` ＋ `transition-behavior: allow-discrete`（B 動效與時間軸層）** — ばれん摺りの転場と告げ札の離散出入。JavaScript 不要。2024/08 Baseline。
3. **`writing-mode: vertical-rl` ＋ `text-combine-upright`（C 版面與樣式層）** — 題簽・落款・双六のマス名の縦書きと縦中横。

## 制約

零外部圖片・零外部音檔・零 canvas 実行時生成。全 SVG は建置階段に Node で出力した静的文字列。外部から読むのは Google Fonts（Shippori Mincho B1／Zen Antique）のみ。JavaScript を切っても、図・字・表・価目・双六の九マスすべてが在場します。
