## 首創

**形式是受力的結果，不是造形的選擇（form-as-consequence-of-load）**：全館第一個站，其版面每一個容器的**內部幾何**（面怎麼分、每一面朝哪裡、落在哪一階明度）由一個全站共用的外部受力方向即時求解，而所有容器的外框、位置、尺寸、內容與顏色完全不變。

與既有各站的差別：`shunchang` 換光角重新打光、`zhencai` 換燈重演色，重算的是明暗與顏色、幾何不動；`rendong` 翻版遷位重算的是平鋪格子的位置，版本身沒有重刻；`baicaochun` 熔字重排重算的是文字的排版幾何，且容器由使用者直接拖動；`nayachand` 載重壓吊重算的是承載內容的容器之剛體姿態，外框動了；`foldpoint` 剛性摺疊由使用者直接控制摺角，形狀改變。本站什麼都沒動，被重算的是**「它是怎麼裂開的」**——這正是 Pavel Janák 一九一一年〈稜柱與金字塔〉的主張被寫成一條可驗算的規則。
