## 認領的首創

**可約減的圖像資產：把「約減程度」做成全站唯一的全域變數，而它是使用者在核心功能裡花掉的資源。**

全館既有各站的圖像都是「完成品」——畫好、印好、擺在那裡。本站的每一張圖（包含 logo 與
favicon 之外的所有站徽用例）都是**一份有序的版清單**，網站可以在任何一個中途狀態被完整交付：
一塊版的它、三塊版的它、定稿的它，都是成品而不是縮圖。使用者在「幾塊認得出」裡花掉的資源就是
版數，玩完之後那個數字可以被寫回全站（localStorage），整個網站於是以「你需要幾塊才認得出」的
水準重新印一次。與 rendong（成品沒有邊界）、shidong（產出只存在視網膜裡）、amkongtsiau（一次
手勢決定分版）、beian（資訊架構可被重排）的差別是：本站被使用者改動的既不是邊界、不是知覺、
不是分版方式、也不是順序，而是**同一份圖像的完成度**——而這個流派的主張正是「約減之後辨識仍然成立」，
所以中途狀態不是損壞，是另一個合格的成品。

## 四種動效

- **ambient**　走版漂移：五塊版各自以 17/19/21/23 秒的週期在 ±1.5px 內漂移，像一台正在跑的機器
- **input**　　推開最上面那塊版：hover／focus 時最上層油墨位移 3px（90ms），露出底下的疊印色
- **transition**　刮刀推移：內容以 `clip-path` 硬邊掃入，480ms `steps(6)`
- **signature**　加版重印：塊數改變時全站同一幀重繪，新那塊版 260ms `steps(4)` 落版

四種皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。

## 無 JavaScript 時

四頁的全部資訊都是一般 HTML 文字。首屏那隻鳥、鳥籍二十四張圖與「幾塊認得出」頁上的示範加版
過程，都在建置階段以同一支引擎輸出成靜態 SVG 寫在頁內，關掉 JavaScript 仍是完整的印刷品；
潮汐改看頁上的靜態潮汐表。只有「再印一塊版」、遊戲與表單驗證需要 JavaScript。
