## 首創（全館第一次做的事）

**把背景圖樣釘在頁面的世界坐標上，讓元素成為「切口」而不是「容器」，並以此做出可互動的「對花」。**
全館二八○站之前，沒有任何一站的版面單位是「從一張無限圖樣上裁下來的一塊」：每一塊裁片的 `background-position` 由它自己在頁面上的絕對位置對圖樣單元取餘決定，所以相鄰兩塊拼得回去、母題必定被邊緣切斷、而移動一塊它裡面的花就換了。導覽的現用態（相位對上了）與簽名動效（切口在漂移而圖樣不動）都是同一個機制長出來的。
