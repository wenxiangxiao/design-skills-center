EDITOR'S DESK ／ 編輯台

這本刊物的
版式是抄來的

一九九二年到一九九八年，美國有一本音樂雜誌叫《Ray Gun》，美術指導是 David Carson。他把標題切掉一半、把內文壓在圖上、每一期換一次刊頭；最出名的一次，他把一篇 Bryan Ferry 的專訪整篇排成 Zapf Dingbats——一整篇符號，一個字也讀不出來。

他的說法是：不要把「可讀」（legibility）和「傳達」（communication）搞混。這句話當年被罵了很多年。

我一九九三年在《噪聲》做美編的時候抄過他。二十七年後我在聽力檢查室裡想起這件事，理由和當年完全不同——原來我早就做過一次「看得到但讀不懂」的東西，只是那時候我不知道那是什麼感覺。

所以這本刊物長這樣。它不是致敬，也不是玩笑。它是一個可以被別人翻開來、然後說「這什麼鬼」的東西——而說出這句話的人，就在那一秒懂了我岳母的晚餐。

參照：David Carson／《Ray Gun》1992–1998、《Beach Culture》1990–1991、《The End of Print》1995；Emigre 雜誌與 Zuzana Licko 的字體；Neville Brody 與《FUSE》1991–2000 的實驗字型；1990 年代影印機 zine 的複印退化。

FIVE ／ 拿掉就不是這個風格的五件事

01有一張真的網格，然後被違反

12 欄、8pt 基線是實際存在的（本站以 CSS subgrid 讓巢狀區塊對齊祖先的欄與基線），而且淡淡地畫在畫面上。標題騎過欄溝、切出血、壓過欄線——沒有網格就沒有「壞」可言，隨手亂放不等於這個風格。

.spread{display:grid;grid-template-columns:repeat(12,1fr)} .blk{display:grid;grid-template-columns:subgrid}

02字級跳階、負字距、行距塌陷

同一組語意至少橫跨三個字級，最大／最小 ≥ 5 倍；字距 −0.045em 以下、行高 0.74–0.86 讓字身互相咬合。標題不是一行字，是一塊材質。

.cjkdis{font-size:clamp(50px,10vw,140px); letter-spacing:-.08em;line-height:.74}

03過曝二值化：沒有中間調

圖像只有純黑與紙白，邊緣帶碳粉外擴的碎點。零漸層、零模糊陰影、零柔邊。本站以 feMorphology 把邊緣撐胖，再用 feColorMatrix 的 alpha 列硬切成二值。

<filter id="xerox"> <feMorphology operator="dilate" radius=".55"/> <feColorMatrix type="matrix" values="0 0 0 0 .09 0 0 0 0 .09 0 0 0 0 .105 0 0 0 22 -9.5"/> </filter>

04錯版三色疊印

關鍵的字印三次：濁青一版、螢光洋紅一版、墨一版，各偏 2–4px，一律 multiply。錯位方向要一致，那是機器沒對準，不是手抖。

.op i:nth-child(1){color:#2E5A66; transform:translate(-2px,-1px);mix-blend-mode:multiply} .op i:nth-child(2){color:#FF2E7E;transform:translate(2px,1px); mix-blend-mode:multiply} .op i:nth-child(3){color:#17171B;mix-blend-mode:multiply}

05撕邊遮片與出血裁切

色塊邊界不是矩形也不是圓角，是鋸齒撕邊的 polygon；每一個跨頁至少有一個元素被畫布邊緣切斷。

.torn{clip-path:polygon(0% 0%,11% 1.9%,22% .2%, 33% .5%,…,100% 100%,0% 100%)}
