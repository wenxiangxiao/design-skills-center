## 核心功能：寄一張訂購單

三條規矩，寫在單子的天頭上：

1. 照目錄上的貨號與價目填單，每一項寫明打數或件數。
2. 郵資按包裹總重每十六盎司跳一級，隨單附上款項。
3. 本目錄是上一季印的——單上請勾「漲價照買」或「漲價退回」。

十五項貨品、£sd 即時試算、郵資級距（每 16oz 加 1d.）、缺貨與停售、
以及**目錄印製後的料價變動**（線索藏在帖丁第十條補正告示裡：
「雁鵝毛與印度公雞頸羽之料價續漲」「黃銅與鋁料之價亦有變動」——
用到這些料的式樣就是會漲的那幾支）。

按下「摺起・付郵」之後，單子摺成三摺、蓋戳、滑出視窗上緣。**結果不會立刻出現。**

## 首創：寄出去要等（dispatch-and-wait）

全館第一個站，其核心功能的結果不在使用者按下按鈕的那一刻產生，也不在同一次互動裡交付。

送出之後那份文件真的離開頁面；回函要等一個真實的時間門檻——四十五秒的郵班——才會落進帖甲的信盤。
等待期間使用者可以繼續逛目錄，刊頭底下那條花邊就是郵路，郵車一格一格走過去，
而且它跨頁、跨重新整理、跨關掉再開都在它該在的那一格（`Animation.currentTime` 對齊真實 epoch，不是重播）。
等不及的人可以「親往局裡自取」——那是把動畫 `seek` 到終點，不是取消重播；本行不另收費，
惟郵路上那一格一格的路程就看不到了。

所有的網路購物都在消滅這段等待。本站把它裝回去，並且讓等待本身變成版面上讀得出來的東西。

- 與 **yoiwan-hanabi**（光即時、聲後到）的差別：那是同一個事件的兩個通道有物理時差，
  使用者只是觀眾、送不出任何東西；本站等的是**自己送出去的那份文件**的回覆。
- 與 **nightspin／cosmic-lanes**（偽即時多人）的差別：那是別人在動、你在看；
  本站沒有別人，等的是自己的東西繞一圈回來。
- 與 **liuhu**（手上的炭跨頁帶著走）的差別：那是一個跨頁持續的**狀態**，隨時可讀；
  本站等的是一個**尚未存在**的東西——它在時間到之前不存在，而且時間是真的在走。
