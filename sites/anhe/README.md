# 安和棉被店 AN-HO QUILT SHOP

彰化縣和美鎮的一家棉被店：張水木手工彈被胎，媳婦賴秀霞做拼布被面，每月第二個週六在店後面辦換布會。

## 首創

**規格書要求自己被破壞一次**（a specification that mandates exactly one violation of itself）：
本站的規格寫了五條不可省略的特徵，然後加上第六條——以上五條必須恰好被違反一次。
站上每一頁真的有一塊布違反了規格（三種錯法擇一），位置由訪客當天的日期決定性算出，可被找到、可被點擊、頁尾會記數。
核心功能的驗收也照此執行：使用者做出來的被面若三條全過，店裡會替他換掉一塊。

## 動效四式

| 類別 | 內容 |
|---|---|
| ambient 環境 | 布面呼吸——每塊布同時跑 `drape`（22s 全域傾側）與 `ripple`（各自相位的微位移），以 `animation-composition:add` 相加 |
| input 輸入 | 拈起——hover／focus 時布塊上提 3px、該邊的縫線針距拉開（90ms） |
| transition 轉場 | 翻被——進頁時整幅布以 `clip-path` 分五欄翻過來（480ms `steps(5)`） |
| signature 簽名 | 謙卑塊——那塊錯的布以 40 秒週期微微挪動縫份；點它一下，全站縫線同時抽緊一次（`body.tug`，260ms） |

四式皆備 `prefers-reduced-motion` 降級：動畫全停、謙卑塊改為靜態位移仍找得到、翻被直接是最終畫面，資訊零損失。
