# 好日帆布行 HO-JIT CANVAS — City Pop 唱片封面插畫・永井博半身

高雄鼓山濱海一路的遮陽棚與帆布行（虛構）。1978 年替西子灣海水浴場縫第一批海灘傘，1981 年開店，做伸縮遮陽棚、固定式雨遮、舊棚換布與海灘傘。

**風格**：City Pop 唱片封面插畫（シティポップ・イラストレーション），取永井博（Hiroshi Nagai）的無描邊平塗半身——噴槍漸層天空、刀切硬邊、藍紫色的影子、沒有人的泳池與白牆、角落裡小而輕的字。
**一句話**：這個站賣的是一塊影子，而每一道影子都是用今天、這個地址的太陽算出來的。

## 首創

**ephemeris-hard-shadow 日照星曆硬影**：全館第一個以 NOAA 太陽位置演算（赤緯、均時差、真太陽時、時角）依店址經緯度與訪客真實時鐘，把場景內每一個物件的影子（地面與牆面兩個投影平面，Sutherland–Hodgman 裁切）即時投影成平塗硬邊多邊形的站；連頁面上白牆區塊的 box-shadow 與導覽的 drop-shadow 方向、長度也由同一顆太陽決定。透光帆布的影子以「影子色 × 布色」的不透明混色逐條紋投影（不使用 alpha）。
