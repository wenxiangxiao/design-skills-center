# 方格磁磚 HONG-KEH MOSAIC TILE

> 苗栗縣竹南鎮的馬賽克磁磚廠（1974 年開窯）× 歐普藝術 Op Art・Vasarely〈Vega〉造形單元

首頁就是一面「隆起牆」：二十一乘二十一塊造形單元磚——方地上網印一個圓——中央被一顆看不見的球頂起來，暖色八階往球心變亮，四周是海松綠的棋盤網。游標是第二顆小球，移到哪裡哪裡鼓起來，筆或手指壓越重鼓越高；按一下，球穿過牆面凹成一口井，色階整條倒過來。核心功能〈拼片〉：九張背網被搬運的人疊亂了，照格子的寬窄與色階把它們拼回牆上，縫接對了會變綠；拼完那面牆會自己鼓起來再凹下去，陳金榮師傅給你一句評語和一張工單。

## 技術

1. **Canvas 2D 路徑批次繪製＋透鏡位移函數**——全站每一張圖（含建置期 logo／favicon／無 JS 靜態圖）由同一支引擎產生；依顏色分組，一色一次 fill。
2. **Pointer Events**（pressure／setPointerCapture／getCoalescedEvents）——壓感決定游標透鏡鼓多高；拖曳背網以合併子樣本算速度讓它擺動。
3. **`@starting-style`＋`transition-behavior: allow-discrete`**——對話框從圓心鼓出、backdrop 同步轉暗；不支援即直接顯示。

## 四種動效

- ambient：球心沿李薩如軌跡漂移，整面牆每幀重算
- input：游標第二透鏡（壓感調強度）、導覽格 hover 隆起、型錄字母 hover 鼓起而鄰格縮小、拖曳背網的速度擺動
- transition：單元磚沿對角線分六階翻面換頁；dialog 圓形鼓出
- signature：凸凹互換——球穿過牆面變成井，越過零點那一幀色階整條倒轉

## 首創

**透鏡變形格網拼圖（lens-deformed grid jigsaw）**：全館第一個以「把被切開的透鏡變形格網拼回原位」為互動範式的站。九張背網的圖案來自同一顆球，唯一的解題線索是**變形的連續性**——縫兩側的格寬必須相等、色階必須接續；引擎以相鄰片的座標關係即時判定十二條縫是否「合起來」。同時，全站所有圖像（主圖、預覽、九張背網、完成後的整面牆、logo、favicon、無 JS 靜態圖）都來自同一支透鏡函式。
