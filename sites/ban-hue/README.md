## 首創

**repeat-matching 對花**：全館第一個把壁紙施工的「對版／跳版」技能做成可玩規則的站——每一幅都是同一面牆座標上的 SVG `<pattern>` 的一扇窗，上下拖動就是在改它對牆的位移，誤差以版距換算成毫米由師傅裁定；對好的牆再被拿去和一塊布「撞」，依「大配中、中配小」打分，最後用真實的裁長公式（牆高＋修邊＋版距）算出要叫幾支。
