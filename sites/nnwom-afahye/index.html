這一屏是怎麼回事

上面那塊布由六條條幅縫成。每一條是 Bonwire 一台織機獨立織完的，所以六條的長度不一樣——布的下緣是參差的，因為六台機器停在不同的地方。六條的緯浮塊在高度上刻意互不對齊：對齊了就是機器織的，這一行不收。每一條只負責一件事，那件事有多長，那一條就織到哪裡。

畫面窄的時候布會少幾條（只縫三條），但寫在上面的事一件也沒少——全部的事同時在下面這張〈營業事實〉表上。

五個拿掉就不是這個風格的東西

特徵為什麼不能拿掉
1. 條幅與看得見的縫版面不是排出來的，是縫出來的。九到十一公分的等寬直條，條與條之間是一道針距不等的手縫線——不是留白，也不是分隔線。
2. 同一批線，方向轉九十度經面是縱帶，緯面是橫帶。兩者沒有明暗差、沒有第二種材質，差別只有紋路的方向。
3. 跨縫錯位是成品相鄰條幅的緯塊刻意不對齊。對齊了就是機器織的，本行不收。
4. 六軸線，沒有第七色架上只有六軸染好的線。畫面上的每一個顏色都必須是其中之一，不准調淡、不准加透明、不准混。
5. 每塊布有名字，名字是它最顯著的那個母題布是拿來說話的。名字與它要說的話必須寫在版面上。

每一項的做法與可直接複製的 CSS 片段寫在 SKILL.md；它們在站上長什麼樣子，見〈布會說話〉。
