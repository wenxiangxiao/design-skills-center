# 緯昌織網廠 WEICHANG WIRE WEAVING WORKS

**金屬編織網廠 × 莫列干涉 Moiré Interference**

彰化和美的金屬編織網廠。不鏽鋼與銅合金，平織／斜織／荷蘭織，10 目到 200 目，接整捲、裁片、包邊，也接沒有標籤的舊網做目數鑑定。

這個站的出發點是一句巧合：Gerald Oster 與 Yasunori Nishijima 在 1963 年 5 月《Scientific American》的〈Moiré Patterns〉開頭，用來解釋莫列紋的比喻就是**「隔著一片紗窗看另一片紗窗」**。也就是說，歐普藝術干涉分支的第一個例子，本來就是金屬編織網。於是這間廠的產品，正好是這個流派的原料——而且它同時是這間廠的量具。

## 認領的首創

**`moire-vernier` 干涉放大讀數**——全館第一個站，其可讀的量必須靠兩個週期系統的**頻率差被放大**之後才看得見：單獨看任何一層看不到，把兩層相加也看不到，只有**相乘**才會出現；而且出現的圖樣週期是原量的 420 到 1,640 倍。

與既有登記最需辨明的是 yagruma 的「疊印生成內容」：那是兩個不透明墨層的**平移對位**，資訊在位移量上，位移一公釐、內容就位移一公釐，是線性的一對一。本站是兩個週期系統的**頻率差**，資訊在拍頻上，是非線性的放大——上層只要移動 0.0302 公釐（小於畫面上一個像素的五分之一），拍紋帶就整整走過一個 12.70 公釐的週期。

## 核心功能：對目台

規則三句：

1. 檯上這捲來料沒有標籤，只知道是本廠做得出來的七種目數之一（20／24／30／36／40／48／60）。
2. 從抽屜拿一片標準片蓋上去，再把它轉正——條紋越寬代表兩片越接近，條紋整個不見了就是同一種網。
3. 看不到條紋就按〈判定〉；三批都判對，鑑定章給你。

這是**零位法**（null method）：使用者不是去讀一個數字，而是把一個東西調到「什麼都看不到」。看不到的那一刻，兩片就是一樣的。整局約 90 秒。

## 動效四種

| | |
|---|---|
| ambient | 下層以 0.08 公釐／秒送經。位移本身肉眼看不出來，但拍紋跟著跑，速度是它的二十倍 |
| input-driven | 在網上拖曳（或用滑桿、方向鍵）轉動上層，±3°。以 `getCoalescedEvents()` 取回被合併掉的子影格取樣點 |
| transition | 換頁時整站的網回到零位：疊著的對正、斜的轉正、鬆的繃緊；到站再張開。時間軸由 Web Animations API 提供 |
| signature | **干涉放大**：上層只轉 0.1°，畫面上那片巨大的圖樣整個轉過去——沒有任何一個元素在動，動的是兩層的關係 |

四種都有 `prefers-reduced-motion` 降級，且降級後所有讀數（角度、帶距、帶向、規格、價格）完全不變。

## 技術

| 層 | 技術 | 用途 |
|---|---|---|
| A 渲染 | Canvas 2D `ImageData` 逐像素合成（覆蓋率 LUT ＋ 相位累加器） | 干涉紋是兩層透射率相乘的真實結果，不是貼圖或濾鏡 |
| D 輸入 | Pointer Events `getCoalescedEvents()` | 拍紋對角度的放大倍率極高，被合併掉的取樣點會變成肉眼可見的跳動 |
| B 動效 | Web Animations API（`currentTime` 當時間軸／`reverse()`／`finished`） | 換頁的回到零位、判定回饋的硬邊掃桿 |

支援度查證、fallback 具體行為與效能實測值見 `SKILL.md` 第十二章。實測：兩層合成 1100×440 為 7.2 ms／幀；單頁 25.9–27.7 KB。
