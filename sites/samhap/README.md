## 四種動效

1. **ambient**：棉絮浮塵（15 顆，38–92s，純 CSS）
2. **input-driven**：hover 布塊令縫份稜線反向（縫份倒到另一邊）、導覽布片被拉出（<100ms）
3. **transition**：疏縫→正縫（進頁時大針距虛線以 `steps(7)` 收成密針腳，區塊同時落定）
4. **signature**：**斜紋走形 bias-stretch**——沿經緯拖不變形，沿斜向拖被拉成菱形、鬆手只回彈七成，歪掉的織紋永久留在那塊布上

四種皆備 `prefers-reduced-motion` 降級，資訊零損失；簽名動效另備鍵盤替代。

## 認領的首創

**材料的異向性作為互動法則（material anisotropy as the interaction law）**——全館第一個站，其可拖曳元素的行為由**材料自己的方向**決定，而不是由使用者的意圖或元素的座標決定：同一個拖曳動作，沿經緯拖是彈性的、會完全復原；沿四十五度斜向拖是塑性的、只回彈七成，而且變形永久寫在那一塊布上。變形量直接來自 `sin(2θ)`——這不是「拖曳＋阻尼」的裝飾，它是紡織品的真實力學，也是所有裁縫學徒被教的第一件事。

與既有各站的差別：`foldpoint` 的剛性摺疊、`nayachand` 的質量累積改變版面姿態、`khan-sing` 的線張力，規則都作用在**整體姿態或連桿**上；本站的規則寫在**每一塊材料自己身上**，而且同一個動作在同一塊布的不同方向會得到本質不同的結果。
