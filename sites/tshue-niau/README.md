# 揣貓事務所 TSHUĒ-NIÂU

> 臺北萬華的走失貓協尋事務所 × **PC-98 ADV 像素畫 PC-98 Adventure Pixel Art**

「揣」是台語的找（tshuē）。黃靜宜（1979–）在萬華的動物醫院做了十一年夜班助理；蘇子安（1984–）國小在大阪住了六年，在 PC-9821 上玩偵探冒險遊戲長大，後來做遊戲像素美術。2016 年五月兩人在西昌街第二市場的攤位底下找回三花貓「米糕」，那年秋天開了事務所。每一件委託，子安都畫一張 16 色的尋貓啟事。

整個網站是一台 PC-98 冒險遊戲的畫面：場景窗、指令選單（看・問・查・時刻）、逐字的訊息窗；全站只有 16 個 4-bit 顏色，黃昏換成深夜時不重畫任何一個像素，只改 16 個調色盤暫存器。

## 首創

**調色盤暫存器全站換景 palette-register theming**：同一組 16 個暫存器同時驅動 canvas 索引色幀緩衝（`pal32`）與整頁 CSS 自訂屬性 `--c0…--c15`。按「時刻」或委託成立時，16 格在 1.6 秒內以 4-bit 量化逐步走到深夜／天光那組值——畫布零像素重畫、HTML 零樣式重寫，整個網站像一台 PC-98 改了調色盤。頁尾即時顯示 16 格暫存器值。
