## 首創

**一塊磚四面牆的旋轉波 × 無對稱手性磚的找缺口配對**：全館第一個把「同一塊圖案磚、只改旋轉就排出不同的牆」做成簽名動效的站——點任一塊磚，整面牆每塊磚各轉 90°、延遲依與起點的距離傳開，四磚成花→半花相接→花瓣錯位→背對背四種排法循環。磚由程式生成時刻意不留任何對稱（葉子左右交錯＋單側卷鬚），於是鏡像成了「轉幾次都轉不回來」的另一塊磚；〈缺磚〉以此與「另一窯」（鈷偏灰、無銻黃）、「別種花」（瓣數不同）一起當陷阱，讓玩家實際學會怎麼看轉角。
