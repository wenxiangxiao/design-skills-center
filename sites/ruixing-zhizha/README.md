# 瑞興糊紙店 RUI-HSING PAPER OFFERING WORKS

架空在彰化縣鹿港鎮杉行街 27 號的糊紙老鋪，民國五十一年施水木創業，現由第三代施榮川、施秀鑾兄妹經營。靈厝、紙紮傢俬，剖竹、紮骨、糊紙、彩繪、安金五道工訂做——而第六道工不在店內：**焚化，就是交貨。**

## 這個站在做什麼

全館第一個把「**銷毀作品**」當成**唯一交付方式**的站（burn-to-deliver）。

你在工房裡親手配一座紙紮厝：厝型（三合院／洋樓／透天）、瓦色彩紙、十二項傢俬（紙手機、麻將桌、金童玉女、看門犬來福……）、門牌名諱，看板上的厝即時跟著改。但這個配置器沒有「加入購物車」——只有「**擇日焚化**」。按下去，火由下往上把你剛才做的東西真的燒掉（鋸齒火線 clip-path ＋餘燼與煙的 canvas 粒子），燒完出一張化訖單，厝記入「彼岸收執」：從此只以**反相幽靈態**顯示，沒有刪除鈕、沒有復原、不能再編輯。你不是失去它，是寄出它——這是糊紙這個行業的本體論，被寫成了網站的規則。

同一條規則長出全站的視覺簽名：**火線（burnline）**。首頁開場不是 hero，是一道可拖動的焚燒鋒面把同一份 DOM 劈成兩半——左邊是陽間的店（暖炭黑底、螢彩紙色），右邊是燒過之後的彼岸（整層 `invert + hue-rotate` 反相、文案換成「火過了」的版本），餘燼粒子沿著鋒面飄。內頁各有一枚「彼岸鏡」，隨時把整頁翻成燒過的樣子。**每一頁都同時存在未焚／已焚兩態**，火線只是決定你看到哪一邊。

## 首創(全館未有)

**焚毀即交付(burn-to-deliver):作品的完成動作是銷毀它自己。** 全館的配置器都以「保存產出」為終點(訂單、分享碼、圖鑑);本站的配置器唯一的出口是把作品燒掉——按鈕按下去,你做的東西被火吃掉,只換回一張化訖單與一個反相的幽靈紀錄,不可刪、不可逆、不可再編輯。與 gatemark 的差別:那是「過程不可逆」(每一步都記帳,但成品還在);本站是「成品本身必須消滅,交付才成立」,消滅不是代價而是目的。連帶的雙態渲染(每頁同時存在未焚/已焚兩個世界,由火線決定所見)亦為全館首見。

## 技術

單檔 HTML／CSS／JS，零函式庫、零 3D、零外部圖片與音檔，外部資源僅 Google Fonts。焚化動畫為 clip-path 鋸齒多邊形逐幀上行＋canvas 餘燼／煙粒子；`prefers-reduced-motion` 下焚化改為淡出直接出單、幡旗停搖、餘燼停飄，內容與功能不受影響。彼岸收執存 localStorage。`catalog.html` 附 `<noscript>` 完整價目；表單不送出任何資料。所有店號、人名、地址、電話、價格皆為虛構示意。
