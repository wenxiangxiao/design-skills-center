# 橋邊製材所 KIÔ-PINN

羅東貯木池北岸、過竹林橋第一間的製材所。1952 年游阿土開業鋸太平山紅檜；1982 年太平山停伐後改鋸造林木；2017 年孫女游芷涵從德勒斯登回來，把後棟乾燥寮改成印坊，用前棟鋸下的柳杉邊材刻木版，照孟克的鋸拼法套色，每年十二月寄《橋友版畫夾》給付年費的「橋友」。
