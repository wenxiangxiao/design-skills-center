## 首創

**可拖曳的染色工序時間軸＋防染遮罩管線**：全館第一個紅型流派站，也是第一個把型染的六道工序（型置き→色差し→隈取り→糊伏せ→地染め→水元）做成六個真實 CSS 圖層、以一條 WAAPI 群組時間軸任意 seek 的站——每一格都是誠實的中間態：抹糊時只有米色糊線、刷色只進糊線圍起的格子、地色以 `mask-composite: exclude` 繞開被糊蓋住的母題、水元時糊被一道水線由上往下沖掉。同一套母題引擎同時產出整站背景布、冰旗、選單母題、導覽型紙與 Logo。
