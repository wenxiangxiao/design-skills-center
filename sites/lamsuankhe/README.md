# 南山溪蝶園 LAM-SUANN-KHE BUTTERFLY GARDEN

**產業**：蝴蝶生態園（復育、導覽與牌房）｜南投縣埔里鎮南村路 187 號
**風格**：中世紀現代 Mid-Century Modern（一九五〇至六〇年代美國平面現代主義）
**風格代號**：`mid-century-flat-plate`

一九六三年徐阿川在南山溪口開了一間蝶社，做玻璃框標本外銷美國。買家寄來的型錄上，
一隻鳥只用六、七個平色塊就畫完，卻誰都認得出來——那疊型錄被留了下來，
本園的導覽牌從此照那個路數刻。一九八七年停止標本外銷改為復育園，牌照樣刻，
四塊版與十二個形的規矩一條也沒改。

## 八維帳本欄位

- **opening**：`reduction-first` 化約序列直開場
- **nav**：`wingspread` 展翅導覽（現用頁那一隻把翅張開）
- **signature**：`form-budget cascade` 形數連動
- **illust**：`rank-primitive reduction` 排序原語化約構成
- **mood**：`overprint-flat` 疊印平塗
- **func**：認得出來就減一形（辨識驅動的化約，非模擬、非編輯、非蒐集）
- **tech**：`mix-blend-mode:multiply`（A 渲染）／`steps()` 限格動畫（B 動效）／CSS Grid `subgrid`（C 版面）
- **first**：形數作為全站共用的可調預算，且化約順序是圖像資料的一部分

## 認領的首創

**形數作為全站共用的可調預算，且化約順序寫在圖像資料裡**
（form-budget as a site-wide adjustable parameter, with reduction order as image data）

全館第一個站，其**所有插圖共用同一個可調的「形數」**，而每個原語的去留順序是圖像資料的一部分：
按下 12／8／5／3，頁面上每一張圖同時被重畫成新的形數，且愈往下減，二十四種蝶愈長得一樣——
到第三個形時全部相同。核心功能產出的不是分數也不是圖，是一份**六個數字的規格單**；
按下「貼到全園」之後，四頁的每一張圖都改照那份規格刻。

與既有各站的差別：`yongzi-foundry` 改的是字形骨架、字身框不動；`baicaochun` 改的是裝字的容器、字形不動；
`shidong` 產出的東西只存在使用者的視網膜裡；`rendong` 產出的是一個沒有邊界的平鋪；
本站被改變的是**每一張圖各自由幾個形構成**，而那個數字同時是畫面、是成本、也是功能的輸出物。

## 四種動效

1. **ambient**：開場序列每 7.2 秒整組換一種蝶（限格重畫）；標題帶有一隻限格拍翅飛過的青鳳蝶
2. **input**：hover／focus 色域卡上推 4px 並吐出「名稱／幾個形」標籤，90ms 內完成
3. **transition**：內容以 `clip-path` 由左往右限格擦除進場（載入、換篩選、出回執各一次）
4. **signature**：形數連動——全站每一張圖同時改形數

四種皆有 `prefers-reduced-motion` 降級且資訊零損失。
