# 崁仔腳夜市 KHÀM-Á-KHA NIGHT MARKET

**產業**：夜市攤商自治會（新北市板橋區崁仔腳街，24 攤 3 條巷，每晚 17:30–24:00，週一公休）
**風格**：新粗獷 Neubrutalism（型錄「數位與螢幕原生」類「Neubrutalism 網頁新粗獷」條目，全館第 1 站）

## 品牌設定

2025 年夏天，崁仔腳夜市攤商自治會投票通過〈招牌五條〉，二十四面招牌照同一套規矩重畫：

1. 價錢要比菜名大。
2. 黑框三公分，一面一個顏色（北巷黃、中巷粉、南巷薄荷綠）。
3. 影子只往右下，掛多高影子就多長。
4. 字一律粗黑，不准花體、不准漸層、不准 LED 跑馬燈。
5. 加價的東西寫出來，寫在貼紙上。

這五條就是新粗獷的五個不可省略特徵——風格從產業裡長出來：夜市招牌本來就是「一塊一色、價錢最大、要在人群裡三秒被看見」。

## 核心功能〈掃街〉

1. 把攤位拖進托盤（或按一下）。錢包 NT$350，胃 12 格。
2. 塞不下、錢不夠，托盤會把它彈回去。
3. 按「開吃」，排出最短的掃街路線（Held-Karp），印一張號碼牌：路線地圖、公尺數、評語、分享連結。

## 首創

**陰影即高度（shadow-as-elevation）**：一個 `@property` 型別化的 `--z` 同時驅動 transform 與 box-shadow，靜止／懸停／按下／拖曳／落下都是同一個變數；簽名動效〈落牌〉用一條帶超調值的 CSS `linear()` 寫完下落、撞地、回彈，撞地瞬間隔壁板子震一下；拖曳中的價牌用 CSS 錨點定位跟著板子走並在視窗邊自動翻面。
