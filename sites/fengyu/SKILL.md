# 觀察蜂箱風 Observation-Hive

## 一、設計哲學

這個風格從一件事長出來：**蜜蜂在漆黑的蜂箱裡，用一支舞把幾公里外的一朵花講清楚。** 沒有畫面、沒有燈、沒有文字——只有一面直立的巢脾、一個重力方向，和一隻擺著尾巴走直線的偵察蜂。整個視覺語言要做的，是把「觀察箱」那股暗、蜂蠟的暖、六方巢格的秩序，糊成一個能親手讀、也能親手編的舞台。

三個信念：

1. **巢格即版面。** 六方蜂巢的鑲嵌不是裝飾底紋，而是整站的結構網格：面板、卡片、導覽、徽記都從六邊形長出來。
2. **一支引擎畫完全部。** 沒有任何外部圖片。蜂、巢格、舞徑、太陽羅盤、田野地圖、蜜源縮圖、報名舞印——全是同一支「巢格＋舞徑」引擎照參數畫出來的。畫成寫實插圖或拍照風就退化了。
3. **暗，是觀察箱的暗，不是儀器的黑。** 底色是蜂蠟被燻黑的暖褐，作用色是蜜的琥珀、花粉的金、蜂膠的赭；避免落進「冷色暗底＋量表」的儀器台公式。

## 二、色彩系統

| 用途 | Hex | 佔比 | 說明 |

| 蠟盤 panel（控制台、篩選列） | `#2B2010` | ~6% | 操作區底 |
| 蜂蠟 wax（正文、亮面、巢格奶油） | `#EFE0BE` | ~18% | 主要前景色／舞徑返回環 |

| 花粉金 pollen（高亮、太陽、直行段、數字） | `#F2C74B` | 作用 | 直行段（訊息）與讀數的金 |

比例守則：暖褐三階（comb／comb2／panel）撐起暗底；蜜琥珀是唯一被允許大量出現的暖作用色；金只點在「訊息」（直行段）與讀數上；綠嚴格保留給花與命中，不外溢。**禁止**把底色壓成冷灰或近純黑——那會退化成儀器台。

## 三、字體系統

- **標題（中文）**：`Noto Serif TC` 900／700。刊頭 900、區塊 h2 700。字距 `.04–.06em`。
- **標籤／英文副題／圖說**：`Fraunces`（opsz）500/600，多用 `italic`。它是這個風格的「田野筆記手感」——標本標籤、圖註、eyebrow 一律用它。
- **讀數／座標／編號**：`Space Mono` 400/700。方位角、距離、擺尾毫秒、留位號、統計數字一律 mono——這是「量出來的字」。
- **內文**：`Noto Sans TC` 400/500，行高 1.7–1.8。
- 字級 scale（桌機）：刊頭 h1 `clamp(23px,3.5vw,40px)`；區塊 h2 `clamp(18px,2.6vw,24px)`；內文 15–16.5px；讀數 19px；標籤 11–13px。

## 四、版面與網格

- **不對稱雙欄**：核心頁把「巢脾舞台」與「田野羅盤」並置成 1:1 雙欄，控制台橫貫其下；≤820px 疊為單欄。
- **六方格是結構不是紋樣**：導覽是右上角四枚六邊形巢格；舞台底是烘一次的六方鑲嵌（pointy-top，橫距 √3·s、縱距 1.5·s、奇數列右移半格）。
- **留白密度中等**：面板間距 14–16px，3px 墨色描邊、2–3px 圓角（近無圓角），硬邊、無模糊陰影。
- **旋轉**：本風格幾乎不旋轉版塊；唯一會轉的是「直行段」與「蜂身」——那是訊息本身，不是裝飾。

## 五、元件配方

- **nav（comb-cluster 巢脾六格）**：`position:fixed` 右上角一枚 118×112 的 SVG，四頁為四枚六邊形 `.cell`（預設 comb2 填色、3px 墨邊）。現用頁 `aria-current="page"` → 該格翻蜜琥珀、頁名翻墨、格內浮出一隻小蜂 `.bee`（預設 `opacity:0`）。hover 翻蜂膠赭。≤820px 縮到 92px。**非置頂列**。
- **按鈕**：主行動 `.btn.go` 蜜琥珀底墨字墨邊；次要 `.btn` 巢2 底、蜂膠赭邊、hover 翻赭。無「按壓硬陰影」位移特效。
- **模式切換**：兩顆相連的 `.modes button`，`aria-pressed="true"` 翻蜜琥珀。
- **卡片**：巢2 底、3px 墨邊；左側恆為一枚由引擎生成的小舞徑 SVG，右側資訊。標籤用 `.tag`（mono、細墨邊）。
- **表單**：input 巢底、`#4a3818` 邊、focus 翻蜜琥珀邊；錯誤訊息 `.err` 用警示紅；label 用 Serif 700 蜂膠赭。
- **滑桿 range**：軌道巢底細邊、thumb 蜜琥珀圓鈕墨邊、focus 翻花粉金。
- **footer**：`#160F06` 更深底、3px 墨頂邊；品牌 Serif 900、`.built` mono 註記卷別、`.fx` 虛構聲明與跨頁連結。
- **readout**：四格 mono 讀數卡（key 用 Fraunces italic、n 用 Space Mono 花粉金、u 用蜂膠赭）。

## 六、動效規則

- **核心動效＝直行段與蜂的舞**（使用者／時刻驅動，非裝飾）：
  - 舞徑：`figure-eight`＝一條直行段（訊息）＋兩側三次貝茲返回環；直行段方向 `dir=(sinθ,-cosθ)`（θ 為對重力順時針角）、長度隨距離 `L=42+min(d,5000)/5000*128`。
  - 蜂：`requestAnimationFrame` 沿舞徑走；直行段時腹部橫向擺動 `sin(q·7π)`＋蜂身微傾，返回環左右交替。全週期時長由擺尾毫秒推得。
  - 派工蜂：14 隻由巢心飛向被解出的花叢，每隻帶高斯角度誤差（sd≈7°）與 ±16% 距離誤差，`ease-out cubic` 約 1.15s；落在花叢半徑內即翻蜜源綠、計命中。
- **太陽補償**：拖「當地時刻」桿 → 太陽方位 `sunAz(h)=90+(h−6)·15` 改變 → 直行段即時重算重繪（編舞模式最明顯）。
- **克制清單（本站刻意避開，不得作為 signature 主打）**：揭示淡入、數字計數/滾動、按壓硬陰影、`stroke-dashoffset` 描繪。無跑馬燈、無自動輪播、無自動播放。
- **`prefers-reduced-motion`**：停用 rAF；蜂靜置於直行段中點、派工蜂瞬間就位、關閉平滑捲動。核心可玩性不減（讀數與換算全靠滑桿與拖曳，本就不依賴動畫）。

## 七、插畫與圖像風格（hexcomb-waggle 六方巢格與搖擺向量構成）

全站沒有一張外部圖片，也沒有一張「描外形」的插圖。三種原語構成一切：

1. **六方巢格 hex-comb**：pointy-top 六邊形鑲嵌；每格填色由決定性 PRNG（`mulberry32`）抽自 {巢2 暗格、蜜琥珀封蓋蜜、育蟲蠟、花粉金、蜂膠赭}，暗格不透明、暖格半透明。
2. **搖擺舞徑 waggle-path**：直行段（金、粗）＋兩側返回環（奶油、細、半透明）＋對重力夾角弧（蜂膠赭）＋角度讀數。一張「舞圖」＝一組 `(θ, 距離)`。
3. **程序蜂 bee**：橢圓腹（蜜琥珀）＋三道墨色條紋＋墨頭＋兩片奶油翅，由部位幾何生成、可任意縮放與旋轉。

太陽羅盤（同心距離環＋放射光的太陽圓）、田野地圖（以巢為原點、N 向上、方位=角度）、蜜源縮圖、報名舞印，全部復用這三種原語。分工不可對調：**金＝訊息（直行段/讀數）、奶油＝結構（返回環/正文）、綠＝花與命中、赭＝夾角與強調**。同一組參數恆得同一張圖。

## 八、Logo 與 Favicon 設計指南

- **Logo**（`assets/logo.svg`，132×132）：巢影底上四枚六邊形巢格（其一為蜜琥珀封蓋蜜、含花粉金蜜蓋點）＋一組搖擺舞徑（金直行段＋奶油返回環）＋一隻程序蜂停在直行段上；外框 2px 育蟲蠟。**它用的原語就是全站引擎的原語**。
- **Favicon**（inline SVG data URI，32×32）：巢影底＋一枚蜜琥珀六邊形＋一條傾斜的金色直行段＋一隻暗色蜂身橢圓。三筆說完「巢＋舞＋蜂」。
- 禁止用 emoji（🐝/☀/📞…）或任何外部圖示；太陽一律以「圓＋放射短線」畫，不用 ☀ 字符。

## 九、Do & Don't

**Do**
- 讓「角度＝對太陽方位、時長＝距離」這組換算成為互動核心；任何頁面的舞圖都要能被讀回座標。
- 暗底用暖褐三階；金只給訊息與讀數；綠只給花與命中。
- 圖一律由引擎生成、同輸入同輸出；靜態頁把舞徑烘成 SVG，無 JS 也看得到。
- 一定要有「當地時刻／太陽方位」的桿——沒有它，角度讀不出方向。

**Don't（含去 AI 化禁令）**
- 不用紫藍漸層 hero、不用「置中大標＋副標＋兩顆按鈕＋三張圓角卡片」模板、不用置頂純文字列導覽。
- 不用 emoji 當 icon、不用寫實蜜蜂照片或外部插圖、不用細線幾何線描（thin-lineart）。
- 不把暗底壓成冷灰儀器台、不用米白紙感底。
- 不把「揭示淡入／數字計數／按壓硬陰影／dashoffset」當招牌動效；不放跑馬燈與自動輪播。
- 不用 Lorem ipsum、不用 AI 腔（「在當今快節奏的世界」）、不用「EST. 19xx」徽章、不用「把 X 變成 Y」標題。

## 十、頁面骨架範例

```html
<!-- comb-cluster 導覽（四頁四格；現用頁翻蜜琥珀＋浮蜂） -->
<nav class="combnav" aria-label="主導覽">
 <svg viewBox="0 0 118 112" role="presentation">
  <a href="index.html" aria-current="page"><title>舞台</title>
    <polygon class="cell" points="38,14 55.3,24 55.3,44 38,54 20.7,44 20.7,24"/>
    <text class="lbl" x="38" y="33" text-anchor="middle">舞台</text>
    <text class="en" x="38" y="45" text-anchor="middle">STAGE</text>
    <ellipse class="bee" cx="49" cy="19" rx="3" ry="4.4" fill="#241A0C" stroke="#140E06" stroke-width="1.2"/>
  </a>
  <!-- 其餘三格同理 -->
 </svg>
</nav>

<!-- 一支舞徑：直行段(訊息) + 返回環 + 蜂 -->
<svg viewBox="0 0 96 118">
  <line x1="48" y1="10" x2="48" y2="106" stroke="#5a4620" stroke-dasharray="3 4"/>
  <!-- 返回環（奶油、半透明）＋直行段（金）由引擎依 (θ,距離) 生成 -->
  <line x1="48" y1="96" x2="68" y2="46" stroke="#F2C74B" stroke-width="3" stroke-linecap="round"/>
</svg>
```

核心換算（可直接複用）：

```js
function sunAz(h){return 90+(h-6)*15;}          // 太陽方位：06→90(E) 12→180(S) 18→270(W)（教學簡化）
function distToDur(m){return m*0.75;}           // 擺尾毫秒 ≈ 距離公尺 × 0.75（約每 100m 75ms）
var bearing = (sunAz(h) + danceAngle) % 360;    // 解舞：角度 → 方位
var danceAngle = ((bearing - sunAz(h))%360+540)%360 - 180;  // 編舞：方位 → 角度
```
