# 羊齒園 IÛNN-KHÍ FERNERY

**蕨類苗圃兼晴天曬圖 × 藍曬 Cyanotype（Anna Atkins 光圖半身）**

新北石碇溪邊坡上的蕨類苗圃：1978 年從山蘇開始，現在有六百多盆腎蕨、鐵線蕨、過貓；第三代游晴在林業試驗所標本館看到 Anna Atkins 1843 年的藍曬複刻本之後，每一盆都附一張同一株葉子曬出來的藍曬卡。整個網站是一張正在曬的感光紙：首屏的曬台依**石碇此刻的真實太陽**曝光，葉尖的影子往太陽的反方向糊開，沖水時藍從水流過的地方綻出來。

> 店名、人物、地址、電話、價格皆為虛構示意。石碇、國道五號石碇交流道、林業試驗所植物標本館、Anna Atkins 與 John Herschel 的藍曬史為真實背景。

## 動效

- **ambient**：首頁曬台自己跑一輪又一輪——刷感光液、放葉、依石碇此刻太陽曝光（離紙的葉尖隨微風擺）、拿開、水洗、晾、換下一片；夜裡自動改「UV 燈箱」、比較慢＋ML
- **input**：首頁游標是你的手影（遮光，曝光時留下較淺的一塊）；曬一冊拖曳／方向鍵挪葉子（曬的時候挪會留下兩層影子）；圖譜圖版 3D 微傾；導覽 hover 一階曝光
- **transition**：塗布換頁——一道刷邊的普魯士藍蓋滿、下一頁由左往右洗開；新紙的感光液前沿＋ML
- **signature**：**水洗顯影 wash-bloom**——斜向水流前沿掃過，前沿前是黃綠／灰古銅的未洗紙，前沿後綻成普魯士藍、沒曬到的地方洗回紙白

## 首創

**兩段式光化學顯影著色器**：全館第一個把「藍曬的化學」寫成渲染管線的站——曝光是逐像素累積的光量（16-bit 打包在 RGBA8 的 ping-pong 紋理裡，所以拖動葉子、手影遮光都會真的留在紙上），顯示時才依水洗前沿把「未洗黃綠／灰古銅」換成「普魯士藍／紙白」；離紙葉片的半影方向與寬度由石碇此刻的太陽方位與高度（NOAA 算式）推算，曝光速率由太陽高度決定。
