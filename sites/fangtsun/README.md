## 品牌設定

創辦人方梅溪一九六〇年在大溪租磚房沖貝殼扣起家，一九七〇年翻修廠房時把娘家裁縫店門上的石刻搬過來，重刻「扣有其格，格有其扣」八個字。二代方允中在成衣外移的年代把最低訂量從三十籮降到五籮改做小批量；三代方頌宜二〇一四年接廠，加了「同批色差樣」的規矩，二〇二一年停掉所有彩色印刷品——因為彩色印不準，客人收到貨會吵架，材質改用**格子記號**分：貝是四角四格、椰是對角三格、角是半格、膠木是滿格。

廠裡九個人，一年出四萬八千籮。釘卡師傅何清和是本站對局功能的對手。

## 八維中的 function：六六方

一張三十六格的扣卡，你與釘卡師傅何清和輪流往上釘扣。規則三句話：

1. 輪流從本季八顆扣裡揀一顆，釘在空格；
2. 一顆扣跟它上下左右的鄰扣只能差一項——材質不同就得孔式相同，孔式不同就得材質相同；
3. 每圍出一個「同孔式、材質兩兩相間」的二乘二就得一分，先得五分或格滿時分高者贏。

贏的那張卡按「掛到門口」會取代首頁陳列窗裡的樣卡（`localStorage` 跨頁生效），並發一個卡號與可還原的 `?k=` 分享碼（三十六字元，一格一字元，同碼恆得同卡）。

**實測**（Node 22，八百局全自動對打）：平均 19.6 手、填 19.6 格、成 7.46 個相間方；違規手 0 次；編解碼往返 100% 一致；師傅單手決策 1.76 ms。難度是設計過的——完美打法對師傅勝率 80%、一般水準 29%、生手 8%，所以贏得到，但要動腦。

## 認領的首創

**版面尺寸的量化作為全站唯一的空間語法（quantised layout as the site's only spatial grammar）**：全館第一個站，其所有幾何量——牆寬、欄寬、留白、圖版、卡格——都在 CSS 內被 `round(down, …, var(--u))` 鉗到同一個格單位的整數倍，因此改變視窗時版面不是連續縮放而是**一格一格跳**，且右上角的格數讀數與頁首棋盤格帶會同步跳一次、閃一次金。

與既有各站的差別：`beian` 的磚「大小＝資訊密度」改的是每一塊磚說多少話（容器查詢），版面本身仍是連續的；`rendong` 的翻版遷位重算的是平鋪的格子怎麼咬合，畫布尺寸不參與；`shidong` 以 `ResizeObserver` 保證整數格數但那是為了不讓場被拉伸，尺寸本身仍連續。本站被量化的是**長度這件事本身**——這個站上不存在任何一個非整數格的尺寸，而這正是分離派把 Ver Sacrum 做成正方開本時想要的那件事，一百二十六年後由 `round()` 執行。
