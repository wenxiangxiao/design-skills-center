## 首創

**毛細前緣作為狀態變化的媒介（capillary wet front as state-change medium）**：全館第一個讓「顏色改變」不是切換、也不是淡入，而是一道從水線往上爬的濕潤前緣——每一欄高度依 Washburn 定律 h∝√t 上升並帶雜訊；先上未媒染的色，前緣到頂後由下而上再跑一道媒染翻色；晾乾時濕暗退去，在最高處留下永久的潮線，重覆浸會疊出一級級的階。同一套前緣也是換頁轉場的形狀。

**全站色碼單一來源**：CSS、SVG logo、favicon、canvas、表格裡的每一個 hex 都是 `dye(染材, 媒染, 回數)` 的輸出，建置時有任何未解記號即中止。
