五條規矩FIVE RULES THAT MAKE IT THIS STYLE

把任何一條拿掉，它就不是這個風格了。每一條下面都有一塊可以直接動手驗的實物。

一．只有一個光源，而且全站共用ONE LIGHT, SHARED BY EVERYTHING

這是最多人做壞的一條。三顆按鈕各自畫一個白色橢圓在正上方，看起來就像三顆貼紙； 正確的做法是先決定燈在哪裡，再讓每一個面自己算出它的高光該在哪一側。

三塊的高光角度不一樣，因為它們離燈的方向不一樣；強度也不一樣，因為離燈的距離不一樣。 這兩件事都是 atan2() 與 hypot() 在 CSS 裡算的，沒有 JavaScript 在算幾何。

二．濕的會位移，乾的不會REFRACTION, NOT PARALLAX

底下四塊的顏色、大小、圓角、陰影完全一樣。差別只有一個：它們在水面下多深。

移動指標。第一塊完全不動；後面三塊越深錯得越多。 位移量不是隨便設的係數，是把入射角代進 Snell 定律（n = 1.33）算出來的折射偏移。 這一站把它當簽名動效：全館沒有第二個站的東西是這樣動的。

三．水會吃掉紅色DEPTH EATS RED FIRST

水對長波的吸收比短波快，所以越深的東西越偏青、對比越低。這件事不是濾鏡，是調色盤規則： 同一個顏色在不同深度必須用不同的色票，而且那組色票是算出來的，不是憑感覺調的。

同一顆橘色的魚，從貼著玻璃游到五十公分深，就是這六格。紅走得最快。

四．光澤是切出來的，不是畫上去的THE GLOSS IS A MASK, NOT A SHAPE

Aqua 鈕上面那一道上弦月不是一個白色橢圓——它是一個圓減去另一個圓剩下的部分 （mask-composite: exclude）。所以它的兩端會自然收成尖的，而且鈕變寬變窄時月牙會跟著變形，不會走鐘。

　　

把瀏覽器縮到很窄再看一次：月牙的比例不會跑掉。這就是用遮罩做而不是用圖形做的差別。

五．有機的東西要真的朝著光LIVING THINGS LEAN

這個風格裡一定有一片葉子、一株草、一滴水。它們不是裝飾貼圖——它們必須知道燈在哪裡。 缸裡每一叢草的傾角都是從同一組光源變數算出來的；燈推到左邊，整缸草會慢慢倒向左邊。

做不到這一點的時候，寧可不要放草。一株朝著錯誤方向的草會讓整個畫面立刻變成貼圖拼貼。

「減少動態效果」開啟時草不會再擺動，但它們仍然是朝著光的——降級掉的是過渡，不是資訊。

不准做的事DON'T

  • 不要對角漸層。光從上面來，所以漸層只能是垂直的。
  • 不要紫藍漸層、不要彩虹漸層。這個風格的色相只有天空、水、草三族。
  • 不要對介面元件用模糊陰影堆疊。模糊只能用在水面以下（那是景深），介面本身要硬邊。
  • 不要用一張水滴照片。水滴要自己畫，而且它的高光必須跟其他所有東西指同一個方向。
  • 不要把長文放在濕的那一層。會晃的東西不能拿來讀。
