# tit-tâng 直筒洋裁教室・自家手印棉布

> 洋裁補習班兼手印棉布行 × 芬蘭印花布 Finnish Printed Cotton（Printex／Marimekko 1949–1970s，Maija Isola 大圖平塗印花）

臺南市中西區民權路二段 143 巷 7 號的洋裁教室。1966 年林素卿在民權路二樓開洋裁補習班；1968 年從一本神戶寄來的家政雜誌上看到芬蘭印花布做的直筒洋裝，從此認定「褶越多，花被切得越碎；花越大，衣服就要越簡單」。1971 年與先生陳文雄在後院搭起十二公尺印台，自己繃網、感光、調墨，第一張網〈菝仔〉至今仍在印。現在只教一種衣服：直筒。印台師傅黃德明（1979 年起）、第二代陳以安管配色本。電話 (06) 222-0571，週二至週六 10:00–19:00、週日 13:00–18:00、週一休，每週四開台印布。

## 〈配色本〉怎麼玩

1. 選一張網（菝仔／水窟／竹篙／風颱），從架上十罐墨挑兩罐給 A 網、B 網，再挑布地（漂白／生成／淡天）。
2. 墨是透明的：兩版相疊處自己長出第三色（線性光相乘），你不能直接選它；B 網永遠套偏 4 mm。
3. 拖動人台（或方向鍵、「轉一圈」），越快裙擺張越開；按「交給林老師看」——兩版分得開、疊得出第三色、淺墨吃得住布地，三條都過才能印（試印布巾 NT$350 或直筒洋裝四堂 NT$3,200）。黑墨永遠過不了第二條。

## 風格關鍵字

放大到被布幅裁掉的巨形・筆刷邊平塗・一張網一罐墨・透明墨疊印長出第三色・套偏不修・版距可見的半錯接重複・布邊印字・布頭留白承載文字・小寫無襯線小字・吊牌・鋸齒剪邊
