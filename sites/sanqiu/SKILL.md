# 拋物運動風 Ballistic-Notation

> 一套從「雜耍記譜」長出來的視覺語言。所有圖像都是某串 siteswap 記譜的拋物線與落點，換一串數字就換一張圖。高飽和撞色、粗描線、硬陰影，像一本會動的運動筆記。

## 一、設計哲學

- **記譜即美術**：不放任何裝飾插圖。招牌、favicon、圖鑑縮圖、報名印記，全都是拋接引擎照某個 siteswap 生成的拋物線族與落點梯圖。線有語意（拋幾拍、過不過手），不是純裝飾。
- **先動再算**：頁面一載入球就在丟（cascade-live），使用者先看到運動、再回頭理解規則。互動的重點是「編一段能丟的節奏」，不是讀一篇文案。
- **高能但有秩序**：色彩撞得很兇，但每個顏色綁定固定語意；版面靠 3px 硬線與網格撐住，讓能量不散。
- **去AI化**：無紫藍漸層、無置中大標＋兩顆按鈕、無圓角模糊卡片、無 emoji（icon 一律自繪 SVG）、無跑馬燈、無 EST. 徽章當裝飾。

## 二、色彩系統

| 色 | Hex | 用途 | 比例 |
| --- | --- | --- | --- |
| 奶油底 | `#FBF2DE` | 全站大面積地色、面板反白 | ~40% |
| 墨黑 | `#16130E` | 文字、3px 描線、動畫台深底、footer | ~28% |
| 訊號黃 | `#FFC400` | hero 面板、favicon 底、hover、合法徽章 | ~10% |
| 群青 | `#1E44C8` | eyebrow、統計條、focus 外框、主要拋物線 | ~9% |
| 朱紅 | `#EF3B1C` | 現用態、警示／非法、行動、球 | ~8% |
| 草綠 | `#2AA968` | 第五拋物線色、成功背景輔助 | <5% |

用色規則：**顏色語意不可對調**。朱紅永遠是「現在／錯誤／行動」，群青是「資訊／主拋線」，黃是「肯定／高亮」。動畫台與軌跡圖固定深墨底（`#16130E`），球與弧線用四到五個 accent 循環上色。錯誤態用朱紅，不另引入新紅。底色一律奶油暖白，禁止改成米白紙感以外的冷灰。

## 三、字體系統

- **標題 Display**：`Bricolage Grotesque`（800）。粗、略帶手感的 grotesque，字距 -0.01em，行高 1.02–1.08。用於 h1/h2/h3、品牌名、大數字。
- **內文**：`Noto Sans TC`（400／500／700），行高 1.65–1.72。
- **記譜與標籤 Mono**：`Space Mono`（400／700）。所有 siteswap 數字、留位號、eyebrow、統計 k 標籤、座標讀值都走這支等寬字，字距 0.1–0.24em、常大寫。
- 字級 scale（桌機）：hero 30–52px、section 標題 26–40px、卡標 18–24px、內文 14.5–17px、mono 小標 9.5–13px。
- 僅從 Google Fonts 載入這三支；無其他外部資源。

## 四、版面與網格

- 最外層容器 `max-width:1120px`；閱讀頁（記譜／報名）收窄到 720–760px。
- **不對稱開場**：首屏切成左右兩塊——左邊深墨動畫台（略寬 1.15fr），右邊訊號黃文字塊（0.85fr），中間一條 3px 墨線分隔。不做置中大標。
- 網格分格一律 3px 實線、**去圓角**（border-radius:0）。卡片用「位移硬陰影」：`box-shadow: 5–8px 5–8px 0 #16130E`（純黑、無模糊、無透明）。
- section 間用 `hr` 3px 墨線或 `border-top` 分段。
- 留白中等密度：資訊塊之間 40–46px，卡內 padding 18–26px。

## 五、元件配方

- **導覽 apex-arc**：頂列右側一段 SVG 拋物線，四頁是四顆坐在拋物線頂點與端點的球（各標一個 siteswap 數字）。現用頁球翻朱紅底＋4px 墨色 offset 陰影，其餘描邊反白。≤680px 隱藏拋物線，改底部固定四格 dock（現用格朱紅底）。
- **按鈕**：`3px solid #16130E` 邊、方角。主按鈕墨黑底反白字，hover 轉群青；次按鈕反白底墨字，hover 轉黃。font 用 Space Mono 700。
- **記譜輸入框**：大號 Space Mono（30px）、字距 0.14em、3px 邊、方角；focus 時 `outline:3px solid #1E44C8; outline-offset:2px`。
- **判定列 verdict**：一整條橫列，合法時淡綠底＋黃徽章，非法時淡紅底＋朱紅徽章；右側並列大數字統計（球數／週期／最高拋／難度星）。
- **卡片**：反白底、3px 墨邊、位移硬陰影；上半是深墨底的軌跡圖 viz，下半是記譜大字＋說明＋語意標籤（tag：群青／黃／描邊三型）。
- **表單**：三步驟進度條（3px 邊、現用格墨底黃字、完成格黃底）；選項為大塊 label 卡，選中翻黃底＋硬陰影；輸入框同記譜框規格；錯誤訊息朱紅粗體即時顯示。
- **footer**：深墨底、三欄，標題反白 Bricolage、連結淺褐 hover 轉黃、meta 用 Space Mono。

## 六、動效規則

- **核心：拋接動畫**（canvas）。連續拍時間 `t = 經過毫秒 / BEAT`（BEAT≈430ms）。每拍依 `seq[b mod n]` 決定拋高 h；一次拋接從第 b 拍（手＝b mod 2）飛到第 b+h 拍，飛行進度 `p=(t-b)/h`：
  - 水平：奇數 h 在左右手 x 之間內插（過手）；偶數 h 留同手，走一段 `sin(πp)` 的向外小弧。
  - 垂直：`y = baseY - peak(h)·4p(1-p)`，`peak(h) ∝ h²`（拋越高停越久、飛越高）。
  - 球用 accent 循環上色，12px 半徑、3px 墨描邊、左上白色高光點。
- **落點梯圖 / 軌跡圖**（SVG，靜態）：橫軸為拍、每次拋接畫一條二次貝茲弧從第 i 拍跨到第 i+h 拍，弧高 ∝ h²；`2` 畫成原地小回圈，`0` 不畫。撞球的兩拍改朱紅虛線標出。
- **避開的過載語彙**：不以「揭示淡入／數字計數滾動／按壓硬陰影當簽名／stroke-dashoffset 描繪」作為動效簽名；拍數與統計的數字更新是功能性讀值，不做計數動畫。無跑馬燈、無自動輪播。
- **reduced-motion**：`prefers-reduced-motion` 時停止動畫，改畫所有球停在各自拋物線頂點的靜態格，並保留可讀的落點梯圖；音訊類一律不自動播放。

## 七、插畫與圖像風格（siteswap-orbit）

- 唯一原語：**拋物線弧＋落點刻度＋球點**。一張「圖」＝一串 siteswap。
- logo：兩隻手（墨色矮托台）＋三條交錯拋物線（群青主線、朱紅次線、墨色虛線）＋三顆描邊球（黃／朱／群青）＋底部一行 mono 記譜數字。
- favicon：訊號黃底、一條墨色拋物線、三顆小球（朱／群青／奶油）。
- 圖鑑縮圖／報名印記：深墨底上畫該記譜的弧線族＋落點，配 mono 數字；報名印記的記譜由留位號經 FNV-1a → mulberry32 決定性生成（同號恆得同印）。
- 分工不可對調：弧線用 accent、落點球墨底上用奶油、數字用奶油或黃、底恆深墨。全站零外部圖片。

## 八、Logo 與 Favicon 設計指南

- Logo 必含三要素：**手（基線托台）＋拋物線（至少兩條交錯）＋描邊球（2–3 顆）**，可加一行 mono 記譜數字點題。比例橫向、留白透明。
- Favicon 用 inline SVG data URI 寫在 `<head>`；32×32、黃底、一弧三球，維持與 logo 同一語彙。
- 所有球一律 3px 墨描邊；拋物線 stroke-linecap:round。

## 九、Do & Don't

**Do**：先讓球動起來再解釋；每個顏色綁固定語意；用 3px 硬線與位移硬陰影；記譜與座標用 Space Mono；圖全部由拋接引擎生成；提供 reduced-motion 靜態格與純文字方法頁。

**Don't**：不放外部圖片或照片；不用圓角模糊卡片；不用紫藍漸層 hero；不用置中大標＋兩顆按鈕模板；不用 emoji 當 icon；不放跑馬燈；不用 EST. 徽章當裝飾；顏色語意不可對調；不把數字更新做成炫技計數動畫。

// 合法性核心：落點雙射
function analyze(seq){
  const n=seq.length, land=new Array(n).fill(-1);
  for(let i=0;i<n;i++){ const l=(i+seq[i])%n;
    if(land[l]!==-1) return {valid:false, collide:[i,land[l]]};
    land[l]=i; }
  const sum=seq.reduce((a,b)=>a+b,0);
  if(sum%n!==0) return {valid:false};
  return {valid:true, balls:sum/n, period:n, max:Math.max(...seq)};
}
