記譜法 · SITESWAP

看得懂一串數字，
就看得懂一場雜耍。

Siteswap 是雜耍界通用的記譜法，1980 年代由幾組人各自獨立想出來。它把「怎麼丟」寫成一串數字。這一頁把規則講清楚，全部純文字，不用開動畫也讀得完。

一、每個數字＝滯空拍數

想像你左右手輪流、每一拍丟一顆球。某一拍丟出去的球，數字就是它「要在空中待幾拍」才會被再次接到並丟出。

數字意思手感
0這一拍空手手上沒有球，休一拍
1快速橫遞到對手幾乎是用推的，很低很快
2拿著不動球停在手裡等一拍
3標準拋（三球基準）最順、最省力的高度
4中高拋，回同一手四球噴泉的基準
5高拋，過手五球基準，或三球花式的亮點
7、9更高的拋停留更久，給你時間處理別的球
a、b…10、11…（十進位以上用字母）超高拋，多球炫技用

二、奇數過手、偶數回自己

因為左右手每拍交替，一顆球飛越的拍數是奇數，就會落到「另一隻手」；是偶數，就回到「同一隻手」。

所以 3 一定交叉（三球連拋看起來像個 X），4 一定同手（四球噴泉是兩條平行的柱子），2 是同手的短暫停留，1 是過手的超低快遞。

三、平均就是球數

把整串數字加起來、除以它的長度，得到的平均值就是你需要的球數。這是 siteswap 最好用的心算：

記譜加總 ÷ 長度球數
531(5+3+1)/3 = 9/33 顆
441(4+4+1)/3 = 9/33 顆
552(5+5+2)/3 = 12/34 顆
97531(9+7+5+3+1)/5 = 25/55 顆

如果平均不是整數，這串就不可能是一個合法的拋接——例如 32 平均 2.5，不成立。

四、合法性：落點不能撞

光是平均為整數還不夠。真正的判準是：每一拍丟出的球，落點必須各自落在不同的拍上；只要有兩顆球排到同一拍落進同一隻手，那就是撞球，丟不成。

落點雙射定理

一串長度 n 的記譜，把第 i 拍（i 從 0 數起）的球排到第 (i + 該拍數字) mod n 拍。若這 n 個落點恰好是 0…n−1 的一次不重複重排（一個雙射），這串就合法；此時平均必為整數。

拿 531 驗算（n=3）：第 0 拍 → (0+5)%3 = 2；第 1 拍 → (1+3)%3 = 1；第 2 拍 → (2+1)%3 = 0。落點是 {2,1,0}，三個都不同 → 合法。

再看長得很像的 521：第 0 拍 → (0+5)%3 = 2；第 1 拍 → (1+2)%3 = 0；第 2 拍 → (2+1)%3 = 0。第 1 拍和第 2 拍都排到第 0 拍 → 撞了，丟不成。這就是拋接台會擋下 521 的原因。

記譜落點判定
531{2,1,0}合法・3 球
441{1,2,0}合法・3 球
423{1,0,2}合法・3 球
521{2,0,0}撞球
54{1,1}撞球

五、道具與轉數

同一套數字，換成球棒（club）或環（ring）都成立，落點規則完全一樣——差別只在球棒還要顧到「轉幾圈」。我們入門一律用沙包球把落點練熟，第四期才換棒，把轉數疊上去。

練習建議

先把 3 接到不用看也穩，再依序解鎖 423 → 441 → 531 → 51。這條路每一步只多改一件事，是研究所八週課的骨架。想邊讀邊試，回拋接台把這些數字打進去，引擎會即時告訴你成不成、要幾顆球。
