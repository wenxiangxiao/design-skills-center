## 首創

**館內時鐘：音訊速度驅動全站動畫時間**——全館第一個讓網頁上所有正在運行的動畫共用音樂的時鐘：音樂放慢（音高同時下降），`document.getAnimations()` 的每一支動畫以同一速度滑行放慢；殘響越深，剪影拖出越多錯時殘影；切段迴圈每轉一圈，全站動畫一起倒帶回同一位置；存下的慢版會讓之後每一頁都以你的速度運行。附帶：瀏覽器端程序化產生的卷積殘響脈衝響應。
