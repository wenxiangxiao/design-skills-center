# 繩仔冊 TSÎN-Á-TSHEH 北港歌冊局

> 巴西 Literatura de Cordel・木刻冊皮 Xilogravura × 歌仔冊印刷與廟口唸歌（雲林北港・1934 年起）

臺語「繩仔」tsîn-á，就是葡萄牙文的 cordel。1934 年林阿秋在北港朝天宮前兩支廊柱中間拉一條麻繩，把翻印的歌仔冊用衫仔挾吊著賣；1962 年林清水買不起鋅版，自己用龍眼木刻冊皮；1973 年冬一個巴西水手在高雄港送他一捆 Pernambuco 的 cordel——黑墨木刻、色紙冊皮、同樣吊在繩上——隔年起冊皮就改用色紙。2013 年林雅雯去 Bezerros 的木刻工作室待了五個月，2015 年接手，寫新歌、開木刻課，每禮拜六在廟口繩下唸歌。

- 八頁冊 NT$60・十六頁冊 NT$100・手拓木刻 NT$1,200・揀三本送一張 A6 手拓
- 訂一本：七字仔四十八句＋刻一塊封面＋印一百本 NT$13,500 起（9,000＋每本 45）
- 雲林縣北港鎮中山路 146 號（門牌虛構）・(05) 783-1934・08:30–18:00 週三休・農曆三月每日 07:00–22:00
- 唸歌：每禮拜六 15:00–16:30 廟口繩仔下；木刻課：禮拜日 10:00 NT$1,500

店名、人物、門牌、電話、價格與冊中歌詞皆為虛構；北港朝天宮、中山路、北港溪、北港糖廠五分車、高雄港、Pernambuco 的 Bezerros、巴西 literatura de cordel 與臺灣歌仔冊（1926 年起鉛字發行）為真實背景。
