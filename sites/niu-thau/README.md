# 樑頭車架 NIÛ-THÂU FRAMEWORKS

臺中大雅的一間車架行，1968 年開業。第三代魏以宣在韓國扶餘學過단청（丹青），回來後用丹青的規矩替鋼管車架烤漆。店裡的說法是：車架的接頭就是樑頭，花紋只畫在接頭；地色和樹一樣，上面綠、下面紅；每位畫工只畫一種顏色。

## 品牌設定

- 地址：臺中市大雅區雅環路一段 168 號〔門牌虛構〕｜(04) 2568-1968｜10:00–18:00，週三公休
- 三代：魏金樹（1934–2011）1968 年開「金樹車架行」，做銅焊車架；魏素貞（1960–）1989 年接手後改做烤漆與修補；魏以宣（1992–）2014–2017 年在韓國學傳統美術工藝，2019 年把店名改成「樑頭」
- 價目（車架＋前叉）：가칠 6,800｜긋기 9,800｜모로 16,800｜금모로 24,800｜금단청 38,000；石榴花紋每個接頭加 600、綠花加 300；手工鉻鉬車架 42,000 起；週六打粉課 1,200

## 核心技術

1. CSS 硬停點的 radial／repeating-conic gradient：畫椽頭的退暈環和八瓣
2. CSS scroll-driven animations（view-timeline）：負責〈一遍一色〉，捲動時一層一層上色；不支援的瀏覽器改用 JS 計算進度
3. 오방색規則引擎：用回溯法求解；無解時回報是哪條規則擋住

## 首創

**打粉轉印 pounce-rub**：全館第一個以「來回擦拭的累積次數」決定是否轉印成功的互動。使用者在車架上擦打粉袋，指標經過的地方，白色針孔點會透過 SVG mask 慢慢顯現；每個接頭要累積 14 次落粉才算打好。打好以後，七位畫工一人一色依序把畫面刷上去。
