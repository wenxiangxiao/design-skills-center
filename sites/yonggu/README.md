## 核心功能：刻一塊版（模版房）

規則三句話，九十秒玩一輪：

1. 揀今天要出的一條公告。
2. 按**抽版**——沒接住的碎片會整片掉下來，掉到落料槽裡；而它原本在的地方不會變成空白，會變成一團實心的墨。
3. 切到**橋**，在掉下來的地方點格子把碎片接回外框，接完就能上窗。

判定用的是平面連通性：從紙板四邊灌水，灌不到的紙板團就是會掉的。落料六塊版分別有 5／1／2／2／1／2 片，師傅的解分別用 5／2／6／5／3／3 格橋。上窗後首頁對應那一格會換成訪客刻的版（localStorage 跨頁生效），並發一個版號與可還原的 `?b=` 分享碼。

沒有滑桿、沒有模擬引擎、沒有隱藏真值、沒有分數——只有一條會讓紙板散掉的物理，和一根把它接回去的橋。

## 首創

**平面連通性作為製造可行性的裁決者，且違規的後果是反相而不是缺口。**

全館第一個把「拓樸連通性」當成核心互動裁決規則的站：使用者不是在調參數、不是在解隱藏真值、不是在跑物理模擬，而是在滿足一條「這塊板子切完不能散」的製造約束。而懲罰的形式是本站獨有的——沒接住的碎片掉下來以後，那個位置不是空白，是一整塊實心的墨（洞會漏墨）。與 foldpoint 的剛性摺疊運動學（幾何、連續可逆、由使用者直接控制）、meixi-signalbox 的安全連鎖（阻止尚未發生的違規動作）、gatemark 的不可逆工序（讓你做完再記下代價）皆不同：本站不阻止你，也不記帳，它把違規直接翻譯成畫面上多出來的一塊顏色。

## 動效預算（四種）

| 類別 | 內容 |
|---|---|
| ambient | 套印錯位漂移：`--rx/--ry` 以 `steps(1,end)` 每 13 秒跳三個位置，全站紅版與紙背後的紅框跟著偏 |
| input-driven | 游標移到某一格 → 該格套印瞬間對準、格號塊翻成紅版（80ms）；模版房拖曳逐格切／補 |
| transition | 覆貼 paste-over：導覽紙條上移、旋轉歸零、上緣長出未乾的漿糊痕（90ms，steps） |
| signature | **落料補橋 bridge-drop**：抽版瞬間沒接住的碎片整片掉出畫面落進落料槽，同時成品預覽上那個位置變成實心墨 |

四者皆有 `prefers-reduced-motion` 降級，且降級後落料片數、格數、橋數、判詞全部照常顯示，資訊零損失。
