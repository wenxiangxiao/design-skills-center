# 再來罐頭 TSÀI-LÂI CANNERY

> 彰化員林的罐頭工廠直營門市（1961 年開廠，1963 年第一張美國洋菇訂單）× 普普藝術・Warhol 絹印連作半身（1962 Ferus 畫廊 32 張湯罐頭 → 1962 年 8 月照相絹印 → 〈Marilyn Diptych〉→ 1964 銀色工廠）

首頁就是一面貨架：三十二罐洋菇片滿版排開、格與格之間沒有縫，每一罐是同一張「照片」——瀏覽器先把罐頭打光拍下來，再二值化成一張黑版——底下各刷三塊手切的螢光平色，黑版壓上去時永遠偏一點。載入時一把刮刀從左橫過整面牆，黑版一欄一欄落下，越往右墨越少、開始斷線掉白。之後每隔一秒多，就有一罐被重刷成另一組顏色；游標移到哪，所有黑版就往哪裡偏。

核心功能〈再來一罐〉：四面連作牆，每面藏著一罐真的不一樣的——套歪、糊版、缺墨都不算不一樣，那只是絹印。第一面是麵筋裡混了一罐花瓜，第二面是一罐顏色刷錯版，第三面是一罐黑版曬反，第四面五十罐裡全部都套歪了，只有一罐套得剛剛好。找到幾罐，就換幾罐的門市兌換券，帶到〈工廠〉頁出示。

## 四種動效

- ambient：每 1.4 秒一罐被重刷成另一組顏色（瞬間換、不補間）；銀箔底皺褶 38 秒來回滑動
- input：游標位移經彈簧寫入 `--px/--py`，每罐黑版依自己的係數偏移（Alt＋方向鍵等效）；遊戲牆方向鍵移動、點錯會抖
- transition：灌墨（flood stroke）——一片平色由上往下灌滿畫面再換頁，新頁由上往下收走
- signature：〈拉版〉刮刀從左橫過連作，黑版逐欄落下，墨量往右遞減到斷線掉白（Diptych 的淡出）；「再拉一版」每次墨量不同

## 首創

**serial odd-one-out 連作找異**：全館第一個把「設計流派的偶然雜訊」當作偽裝層的知覺遊戲——每一格都有不同的錯位、糊版與缺墨（這正是 Warhol 連作的樣子），玩家要學會忽略它們，去找系統性的不同（別的品名、刷錯的色版、曬反的網版）；第四面牆的答案則是整面五十罐裡**唯一一罐完美套準的**——在這個風格裡，「對準」才是錯。所有罐頭圖像都由同一支引擎在瀏覽器執行期「拍」出來：Canvas 打光成灰階照片、單一閾值加值噪聲糊版與沿刮刀方向的缺墨條紋，以 `mix-blend-mode:multiply` 疊在手切平色上。
