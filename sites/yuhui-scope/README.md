## 首創

**聲音即圖像訊號（stereo-audio-as-vector-signal）**：全館第一個把立體聲音訊本身當作向量繪圖訊號的站。使用者打的字被編成一圈左右聲道樣本（左→X、右→Y）實際播放，畫面上的光束不是另一份動畫資料，而是每幀用 AnalyserNode 從正在播放的音訊讀回來描出——聽到的和看到的是同一份資料；描繪率同時是音高與閃爍，換管同時換餘暉長度。
