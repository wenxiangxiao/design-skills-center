整個網站是一組 Superstudio 式的圖版（tavola）：首頁第一張圖是一條覆滿黑色方格的白色平台，直直橫過一座即時算繪的山谷——它在你眼前從近景長向地平線，切過山頭、跨過溪溝，然後消失在畫框外，因為它沒有盡頭。那條平台就是露營場：三列、每列 128 格、每格三公尺見方、每一格同價。點一格，就去選它；拿到的格位證上是你那一格在紀念碑上被標成紅色的圖版。

## 核心功能〈選一格〉

規則三句：在圖上點一格（或聚焦圖版後用方向鍵走過去）；選日期、晚數與人數；拿格位證。灰色的格子在你選的那幾晚已有人（依日期決定，每晚不同），週三全場休息；選到有人的格子會告訴你最近的空格。格位證是當下那張圖版的截圖——你的那一格標成紅色——加上號碼、入住退房與合計。

## 首創

1. **Voxel Space 高度場投射作為全站唯一圖像引擎**：全館第一個以 Comanche（NovaLogic 1992）式逐欄高度場投射、在 Canvas 2D 以 `Uint32Array` 直寫像素即時算繪地形的站；山谷、雲影、時刻光線與紀念碑全部是同一支渲染器。
2. **逐像素 pick buffer 選位**：渲染時同步寫出每個像素屬於哪一格，讓「在一張照片蒙太奇上點一格」成為真正可用的預約介面；滑鼠、觸控、方向鍵三種輸入等價。
3. **紀念碑生長**：連續紀念碑在載入時從近景沿地平線長出去，穿過山頭時把山切開。
