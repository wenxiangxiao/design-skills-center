# 九降紙鳶所 Jiujiang Kite Atelier

> 產業：紙鳶工坊／風箏學堂　·　風格：風信紙鳶風 Windward Kite-Chart
> 新竹風城・港南濱海風區的一間糊鳶坊。整片天空就是首頁——你握著線，把一具受風的紙鳶放上去。

- **坊名**：九降紙鳶所（取新竹入秋的「九降風」——又乾又強、連颳數日的東北季風，是糊鳶人一年裡最盼的季節）

- **糊鳶**：徐阿水（開場二十六年）
- **營業**：週四至週日 10:00–17:00（起風日順延）・糊鳶與放飛預約 (03) 536-1109
- **性格 voice**：嚴肅職人——讀風的老手，話不多，說的都是提線點與尾巴
- **一句話**：紙鳶不是被風吹上去的，是被風撐上去的；放飛的手，是替帆面找到剛剛好斜的角度。

## 頁面

1. **index.html — 放飛台**：`windfield-first` 開場。一片天、一具握在線端的紙鳶。放線（▲）讓它爬、收線（▼）繃住、曳線（空白鍵）起飛；風速滑桿與陣風開關給環境。下方**紙鳶配置器**（型／帆面／提線點／尾巴）即時算出起飛風速、風速範圍、升阻比與定飛線角，而且你改的每一項都立刻作用在正在飛的那具鳶上。核心互動＝首創（見下）＋功能＝客製化配置器。
2. **feng.html — 風法**：不需 JavaScript 即完整可讀的原理頁。迎角把風翻成升力、風梯讓高處風更大、提線點決定吃風多斜、尾巴替它壓穩頭，加上九降風的來歷與風力對照表，附三張自繪 SVG 圖解。
3. **yuan.html — 紙鳶圖鑑**：二十四式紙鳶（菱形／六角／三角／八卦／軟翼），每一具都由同一支 kite-frame 引擎當場糊出、標出起飛風速與定飛線角；依鳶型×風力×難度×產地多條件即時交叉檢索＋計數（第二功能：資料庫查詢）。
4. **ru.html — 入所**：三步驟報名（選場次含餘額／額滿鎖定 → 驗證稱呼≥2、手機 `^09\d{8}$`、Email 選填格式、人數 1–6 → 生成 `ZY-YYMMDD-NNN` 留位號與一具由資料 FNV→mulberry32 決定的專屬紙鳶手印，同資料恆得同鳶）（第三功能：多步驟報名表單）。

## 八維配方（§2.4 / §2.7）

- **opening**：`windfield-first` 風場放線直開場（新原型）——首屏即一片空的天與一具握在線端、在風場裡待放的紙鳶，內容從「你怎麼放它」長出。與 `live-world`（自主生態，不等你也演化）、`skyfield-first`（yoiwan 夜空選席看花火演出，觀賞式）、`cascade-live`（sanqiu 首屏已在自動週期地丟）皆不同：本原型的紙鳶在你動手前靜止／低飛，動力來自你放線收線曳線管理那條線，是「被線約束的翼面在風場中」的操作本體。
- **nav**：`kite-train rail` 連凧列導覽（新原型）——桌機左緣一條繩掛四具小紙鳶，現用頁那具升上風裡、翻朱紅帆。與 `cordloop-rail`（wanjie 繩耳收結）、`lantern-string rail`（yoiwan 提灯點亮）不同：這裡掛的是紙鳶、現用態以「升上風裡＋翻帆色」標記。
- **signature**：tethered-airfoil 飛行——力平衡線角 + 陣風管理 + 失速/翻頂/打轉動態，提線點與尾巴設定穩定度；kite-frame 引擎統治全站圖像。動效避開四項過載語彙，無跑馬燈/自動輪播/自動播放。
- **illust**：`kite-frame` 骨架帆面構成（新技法）——全站每張圖都是同一支引擎依 `{型,帆面,提線點,尾巴}` 幾何求解的紙鳶（骨/帆/提線/尾/牽線），零外部圖片。
- **mood**：`mid-tone` 彩色中間調底——帶灰風藍為大面積地色（~44%），暖紙面板、朱靛黃三顏料點綴。刻意用風城陰空的冷中明度藍為底，與近期暖工坊底、暗底儀器台兩端拉開；非暫禁 paper-light。
- **func**：客製化配置器（選型／帆面／提線點／尾巴 → 即時算起飛風速、風速範圍、升阻比、定飛線角並即時作用在飛行中的鳶）。
- **era**：1960s–70s 戰後台灣手工紙鳶　·　**locale**：台灣本土（新竹風城／九降風）　·　**texture**：紙感（棉紙裱竹）＋竹骨　·　**density**：極疏（大量留白＝天空）。

## 首創（§2.6 _first_registry）

**受線約束的翼面空氣動力作為互動範式（tethered-kite aerodynamics as interaction，zhiyuan）**：全館第一個以「放風箏」——一具被飛線約束、靠迎角在風場中生升力的翼面——為核心互動的站。放線／收線改變線長與高度、曳線灌入視風起飛；提線點沿骨架前後移設定平衡迎角（前＝吃風平而穩、後＝斜而高但強風易翻頂），尾巴以阻力壓頭消解打轉，風梯讓高處風更大，陣風把迎角衝過失速點就下墜。與 tackline（水面帆船極曲線 VMG、必須之字搶風）、sanqiu（siteswap 多顆自由拋物、無繩無接玉面）、nichigetsu（けん玉弦繫木玉的拋接—屈膝收球）、jinsheng-glove（verlet 提線操偶、線是軟約束非升力）皆不同：本站互動對象是一具受線約束、靠迎角生升力的翼面，判定的是「這樣調、這樣放，它飛不飛得穩、爬不爬得高」。同一支 kite-frame 引擎渲染放飛台、二十四式圖鑑、logo、favicon 與報名手印，全站無一張圖是外部圖檔。

## 技術

單檔 HTML（CSS/JS 全 inline）、頁面間相對路徑互連、favicon 為原創 inline SVG data URI；零外部圖片與音檔、零 3D／WebGL／第三方函式庫，僅 Google Fonts（Fraunces＋Noto Serif TC＋Noto Sans TC＋Space Mono）。飛行物理與各鳶型 spec 為教學近似模型，非野外操作或風洞依據；坊號、人物、地址、電話、場次、費用皆為虛構教學示意。已 `node --check` 四頁 inline JS 全通過、jsdom 實跑四頁 0 console error，飛行模型經驅動測試（均衡配置穩定定高；提線點過後＋無尾＋強風打轉失速下墜；提線點靠前＋無尾仍穩；低風＋輕帆拉不起）、圖鑑篩選/計數/空狀態、報名稱呼≥2/手機 `^09\d{8}$`/壞 Email 擋下/生成 `ZY-` 留位號與手印皆測試。
