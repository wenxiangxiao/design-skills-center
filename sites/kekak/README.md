## 首創

**把「複製次數」當成唯一的評價（reproducibility as the score）。** 全館第一個站，使用者交出來的東西不是被評好不好看、不是被判對錯、不是被算成本，而是被問「它能被刷幾張」。判準完全來自複製工序本身：紙會不會掉、橋會不會被墨咬斷、細節會不會被脹死——而且這個判準在頁面上是**看得見的**：按下「刷一百五十張」，畫面就真的一張一張變糊，直到那條太細的橋被墨吃斷，那塊紙落下來變成一坨黑。

與 `rendong`（成品沒有邊、成功的定義是自己看不見）的差別：本站的成品有明確的邊，被量的是它**撐得住幾次重複**；與 `khoaibeng`（介面幾何作為被優化的對象，有成本函數與最優解）的差別：本站沒有最優解，只有壽命；與 `shidong`（把觀看者的視網膜當成輸出媒介）的差別：本站被量的東西完全在螢幕上，而且會在你眼前壞掉。

## 核心功能：刻窗

三句話：在三十二格的蠟紙上刻一個剪影；被墨圍住的白要用橋接出去，橋越粗刷得越多張；刻到刷得了一百五十張，就跟一九二〇年的莫斯科一樣。

四條驗收（即時亮燈）：孤島＝0 ／ 必須有內白 ／ 墨面積 15–45% ／ 刷得了 ≥75 張。
壽命公式：`刷得了的張數 = (r* − 1) × 75`，r* 為「墨脹幾格時第一塊紙落下」。

## 動效預算（四種）

1. **ambient** 街光掃牆 58s ／ 玻璃斜光 26s
2. **input** 抬紙 `translate(-4px,-5px)` `.09s steps(2)`（<100ms）
3. **transition** 刮刀推刷 `clip-path` `.62s steps(9)`
4. **signature** 刷次墨脹 `feMorphology` dilate

四種皆有 `prefers-reduced-motion` 降級，且降級後資訊零損失（落版張數永遠印在號帶上）。
