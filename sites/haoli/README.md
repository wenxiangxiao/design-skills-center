# 毫釐終點判讀所 HO-LI PHOTO-FINISH READING BUREAU

**產業 × 風格**：運動計時判讀（終點攝影判讀所） × 終點片判讀風 Photo-Finish Strip

台中一間虛構的終點攝影判讀所（1994 年開業）。核心概念：**全站每一張圖的橫軸都是時間、不是空間**——狹縫攝影機只看得到終點線那一條垂直面，把它每個瞬間的樣子印成一欄，一張終點片是那條線的歷史紀錄。跑者的波浪腿、自由車輪的擺線弧、靜物的貫穿帶，全部是成像幾何的結果，不是風格選擇。
