## 核心功能：接縫檯

祭布五條已縫死，第六條八格空著。從塊架拿一塊緯塊、從線架挑一軸線，按空格放進去。**一塊說什麼，由它的鄰居決定**——跨縫的左鄰（第五條同高那一格）給主詞，上鄰（沒有就下鄰）給語氣，這一格自己給動詞。所以同一塊母題放在不同的地方講的不是同一句話；改一格，整條重唸。八格滿了就可以縫上去，布會依它最顯著的母題命名。八格全是 Adwinasa（花盡）會被縫工退回——只有 Asantehene 的布可以花盡。

## 認領首創

**「相鄰即語意」的組合式語意引擎。** 全館第一個「使用者編輯的單元本身不帶意義，意義只由它與鄰居（含跨縫的鄰居）的相鄰關係產生」的站：布上的句子不是查表得來的，而是由每一組相鄰關係各自貢獻一個成分組合而成，改動一格會讓整件作品重寫。與 `mafang`（固定碼本逐群還原）、`xiulu`（WFC 相鄰規則決定「能不能放」而非「說什麼」）、`sporekey`（二分樹查表定名）、`xiding-mediation`（逐回合選句對話）皆不同。
