# 拆線古著 CHAI-SIAN

**產業**：古著店（二手衣，單件孤品）　**風格**：解構編輯排版 Grunge／Ray Gun（1992–2000，David Carson）

台北市中山區長安東路二段 63 巷 4 號 1F 的一間二手衣店。店的目錄是一本在巷口影印機印出來的刊物《拆線》，本期第 31 期，收 24 件孤品。

這個站在做一件事：**把「排版有多破」這件事，交給商品身上實際有幾道傷來決定。** 每一件衣服都有一份瑕疵清單（破洞、蟲蛀、汙漬、褪色、脫線、腋下裂、拉鍊壞、肩線脫），每一道傷都有座標、嚴重度、折價與工錢。你在驗傷單上選擇「留著」或「修補」，版面就當場重排——破洞是一個真的浮動障礙物，欄裡的字繞著它走；汙漬用 CSS Custom Highlight API 蓋在真實文字上（DOM 一個字都沒動）；脫線把欄距拉開、把欄線拿掉；褪色把那一段字洗淡到對比 4.85:1（底線）。付錢補起來，可讀性就回來。

**可讀性在這裡是明碼標價的商品。** 而每一頁右下角永遠有一顆「讀順版」——按下去全部退開，字一個都沒少。這是照抄 Carson 一九九四年把 Bryan Ferry 專訪排成 Zapf Dingbats、卻在同一期後面附上可讀版的做法。

## 核心功能：驗傷成交

規則三句話，一輪約 90 秒：

1. 每一道傷選「留著」（折價）或「修補」（付工錢）
2. 結構性破損（腋下裂、肩線脫、拉鍊壞）必修，不修不賣
3. 至少留一道傷；工錢合計不得超過售價六成

24 件、180 種合法組合中 **159 種可成交（88.3%）**，0 件無解；11 件帶結構性破損。價格會隨真實日期變動：入店每滿三週劃一次價（×0.88），最多三次，第 12 週起進原樣區不再降——牌子上被劃掉的數字是每次載入用今天的日期重算的。

## 建置紀錄

- **opening**：`bin-first` 翻箱直開場（新原型）
- **nav**：`pricetag-strike` 吊牌劃價導覽（新原型）
- **signature**：`flaw-displacement` 傷痕推版（全館唯一）
- **illust**：`toner-dither` 碳粉誤差擴散構成（新技法）
- **mood**：`bitmap-1bit` 一位元點陣（新增 mood）
- **tech**：CSS Custom Highlight API／CSS 多欄 column-span／OffscreenCanvas + Worker + Floyd–Steinberg
- **首創**：可讀性作為可交易的商品（legibility as a purchasable commodity）——全館第一個站，其版面的破壞度不是設計決定，而是由商品的物理損傷資料驅動，且使用者可以用錢逐項買回可讀性；同時，成交的產出物是「站上少了一件東西」。

四種動效齊備：ambient 碳粉走紙／input 抽到最上面／transition 過機 run-through／signature 傷痕推版，四種皆有 `prefers-reduced-motion` 降級且資訊零損失。

單頁大小（含 inline 全部資源）63–68KB；24 張 1-bit 圖在 Worker 裡算完約 74ms，不佔首屏。零外部圖片、零音檔，外部資源僅 Google Fonts。
