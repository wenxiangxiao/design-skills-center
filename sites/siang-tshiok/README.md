## 品牌設定

1957 年，護理師 Esther Hershey 從賓州蘭卡斯特來到 1954 年開院的花蓮門諾醫院，行李裡夾著一張 1823 年、門諾會學校老師替她家長子寫的出生紀錄 Geburtsschein（門諾會不行嬰兒洗禮，所以它只記出生）。助理護士林秀枝（1936–2019）在值班室照著描了十幾遍；1969 年她在醫院對面巷子開了「雙雀命名所」：替新生兒取名，再用鵝毛筆沾鐵膽墨把名字寫進一張出生書——鬱金香兩盆、金翅雀一對、四色上彩、摺四摺交給父母。1976 年起請東光活版所印只有墨線的「空白樣張」；1988 年兒子林志明（1962–）接下取名諮詢；2011 年黃郁婷（1984–）入門，現為主筆。至今寫過一萬一千四百餘張。

## 首創

**逐色上彩重演＋心形版心排字（pigment-pass replay × heart-shaped measure）**：全館第一個 Fraktur 站。簽名動效不是「畫出來」而是重演書手的工序——鉛筆圓規、鐵膽墨由上而下、然後一罐顏料把整張該上的地方一次走完再換下一罐，每塊洗色從自身中心暈開、溢出墨線、邊緣積深；心內文字以同一個心形多邊形逐基線求弦長排字，名字拆進左右兩個心瓣，放不下就縮字級而不刪字。附帶：每個母題的兩份鏡像共用同一個鍵，所以 hover、啄食動畫與上彩天生成對。
