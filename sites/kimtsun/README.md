## 核心功能：驗貨議價（90 秒一輪，規則三句話）

一、挑一支板。
二、指出它身上真的有的傷——指對了發哥讓價，指錯了他加七百回去。
三、三次出價之內談攏就成交。

- 發哥的耐性是 **5 次指認**，八個傷勢選項裡每支板只有 2–4 個是真的，所以不能全部點過去。
- **指認結果會畫在板況圖上**（螢光圈），圖本身就是證據：泛黃＝整體網點變濃、壓凹＝一串小暗斑、
  分層＝斑駁塊、折斷＝一條橫過去的暗帶、撞裂＝從缺口放射出去的暗線。
- 出價高於現價時他不會多收（「不用那麼多，算你 X」）；三次談不攏就破局，板放回架上。
- 成交後發一張**讓渡書**：成交價、你指出的傷、你漏掉的傷、你指錯幾次、四級判詞
  （你有在看板／還行，眼睛沒瞎／你在猜／你根本沒看板，你在看價錢），
  外加一張成交那一刻用 canvas 重新複印的板況圖與可分享還原的 `?d=` 碼。

## 開場・導覽・動效・插畫・氛圍

- **opening**：`spread-first` 跨頁直開場——首屏是一個有書溝、有中縫規線、有欄外標題的跨頁，
  左頁圖、右頁資訊，刊頭橫跨兩頁並被視窗左緣裁掉。沒有大標＋副標＋按鈕組。
- **nav**：`trim-bleed folio` 出血頁碼導覽——四個頁碼散在右緣四個不同高度與角度上，
  **現用頁那一個被推出裁切線外、數字被視窗邊緣切掉一半**。現用態不是被標示，是被裁掉。
- **signature**：**逐字換面 glyph-wise face-swap**——字面（typeface identity）本身就是狀態讀數。
  發哥講的每一句話都是逐字獨立指派字面、字級、基線與角度重排出來的，
  而它散開的程度由「他的耐性剩幾格、你指錯幾次、你還剩幾次出價」算出來。
- **motion**：四式──ambient 影印掃描帶（11s，`steps(26,jump-none)`，multiply）／
  input 逐字換面重排（pointer 進入即重排，<100ms）／
  transition 落版 paste-up（`clip-path` wipe，340ms，`steps(5,jump-start)`）／
  signature 逐字換面作為狀態讀數。四式皆有 `prefers-reduced-motion` 降級且資訊零損失。
- **illust**：`halftone-bitmap` 一位元抖動位圖——全站沒有一張外部圖片、沒有一條向量插畫，
  所有圖像都是「連續調純量場 → Bayer 8×8 有序抖動 → 兩色點陣」的產物，
  且每一塊斑點都對應一件可以被指名的事。
- **mood**：`xerox-grey` 影印灰階＋單一螢光（紙灰 `#CDC9BE` / 曝白 `#F4F2EC` /
  影印黑 `#100F0D` / 中灰網 `#7E7C74` / 螢光黃綠 `#DCFF1E`）。

## 首創

**字面（typeface identity）作為介面狀態讀數。**
全館第一個站，其狀態不是用顏色、位置、大小、明暗或圖地關係表示，而是用「這個字是用哪一套字體排的」表示——
同一句話在不同狀態下會被指派不同的字面組合、字級離散度、基線位移與旋轉量，
散得越開就是他越不耐煩。與 `luyi`（聲音即時驅動同一套可變字型的 wght／wdth 軸）的差別是
本站換掉的是**字體本身的身分**而不是同一套字的軸值；與 `baicaochun`（拖包絡讓字重新填滿一個形狀）
的差別是本站的字沒有被塞進任何容器，被換的是「這個字是從哪一本印刷品上剪下來的」；
與 `yongzi-foundry`（改字的骨架與筆型）的差別是本站一個字形都沒有改，改的是選了誰。
