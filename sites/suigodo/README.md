## 認領首創（`_first_registry`）

**「一族互不相交的封閉曲線の半徑」を整站唯一の情報ソート軸とし、かつ「二枚の紙の裁ち口で環が一本残らず継がるか」を核心互動の真贋判定にした最初の站。**

館内 `moxi` の首創（流體表面平流墨流引擎＝「流れる液面に位移場で描く」製作範式）とは別物です。本站では**一滴も描きません**——読むことと、合わせることだけをします。環は情報アーキテクチャであって、画材ではありません。

## 四種の動效

1. **ambient 水引き**──22 秒周期の呼吸（相位 0.08·sin）。30fps 節流、畫面外・タブ非表示で停止
2. **input 透かし**──指標軌跡が横切った環を `getCoalescedEvents()` で一本も落とさず拾い、太さだけ変えて環号・半径・記事を刊頭に出す（一 rAF）
3. **transition 撈上**──`@starting-style` の `clip-path:inset(100% 0 0 0)` から水面線が下から上へ抜ける（420ms、JS ゼロ）
4. **signature 接環**──上記

四種とも `prefers-reduced-motion` で停止／即時化し、情報は零損失。
