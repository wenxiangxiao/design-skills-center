# 三球雜耍研究所 SANQIU Juggling Lab

台北・大稻埕的雜耍與拋接學校。整站以 **siteswap（雜耍記譜法）** 為核心——把「怎麼丟」寫成一串數字，我們的拋接引擎替你驗算：這串合不合法、要用幾顆球，並把它真的丟給你看。

- **產業**：雜耍／拋接學校
- **風格**：拋物運動風 Ballistic-Notation（自創風格皮膚：彈道拋物線＋節奏格柵＋沙包球的塑膠亮面，高飽和撞色 vivid-bold）

## 開場 / 導覽 / 動效簽名 / 插畫 / 氛圍

- **opening**：`cascade-live 拋接直開場`（新原型）——首屏是一段已經在丟的三球連拋（siteswap 3），旁邊一格可編輯的記譜；改數字就改變正在丟的東西。無大標 hero。
- **nav**：`apex-arc 拋物頂點導覽`（新原型）——四頁是四顆坐在拋物線頂點的球（3／5／1／7），現用頁那顆翻朱紅；行動版落為底部四格 dock。
- **signature**：siteswap 記譜的即時合法性驗算 ＋ 正確物理的拋接動畫（左右手交替、奇偶過手、拋高 ∝ 高度²）＋ 落點梯圖。刻意避開揭示淡入／數字計數／按壓硬陰影當簽名／dashoffset 四項過載語彙；拍數讀值為功能性非裝飾計數，無跑馬燈、無自動輪播。
- **illust**：`siteswap-orbit 拋接軌跡構成`（新技法）——全站沒有一張外部圖片、沒有一張「畫」的插圖；logo、favicon、圖鑑軌跡圖、落點梯圖、報名印記全由拋接引擎照某個 siteswap 的拋物線族＋落點生成，換一串數字就換一張圖。
- **mood**：`vivid-bold`（奶油底 #FBF2DE 約 40%＋墨黑 #16130E，訊號黃／群青／朱紅／草綠四色高飽和撞色各守語意；刻意脫離近期暗底儀器台）。

## 首創（claim）

**siteswap 雜耍記譜作為互動範式**：全館第一個以「拋接記譜的合法性」為核心互動的站——輸入一串數字，引擎以落點雙射定理判定合不合法、由平均算出球數，並以左右手交替＋奇偶過手＋拋高 ∝ 高度² 的正確物理把它動畫丟出來；非法時擋下並指出撞在哪兩拍。同一支拋接引擎渲染全站每一張圖（軌跡圖、梯圖、logo、favicon、報名印記）。與 qizhong（排列群換鐘鳴奏、以鐘聲為內容、對象是排列群生成集）的差別：本站對象是拋接記譜的滯空高度序列，合法性由「落點是否為雙射」判定，且會被動畫成空間中的拋物線，內容是可玩可丟的雜耍而非鳴奏。
