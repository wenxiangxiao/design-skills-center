# 金石果子行 KIM-TSIO̍H KUÉ-TSÍ-HÂNG

**臺中第二市場水果行 × 硬石鑲嵌 Pietra dura（佛羅倫斯 commesso）**

## 首創

**以石代筆的配色遊戲 stone-as-pigment matching**：全館第一個「不能調色、只能選材」的配色互動——顏色不是撿色器，而是十二種程序生成的天然紋石；同一種石換一處紋路切，平均色就不同。分數以嵌片實際渲染像素的平均色對畫稿目標色算 CIE Lab ΔE76，提示會告訴你「偏亮——找這塊石頭比較深的地方」。也是全館第一個以 `CanvasPattern.setTransform` 讓使用者在固定輪廓裡拖曳材料紋路的站。
