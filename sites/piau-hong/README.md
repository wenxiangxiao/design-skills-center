## func：〈戳一板〉

三句規則：① 你有 8 根戳棒，戳破任何一格，紙籤就是一個零件；② 板頭印著每類剩幾個、下一戳機率多少——不放回，戳一格少一格，集滿車殼、馬達、齒輪、滾輪、輪胎五類就能組車（缺的用店裡的「借用件™」補）；③ 按「上賽道」，車自己跑兩圈，第一圈走換道橋、第二圈從橋下穿過，拿一張計時單。馬達太猛、滾輪太小，車會在換道橋出口被甩出去（COURSE OUT™）。同類抽到兩個以上可點槽位換裝。結果：計時、今日紀錄排名、佩珊評語、FNV-1a 計時單號、`?r=` 分享網址、sessionStorage 帶到〈賽道日〉紀錄板與預約表單。

## 首創

**公開存量的不放回抽樣作為互動範式（戳戳樂零件板）**：全館第一個把「有限籤池、不放回」做成可玩規則的站——60 籤的組成印在板頭，每戳一格存量劃掉、下一戳各類機率即時重算顯示；抽到的零件直接組成一台車，由 **CSS offset-path 驅動跑過三線立體交叉換道橋**（橋上 z 層翻到橋面之上並放大、橋下從橋面底下穿過），速度與貼地值決定它會不會在橋的出口沿切線飛出去。
