## 認領的首創

**版面幾何在樣式層裡求解，而骨數是一個可以被改的 CSS 變數**
（layout geometry solved in the style layer; the rib count is a CSS custom property）——
全館第一個站，其放射版面的每一個座標都不是寫死的、也不是 JavaScript 算的，
而是由 CSS 的三角函數從 `--ribs`（骨數）與 `--open`（開合角）當場解出來：
十六片扇布的張角、每一片標籤的落點、滑塊在桿上的高度、開合時的收縮量，全部如此。
把 `--ribs` 從 16 改成 24，版面自己重新解一次，JavaScript 一行都不必動；
JavaScript 只負責語意（哪一片上哪一捲布），不負責任何一個座標。

## 四種動效

1. **ambient 拱下的影**　柱廊的影橫過砌層，96 秒一趟，硬邊、零模糊，位置由 `tan(--sun)` 算出。
2. **input-driven 推彈子**　拖曳或方向鍵推桿上的彈子，傘即時開合（無補間，逐帧跟手）。
3. **transition 起拱揭幕**　面板切換時新的那一面由起拱線往上推出來，邊緣騎一道 4px 鉛丹硬邊。
4. **signature 過中點起拱**　撐傘時十六骨的中點不在同一個角度，所以它們一根一根過去；
   每一根過中點的那一瞬間，那一片扇布的外緣**由直弦換成兩心尖拱**，先過衝到 1.42 倍鼓度、
   115ms 後才收回。它不是淡入也不是縮放——是一段幾何被換掉。

四種皆有 `prefers-reduced-motion` 降級，且降級後資訊零損失。
