## 首創

**配方即色值（formula-as-source colour）**：全站每一片色都不是寫死的 hex，而是由印在它下面的油墨份數，以巢狀 `color-mix(in oklab, …)` 與 `calc()` 正規化百分比當場算出；配方文字則用 CSS counter 從同一組自訂屬性印出。試色台上微調任一罐 ±1 份，色與字一起變；而且「透明底」的承印物是你選的膚色所推得的甲床色——同一個號碼在不同膚色上真的會算出不同的顏色。
