## 核心功能：還禮簿（人情往來／回禮型）

這一帶的粿是往來的。人家送你一籠，你明年要回一份——而且**不能回一樣的**：
回一樣的等於把人情折現，是斷交的意思。

三句話規則：

1. 回禮不可與來禮同一樣。
2. 回禮的斤數不可少於來禮。
3. 回禮的斤數不可超過來禮的一成（多過頭是逼人家再還一輪，一樣算失禮）。

六戶、架上十七樣，每戶各有 2–3 種合法解（已程式驗證無死局），一輪約 90 秒。
六戶全清時觸發簽名事件「開籠」：六層籠的剪裁弧線由下而上依序收掉，
一層讓出一層的粿，最後蓋「清」印。
失禮不會鎖住你，但簿子會記下用了幾手、失禮幾次。

未啟用 JavaScript 時，六戶來禮、架上十七樣與三條規矩已完整列在頁面上，可以用紙筆對。

## 首創：`unclip-as-reveal` 解剪即揭示

全館第一個**以「元素自身剪裁形狀的即時重算」作為唯一顯示／隱藏機制**的站。

全站零 `opacity`、零 `height`、零 `transform`、零 `display` 的顯示切換
（`transform` 只用於紙條 ≤1.4° 的靜態貼歪，不參與任何顯示切換）。
每一次「露出」都是元素自己 `clip-path: shape()` 的弧線往旁邊讓位——
所以掀起來看到的不是背面、不是底層、也不是新插入的節點，
是**它自己原本被裁掉的那一段字**。字一直在 DOM 裡、一直可被搜尋與朗讀，只是不在剪裁區裡。

高潮事件為「開籠」：六層籠的剪裁弧線依序收掉，一層讓出一層的粿。

## 四種動效

| 類型 | 觸發源 | 內容 |
|---|---|---|
| ambient 環境 | 時間 | 「起風」：整牆紙條的捲邊弧以 −0.42s×i 的相位差起伏（9s 循環，2→10→5px）；帆布條紋 74s 極慢橫移 |
| input-driven 輸入 | 游標／鍵盤 | 「掀角」：`--lift` 0→1，160ms，起動 <100ms，紙的捲邊往左讓位＋提到最上層，露出被壓住那半邊的直行 |
| transition 轉場 | 導覽 | 「落布」：紅白藍條帆布自上垂落覆蓋（240ms）再導頁；自寫，不用 View Transitions API |
| signature 簽名 | 全站機制 | 「解剪即揭示」＋高潮事件「開籠」 |

四種皆有 `prefers-reduced-motion` 降級：風停在中值、紙條永久掀開（被壓住那半邊的字直接可見）、
轉場改為即時導頁、開籠改為即時——**資訊零損失**。

## 外部參照（style_lineage）

- 「台灣紅」運動：2000 年起文建會以桃紅作為台灣代表色，2003 年北歐／英／法巡展以桃紅為概念色；
  前文建會主委陳郁秀以十年研究提出「台灣紅／台灣青／台灣金」三色論。
- 林磐聳（1957– ），2007 年國家文藝獎視覺藝術類最年輕得主。
- 辦桌的物質文化：紅白藍塑膠棚、紅大圓桌與鐵椅、十二道菜、總鋪師與水腳／小工；
  高雄內門約 150 組總鋪師。
- 供品形制：紅龜粿龜甲紋、壽桃、發粿、米糕栫、乞龜還龜。
