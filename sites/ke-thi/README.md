# 雞啼蛋行 KE-THÎ — 彰化蛋行 × 波蘭羅維奇剪紙 Wycinanki łowickie

彰化市長壽街的蛋行，1968 年開始替人染滿月紅蛋；2017 年起每一盒紅蛋都封一張手剪的羅維奇（Łowicz）公雞剪紙——剪的人是從羅維奇旁 Złaków Kościelny 村嫁來的孫媳婦柯安妮。整站是一面刷白的牆：剪紙一層一層被拍上去，換頁時三道石灰刷痕把牆刷白再重貼。

## 首創

**訂單即剪紙（order-to-wycinanka）**：全館第一個以「逐層內縮」演算法生成 Łowicz 多層剪紙的站——同一串原語（leaf／ell／drop／tri／bar）第 k 層往內縮 k×d 並換色，第 0 層剪成鋸齒黑底紙；滿月頁把表單資料（三圈親友→環層、盒數→外圈小葉、取貨時段→公雞身色）直接剪成一張可分享的 gwiozda。也是全館第一個以 Canvas `destination-out` × `scale(-1,1)` 做「對摺剪紙」的站，以及第一個羅維奇剪紙流派站。
