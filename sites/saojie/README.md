## 核心功能：編一扇窗

規則三句話、九十秒玩得完：**一、從十二格裡揀六格，點的順序就是讀的順序。二、每格配一句韻文，六句必須一轍到底。三、最後一格要叫人做事。**

- 兩道退件寫成規則：六句異轍即退件並點名第幾格；末格不是「行動」類即退件（「一扇不叫人動手的窗，只是在罵人」）。
- 產出物是一份**刻版單**：幾塊版、幾個島、幾條刀橋、刻版幾分鐘、每份刷印幾秒、**今晚五個鐘頭抄得出幾份**。刀橋越多，刻版越久，能抄的份數越少——史料上莫斯科一款平均一百五十份，你抄不抄得到，取決於你揀了哪幾格。
- 窮舉：合法窗（不計格序）共 **1,392 扇**；抄本數分布 111–140 份，中位數 120。
- 另可輸出 1020×820 向量 SVG（同一支引擎換 SVG 後端）、以 `?w=` 分享碼還原（同碼恆得同窗、同窗號、同街口）。

## 認領的首創

**可製造性作為圖像的最後一位編輯，且它留下的疤就是這個流派的識別特徵。**

畫面上每一塊墨在被印出來之前都要先通過一次連通性求解：把該格點陣化，從畫布四邊對「非墨」泛洪，泛不到的就是**島**——一塊四周被刻穿、會從卡紙上掉下來的紙。引擎再從島出發穿過墨做廣度優先搜尋，第一次走出墨的那條路徑就是最窄的墨腰，**刀橋下在那裡**。設計者不能挑位置，使用者不能否決，而那條橋會永遠留在印出來的圖上。

- 與 `xiulu`（WFC 約束傳播解出一面可焊的鐵窗）的差別：那支引擎是從空白**生成**尚不存在的圖樣、約束決定「長什麼樣」；本站的圖是既成的剪影，約束不生成任何形狀，它只**切**，而且切在哪裡由島的幾何決定。
- 與 `grip-station`（stencil-spray 噴模鏤空）的差別：那一路的橋是**畫上去的裝飾**，位置由設計者挑、還配噴霧毛邊；本站的橋是**求解出來的結果**，且明文禁用手抖濾鏡。
- 與 `foldpoint`（刀模：平面與立體是同一組資料的兩個投影）、`gatemark`（不可逆工序）的差別：本站沒有第二個投影、也沒有順序相依，它只有一個判準——**這塊紙拿不拿得起來**。
