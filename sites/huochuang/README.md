## 核心功能：押韻壓版

三句話講得完，九十秒玩得完：

1. 揀一則今天進來的通報，**上句已經刻好了**。
2. 用字塊拼一句**七字下句**，把韻押上。
3. 型版工驗過三條，就替你刷成一扇八格窗。

師傅的三條驗收（三條全過才准壓版，沒有分數、沒有星等、沒有排名）：

- **一**　七個字，不多不少。（字塊有 2 字與 3 字兩種長度，2+3+2 / 3+2+2 / 2+2+3 才湊得到七）
- **二**　末字要押上句的**轍**。中文押韻用傳統曲藝的**十三轍**，本站用到六道：灰堆、一七、遙條、言前、江陽、梭波。
- **三**　要**叫人動手**，不是在講事情。五塊描述性動作塊（燒得快／熱烘烘／冒煙／悶著／燙手）永遠不會被停用，但永遠過不了這一條——那正是它們存在的理由。

盤上灰掉的塊不是壞掉：主語塊受「這一則用不上」約束，祈使動作塊受「這樣東西不能那樣處理」約束（鐵鍊只有剪、延長線不能剪），理由印在塊旁邊。

**實測**：9 主語 × 12 動作 × 18 結果 = 1,944 種組合，經通報相容與物件相容過濾後，
六則通報各有 **5–11** 種對得上的說法，全站合計 **50** 扇合格窗；
每一扇都經 `windowCells()` 檢查過「相鄰兩格不得長一樣」，實測 50 扇 × 7 個相鄰對 = 350 對，重複 0。

通過後的圖不是另外畫的：八格窗每一格的剪影**由你揀的三塊字塊直接決定**——句子與圖版是同一份資料。
窗號由 FNV-1a → mulberry32 決定，同一組字塊恆得同一扇窗；網址帶 `?w=` 碼可分享還原。

## 首創

**韻律約束作為互動範式，且使用者的句子直接決定圖版。**
全館第一個以中文語音（**十三轍韻部**與字數）為驗收條件的站——
使用者不能畫、不能拖、不能調任何數值，只能揀字塊拼一句七字下句；
系統以真實十三轍韻部表比對末字、以祈使性判動作塊，三條全過才准壓版。
與 `xiding-mediation`（對話為互動範式，挑一句說出口）的差別：那裡挑句是為了推動兩造的情緒狀態，
句子的**語音形式不被檢查**、也不生成圖像；與 `yongzi-foundry`（字形合成）的差別：
那操作的是字的**骨架與參數**，本站操作的是字的**聲音**；
與 `mafang`（密碼還原）的差別：那是把已存在的密文還原，本站是在約束下**生產一句新的話**。

## 動效預算（四種）

| 種類 | 內容 |
|---|---|
| ambient | 套版錯位漂移（rAF ±0.6px，四塊版各自週期）＋ 補墨（每 6.5 秒隨機一格重壓紅版） |
| input-driven | 分版散開（hover／focus 一格，四塊色版各自位移 5–9px，60ms，`steps(2)`） |
| transition | 刷版擦除（`clip-path` `steps(8)`，440ms，刮刀一次刮過） |
| **signature** | **逐版壓印 plate-pass**——捲到哪一格才刷哪一格的版，每格四塊版依 0/.34/.60/.86s 硬切疊上，並帶一次 4 幀紙面震動 |

四種皆有 `prefers-reduced-motion` 降級且資訊零損失；預設樣式是「已經刷好」，
關掉 JavaScript 看到的是一扇完整的窗。
