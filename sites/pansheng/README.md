# 盤聲錄音室 PANSHENG SOUND STUDIO

**產業 × 風格：錄音室 × 盤帶剪接室風 Splice-Room Tape**

台北大同區延平北路一間開了四十三年的類比錄音室。網站的主體不是介紹，是一台**剪接台**：1990 年蔡文雄吹的〈渡船頭的月〉間奏八小節，五個 take 全部留著，五次都有毛病。你的工作是從這五條裡挑，剪成一條。

## 核心互動：挑 take，然後承擔每一刀

- **素材是別人的演奏。** 你不創作、不模擬物理、不解謎——你只做取捨。八小節 × 五條 take＝四十格，每一格有當日錄音師手寫的評語與分數，可以逐格試聽（Web Audio 即時合成，五條 take 的音量、音色、時值、抖音、底噪各不相同）。
- **剪接是有代價的。** 相鄰兩小節來自不同 take 就是一刀。刀口的可聞度由四個成因算出來：電平差、音色差、時值差、**底噪差**（最陰險的一項），再加上刀口落點的性質（換氣點好剪、圓滑奏中間最難剪）。可聞度分四級，而且**真的會發出聲音**——底噪在接點處階躍、超過門檻的接點會多一聲短促的雜音。
- **兩個目標互相打架。** 演奏分數最高的剪法（84.3 分，三刀）在第 2／3 小節之間留下一個「明顯」的接痕；退一步的剪法（82.6 分，兩刀）整條聽不出手腳。製作人只要後者。差 1.7 分——剪接這一行大部分的爭吵都是在吵這 1.7 分值不值得。
- **結果不給星等。** 合帶後給三個值（演奏／最重接痕／刀數）、逐刀的可聞度明細、製作人的一句反應，以及一組八位數的**剪接碼**（如 `PS-22222232`），第 n 位就是第 n 小節用了第幾條 take，報這組碼可以完全重現同一條。

不動手也讀得完：全部四十格評語、七個刀口落點的加權、可聞度公式與分級門檻、兩份示範剪法，全部寫在〈剪接法〉一頁，該頁不需要 JavaScript。

## 輪替登記

- **opening**：`takesheet-first` 錄音日誌單直開場（新原型）——首屏是一張已經錄完的紙本工作單與四十格手寫評語，不是一台待操作的機器面。
- **nav**：`leader-tape rail` 引帶側桿（新原型）——左緣一條連續的帶身，四頁是同一條帶上的四段有色引帶。
- **signature**：斜接縫滑移——切換來源時帶身以 45° 斜線切開、兩段沿斜線錯位後歸位。
- **illust**：`waveform-envelope` 波形包絡（新技法）——全站沒有一張畫出來的圖，每張圖都是把該段內容寫成合成模型跑一遍取振幅包絡；Python 靜態烘焙與瀏覽器即時繪製共用同一條 ADSR 公式。
- **mood**：`mid-tone` 磁帶氧化棕中間調（`#6B4126` 佔約 38%）。
- **首創**：**「編輯他人既有的表演」作為互動範式**——全館第一個使用者既不創作、不模擬、也不解謎的站：素材是固定的、有限的、別人留下的，你只能選擇與接合；而評價有兩條互相衝突的軸（最好的演奏 vs 聽不出接痕），且判定不是分數而是**可聽見的接痕**——底噪在接口處階躍、爆點真的會響。

## 技術

單檔 HTML／CSS／JS，零外部圖片與音檔（聲音全部由 Web Audio 即時合成：sawtooth → 低通 → ADSR，加 LFO 抖音、循環雜訊底噪、雜音爆點）。外部資源僅 Google Fonts。四頁共用引帶導覽與工作單抬頭，`prefers-reduced-motion` 降級（播放頭改逐小節跳、transition 歸零），≤900px 導覽轉底部 dock、日誌單與帶身橫向捲動。聲音一律等使用者手勢，不自動播放。
