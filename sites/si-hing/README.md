# 時興鐘錶行 SÎ-HING

大稻埕迪化街的鐘錶修理行（虛構）。創辦人吳添丁 1926 年到上海南京路亨達利洋行修錶間當學徒，1934 年回臺北開店，第二年起每年請同鄉畫師照鄭曼陀的擦筆法畫一張月份牌，年底送給修過錶的客人。第三代吳佩珊 2015 年把這個傳統接回來。

- **產業**：鐘錶修理行（機械錶全拆保養・石英錶・掛鐘座鐘・落地大鐘到府・錶帶錶鏡）
- **風格**：上海月份牌 Shanghai Yuefenpai（擦筆水彩中西月份牌；型錄「在地與文化視覺｜上海月份牌」既有流派，全館第 2 站）
- **語言**：繁體中文

## 核心功能〈撕到那天〉Tear to the day

三句規則：往下拉日曆本最上面那張，它就沿針孔撕下來（或點曆帶上任何一天，一路撕到那天；撕過頭按「貼回」）。每張印著那天的農曆、節氣、宜忌與當班師傅，週一那張蓋著「休」。停在你要送修的那天，勾一樣東西、蓋章，取件聯就出來了（預估取件日會跳過週一與春節）。

## 首創

**撕日曆即日期選擇器（tear-off pad as date picker）**：全館第一個以「一張一張撕掉日曆」作為選日期的操作。撕下的那一張是一個真的 DOM 複本：上緣每次重算 22 齒的鋸齒 `clip-path`，以 Web Animations 旋轉落下、疊進紙堆並計數；「貼回」把同一組關鍵影格 `reverse()` 倒播，紙從紙堆飛回本子。曆帶上點任何一天＝依距離自動調間隔的連撕（最多約 147 張）。每一張的內容（國曆、Intl 農曆、壽星公式節氣、以 FNV-1a 決定的鐘錶宜忌、當班師傅、公休章）都在撕的當下才生成，停下來那張就是送修日，再換成取件聯。附帶查證：Node 內建 ICU 把 2027 年正月初一算成 2/7（實為 2/6），本站建置期與前端皆覆寫校正。
