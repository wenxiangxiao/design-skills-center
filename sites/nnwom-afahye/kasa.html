布會說話 · KASA

在阿散蒂，布不是穿好看的，是拿來講話的。你穿哪一塊去，等於你先開了口。這一頁是這塊祭布用的全部語彙：六軸線與十二種緯浮塊母題，以及本風格那五個拿掉就不成立的東西。

十二種緯浮塊母題

驗收：對齊的那一塊是假的

本行的驗收只有一條——把兩條條幅並起來看，緯塊的上下緣不可以齊。齊了就是機器織的，因為機器一次織一整幅。

轉紗 · 這一站的簽名

把游標放到下面那一塊上（或用鍵盤 tab 到它）。它裡面的紋路會從縱帶變成橫帶——同一塊面積、同一組色，只有方向改變。而且它是一步跳過去的，中途沒有斜的中間狀態：織布沒有「轉到一半」這回事，任何連續插值在這個風格裡都是錯的（所以動效用 steps()，不用 ease）。

開啟「減少動態效果」時，左邊那一塊固定停在橫帶、不再自己翻——方向的資訊還在，只是不動了。

特徵 1　條幅與看得見的縫

版面必須由九到十一公分的等寬直條縫成。條與條之間是一道針距不等的手縫線——它是本風格的版面上唯一合法的「線」，不准再有第二種分隔線、不准用留白代替它。

/* 針距不等：5-4-3-7-4-5，刻意不是等分 */
.strip > * { position: relative; }
.strip > *::after {
  content: ""; position: absolute; top: 0; right: 0;
  width: 3px; height: 100%;
  background: repeating-linear-gradient(180deg,
    var(--fitaa)  0   5px, var(--tuntum)  5px  9px,
    var(--fitaa)  9px 12px, var(--tuntum) 12px 19px,
    var(--fitaa) 19px 23px, var(--tuntum) 23px 28px);
}
.strip:last-child > *::after { display: none; }

特徵 2　同一批線，方向轉九十度

經面（warp-faced）是縱帶，緯面（weft-faced）是橫帶。兩者用的是同一組色、同一個帶寬，沒有明暗差、沒有陰影、沒有第二種材質——差別只有紋路的方向。布面就是這兩種方向交替出來的棋盤。

.warpface { background: repeating-linear-gradient(90deg,
   var(--sika) 0 3px, var(--tuntum) 3px 6px,
   var(--kokoo) 6px 9px, var(--tuntum) 9px 15px); }
.weftface { background: repeating-linear-gradient(0deg,
   var(--fitaa) 0 3px, var(--ahaban) 3px 6px); }
/* 同一支宣告，只有第一個參數（角度）不同 */

特徵 3　跨縫錯位是成品，不是失誤

相鄰條幅的緯浮塊在高度上刻意錯開，至少三分之一塊高。對齊了就是機器織的——這一行不收。做法是讓所有條幅共用同一組列軌（subgrid），錯位量因此是可以宣告的整數緯數，不是隨手調出來的 magic number。

.cloth { display: grid; grid-template-columns: repeat(6, 1fr);
         grid-template-rows: repeat(36, var(--pick)); }
.strip { display: grid; grid-row: 1 / -1;
         grid-template-rows: subgrid; }       /* 共用母網格的列軌 */
.strip > .sp:first-child { grid-row: span 3; } /* 錯位＝整數緯 */
@supports not (grid-template-rows: subgrid) {
  .strip { grid-template-rows: repeat(var(--rows), var(--pick)); }
}

特徵 4　六軸線，沒有第七個色碼

架上只有六軸染好的線。畫面上出現的每一個顏色都必須是其中之一：不准調淡、不准加透明度、不准混、不准做明度階。明暗的變化只能由方向造成。這條規則可以機械檢查——把樣式表裡的色值列舉出來，必須恰好六個。

:root {
  --tuntum: #0E0C09;  /* 黑：成熟、已經過去的事 */
  --sika:   #F2B01E;  /* 金：豐年、王室 */
  --kokoo:  #D22B1E;  /* 朱：血緣、非講不可的事 */
  --ahaban: #0E7A45;  /* 綠：新苗、第一次來的人 */
  --bibiri: #173E86;  /* 靛藍：和睦 */
  --fitaa:  #F4EFE2;  /* 棉白：還沒決定的 */
}
/* 明文禁止：opacity、rgba 第四位、filter、任何漸層的
   軟停點、任何陰影、圓角 > 0 */

特徵 5　每塊布有名字，名字取自它最顯著的母題

布是拿來說話的，不是拿來看的。母題必須是軸對齊的矩形、長在塊內 12×12 的格上（沒有斜線、沒有圓弧、沒有描邊）；而布的名字與它要說的話，必須寫在版面上——看得到卻讀不出來，這個風格就只剩壁紙。

/* 母題只有矩形，只有兩色，只在 12×12 的格上 */
<svg viewBox="0 0 12 12" shape-rendering="crispEdges">
  <rect width="12" height="12" fill="var(--tuntum)"/>
  <rect x="0" y="0" width="3" height="3" fill="var(--sika)"/>
  <rect x="3" y="3" width="3" height="3" fill="var(--sika)"/>
  <rect x="6" y="6" width="3" height="3" fill="var(--sika)"/>
  <rect x="9" y="9" width="3" height="3" fill="var(--sika)"/>
</svg>  <!-- Nkyimkyim 曲折 -->
