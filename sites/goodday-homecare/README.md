# 日安到宅居家護理所（Goodday Home Nursing）

台北「日安到宅居家護理所」品牌示範站——以**照護手帳（Care-Journal Console）**視覺語言打造的**四角色作業系統**：同一份資料模型與同一支演算法，翻成業主管理端、居服員操作端、被照護者／家屬端與公開網頁端四種視角。

> 本站內容為虛構示意，非真實醫療機構、非醫療建議。所有機構、人名、立案字號、個案資料、收費、距離與排程結果均為設計展示用途。

## 這一版做了什麼（2026-07-27 大改造）

原版是三頁的品牌站，預約只是「選項目 → 選時段 → 填表」的線性流程。本次改造把它變成一套**真的會算的排班系統**：

1. **距離是真的**：13 個行政區與 16 個照護點都有近似真實經緯度，用 haversine 算直線距離、乘市區繞行係數 1.32 得道路里程，再依交通工具（機車／汽車／大眾運輸）與**尖峰離峰**車速換算車程分鐘。
2. **雙向智慧配對**：五項硬條件先淘汰（服務線資格、指定性別、必要語言、服務半徑、週工時上限、時間無交集），六項軟條件加權計分（距離 30／空檔吻合 25／專長 18／語言 12／連續性 10／負荷平衡 5），**每一分都列出理由**，被排除的人也寫明卡在哪一條。
3. **當日路線最佳化**：最近鄰起始解 ＋ 2-opt 改善，算出總里程、車程、服務時間、空檔等候與收工時間，並在超出案主偏好時窗時提出警告。實測 6 點行程可比未最佳化少跑約 25%。

## 四個角色端

| 頁面 | 角色 | 核心功能 |
|---|---|---|
| `index.html` | 公開網頁端 | 服務區域地圖（點行政區看收案與駐區護理師）、三條照護線、到府流程、團隊 |
| `services.html` | 公開網頁端 | 九個服務項目的內容／時間／收費、常見問題（不需 JavaScript 亦可完整閱讀） |
| `booking.html` | 公開網頁端 | 五步預約：選項目 →**標出照護地點看每位護理師的距離與車程**→ 設定時段與偏好看即時配對 → 填資料 → 預約代號 |
| `client.html` | 被照護者／家屬端 | 本週誰會來與**預計到達時間**（由當日路線推估）、設定性別／語言／連續性／需求時數／方便時段，即時看到配對結果與理由 |
| `staff.html` | 居服員操作端 | 當日路線圖與**逐點距離、車程、到達／離開時間、空檔等候**；可手動調整順序並即時比較與最佳解的差距；設定可服務半徑、交通方式、週工時上限 |
| `admin.html` | 業主管理端 | 所務儀表板、**配對中心**（逐案候選排名與計分理由、一鍵全所自動派工）、人力負載、全所當日路線總覽 |

## 演算法摘要

```
道路里程 = haversine(A,B) × 1.32
車程分鐘 = 里程 / 車速(交通工具, 尖峰?) × 60 + 固定損耗
配對總分 = 30·e^(-km/8) + 25·min(交集分鐘/240,1) + 18·專長命中率
         + 12·語言 + 10·連續性 + 5·(1 - 排入後負荷率)
路線     = 最近鄰起始解 → 2-opt 改善（含返回本所選項）
```

硬條件任一不符即淘汰，不進入計分。全部規則寫在介面上，不藏。

## 硬性輪替約束（PLAYBOOK）

- **導覽原型 bottom-dock**（沿用）：底部固定的布質書籤帶，六個入口配手繪圖示，現用頁在頂緣露出 4px 暖橘書籤角。
- **插畫技法 hand-drawn round-stroke**：全站圖示為圓端描邊自繪 SVG；作業地圖為等距長方投影的真實座標圖（含比例尺），非示意圖。
- **mood**：亞麻布暖褐中間調（`#E3D9C6`）＋紙卡，非米白紙感、非深色儀表板底。
- **零外部圖片與圖示字型**，外部資源僅 Google Fonts（Noto Serif TC／Noto Sans TC／Caveat）。

goodday-homecare/

├── staff.html      居服員操作端：路線與各點距離

每頁單檔 HTML（CSS／JS 全 inline，四端共用的核心引擎與 UI 模組內嵌於各頁）、相對路徑互連、favicon 為原創 inline SVG data URI。

## 無障礙與可用性

- 全站可鍵盤操作；`aria-pressed`／`aria-current`／`aria-label` 狀態齊備；表單皆有 `label for`。
- `prefers-reduced-motion` 下關閉全部 transition／animation 與平滑捲動；因資訊不靠動畫傳達，功能完全不減。
- RWD：≤900px 雙欄塌為單欄、≤560px 收合次要資訊；底部 dock 六格在窄寬仍可點擊。
- 各作業端附 `<noscript>` 提示，並指向不需 JavaScript 的 `services.html` 與服務專線。
