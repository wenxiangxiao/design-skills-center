# 馬崗石花 MÁ-KANG TSIO̍H-HUE

新北貢寮馬崗的石花凍店。簡阿蕊（1938–）十四歲跟母親下海，馬崗的海女不揹氧氣瓶，四到七月退潮時在海蝕平台與低潮線下的礁岩上採石花；上岸後「七洗七曬」——每洗一次、曬一天，紫紅就退一點，七次之後成了可以煮的米白。1979 年她在三貂角燈塔下坡擺攤賣石花凍；1996 年女兒簡月娥接手煮凍、在每個麻袋寫「第幾曬收」。2014 年十月孫女簡以青在紐約 MoMA〈Henri Matisse: The Cut-Outs〉看見〈Memory of Oceania〉，覺得牆上那些白色海藻、珊瑚、燕子就是阿嬤攤在曬場上的石花。2016 年她回馬崗，把店牆漆白，每季刷幾張水粉紙、照曬場上的石花剪一片當外帶盒的盒標，舊的就釘在牆上——這個網站就是那面牆。
