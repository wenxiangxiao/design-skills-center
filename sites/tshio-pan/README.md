# 笑版仔租書店 TSHIÒ-PÁN-Á

> 嘉義文化路夜市北口的漫畫租書店 × **Lubok 俄羅斯民間木刻版畫 Лубок · Russian Popular Print**

「笑版仔」是店裡對 lubok 的叫法——會讓人笑的版畫。黃金水（1939–2010）1971 年在文化路夜市口擺兩座木架開「金水租書」，武俠小說與四格漫畫一本一元；女兒黃秀蘭（1966–）1994 年接手，加了冷氣、板凳和一鍋泡麵；孫子黃柏宇（1990–）2012 年在莫斯科交換時，在伊茲麥洛沃的跳蚤市場買到一疊十九世紀 lubok 的複製畫，2019 年把店改名，每月的新書單改成一張椴木刻的笑版：黑版印好，秀蘭和隔壁三位阿姨一人一罐色手刷，貼在門口。

lubok 是十七到二十世紀初在俄羅斯市集賣給平民的版畫，便宜、熱鬧、有字有故事，成套的 lubki 被看作連環漫畫的前身——拿來做漫畫租書店剛好。
