## 認領的首創

**把「可讀性」設為稀缺資源與互動貨幣（legibility as a scarce resource）。**

全館第一個站，其正文不是全部可讀的：四欄內文真的疊印在同一塊版心上，任一時刻只有最上層那一欄完整可讀，其餘退成空心輪廓；層序由讀者的捲動位置與指標即時決定，因此「讀這一段」這個動作本身就是把它拉到最上層並犧牲另外三段。核心功能延續同一條規則——使用者交出內容（一場賽後嗆聲的五個答句），但**排版權不在他手上**：版規引擎只讀每一句的四個數字（音量／具體／危險／廢話），裁定它的字級、層序、被畫布切掉幾成、以及是否整段被降級成非文字符號（《Ray Gun》1994 年把 Bryan Ferry 專訪排成 Zapf Dingbats 的真實事件，被寫成第二條版規），最後回報「你講的字有幾成真的被讀到」。

與既有各站的差別：`yongzi-foundry`／`baicaochun`／`beian` 讓訪客接管的是識別外觀、裝字容器或資訊架構，交出去之後結果由訪客自己決定；本站訪客交出的是內容，而**版面會用他自己算得出來的規則對他的內容做出他不能否決的判斷**，且這個判斷的代價是他的話被讀到多少。與 `shidong`（把觀看者的視網膜當成輸出媒介）的差別是本站沒有任何知覺現象，被扣掉的可讀性完完全全發生在螢幕上、且可以逐字驗算。

## 可用性保底

- 首頁四欄疊印之外另有一份「乾淨版」完整文字；`fa.html` 全頁不疊印、不切字。
- 「全部攤平」開關隨時可關掉疊印；`prefers-reduced-motion` 時自動開啟。
- ≤700px 一律不疊印，四欄依序全寬排列。
- 無 JavaScript 時第一欄恆為實心可讀，其餘為輪廓，全文另存於乾淨版；嗆聲台的全部規則與屬性表印在 `fa.html`，可用紙筆算出一模一樣的結果。
- 零外部圖片、零音檔、零函式庫；外部資源只有 Google Fonts 三個字族。
