# 終點片判讀風 Photo-Finish Strip

## 一、設計哲學

本風格的母題是**狹縫掃描成像**：相機只看得到一條線，底片連續捲動，橫軸因此是時間。整個網站被當成一間判讀室來設計——深色房間、發亮的光檯、躺在檯上的銀鹽片、一條紅色判讀標線。三個不可妥協的原則：

1. **圖像的橫軸是時間。**任何主視覺圖像都必須可以被讀成「某條線的歷史」：移動者有始有終、快者窄慢者寬、往復者成波帶、靜止者成貫穿帶。畫一張「普通的照片」就是破格。
2. **判讀優先於裝飾。**每張圖都配時標、讀值或標線；mono 數字是本風格的第一裝飾。沒有可讀出數字的圖是海報，不是片。
3. **暗房裡只有三種光**：光檯的象牙、時標的琥珀、判讀的紅。紅色只給「判定」——標線、判定文字、現用頁。紅一多，判讀就廉價了。

## 二、色彩系統

| 色票 | 用途 | 比例 |
|---|---|---|
| `#15171C` 判讀室墨青 | 全站底色（疊 7px 橫向極淡掃描線紋理） | ~45% |
| `#1D2026` 檯面板 | 面板、卡片、表單底 | ~20% |
| `#1B1D22` 片基黑 | canvas／圖版底（片的黑） | ~15% |
| `#EFEAE0` 光檯象牙 | 光檯框、亮部文字、使用者讀線 | ~8% |
| `#D7D3C8`→`#AFAA9D` 銀鹽灰階 | 影像本體（軀幹最亮、頭次之、肢體最暗） | 圖像內 |
| `#C99B4A` 時標琥珀 | 時間刻度、輔助讀值、hover 強調 | ~5% |
| `#E2442C` 判讀紅 | 標線、判定、現用頁、必填星號 | ~3%，只給判定 |
| `#8A93A0` 藍灰 | 次要文字 | 文字用 |

邊線一律 `#343945`（外）與 `#2A2D34`（內），1px，無圓角（光檯框可 0）。禁止漸層 hero、禁止彩色影像——片是銀鹽的，彩色只屬於介面。

## 三、字體系統

- **Noto Sans TC**（Google Fonts）：內文 400／強調 700／標題 900。標題字距 `.08–.14em`。
- **IBM Plex Mono**（Google Fonts）：一切數字、時標、卷號、按鈕、導覽小標。讀值必用 mono，且保留三位小數（`10.874`）。
- 字級 scale：30／21／17／15／13.5／12.5／11（px），行高內文 1.75–1.85。
- 大標語氣：短句斷言（「這張片已經顯影。名次還沒有。」），禁止「把 X 變成 Y」句式。

## 四、版面與網格

- 最寬 1180px；核心工作面用「窄 rail（~252px）＋寬檯面」的不對稱兩欄，rail 在左承載判讀欄與按鈕，檯面在右。
- **光檯構造**：`border:6px solid #0E1013; outline:1px solid #343945; background:#EFEAE0; padding:10px`，內放片基黑的 canvas／SVG。象牙框就是「發光的玻璃」，全站唯一大面積亮色。
- 開場採 **strip-first**：首屏即工作物件（一條片＋判讀欄），無大標 hero、無宣傳標語、無按鈕組。品牌只佔頁首一條細列。
- 資訊表用 1px 網格拼接（`gap:1px; background:var(--line)`），格內各自 `background:var(--panel)`。
- 頁面背景疊 `linear-gradient(rgba(255,255,255,.018) 1px,transparent 1px); background-size:100% 7px` 的極淡橫紋（底片走帶感）。

## 五、狹縫掃描引擎（本風格的圖像配方）

所有圖像由同一支引擎生成，不畫「普通插圖」：

1. **場景模型**：每個移動體寫成部件集合，部件＝`(x0,x1,y0,y1,tone)`，x 為沿行進方向相對「判定點」的公尺偏移（判定點過線瞬間 x=0），y 為離地高度比例。往復部件（臂、腿）的 x 偏移寫成 `A·sin(2π·cad·t+φ)`。
2. **掃描**：對每個像素欄取 `t = t0 + px/pxs`，求該瞬間哪些部件的 x 區間含 0，把它們的 y 區間畫成 1px 寬的色帶。**這一步就是全部**——所有形變自動發生。
3. **調性**：軀幹 `#E7E2D6`、頭 `#CFC9BB`、肢體 `#AFAA9D`；號碼布以片基色印在軀幹帶上。
4. **時標**：頂部 26px 尺帶，每 0.1s 琥珀實線＋mono 標籤，每 0.01s 琥珀 18% 細線。
5. **標線**：真值紅 1px 實線＋mono 讀值；使用者讀線象牙 1px 虛線（`setLineDash([3,2])`）。
6. **決定性**：一律 `mulberry32(seed)`；字串輸入先過 FNV-1a。同 seed 恆得同片。
7. **輪類**：圓心 `xc=v(tf−t)+r`，`|xc|≤r` 時畫弦（外緣留 0.045m 輪框厚度），輪緣測點 `θ=ωt`（`ω=v/r`）過縫時打 2px 琥珀點——擺線弧自動出現。

## 六、元件配方

- **導覽（hairline-rank）**：右上固定一枚 178×88 SVG——迷你片（三條銀鹽波帶）＋N 條垂直標線＝N 頁。現用頁標線 `#E2442C` 2px 貫穿全高、頁名 700 反白、下綴紅 mono 小標；他頁琥珀 1px 短線、灰字。≤900px 收成底部四格 dock（現用格 `inset 0 3px 0 var(--red)`），頁尾另備完整文字連結。
- **按鈕**：mono 12px、`background:#1B1D22; border:1px solid #343945`，hover 轉琥珀；主按鈕紅底白字。無圓角、無陰影。
- **表單**：欄位深底 1px 框、focus 琥珀 outline；錯誤紅框＋紅字說明（寫人話：「電話格式不對——市話含區碼或手機十碼」）。
- **表格**：th 灰字 sans、td mono，行線 `#2A2D34`；評註欄以綠 `#9BC07C`／琥珀／紅三級著色。
- **回執印記**：紅圈環形字（textPath）＋中央一小段雜湊顯影的片＋標線＋mono 讀值，全印 `#B23A28`。
- **footer**：三欄（所址電話／頁面連結／格言），末行虛構聲明＋建置模型。

## 七、動效規則

- **slit-write 狹縫寫入（signature）**：圖像出現的唯一方式——沿時間軸由左至右寫出（offscreen 先渲染，rAF 以 ~1.7s 掃完，前緣一條象牙寫入頭），畫面的增長即計時本身。**禁止**改用 opacity 淡入。
- 導覽 hover：標線由 1px 琥珀增為全高；`transition` ≤ .15s 或乾脆瞬時（真的燈與標線沒有 easing）。
- 空間視角重播：rAF 逐幀推進，同一組部件函數換回空間軸。
- `prefers-reduced-motion`：slit-write 直接整片顯影；自動播放停用、改拖桿逐格；`scroll-behavior` 轉 auto。資訊零損失。
- 禁用：進場淡入序列、數字滾動計數、視差、跑馬燈。

## 八、Logo 與 Favicon

- Logo＝一小段終點片（片基黑＋時標帶＋一位狹縫掃描跑者：軀幹厚帶、波浪肢帶、號碼布）＋紅標線與讀值，右側字標「毫釐」900 大字＋mono 英文。
- Favicon＝32×32 inline SVG data URI：片基黑底、象牙軀幹塊、一條灰波帶、右側 2px 紅標線。與 logo 同語彙的最小化，不是縮小版。

## 九、Do & Don't

**Do**：每張圖配 mono 讀值；紅只給判定；快者窄慢者寬；同 seed 同片；文案用判讀室的短句與具體數字（千分之六、廿四小時回件）。

**Don't**：紫藍漸層 hero；置中大標＋雙按鈕＋三卡片；emoji icon；圓角卡與模糊陰影；Lorem ipsum 與 AI 腔（「在當今快節奏的世界」）；EST. 19xx 徽章；把彩色塗進銀鹽影像；沒有時間軸意義的裝飾波浪線（那是 thin-lineart，不是片）。
