## 首創

1. **固定筆刷的車床繪製**：圖案不是由游標畫出來的——筆刷固定在右側不動，使用者轉動盤面（WAAPI `currentTime` 即角度），轉過筆刷的那一段才落筆；順時針才畫、逆時針只轉。全館第一個「旋轉量＝繪製進度」的互動。
2. **進窯色變簽名**：以 SVG `feColorMatrix` 對角插值把銀精確映成金（同時把覆盆子朱映成正朱）＋`feDisplacementMap` 熱氣——重現 Khokhloma「清漆一黃、銀就成金」的真實工序。
3. **轉速平均色環**：干樂放下去高速旋轉時，每一圈花樣依黑／朱覆蓋率混成一個平塗色環。
