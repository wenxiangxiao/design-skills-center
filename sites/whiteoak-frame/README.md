## 認領的首創

**一筆畫（歐拉路徑）作為互動範式，且使用者走出的路徑直接變成網站表面的實體起伏。**

- 互動對象是一張圖（graph）與它的奇次頂點集合；被計算的是「最少要斷幾次線」
  ＝ Σ over components max(1, odd/2)，這是可證明、可驗算的最佳解，而且明白印在畫面上。
- 使用者走過的每一段立刻獲得起伏（棉胎被壓線圍住後浮起來），
  所以路徑的積分就是這床被的表面高度場；斷過線的地方留下永久的結，收工後仍看得到。
- 與 `qizhong`（排列群與相鄰對換的鳴奏）的差別：那裡的對象是一個群與它的生成集，
  每一步是一次對換；本站的對象是圖與邊的遍歷，被求的是覆蓋所有邊的最少開放跡數。
- 與 `muli-arbor`（逆問題）、`xiulu`（WFC 約束傳播）、`sporekey`（二分檢索）的差別：
  那些是在推論一個隱藏的真值或分類；本站沒有隱藏真值——最佳解一開始就寫在表上，
  難的是走。

四床壓線圖的實測（建置階段以 Hierholzer 於補完圖上驗證可達）：
斜格 28 段／最少 1 次；羽毛環＋繩索紋 40 段／2 次；貝殼紋 21 段／3 次；南瓜籽 24 段／4 次。

## 四種動效

1. **ambient 燈影橫掃**——煤油燈位每 26 秒緩慢移動，全站壓線兩側的暗線與亮線隨之互換。
2. **input 布標翹角／針路點亮**——疏縫布標 hover 掀起一角（.12s）；被架上針還接得到的段即時亮起（<100ms）。
3. **transition 走針推移**——`clip-path:inset()` 以 `steps(14)` 一針一針推開，換頁、換被、篩選、出被票都用它。
4. **signature 落針起伏**——走過的壓線段當場鼓起來；起伏是路徑的積分，結留在原地不消失。

四種皆有 `prefers-reduced-motion` 降級：燈停在正上方、推移歸零、起伏改為瞬間到位，資訊零損失。
