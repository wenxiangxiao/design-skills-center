## 核心功能〈改檔台〉

規則三句：①選一個花樣，它的花型檔攤在右邊，每一格是一個位元組；②點一格，再點它的一個位元把它翻過去——最多咬三口；③錯誤沿著檔案一路往下跑，跑完就是全世界只有一雙的錯檔襪，憑檔號週三取貨。整雙襪的錯誤就在網址裡（`?p=2&f=202.2,268.6,380.0`），複製網址＝把那個壞檔交給別人。

## 認領的首創

**位元級 databending 作為核心互動**：全館第一個讓使用者直接翻轉一個檔案的位元，並由真實的逐列 RLE 解碼器把錯誤傳播成畫面的站。畫面上的 glitch 沒有一格是畫的——翻「長」位元那一列後半整排滑開（橫向撕裂）、翻「紗」位元一段變色、翻「列首」底下幾十列全部讀錯行並抄上一列（datamosh 拖影）；顏色則由解碼結果與原稿逐格比對決定（色即是錯）。整個壞檔可序列化進網址分享。

## 動效預算

- **ambient**：首頁那雙襪的 datamosh 漂移（8×8 區塊沿動態向量抄鄰格，48 拍一個 I-frame）；標題撕裂帶偶發換位；排序滴流 steps(8) 生長；位置圖上的錯點明滅
- **input-driven**：指標水平速度 → 全站色版分離量 `--s`（整數 px，逐幀衰減）；按住錯誤圖看原稿
- **transition**：跨頁水平撕裂（View Transitions，steps(6)）
- **signature**：**錯誤沿編碼往下跑**——從第一個受損列起一幀解一列，讀頭是一條黃線

四種皆有 `prefers-reduced-motion` 降級，降級後直接顯示最終狀態，資訊零損失。
