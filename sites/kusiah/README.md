## 核心功能：分診台

規則三句話：**一、挑一件今天送來的東西。二、你只做得完三次檢查（一次十分鐘）。三、指出它壞在哪一個零件。**

六件東西各有 5 個候選故障與 5 項檢查。每項檢查對應一個候選子集，因此「哪三項檢查足以定案」是可以窮舉的。全部窮舉結果（`C(5,3)=10` × 6 件 = 60 種組合）：

| 件 | 足以定案的三項組合數 | 是哪幾組 |
|---|---|---|
| 甲 金屬夾式檯燈 | 4／10 | 123・134・234・235 |
| 乙 塑膠底座果汁機 | 4／10 | 123・134・234・235 |
| 丙 三折自動傘 | 4／10 | 124・234・235・245 |
| 丁 桌上型收音機 | **2／10** | 135・345 |
| 戊 外七速通勤車 | **2／10** | 234・235 |
| 己 榫接餐椅 | 8／10 | 124・125・134・135・234・235・245・345 |
| **合計** | **24／60（40%）** | 平均做完三項後剩 1.29 個可能 |

所以紀錄卡上不只寫對錯，還寫**「你選的這三項到底夠不夠」**——四種判詞：指對且足以定案（不是運氣）／指對但不足以定案（**你是猜的**）／指錯但其實夠（資料在你手上）／指錯且本來就不夠。這對應第五條攤規：「不確定的時候講我不知道。」

分享／還原：`?d=<件>.<件號>`，同碼恆得同一件故障。

## 認領的首創

**瀏覽本身即消耗（browsing-as-consumption）**——全館第一個把「使用者看過幾頁」當成渲染參數的站。每一次跨頁轉場，全站裝飾圖像的影印世代 +1（模糊 σ、閾值中心、碳粉膨脹半徑、掃描黑邊寬度、碳粉屑數五個參數單調惡化），**不可回復、無正確值、無法調準**；使用者唯一的介入是付出代價「重新製版」把它歸零，或關掉它。

- 與 `patchframe`（損毀—校正式站體）的差別：那裡有隱藏真值、有調桿，使用者調準後畫面即還原，退化是一道待解的謎題；本站沒有真值也沒有調桿，惡化是使用行為本身的必然結果。
- 與 `gatemark`（不可逆工序卷）的差別：那是單一任務卷內的不可逆；本站的不可逆跨越整個站體與多次造訪。

**安全底線**：只有裝飾與插圖退化；正文、價目、電話、時間、表單標籤永遠是第一代的一般 HTML 文字。畫面上一直看得到目前代數，並隨時可「重新製版」或「停在第一代」。
