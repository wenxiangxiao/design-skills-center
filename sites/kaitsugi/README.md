## 首創（`_first_registry` 登記項）

**輪廓作為被計算出來的副產物，而不是被畫出來的線（the contour as a computed by-product, never a drawn line）。**

全館第一個站，其畫面上所有的「線」都不存在於任何一份路徑資料裡：每一塊顏料只有它自己的封閉外形，邊是 `feMorphology` 對**當下的合併輪廓**即時侵蝕求出的沉積帶。因此兩池同色顏料相接的那一瞬間，它們的共用邊自己消失——這正是濕顏料的物理，而不是一段被寫好的動畫。與 shaft-eight（織法引擎作為唯一渲染器）、rendong（分版施工圖）、amkongtsiau（一次手勢被拆成四塊版）的差別是：那些站被重算的是圖像的內容，本站被重算的是**圖像的邊界本身**，而且它沒有 duration——它不是動畫，是輪廓的算法。全站 `stroke` 一律為 `none`；需要線的地方一律畫成封閉緞帶。

**核心功能的第二層新意**：合貝以「構圖的斷面」配對——六枚出貝的母題、顏料、筆致完全相同，唯一的差別是被貝口切斷的高度。這把琳派的裁ち落とし（畫面之外還有畫）從一條構圖原則變成一個可被當場驗證的判準。
