## 核心功能：鑿一塊冰

三句話：**一、挑一支冰（三種模，都是 135 公斤）。二、下三到六刀，每刀選方位、鑿角、深度。三、交件，師傅照四條規矩驗。** 一輪約九十秒。

四條規矩都是量出來的，不是評分：

1. **站得住** — 必須留著一個水平底面，且重心的垂直投影落在它裡面。
2. **心不破** — 每一刀的平面到濁心球心的距離要大於心的半徑。
3. **面要斜** — 至少三個新生面與水平夾角在 15°–75°，面積 ≥ 原表面積 0.5%。平切與垂直切不算。
4. **不鑿碎** — 剩餘體積 ≥ 原體積的 52%。

結果不是分數也不是星等，是**去處**：宴會冰雕檯座／魚市鋪冰／食用角冰／刨冰料／回槽改鑄。

## 認領的首創

**減法作為唯一的造形動作，且一個角度同時決定形狀、明度與代價**（subtractive half-space cleaving as the sole formative act）。

全館第一個站，其產出物只能由「拿掉」產生：使用者不能加、不能畫、不能拖動任何既有的面，只能選一個平面把物體切成兩半並丟掉一半。三個獨有點：

1. **一個決定同時是三件事。** 因為著色只由面的法線與一盞不會動的燈決定，選鑿角的那一下同時決定了新面的形狀、它的明度階、以及丟掉的體積。「選角度＝選顏色＝付代價」是這個流派的本體規則被做成可操作的東西。
2. **不可逆但可交換。** 半空間的交集可交換，所以順序不影響結果——本站因此明講「不提供上一步，因為順序不值得回頭」；但體積不會長回來，要換只能重新拔一支。與 gatemark 的「不可逆且順序相依、把放棄之物記下來」恰好互補。
3. **與既有各站的差別。** foldpoint 的剛性摺疊是等距、可逆、面數不變的加法性變換；shuimo 的嵌石磨顯改變的是觀看的斷面平面而物體本身不動；gluhwerk-glass 是被觀看的物理模擬台。本站的物體真的少掉了東西，而且少掉的那塊會沿切面法線離開，然後留在旁邊慢慢飄走。
