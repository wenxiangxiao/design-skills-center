## 八維輪替欄位

- **opening**：`blast-list-first` 雙欄名單直開場——首屏沒有 hero、沒有大標題、沒有圖，只有照 1914 年《BLAST》第一批頁面排法的 BLAST／BLESS 兩欄名單（左欄是本廠不接受的五件事，右欄是本廠的全部工法），h1 排在名單之後。立場先於說明。
- **nav**：`true-course-strip` 真航向帶——頂端一條分成四格的帶，每一格都被 `skewX(-13deg)` 斜推；現用頁的表示法不是變色或加底線，而是**它是唯一一格沒有被斜推的**（回正、換成紙色底、角落標 TRUE）。周圍都在說謊，只有你在的那一格是真的。
- **illust**：`wedge-fan` 楔扇構成——所有圖像是一個偏心渦心的硬停點 conic 扇，用 `clip-path` 裁成輪廓；零曲線、零漸層、零陰影、零紋理、零外部圖片、零 SVG path 資料。整站的全部圖樣只靠兩個扇的定義。
- **mood**：`blast-puce` ——冷紙白 + 近黑高反差骨架 + BLAST 的 puce（≤16%）+ 鴨綠 + 鉛灰。顏色是「版」，不是光。
- **signature**：〈走樣〉the mis-read——判讀揭曉的那一刻，船身上整套分版以 `steps(5)` 一格一格轉到**真航向**上，同時那道說謊的假艏波消失。使用者是看著圖案停止說謊。
- **func**：〈試航判讀台〉——挑一套分版貼上船身，按放行，它在窺孔裡以 `steps(16)` 走一趟然後出視野；從八個方位裡判它剛才往哪走。**判得越離譜，分版越成功**（計分是反的）。四次試航後給平均誤差與出廠／合格／重畫的結論，本廠合格線 45°。規則三句話說得完，一輪約 90 秒。線索只有三個：橫過視野的方向與距離、船身看起來多寬、以及那道會說謊的假艏波。

## 技術（tech）

1. **`conic-gradient` 硬停點楔扇（A 渲染層）** — 全站零真漸層；所有「漸層」都是前段結束＝後段起始的硬停點，輸出的是一組角寬全不相同的平色楔。`@property --vir` 讓渦心起角可補間，承載 ambient〈渦〉與 input-driven〈刃〉。整站圖像只靠兩個扇的定義。
2. **`shape-outside: polygon()` ＋ `shape-margin`（C 版面與樣式層）** — 浮動的楔與它的文繞排邊界是同一組幾何，正文沿斜邊走而不是沿外接矩形。Baseline 自 2020-01 起四大瀏覽器齊備。
3. **`steps()` 逐格時間軸（B 動效與時間軸層）** — 全站零 `ease`、零 `cubic-bezier`、零 `linear`，連 hover 的換色都是 `steps(2,end)`。這不是效果而是風格論點：平滑的時間是未來派的速度感，漩渦主義的渦心是靜止的。

## 首創

**反向計分的誤導判讀（inverted-score misreading）** — 全館第一個站，其核心功能的成功條件是**使用者答錯**，而且錯得越多分數越高：〈試航判讀台〉要你判斷船的航向，但判準寫在廠規裡——四次平均誤差要大於 45° 才算合格，小於 45° 叫「被看穿」，要回放樣室重畫。頁面上唯一在說謊的元素（假艏波）是使用者自己選的那套分版畫上去的，所以使用者同時是被騙的人與下單騙自己的人；而揭曉時那套分版會一步一步轉回真航向，讓人看著自己剛剛信的那條線被抽掉。

## 動效預算（四種齊備，全部 `steps()`）

| 種類 | 名稱 | 觸發 | 降級後 |
|---|---|---|---|
| ambient | 〈渦〉 | 無需輸入，24s `steps(18,end)` 推進 `--vir` | 渦停在起角 34°，畫面相同 |
| input-driven | 〈刃〉 | `pointermove`（rAF 節流，30 個離散階，<20ms） | 不綁定，扇留在靜態角 |
| transition | 〈分版推移〉 | 狀態切換，280ms `steps(6,end)` 斜面推入 | 直接換，無動畫 |
| signature | 〈走樣〉 | 判讀揭曉，520ms `steps(5,end)` 轉回真航向 | 直接到位，假艏波直接消失 |

四種皆有 `prefers-reduced-motion` 降級；降級後所有報文、真航向、誤差角度、試航紀錄與結論完全照常顯示，航程縮為 900ms 且船直接就位。
