# 火紅自助餐 HÓE-ÂNG

臺南市中西區西門路二段 317 號〔門牌虛構〕的自助餐。1979 年林月娥開店，牆刷廟宇彩繪行賣剩的黃土粉兌石灰；1994 年 7 月 12 日中午炸排骨的油鍋起火，爐邊那面牆從黃變成紅——跟龐貝很多「龐貝紅」的牆一樣，是赭黃裡的針鐵礦被燒成了赤鐵礦。熟客叫它「火紅仔」，1995 年改名。2021 年起二代林佳蓉顧櫃台，2026 年重新粉刷時照龐貝第三風格分三段畫牆，紅的那一片留著。

- 主菜：滷雞腿 75・炸排骨 70・煎鯖魚 65・控肉 60；每日特餐（週一紅燒獅子頭 90／週二虱目魚肚 95／週三咖哩雞 80／週四糖醋魚 85／週五滷豬腳 90／週六古早味雞排 75）
- 配菜一格 15–20・白飯 10・湯免費（冬瓜湯／味噌湯）
- 週一至週六　午 10:30–13:30・晚 16:30–19:30・週日公休
- (06) 222-1979〔虛構〕・現金、LINE Pay

品牌、人物、地址、電話皆為虛構；龐貝 Regio V 熱食櫃（2019 局部、2020 年底全面出土）、Hedone 酒館價目（CIL IV 1679）、維特魯威《建築十書》VII.5、Boscotrecase 別墅、Marcaida et al. 2019 赭黃加熱數據為真實背景。

## 首創

**熱變色壁 goethite-to-hematite wall**：全館第一個讓牆面的顏色由一個物理熱場不可逆地改寫的站——每夾一道菜，菜甕上方升起熱羽流（96×40 顯式差分＋上升對流），超過 225°C 的石灰由赭黃轉焦赭再轉龐貝紅、275°C 全轉，門檻取自 2019 年龐貝黃赭碎片加熱實驗；WebGL2 著色器把轉色度、抹刀紋、磨光高光與裂紋一起畫在同一面牆上，轉色紀錄跨頁保存成「你的牆」。
