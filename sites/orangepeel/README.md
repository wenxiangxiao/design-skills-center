## 認領的首創

**全館第一個「把色階量化器當成唯一渲染器」的站。**

整站沒有任何一處連續的顏色變化：所有的立體感、層次與「漸層」，都是一個 `feComponentTransfer type="discrete"` 把一個看不見的連續場切成 N 塊硬邊平色的結果。更進一步，**N 這個數字本身承載資料**——一條色帶被切成幾階，就是那一面唱片有幾首；色帶佔掉的寬度，就是那一面有多長；階梯從哪一罐油墨出發，就是那張封套借了哪一個歷史樣式。於是「顏色」在這個站上不是裝飾，而是三個欄位的視覺化，而且是可以用滴管逐格驗算回去的。

配套的簽名動效〈走階〉也由同一個結構產生：色帶的顏色每一拍整階往前挪一格，**階界一動也不動**——全館既有的動效沒有一個是「顏色跳一整階、邊界不動」。

## 核心功能：〈排面台〉

三句規矩：

1. 架上十二卷母帶，挑三卷排成 A 面。
2. 三卷加起來要落在 **18:00** 到 **21:30** 之間。
3. 最後一首不能是標〈亮〉的那幾卷。

兩條規矩都是從物理長出來的，不是憑空訂的：可刻範圍從外緣 146 公釐開始，本廠溝距固定 115 微米，所以

```
圈數     = 總長（分） × 33⅓
徑向走   = 圈數 × 0.115 公釐
內圈半徑 = 146 − 徑向走        （下限 63.0 公釐）
溝長     = 2π × (146 + 內圈半徑) ÷ 2 × 圈數
```

21:30 這個上限，就是內圈 63.6 公釐反推回來的。18:00 的下限則是生意：一九六五年發過一張 16:40 的，收到一百四十一封信。

十二卷母帶共 220 種組合，其中 94 種長度合格；加上「末首不得標亮」，合格排列 334 種。九十秒內找得到一組，但不是隨便按就會中。

送壓後印出一張壓片單：面序、總長、圈數、溝距、內圈半徑、溝長，外加你這一面的色帶（三塊，寬度各為該卷長度，顏色為該卷的油墨，末端是一小截茄墨的導出溝）。

**關掉 JavaScript**：十二卷母帶的全部資料在靜態表裡，兩條規矩與四條算式在頁面上，範例壓片單是靜態 HTML——一個字也沒有少，只是不能自己動手排。

## 四種動效

| 種類 | 名稱 | 內容 |
|---|---|---|
| 環境 ambient | 〈轉〉 | 刊頭的橙皮螺旋以 1.80 秒／圈持續旋轉（33⅓ 轉的真實週期） |
| 輸入 input-driven | 〈壓針〉 | hover／focus 落在任一色帶，該帶的階數立刻由 N 退到 3（0ms，無 transition） |
| 轉場 transition | 〈翻面〉 | 拉頁以 flex 展開收合 .42s；〈排面台〉的方塊以 FLIP 被搬到新位置 |
| 簽名 signature | 〈走階〉 | 色帶顏色每拍整階前挪一格，階界不動；週期＝該面長度÷60，格數＝該面曲數，所以十二條永不同步 |

四種在 `prefers-reduced-motion: reduce` 下全部停住，階數、寬度、顏色、文字、順序一律不變。
