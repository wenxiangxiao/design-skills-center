# 瑞興磚窯 SŪI-HING

彰化花壇的十八室八卦窯（霍夫曼環窯）。陳水龍（1921–1998）1936 年十五歲進台灣煉瓦會社的工場當學徒、學看火；1963 年在花壇買下一塊黏土田，照舊工場的圖自己砌了一座十八室環窯，煙囪三十二公尺。1983 年隧道窯普及，花壇的八卦窯一座一座熄，瑞興改成一年只點兩次火（4 月、10 月，每次四十天），專燒古蹟修復磚。2018 年孫女陳以安在阿姆斯特丹 Het Schip 博物館翻到整套《Wendingen》（1918–1932）——33 公分正方、和紙單面印、草繩和裝，封面大字是編輯 Wijdeveld 用印刷所的黃銅鉛條一根一根拼出來的。「那不就是砌磚嗎？」從第 58 窯次起，她每一窯出一本正方形的《瑞興窯報》，所有標題字都用磚片的單位拼；2020 年起接「磚砌門牌」的訂單。網站就是第 63 窯次那一冊。
