製牌準則

五條，一條都不能拿掉

這五條不是風格偏好，是這一面牌能不能在兩公尺半外、一點八秒內被讀懂的條件。任何一條被拿掉，牌還是會印出來，但它就不是形數室的牌了。

規則 01

一形一色，形與形之間留一道地色白隙

輪廓不是線，是兩塊顏色之間那一毫米沒有印到的紙。做法不是描邊，是給每一個形一圈與地同色的描邊——它同時吃掉自己一點點，也蓋掉後面那個形一點點，於是兩形之間就出現了一道等寬的地色縫。牌上絕不出現黑色勾邊：勾邊會讓平塗變成著色本。

左：有白隙。右：沒有白隙，兩個形黏成一塊。

.fig > * {
  stroke: var(--gap);   /* 地色，不是黑 */
  stroke-width: 2;      /* A2 實牌上 = 1.2mm */
}
/* 進到湖青色域時，白隙自己跟著換色 */
.teal { --gap: #1E9E9B; }
規則 02

只用四種形，並且把形數印在牌上

正圓、膠囊、等腰三角、同心圓的眼。膠囊與圓是同一個東西——一個左右兩端各一個半圓、中間一段等寬的矩形；當中段長度為零，它就是圓。所以整套系統只需要一組參數（半徑 r、中段長 L、角度 a），這也是牌能被機器一階一階減下去的原因。三角只用在喙、角、耳、鰭；牠不參與合形，牠會先被磨成等效的膠囊再被吸收。

四種形，與由兩個同心圓構成的眼。

<!-- 膠囊：rx 永遠等於高的一半 -->
<rect x="${x-L/2-r}" y="${y-r}"
      width="${L+2*r}" height="${2*r}"
      rx="${r}" transform="rotate(${a} ${x} ${y})"/>
<!-- L = 0 時，同一段程式畫出來就是正圓 -->
規則 03

平塗到底

不准漸層、不准陰影、不准柔邊、不准描邊字、不准圓角矩形當卡片。牌是絹印的：一個顏色一塊網版，一塊網版過機一次，機器不會印出 0 到 100% 之間的東西。螢幕上也照這條做——本站沒有一個 box-shadow、沒有一個 filter、沒有一道 gradient。

/* 本站的禁用清單，直接寫成檢查用的選擇器 */
*:not(pre) { box-shadow: none !important; }
/* 允許的深度只有一種：一塊顏色蓋住另一塊顏色 */
.card { border-left: 3px solid var(--ink); }  /* 實線 */
.card { border-radius: 0; }                   /* 卡片不許有圓角 */
規則 04

湖青是棲地，不是背景

奶白只是地，它不承擔意義。真正說話的是第二塊大色域——湖青，牠代表「這隻動物待的地方」。柿紅只給動作與拒絕，芥黃只給現用態與被選中的事，灰粉只給皮膚與裸露的肉。比例是硬的：奶白 34%、湖青 24%、柿紅 15%、芥黃 12%、墨綠黑 11%、灰粉 4%。

左起：奶白、湖青、柿紅、芥黃、墨綠黑、灰粉。

:root{
  --paper:#F4EFE1;  /* 地 34%      */
  --teal :#1E9E9B;  /* 棲地 24%    */
  --red  :#D9482B;  /* 動作 15%    */
  --yel  :#E9B02A;  /* 現用態 12%  */
  --ink  :#17211F;  /* 線與字 11%  */
  --pink :#E9B4A4;  /* 皮膚 ≤4%    */
}
規則 05

字與形同格

說明文字不繞圖、不置中、不壓在圖上。圖與字掛在同一組列上：名稱一列、圖一列、梯一列、規格一列、註一列，整排牌的同一列必須對齊到同一條線，否則遠看就是一排歪的。網頁上用 subgrid 做——子卡片直接借用外層網格的列，內容再長也不會把自己那一格撐歪別人。

圖靠左欄，字靠右欄，兩欄共用同一條格線。

.atlas { display:grid; grid-template-columns:repeat(3,1fr); }
.pcard {
  grid-row: span 5;
  display: grid;
  grid-template-rows: subgrid;   /* 借用外層的五列 */
}
@supports not (grid-template-rows: subgrid) {
  .pcard { display:flex; flex-direction:column; }
  .pcard header { min-height: 5.2em; }   /* 退回固定列高 */
}

灰粉 E9B4A4 不另開版，以柿紅網點半版套印取得，面積不得超過牌面 4%。套印公差 ±0.4mm；因為沒有勾邊，套不準就會直接被看見，所以白隙寬度不得小於 1.2mm。
