# 湧霞歌仔戲劇團 ENG-HE TAIWANESE OPERA TROUPE

宜蘭員山的外台歌仔戲班示範站。首頁不是形象頁，是一張**配腔桌**：七字仔唱詞先過台語**變調環**（句節內逐字變調、句節尾留本調），你再把六款腔（高平／中平／低平／上行／下行／促收）逐字安上去。引擎依「依字行腔」的規矩比對旋律輪廓與變調後聲調輪廓——安毋著，字就**倒**去：詩變死、買魚變賣魚、落山變落傘。配好按「開喙唱」，Web Audio 以母音腔韻把你的腔真的唱出來，再按「照聲調唸」對照，走鐘的字用耳空就抓得到。
