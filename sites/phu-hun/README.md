# 浮雲號熱氣球 PHÛ-HÛN BALLOONS

> 熱氣球載客飛行 × 茹伊印花布 Toile de Jouy（銅版單墨）

## 核心功能〈晨飛記事〉

規則三句：①機長講了一趟晨飛，分六句，每句的細節都刻在布上；②用雕版放大鏡在布上找，看到就點，每座島重複很多次、點哪一座都算；③六句都對上，就開給你下一個能飛的早晨的訂位單。約 40–90 秒一輪；可用鍵盤（方向鍵＋Enter）；每句有「找不到」會把放大鏡移過去。
