# 禮拜天電台 RADIO MINGGU

**產業**：移工社區電台兼月刊（桃園後站・2009 年起：每週日 08:00–22:00 網路直播、中文／印尼語／越南語／泰語／菲語輪流；後站廣場公開錄音攤；《四方 SIFANG》月刊每月夾一張四語海報；〈點播海報〉移工免費）
**風格**：古巴 OSPAAAL 團結海報（型錄「在地與文化視覺」〈古巴 OSPAAAL 絹印〉條目的**團結海報半身**，全館第 2 站；第 1 站 yagruma 是同條目的 ICAIC 電影海報半身——專色疊印與套準。兩站 mood、主色相、開場三者皆不同，合計已達同風格 2 站上限）

一週只播一天的電台。首頁就是剛從《四方》中間抽出來的那張夾頁海報：先看到摺成四分之一的背面，右半翻開、下半翻下，黃地上一株「收音機天線長成的稻穗」，外面三圈洋紅、紙白、草綠的回聲線，大大的「18」，底下同一句話用中文、印尼文、越南文、泰文排成等寬的四行。選你的語言，整站的四語塊都把它排到第一、放到最大——其他三種不會消失。

## 首創

1. **語言作為版面階層，而非翻譯開關**：全站每一個四語塊（標題、導覽、節目名、海報標語、表單選項）都同時顯示四種書寫系統；使用者選的主語言決定的是排序（`order:-1`）與字級（1em vs .46em），不是把其他語言藏起來。海報上的四語帶再以 `measureText` 求解成等寬方塊，`--fit` 以 cqi 表示所以與海報尺寸無關。
2. **夾頁海報二段展開**當首屏開場：摺成四分之一的背面先出現，`rotateY` 打開右半、`rotateX` 翻下下半；每一個面都是真的內容（背面是刊物頁、正面是海報本身的複本），不是色塊。
