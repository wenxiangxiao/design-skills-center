# 北窗豆腐 PAK-THANG TĀU-HŪ

**豆腐店 × 新擬物 Neumorphism／Soft UI**

雲林西螺延平老街的豆腐店（虛構）：1971 年林阿樹在舊碾米間的西牆上鑿了一扇窗，因為「豆腐要看光」；五十五年來，豆腐上的每一道影子都往右下落。2020 年孫女林語彤回來重做網站時只定了一條規矩——**全站一個光源，放在左上，誰都不准有自己的影子。**

## 頁面

| 檔案 | 內容 |
|---|---|
| `index.html` | 一整板剛壓好的板豆腐（WebGL2 高度場）：凹字店名、豆腐布紋、按下去會凹、放開會晃；今天的板、窗在左上、一個早上（真實時間亮燈） |
| `tofu.html` | 〈摸豆腐〉觸感辨識遊戲＋價目與取貨袋 |
| `window.html` | 天光盤（把窗搬走）、凸平凹六態、五十五年、新擬物五條規矩與可及性、窗底下的人 |
| `visit.html` | 營業時間、浮雕地圖、前一天預約取貨（帶入取貨袋與摸豆腐取貨號） |

## 核心功能〈摸豆腐〉

三句規則：按一下豆腐，看它怎麼晃（越嫩晃越久、陷越深）；替每一塊選一個名字；三盤九塊，對六塊以上豆干多送一片。五種材料（豆花／嫩豆腐／板豆腐／老豆腐／豆干）跑的是同一條阻尼波動方程，只有波速、彈性基底與阻尼不同。結果以 FNV-1a 產生取貨號，sessionStorage 帶到〈來店〉。

## 八維配方

- **industry**：豆腐店（西螺延平老街・磨豆、煮漿、點滷、壓板）
- **style**：新擬物 Neumorphism／Soft UI（Plyuto 2019-11 Dribbble → Malewicz 2019-12 命名推廣）
- **era**：2019–2021 介面潮流 × 1971–2026 老店
- **locale**：雲林西螺、延平老街、福興宮、濁水溪
- **voice**：老店家常口吻，句子短、講手感（「豆子會跟你講今天水多不多」）
- **texture**：豆漿米的單一材料、豆腐布經緯、木框壓痕
- **density**：低——間距給足，讓每一道影子有地方落
- **function**：〈摸豆腐〉觸感辨識測驗＋取貨袋＋預約
- **技術**：CSS 三角函數＋@property 單一光源（C）・WebGL2 高度場＋CPU 阻尼波動方程（A）・DeviceOrientation 傾斜當窗（D）

## 四種動效

1. **ambient**：光向跟著西螺真實時間走；豆腐板上雲影呼吸、偶爾一滴豆漿落下的漣漪。
2. **input**：拖燈鈕／天光盤／傾斜手機，全站每一道陰影同一幀轉向；按鍵＝外影換內影。
3. **transition**：沉板換頁——整頁攤平成一塊同色平面，新頁從平面長出來。
4. **signature**：豆腐面阻尼膜——按下去依硬度凹陷、放開依波動方程回彈晃動。

## 首創

**材料硬度阻尼膜（damped-membrane firmness）**：全館第一個以離散二維阻尼波動方程（含彈性基底項 k·h）模擬軟材料表面，並以 WebGL2 R16F 高度場依全站單一光源做新擬物著色（平面恰等於底色）的站；也是第一個以「材料硬度」作為遊戲判讀依據——同一條方程式只換三個係數，就分得出豆花、嫩豆腐、板豆腐、老豆腐與豆干。同時是全館第一個新擬物站，全站所有陰影、浮雕、凸面漸層由一個註冊過的 `--la` 角度以 CSS 三角函數推導。
