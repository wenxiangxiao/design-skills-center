# Ahwiaa Atumpan　阿威亞會話鼓行

迦納 Ashanti 區 Kwabre East，Kumasi–Mampong 公路 **Ahwiaa 村**（木雕村）的 atumpan 會話鼓作坊。
整段 tweneboa 挖空、duiker 羚羊皮以 ntweaban 木栓張緊，三個人，一年出不到四十對鼓。

網站以 **阿丁克拉印布 Adinkra**（迦納 Asante，Ntonso）的視覺語言製作——整個站就是一塊印好的布。

> 店家、人名、價目與電話皆為虛構示意。Ahwiaa（木雕村）與 Ntonso（阿丁克拉印布村）為 Kumasi–Mampong 公路上真實存在的地名。

## 技術（三項核心，分屬三層）

| 層 | 技術 | 它在本站承載什麼 |
|---|---|---|
| A 渲染 | **SVG 濾鏡鏈**（feTurbulence → feDisplacementMap → feMorphology → feColorMatrix/feComponentTransfer → feComposite） | 一沾四蓋的四個階段：墨擠出來、印被布紋推歪、刻痕只剩一半吃得到墨、布紋低處直接漏白。整站**沒有 canvas、沒有自寫渲染引擎、沒有一張點陣圖** |
| C 版面 | **CSS Grid subgrid** | 一把梳子拉過整塊布：巢狀容器共用最外層 12 條欄線，直梳線從刊頭穿到頁尾都對得上 |
| B 動效 | **CSS `steps()` 逐格動畫** | 四種動效全部。蓋印是離散事件，所以整站一個 `ease` 都沒有 |

附註（非核心）：Web Audio 即時合成兩個鼓音（零音檔，手勢啟動，取不到就走純視覺路徑）。

## 四種動效

| 種類 | 是什麼 |
|---|---|
| ambient 環境 | **乾**——每一排的第四壓在 26 秒內逐階退掉再回來，不需輸入、持續存在 |
| input 輸入 | **壓**——hover／focus 讓那一枚印記下沉一階（60ms，兩格） |
| transition 轉場 | **梳過**——每次頁面載入，一把十二齒的梳子由左至右把整塊布梳出來（`steps(12,jump-none)`） |
| signature 簽名 | **重沾**——點（或 Enter）任何一枚印記＝在那一格重新沾墨，整排從那裡重新排定墨級並逐格重壓。全館唯一 |

四種皆有 `prefers-reduced-motion` 降級，降級後資訊零損失。

## 首創

**以一條 SVG 濾鏡鏈作為全站唯一的圖像生成器，而該濾鏡的檔位是一個會耗盡、也可以被使用者補充的耗材存量。**

全館第一個刻意不做渲染引擎的站：沒有 canvas、沒有自寫繪圖引擎、沒有一張點陣圖。所有圖像（店面布、十二枚印記、logo、favicon、鼓語的高低譜、使用者的布條）都是同一組純幾何 `<path>` 經同一條四級濾鏡鏈的不同輸出，而決定用第幾級的唯一變數是「這一次蓋下去還剩多少墨」。因此**同一枚符號在站上永遠不會出現兩次一樣的樣子，重複在本站不是複製而是消耗**；而墨是使用者可以當場在任何一格補充的全站資源。

與 `squeak`（氣球扭結的充氣長度）的差別：那是單一 func 之內的消耗性資源與失效模式；本站的耗材是**全站每一張圖的渲染參數**，與 func 無關，在四個頁面的每一枚印記上都成立。
