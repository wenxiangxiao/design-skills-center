## 核心功能：湊窗（押韻對句填空）

三句話講得完、九十秒玩得完，沒有模擬引擎、沒有量表、沒有一根滑桿：

1. 六格圖刻好了，下句還沒——每格從詞牌挑一句。
2. 要押上句的韻，要說中那格畫的事。
3. 前四格至少兩句帶刺、末格收在口令，天亮前刻得完就上窗。

四條驗收：**押韻**（下句末字與上句同韻部；六格六個不同韻）、**對題**（說中那格畫的事）、**結構**（前四格 ≥2 句「譏」、末格必為「喊」）、**工時**（一字兩分，總額 170 分＝85 字）。

窮舉全部 5⁶ ＝ **15,625** 種組合實測：押韻與對題兩關都過的 **648** 種（4.1%）、再過結構的 **306** 種、真正刻得出來的 **181** 種（1.16%）。可行解的字數落在 78–90 字，額度 85 字——所以最後擋人的不是韻，是刀。老曹自己那面第一三八號用了 84 字／168 分，剩兩分鐘洗刷子。

通過後產出一份**刻版工單**（逐句字數與刻版分鐘、剩餘時間）、老曹的三到五句話（不給分數、不給星等、不排名）、一枚由六個選擇決定的版記，以及可分享還原的 `?w=` 六位碼。按「貼到鐵門」後首頁那面窗就換成你刻的第一三九號（`localStorage` 跨頁生效），可以再撕下來換回老曹的。

**功能就是這個流派本身**：玩它的過程等於在生產一面 ROSTA 窗——押韻的對句、帶刺的前段、收尾的口令、以及那個永遠不夠用的刻版時間。

## 認領的首創

**減法製程約束作為全站渲染律，且格律是唯一的驗收條件。**

1. 全館第一個把「這個東西做不出來」寫成一支**會實際刪除幾何**的濾鏡並讓它定義風格的站：`feMorphology erode(r) → dilate(r)` 形態學開運算，任何寬度小於 2r 的墨或紙橋都會被永久刪掉。刻版檢查台可以把刀口從 0 加到 4，親眼看見一張圖的細節被製程一層層吃掉直到只剩剪影。與 `shaft-eight` 織法引擎、`foldpoint` 剛性摺疊、`rendong` 分版施工圖的差別：那些是**產生**形的引擎，本站的規則是**消滅**形的——它不畫任何東西，它只否決。全部 119 個圖元在建置階段跑過同一支開運算驗收（0 件消失、平均面積損失 2.19%）。
2. 全館第一個以**格律**（押韻＋語氣結構）作為核心互動唯一驗收條件的站。與 `xiding-mediation`「對話作為互動範式」的差別：那裡使用者說的話會改變兩造的情緒狀態，判準是關係；本站沒有對象、沒有狀態、沒有隱藏真值，判準純粹是形式——韻部對不對、刺夠不夠、收不收得住、刻不刻得完。
