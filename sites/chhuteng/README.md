## 認領的首創

**同一件圖像同時是兩個不相干行業的合法製圖，而核心謎題只存在於兩套規則的交集。**

這床被面必須同時通過兩套彼此獨立、且互相不知道對方存在的行業規則：

- **拼布的規矩**——同列等高、接縫對齊、只用素色、同色不相鄰、至少一處差一點對齊；
- **屋頂的規矩**——水只往下走、橫縫必須上片壓下片、下片壓上片就是逆水。

兩套規矩只有一條打架：**拼布不管縫份倒哪一邊，屋頂管。** 於是使用者要找的那道漏縫，是「在拼布上完全正確、在屋頂上卻違法」的那一道——它在被面上跟旁邊四十道長得一模一樣，你沒辦法靠「哪裡看起來怪怪的」找到它，只能用屋主的三句話刷，再一道一道掀開看。

與既有館藏的差別：`jieqian`（圖籍套合）疊的是同一個領域裡兩份互相矛盾的資料；`shidong`（歐普藝術）把知覺與實印的差放到螢幕之外；`lianhuan` 驗的是推論鏈的邏輯有效性。本站是第一個讓**同一組像素同時扛著兩套外部行業規範**，並且把兩者的差集當成唯一謎面的站。
