曼真照相館　MAN CHAN PHOTO STUDIO　—　工序　擦筆水彩與顏料耐光

三工序擦筆水彩・顏料耐光一掛年本年月份牌與館況二上色房罩染六稿・四條老規矩四相簿與委託廿四件舊件・委託單

三　工序

擦筆水彩不是「幫黑白照上色」。順序是反的：先用炭精粉把整張的明暗擦出來——那一步就把立體做完了——顏色才罩上去。 所以這一行的老話是「擦七分，罩三分」。也因為這樣，同一張稿可以換三次顏色，形一點都不會動。

五道工序

1
放大　底片上放大機，投到塗過膠的厚紙上顯影。十二寸以上一律用一九六二年那支鏡頭，因為它的暈邊是我們要的。
2
擦底　炭精粉裝在小碟裡，用羊毫或棉花團從最暗的地方開始揉。這一步決定整張畫的造形，通常佔七成工時。擦壞了只能重放一張。
3
描形　極淡的墨線勾出邊界——不是輪廓線，是給罩染用的界。這條線在成品上幾乎看不見，但它決定水會停在哪裡。
4
罩染　透明水彩一層一層罩上去，每層乾透才上下一層。邊緣會留下一圈較深的乾涸線——那是水痕，不是失誤，不准修掉。
5
提亮與裱邊　白粉點在最亮處（眼角、扇緣、瓷器高光），最後上下軋銅邊、上緣打兩個掛環。這時它才從一張畫變成一張月份牌。

本風格的五個不可省略特徵

拿掉其中任何一項，畫面就不再是月份牌。下面每一項都附一段可以直接抄走的做法；完整版在 SKILL.md。

一　擦筆炭底承擔全部造形

左邊那張沒有一滴顏色，但形、光、體積全在。這是本風格與所有平塗色塊風格的分野：顏色被抽掉之後，畫仍然完整。 做法是每一個色域底下先鋪一層連續明暗（放射漸層），再統一套一層炭粉顆粒。

.region{fill:url(#ground)}   /* 炭底：造形在這裡 */
<radialGradient id="ground" cx=".34" cy=".3" r=".85">
  <stop offset="0"   stop-color="#F0EAE2"/>
  <stop offset=".55" stop-color="#F0EAE2" stop-opacity=".55"/>
  <stop offset="1"   stop-color="#4A3E36"/>
</radialGradient>
/* 炭粉顆粒：整組炭底套一次即可 */
<filter id="grain">
  <feTurbulence type="fractalNoise" baseFrequency=".82" numOctaves="3" seed="17" result="n"/>
  <feColorMatrix in="n" type="saturate" values="0" result="ns"/>
  <feComponentTransfer in="ns" result="na"><feFuncA type="linear" slope=".30"/></feComponentTransfer>
  <feComposite in="na" in2="SourceGraphic" operator="in" result="grit"/>
  <feBlend in="SourceGraphic" in2="grit" mode="multiply"/>
</filter>

二　透明罩染與水痕邊

顏色一律 mix-blend-mode:multiply 疊乘上去，飽和度上不去是它的本性——不要用平塗色去追。 每一個色域的邊緣必須有一圈比自己深的線，那是水彩乾涸時顏料被推到邊上的結果。沒有這圈線，罩染就變成了填色。

.glaze{mix-blend-mode:multiply}
/* 同一條路徑：先罩色，再描一圈深 38% 的水痕 */
<path d="…" fill="#C2465E" opacity=".60"/>
<path d="…" fill="none" stroke="#782B3A" stroke-width="1.7" opacity=".55"/>
/* 層數＝不透明度階：1 層 .30、2 層 .60、3 層 .90（第三層會蓋死炭底） */

禁用：圓角、模糊陰影、任何一塊沒有明暗變化的平色。本風格沒有「填色」這個動作。

沒有日曆的不是月份牌，是海報。曆格必須雙軌：陽曆用拉丁數字（襯線、高對比），農曆與節氣用中文小字排在下面。 它不是裝飾，是這張紙被留在牆上一整年的理由。節氣那一格轉紅，星期日轉紅，今天那一格用手畫的朱圈框起來——圈是歪的，因為是人畫的。

.cell.today::after{ content:"";position:absolute;inset:2px;

四　直排吉語與縦中横

一年三百六十日

留得容光在紙間

民國115年　第91張

畫的兩側各垂一條直排吉語，四字或七言，一條暖一條冷。中間夾著的數字必須「縦中横」——兩三位數轉正、擠成一個字格， 這是中文直排的本體規則，不是效果。text-combine-upright 現況：Chrome/Edge 48+、Firefox 48+、Safari 15.4+，全球約 96.7%（caniuse，2026-08 查）。 不支援時數字會轉倒，故本站只用 all（不用支援度較差的 digits），並把它限定在兩三位數的短跨度上。

.bless{ writing-mode:vertical-rl; text-orientation:upright;
  letter-spacing:.30em; font-weight:900; }
.tcy{ text-combine-upright:all; -webkit-text-combine:horizontal; }
<p class="bless">民國<span class="tcy">115</span>年</p>

五　銅軋邊與掛環

上下各一條銅軋邊
上緣兩個掛環
右下一個受潮的捲角

它是一張要被掛一年的實體，不是一個版面。上下兩條銅軋邊（6–13px）把紙夾住，上緣打兩個掛環，右下角因為受潮而微微捲起。 少了這三件，它就只是一張圖片；有了，它才是一件掛在牆上、會老、會被摸髒的東西。

.poster::before,.poster::after{ content:""; position:absolute;
  left:0; right:0; height:13px;
  background:linear-gradient(#F6E9BE,#D9B75E 38%,#8A6A22 54%,
                             #E3C778 74%,#8F6F27); }
.rings span{ width:19px;height:19px;border-radius:50%;
  border:3.5px solid #A8842E; background:transparent; }
.curl{ background:linear-gradient(225deg,#E4D3B6,#D3BE9A 42%,transparent 43%);
  clip-path:polygon(100% 0,100% 100%,0 100%); }

顏料耐光　為什麼洋紅先走

石印一張月份牌至少四塊版。四塊版用的不是同一類顏料，耐光度差得很遠： 有機染料系的洋紅與粉桃在紫外線下最先分解，藤黃次之，礦物性的花青與石綠穩得多，炭黑幾乎不動——它本來就是碳。

後果是一張月份牌不會「整張變淡」，它會偏色：掛滿一年的美人先失去唇與衣的紅，再失去金，最後剩下一張青灰調子的畫與一整套完好的炭底。 本站首頁那把竹尺就是拿來看這件事的；上色房交件時附的〈三年後〉也是同一支算式。
