## 認領的首創

**單調不可逆的日曆分割（calendar-monotone irreversible subdivision）**

全館第一個站，其版面的分割數只會隨真實日期增加，永不減少、永不重排。每一條裂都有一個到達日（建置階段寫進靜態 SVG 的 `data-k`），今天看到的網是昨天的網加上今天新到的那幾條；**所有訪客在同一天看到同一張網**。裂多一條，釉域就多一塊、每一塊就小一點，**今天放得下幾件事因此是裂決定的**——今天放得下 10 件，「週一」那一件已經沒有夠大的釉域，只好待在下面那張表上。

與既有館藏最需辨明：

- `jiemian`（皂膜干涉）是**泡沫粗化**——胞會合併、數量遞減、沒有穩定終態；本站是單調細分，胞只會變多，而且有一個算得出來的上限與日期。
- `zook-hollow`（阿米希蜂場）的進度存在瀏覽器裡、逐訪客各自累積；本站不存任何東西，它只是知道今天是哪一天。
- `kimtsun` 依當下時刻重算潮位，是天文週期的往復；本站是單向老化，回不去。

併同「兩族裂紋只以 T 字終止、永不交叉」作為全站唯一的圖像法則：一條新的裂只在一個既有釉域的內部成長，兩端落在該釉域的邊界上，而邊界只由器緣與既有的裂組成——所以 T 字是構造保證的，不是靠自律。建置階段以幾何實測覆核，全站 X 形交叉數為 0。

## 五個不可省略的視覺特徵（規格見 `SKILL.md`）

1. **金絲鐵線**：兩族裂、只以 T 字終止、永不交叉；顏色只有兩級（十年以上鐵線 1.15px／十年以內金絲 0.6px），沒有中間調。
2. **釉的明暗只由釉厚決定**，且只能是硬停點的等厚帶——任何一段兩端異色的漸層即違規。樣式表只宣告五個色碼，其餘全部用相對顏色語法推導。
3. **紫口鐵足**：每一件器都要在某處露出胎（口沿一道紫褐、圈足一圈無釉）。導覽就是這件事做的——現用頁那個部位的釉被磨開，露出胎。
4. **形只有旋轉體的側影＋拉坯旋紋**：所有輪廓都是一條側影與它的鏡射（Catmull-Rom 取樣的曲線，不是折線），下半必有不等距的水平旋紋。
5. **棕眼**：釉面必有針尖大的小孔，而且不騎在裂上（程式驗過：每個孔離最近的裂 ≥ 5.2 單位）。
