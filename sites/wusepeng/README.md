**風格**：墨西哥剪紙旗 Papel Picado（型錄「在地與文化視覺」類，全館第 1 站）

雲林北港的一家外燴辦桌（虛構）。一個鼎、一組六米乘十二米的紅白帆布棚、最多做到四十八桌。
棚頂那一串五色紙旗是煌師的姑婆蔡罔市剪的：四十八張薄棉紙疊起來、對摺兩次，鑿刀落一次，四十八面一起穿。

這個站賣的不是辦桌，是那一串紙旗的規格書。

## 認領的首創

**一疊，不是一張（stack-not-copy）**——全館第一個站，其重複出現的元件不是複本，而是**同一次鑿刻的第 n 張**。

papel picado 一次鑿四十到五十張，所以同一串上的每一面旗都是同一刀的不同張。本站據此立三條規則：

1. **全站禁用 SVG `<use>` 與任何圖形複製**。每一個「同一個」圖示都由同一份鑿刀序列在第 n 張紙上重新求解，
   `n` 決定刀的鈍度（頂點抖動量 `0.16+1.05·blunt`）、疊紙位移（`(n-1)·0.052` 單位）與破角機率（`0.02+0.30·blunt`）。
2. **這一疊是有限的**：48 張。每在「趕桌」收一次單就用掉一張，頁面上的計數是真的在減少（`sessionStorage` 跨頁）。
3. **用完要再疊一疊新紙**，那時候整站換色序、換刀痕種子——「複製一個元件」在本站是有成本、有庫存、會用完、
   而且每一份都不一樣的事。

與既有首創的差別：`rendong`「無邊界的產出物」談的是成品沒有邊，本站談的是複本不是複本；
`wuyi-cang`「編號作為稀缺資源」消耗的是文件自己的序號，本站消耗的是全站圖像共用的那一疊空白紙；
`nayachand`「質量作為互動貨幣」的後果是容器姿態，本站的後果是每一個元件長什麼樣子。

## 動效預算（四種）

1. **ambient**：三個不同頻率正弦疊加出來的風，沒有輸入也一直在吹。
2. **input-driven**：游標 x 位置或裝置傾角即時決定風向，同幀寫入（<16 ms）。
3. **transition**：換頁是一道斜向 `clip-path` wipe（風掀過去），250 ms，不是淡入。
4. **signature**：順紙橋傳裂（見上）。

四種都有 `prefers-reduced-motion` 降級且資訊零損失：風停、不自動撕、不做 wipe，
但「吹這一面」照樣可按、結果照樣以文字顯示，遊戲改用 60 ms 計時器推進。

## 核心功能：趕桌

一個鼎，十二道菜，三十六桌。規則三句：

1. 菜在鼎裡煮好才出得去，早按一次罰半秒。
2. 起鍋之後只熱那幾秒，過了就是冷的。
3. 十二道走完收單，看的是幾道燒、幾道生、幾道冷。

實測：全部準時 **49.9 秒**；完全不按（全部放到冷）**103.4 秒**。收單給一張菜尾單、煌師的一句話，
以及一面用同一支鑿刀引擎鏤空排出成績碼（`S12` / `R0C0`）的旗——那面旗就是這一疊的第 n 張。
