Code 002・本場色碼規範

牌面不載文字

民國七十八年落成時，本場的標示由郭東和訂定。當時場內夜間照度不足、地面油汙、且相當比例的使用者不讀中文標示，因此他把全部標示改成一套四段、五色的色碼，貼在每一格的牌面上。三十七年來只修訂過兩次（一〇二年增列「低樑」、一〇六年換裝照明後把第三段的步數級距各往上調兩步）。

這一面是它的背面。本場所有牌面上不寫的東西，都寫在這裡。

Five Rules

一、編號取代名稱

本場每一件東西都有編號，編號一律排得比名稱大、比名稱前。多數情況下只有編號沒有名稱。

二、牌面不寫它是什麼

說明退到背面。定址與導覽靠色碼，不靠字。這一條造成的所有誤會，本場都不負責。

三、圖是借來的

本場不畫插圖。牆上與各頁上唯一的圖，是本場自己量到的數字被畫成的線，原樣掛上，不加座標軸、不加圖例、不加說明。

四、格線不可協商

全場文件共用同一副十二欄格線，字級只有三階。沒有斜體、沒有花字、沒有第二種強調方式。

五、裝飾只能從工地來

四十五度危險斜紋、反光釘、地面標線、分區色塊。裝飾不得從印刷品上來。

只出現在第四段：消防栓前。其餘三段永不用黑，黑是段與段之間的縫。

同一個顏色在不同段是不同的意思。這是本規範最常被抱怨的地方，郭東和的答覆是：「一格只有一面牌，牌只有這麼大。」

Decoder・解碼器

四段，點四下

依序點選四段的顏色，本器讀出它是哪一類格，並列出本期符合的標的。這是〈048 標售〉那一面的隨身版。

Grid

十二欄

整站的欄線印在底下，隨時看得見。每一個版塊都掛在同一副欄線上，包含這一段字。這條規則的實作是 CSS subgrid：巢狀的版塊不自己排欄，它借用整頁的欄。

字級三階　11 / 15 / 132

Type

三階，兩種字

拉丁字一律 Archivo，標籤全大寫、字距 .24em；漢字一律思源黑體。標題不加粗到九百以外的字重，正文不用第二種顏色。

唯一的例外是那張借來的圖底下那一行——它用一種不屬於這裡的襯線斜體，因為那一行不是本場寫的。
