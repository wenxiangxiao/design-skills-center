## 品牌設定

臺中市大甲區順天路 267 號〔門牌虛構〕，鎮瀾宮往東走五分鐘。

- **王阿蕊**（1911–1994）十二歲在苑裡學編三角藺，帽子給大甲的帽蓆商收去裝船；1936 年在順天路自己開店收帽。
- **王清松**（1939–2016）1968 年買下一套大阪來的木頭帽楦（四十二個頭圍）與一台蒸氣機，開始做毛氈帽。
- **王映如**（1987–）2014 年在舊金山看到 Matisse〈Femme au chapeau〉（1905），2017 年接手，把毛氈泡進九個染鍋：只用不調和的純色，陰影染成對面的顏色。

真實背景：日治時期「大甲帽」（苑裡、大甲一帶三角藺編帽，經大甲商行外銷，1936 年前後最盛）、大甲鎮瀾宮、鐵砧山、大甲溪；1905 年巴黎秋季沙龍第七室與 Louis Vauxcelles 在《Gil Blas》（1905-10-17）的「Donatello chez les fauves」。其餘人物、門牌、電話、價格皆虛構。
