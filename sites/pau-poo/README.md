## 首創

**揉裂即簽名的雙角色禮物網址（crumple-crackle gift link）**：送禮人在布上揉的位置（每處量化到 1/1295）寫進 `?g=`，每處裂紋由「座標決定的亂數」生成，所以收禮人打開同一個網址時，看到的是送禮人親手揉出的同一組裂紋重新長一次；同一頁對送禮人是包裝台、對收禮人是一個必須親手拉開兩隻布耳才會攤開的布包。

## 技術

1. **OffscreenCanvas＋Worker**：攤開的那一匹布在 Worker 裡畫（底版快取＋已乾裂紋層＋生長中裂紋），主執行緒只送揉布座標；不支援時同一份 `WAX` 原始碼在主執行緒跑。
2. **View Transitions API**：跨頁 `@view-transition{navigation:auto}`——舊頁往右摺走、新頁從左攤開；同頁換布時紙標與布面以 `startViewTransition` 換。不支援時直接換（同頁另有 WAAPI clip-path 攤布）。
3. **程序化圖樣生成**：八種母題以 half-drop 重複、靛版／兩個色版各自錯位、獨立 blotch 色塊；裂紋網以佔用格生長、碰到別條就停。
