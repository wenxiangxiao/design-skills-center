## 這是什麼

一座 1969 年開業的小工廠，做的東西只有兩類：轉起來會讓眼球不自主追視的**視動鼓**，
以及一動不動、卻會在你眼睛裡動起來的**知覺訓練圖版**。買主是醫院的視能訓練室、
大學的知覺心理學實驗室、特教資源班，還有設計系的色彩與構成課。

這個產業和歐普藝術是同一件事的兩面：歐普藝術家在畫廊裡做的，正是這家工廠在做的——
用平塗的黑白硬邊，讓靜止的表面在觀看者的視覺系統裡動起來。差別只在一邊叫作品、一邊叫教具。

## 核心功能：六板試板

規則三句話：**六塊板，一塊一題。看著它，照實回答你看到什麼。答完換一張你自己的圖版帶走。**

| 板 | 圖版 | 機制 | 你要做的事 |
|---|---|---|---|
| 一 | 赫曼方格 | 側抑制 | 回答板上實際印了幾顆灰點（答案是零） |
| 二 | 咖啡牆 | 邊界位移 | 拖一根真的直尺去比對那幾條磚縫是不是平行 |
| 三 | 同時對比 | 明度恆常 | 把紙底上的灰調到「看起來」和墨底上那塊一樣，系統再告訴你實際差幾階 |
| 四 | 漂移橫紋 | 方向選擇性適應 | 盯住藍點八秒，然後回答靜止的板往哪邊漂 |
| 五 | 明度階梯 | 邊界對比 | 判斷每一階是不是均勻的，可用白條遮住接縫當場自證 |
| 六 | 單元造形場 | 圖地組織 | 說出你先看到黑菱形還是白菱形——這題沒有正解 |

結果單不給分數、不排名，只逐題列出你答的是「看到的」還是「板上印的」，
並依作答決定性地算出一張專屬圖版（場函數由答錯的機制決定、k 由答對數決定、a 由同時對比的偏差決定），
發一個可以直接報給工廠訂 A2 實體板的板號。

## 版面配方

- **opening**：`drum-first` 視動鼓直開場 — 首屏是一台正在轉的視動鼓與它的讀數，沒有大標、沒有標語、沒有按鈕組
- **nav**：`reversal-cell` 圖地反轉格 — 四個單元造形方格，現用頁那一格整格黑白對調
- **illust**：`unit-modulation` 單元調變場 — 全站沒有一張描外形的插圖，所有圖像都是同一支場引擎的輸出
- **mood**：`mono-ink` 消色差墨階 — 墨 `#101014` / 地 `#F2F1EC` 各約 45%，中灰 7%，群青 `#2233E0` ≤3% 只給量測工具
- **signature**：**反轉波前** — 全站沒有任何一個「高亮」；每一個 hover／選中／現用態都是整塊黑白對調，並由一條硬邊波前掃過
- **tech**：CSS scroll-driven animations（B 層）／CSS `mask-image` 與 SVG `<mask>`（A 層）／`ResizeObserver`（D 層）

## 首創（`_first_registry`）

**把觀看者的視網膜當成輸出媒介**：全館第一個站，它的核心功能所產出的東西不顯示在螢幕上——
運動後效的漂移、赫曼方格的灰點、馬赫帶的亮暗帶，全部只存在於使用者自己的視覺系統裡；
頁面唯一的工作是先讓它發生，再證明它剛才發生了（白條一遮，馬赫帶就消失；直尺一放，楔形就變回平行）。
與既有的模擬引擎、量測台、逆問題、對抗賽局皆不同：本站沒有任何隱藏真值、沒有需要求解的系統，
被量的是使用者的知覺與板上實際印的東西之間的差。

## 技術與相容性

三項技術分屬三層，各自承載一個不可省略的視覺特徵，完整查證與 fallback 見 `SKILL.md` 第十二章。

| 層 | 技術 | 承載 | 支援現況（2026-08-09 查證） |
|---|---|---|---|
| B 時間軸 | CSS scroll-driven animations | 莫列上層角度＝讀者的捲動位置 | Limited availability；Chrome/Edge 115+、Safari 26+、Firefox 未支援。`@supports` 包起來，不支援即靜態莫列 |
| A 渲染 | CSS `mask-image` / SVG `<mask>` | 反轉波前 + knockout 大字 | Baseline 2023。不支援即直接切換 `background`/`color`，狀態語意不變 |
| D 感測 | `ResizeObserver` | 整數格、圖案必被四邊切斷 | Baseline widely available（2020-07 起）。不支援即退回 `resize` 事件 |

四種動效：**ambient**（全站莫列下層以一個條紋週期無限橫移、首屏視動鼓 CSS 3D 旋轉）、**input-driven**（游標即場的形變中心，rAF 節流 <100ms）、**transition**（`clip-path` 對角推移 `steps(6)`）、**signature**（反轉波前）。四種皆有 `prefers-reduced-motion` 降級且資訊零損失。

單頁 29.3–46.3 KB、首屏 JS <10 ms、鼓與莫列皆為 GPU 合成的 `transform`。零外部圖片與音檔，外部資源僅 Google Fonts（Archivo、Noto Sans TC）。
