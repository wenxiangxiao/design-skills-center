- 彰化縣芳苑鄉王功村漁港路 77 號（門牌虛構）・(04) 893-1958・週二至週日 08:00–17:30・週一休
- 週六 14:00 一筆課 NT$900

## 技術

1. **SVG feTurbulence＋feDisplacementMap**：白灰牆質地、乾後蛋彩毛邊、換頁灰水鬃毛邊。
2. **Pointer Events pressure＋getCoalescedEvents**：畫板的筆壓（觸控筆）與速度換算筆壓（滑鼠／手指）。
3. **@starting-style＋transition-behavior: allow-discrete**：紙畫與結果單的 `<dialog>` 進退場。

## 首創

**筆壓即形、筆壓即時**（stroke-as-pressure-timeline）：全館第一個把一種民間畫派的「筆」本身寫成資料的站——每一筆＝中心線×寬度曲線 w(t)，四種筆就是四條 w(t)（梳 `(1-t)^1.25`、籽 `sin(tπ/2)^1.7`、核、雙色）。同一支引擎三用：建置期烘成無 JS 也看得到的靜態 SVG；瀏覽器裡讓全站每一張圖逐筆重長，而且**生長速度曲線由筆壓曲線推來**（籽筆越收越重所以減速、梳筆一甩所以加速）；〈描一條花帶〉則反過來，用使用者那一筆「每點寬度 vs 走到第幾成」的 Pearson 相關係數判斷他畫的是哪一種筆。與 amkongtsiau（一筆＋筆壓落差與覆蓋率驗收、拆成專色版）的差別：本站判的是筆型分類，且全站插畫都是同一套筆的重播。附帶：全館第一個以「重刷一層白灰」（三道 feDisplacementMap 鬃毛邊灰水）做換頁的站，與第一個以「花畫完沒」標記現用頁的導覽。
