## 核心技術

1. 原生 WebGL2 片段著色器（`#version 300 es`，無函式庫）：RGB→CMYK 分色（部分 GCR）、四網角 AM 網點、網點擴大、套準誤差、方形數紗鏡同源取樣；不支援時 Canvas 2D CPU 同算式靜態備援
2. `position: sticky` ＋ scroll-linked（非劫持）倍率：首屏 320vh 捲動把倍率從 9× 連續退到 1×，網點尺寸與影像同步縮放
3. 約束規則引擎（硬條件過濾＋軟偏好計分）：週六對打配對，每一個決定都逐條寫出

## 首創

**即時 CMYK 調幅分色網屏＋同源數紗鏡（live AM CMYK separation with same-source loupe）**：全館第一個把「四色網點印刷」本身做成渲染管線的站。圖像以連續調在離屏 Canvas 繪成，但畫面上從不出現未分色的影像；著色器每一格先把該網格中心取樣分色成 C/M/Y/K，再依各版網角（15°／75°／0°／45°）畫出面積等於階調的圓點，在新聞紙色上相乘疊印，自然生成玫瑰紋；方形數紗鏡在同一次繪製中把局部座標除以倍率重新取樣，所以放大看到的是「同一張印刷品」的網點，而不是另一張圖。進版打樣以 Y→M→C→K 讓各版從送紙方向滑入並對準。
