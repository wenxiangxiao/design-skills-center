# 稜記製冰　Lêng-kì Ice Works

**產業**：製冰廠／冰塊行（角冰、稜冰、碎冰；供漁市、酒吧、辦桌）
**風格**：捷克立體主義 Czech Cubism（布拉格，1911–1914；既有流派，非自創）

一支冰要 26 小時才凍得成，切開它只要 45 秒。稜記賣的不是冰，是把一塊 26.41 公斤的水切成客人要的形狀——
崁仔頂要重量、酒吧要角度、辦桌要一塊立得住的座。同一支冰，三張單子，三種切法，而出冰率最高的那一張最不值錢。

## 認領的首創

**使用者的切割動作生成新的幾何面，而那個面的顏色由它自己的法線當場算出**
（*cut-generated facets that author their own shading*）。

程式在下刀之後只寫下一個數字——新斷面的法線角度；深淺由瀏覽器以 `cos()` 計算、以 `round()` 壓成三階。
沒有色表、沒有查找、沒有預先指定。與既有各站的差別：`shunchang`（斜光掃掠）與 `zhencai`（換燈演色）
重算的是**光**，幾何不動；`baicaochun`（熔字重排）與 `rendong`（翻版遷位）重算的是**排版與平鋪**，顏色不動；
`nayachand`（載重壓吊）重算的是**容器姿態**。本站是幾何被使用者當場「加出來」，而新幾何自己決定自己的外觀。

## 動效四式

1. **ambient**：窖霜結晶（22s 循環，六簇小稜晶各自生滅）
2. **input**：開面（hover／focus 時面真的沿稜線折出 8°，90ms）
3. **transition**：折頁 fold-turn（進頁時整頁沿斜軸展平，560ms）
4. **signature**：落刀生面 cleave-facet（兩半沿刀的法線推開再回位，切口鎘黃線 flash）

四式皆備 `prefers-reduced-motion` 降級，降級後資訊零損失。
