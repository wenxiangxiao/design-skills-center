怎麼讀這串數字

01 / 每個數字

是一次拋的高度

數字＝那顆球要在空中待幾拍。3 是最順的基本拋、5 拋得比較高、1 是快速橫遞、2 是拿著不動、0 是空手一拍。

02 / 奇偶

決定過不過手

偶數（2、4、6…）丟回同一隻手，奇數（1、3、5…）飛到對手。所以 3 會交叉、4 是兩手各丟各的噴泉。

03 / 平均

就是球的數量

把整串加起來除以長度＝幾顆球。531 平均是 3，所以是三顆球的花式；97531 平均 5，得練到五顆才丟得動。

合法性檢查

不是隨便一串數字都丟得起來。

如果兩顆球會在同一拍落進同一隻手，那就是撞球、丟不成。我們的引擎把每一拍的落點算出來，只要出現兩顆球搶同一拍，就當場擋下並指出是哪兩拍打架——這也是為什麼 521 看起來像 531 卻不合法。

試試上面輸入 521、54、423、744，看引擎怎麼判。

落點雙射定理

一串長度 n 的記譜合法 ⟺ 第 i 拍的球落在第 (i＋該拍數字) mod n 拍，而這 n 個落點互不相同（是個一對一的重排）。

滿足時，整串的平均自動是整數——那就是你要準備的球數。

531 → 落點 {2,1,0} ✓　521 → 落點 {2,0,0} ✗
