## 首創

**退回原稿 pull-back ＋ 對話框求解雙聯往返**：全館第一個把「單格放大」這個流派的核心動作本身做成捲動時間軸的站——首屏的放大格以 scroll-driven 動畫退回整頁原稿，網點用 `userSpaceOnUse` pattern 跟著縮放，所以網點從可數回到一公釐是真實的幾何而非換圖；也是全館第一個以 CJK 對話框幾何求解器（避頭標點斷行→最小外接橢圓→尾巴找嘴點）排字、並把整格序列化進網址讓對方回一格組成雙聯的站。
