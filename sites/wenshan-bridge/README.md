# 文山大學橋藝社 WENSHAN UNIVERSITY CONTRACT BRIDGE CLUB

> 大學社團（橋藝社） × 牌例圖版風 Hand-Diagram Plate ｜ 繁體中文示範站

一個大學橋藝社的社網，而首頁不是形象頁，是一張**已經發好牌、正等你出聲的牌桌**。你坐南，只看得到自己的十三張；搭檔的牌你看不到，他的牌力與牌型你只能從他說的話裡推。整站的核心互動是橋牌的**叫牌**——一條只有三十六個字、**單調遞增**（每句必須比上一句高）、而且**與對手共用**（他們全程聽得見）的通訊頻道。

畫面右側兩條「推論帶」是這個站的主角：上排是**搭檔此刻認為你手上有什麼**（點力區間與四門張數區間），下排是**你從他的叫品推出他有什麼**。每多一句叫品，帶子往內夾一次（區間取交集，只會變窄）；白色刻度是真值，帶子沒夾住刻度就是誤會已經發生。叫完之後把定約打完（跟牌規則由引擎強制），結算把成績拆成三段歸因：**溝通**（搭檔對你的五項認知中了幾項）、**定約落點**（你們停的定約 vs 引擎試打出來的最佳定約差幾分）、**打牌**（同一副牌同一定約交給引擎打，它拿幾墩，你拿幾墩）。

- **opening**：hand-first 手牌直開場（新原型）——首屏即已發好的一副牌與正在等你出聲的叫牌盒，沒有標語、沒有形象照
- **nav**：seat-box dock 席次方位盤導覽（新原型）——左下角一枚 N/E/S/W 方位盤，四家各守一頁，現用頁為反白的那一家
- **signature**：inference-narrowing 推論區間夾緊——每說一句話，雙向推論帶就往內夾一次（區間只會變窄），白刻度標真值，夾不住即紅色
- **illust**：hand-diagram plate 牌例圖版構成（新技法）——全站每一張圖（牌例室 64 張縮圖、結算圖版、社籍卡卡面、logo、favicon）都是同一支發牌引擎的輸出，沒有一張是描的

- **func**：不完全資訊搭檔賽局（叫牌 → 定約 → 打牌 → 三段歸因結算）
- **era/locale/voice/texture/density**：當代（社團承襲自 1968 年）／台灣本土（大學社團）／幽默嘴砲（學長口氣的講義）／紙感牌卡×織物檯呢／極密（資訊轟炸：牌、梯、帶、表同屏）
