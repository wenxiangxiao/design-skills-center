# 照葉扇舖 TERIHA — 京扇子絵付け工房 × 琳派 Rinpa

京都市中京區二条通寺町東入、扇の絵付けと仕立てを商う一軒。金箔を貼った扇面に岩繪具で絵を置き、**溜込（たらしこみ）**——先の色が乾ききらぬうちに次の色を落として滲ませる技法——で輪郭線を使わずに形を出す。

網站そのものが一枚の金地である。全ページの地は 108px 角の金箔タイル（一枚ごとに色が違い、継ぎ目＝箔足が消してない）で、26 秒周期の反射帯がその上を移動する。

## 認領した首創

**乾きを不可逆な資源とする——媒材の状態そのものが時計であり、作品の幾何はいつ押したかの記録である。**

全館で初めて、創作の入力が形でも圧力でも位置でも重量でも順序でもなく、**時刻**である站。しかもその時刻は「当たり／外れ」で判定されるのではなく、**そのまま画面の幾何になる**——同じ一滴が潤み 0.86 で落ちれば径 52 の雲になり、0.30 で落ちれば硬い縁の点になる。どちらも扇として成立する。紙は、いつ落としたかを覚えてゐるだけである。

乾きは不可逆で、待ってはくれず、やり直しもきかない（新しい紙になる）。

- **けん玉の「接けるか否か」**との差：あれは時機の合否判定で、玉の形は変わらない。本站は合否がなく、時刻が形そのものを書く。
- **amkongtsiau（一つの手勢が全部を決める）**との差：あちらの入力は形と筆圧＝空間的。本站は空間（どこに落とすか）はほぼ自由で、美的な結果を決めてゐるのは時間だけ。
- **gatemark（不可逆・順序依存）**との差：あちらは工程の順序であって、連続する時計は無い。
- **hushi（揮発の時間軸）**との差：あちらは時間を「軸」として読み進めるもので、何も失われない。本站の時間は消費される資源。

## 動效（四種）

| 種 | 内容 |
|---|---|
| ambient | **照り**——26 秒で金地を横切る反射帯（`mix-blend-mode:soft-light`） |
| input | **雲の再滲み**——hover でフィルタの `stdDeviation`／`scale` が 90ms で増し、離れると 160ms で戻る |
| transition | **扇を繰る**——頂角 102° の楔が要（かなめ）を軸に 620ms で払われて内容が現れる |
| signature | **溜込前線**——滴下から `700+1500w` ms、σ と変位が 0 から潤みの決める終値へ向かって進み、乾いたところで止まる |

四種すべてに `prefers-reduced-motion` 降級があり、情報の損失はゼロ。ただし**乾き（潤みの減衰）だけは止めない**——それはアニメーションではなく操作対象そのもので、止めれば機能が消える。

## 制作メモ

- 外部画像・音声ファイルはゼロ。外部資源は Google Fonts（Noto Serif TC／Zen Old Mincho）のみ。
- 扇面・二十四図・見本図・logo・favicon はすべて同じ引擎の出力で、**一枚も「描いて」ゐない**。
- JavaScript を切っても、扇面・図式・料・溜込五段の見本・断ち切りの見本は完全に見える。止まるのは「間合ひ」（時刻の計測）と誂への自動計算だけで、どちらも同じ数値が頁に文字で書いてある。
- 単頁の大きさ：`index` 57.7KB／`tarashi` 64.4KB／`zushiki` 90.2KB／`atsurae` 32.0KB（いずれも inline 全込み、予算 350KB）。
- 店號・人名・価目・電話・住所はすべて虛構示意。
