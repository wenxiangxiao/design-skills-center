# 七彩樂園 TSHIT-TSHÁI LO̍K-HÂNG

**嘉義中埔家庭樂園 × PS1 低多邊形 PSX Low-Poly Aesthetic**

張金水 1979 年把沄水村半甲檳榔坡地整成兒童樂園，從臺南拍賣場買回一座 1962 年大阪製的旋轉木馬；之後一台一台添了摩天輪、小火車、咖啡杯、海盜船、碰碰船。1998 年，在臺北做遊戲美術的二代張明哲下班把整座園一個頂點一個頂點建成一張 3D 導覽光碟，隨門票送出八千張。三代張以安照那張光碟的規格重做網站——所以整個網站就是那張光碟：320×240、一張 256×256 貼圖頁、頂點一動就跳、貼圖會游、霧色等於天色。

> 園名、人物、門牌、電話、票價、公車路線皆為虛構示意；嘉義中埔、中埔交流道、八掌溪、國道 3 號為真實地名。所有 3D 模型與貼圖皆由程式即時生成，零外部圖片。

## 首創

1. **PSX 管線 PSX pipeline in raw WebGL**：全館第一個把 PS1 的三個硬體缺陷當成風格本體重做的站——頂點投影後吸到 320×240 整數格（無次像素）、`uv·w ÷ w` 抵銷硬體透視校正做出仿射貼圖、片段著色器內 4×4 Bayer＋每通道 31 階量化；同一支著色器在〈設施圖鑑〉可以逐條關掉。
2. **精度開機 precision boot（簽名動效）**：開場時頂點格距從 1/24 收到 1/1、貼圖頁 16 格一格一格「上傳」（未上傳的面是灰的）、霧距從 8 退到 46——畫面是「被算出來」的。
3. **記憶卡導覽 memcard-blocks**：頁面就是記憶卡上的存檔格，現用頁的存檔圖示在播放（PS1 存檔圖示的兩格動畫），其餘靜止；剩餘格數即時顯示。
