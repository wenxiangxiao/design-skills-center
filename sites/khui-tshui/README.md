# 開喙 KTV　KHUI-TSHUÌ KTV

> KTV 歡唱包廂 × 波蘭海報學派・水粉開喙半身 Polska Szkoła Plakatu — Gouache "Open Mouth"

臺南市中西區西門路二段 233 巷 9 號 3 樓〔門牌虛構〕。1992 年，前歌廳駐唱鄭麗卿（1958–，虛構）把一層三樓隔成八間包廂，取台語「開喙」——唱歌，先要把嘴打開。八扇門上的海報是她表弟林志遠（1961–，虛構）畫的：1986–1990 年他在華沙美術學院的海報工作室進修，帶回一條規矩——一張海報只講一件事，而且要用畫的。現任店長鄭雅雯（1986–，虛構）。

小包 2–4 人 白天 NT$280／歡唱 480・中包 5–8 人 380／680・大包 9–15 人 560／980・派對廳 16–30 人 1,200／2,200（每小時）・每人低消一杯飲料 120・午夜場 02–06 時小包三小時 600・每天 11:00–翌日 06:00・(06) 222-1992〔虛構〕。西門路、國華街、赤崁樓為真實地名；Tomaszewski、Lenica、Cieślewicz、Świerzy、維拉諾夫海報博物館與華沙國際海報雙年展為真實背景；其餘人物、店家、價格皆為虛構示意。

## 首創

**麥克風輸入作為畫筆 voice-as-brush**：全館第一個以麥克風（`getUserMedia` 音訊）為輸入的站。使用者的歌聲在本機以 `AnalyserNode` 取音量（RMS）與自相關音高：音量決定筆寬與前進速度、音高決定顏色（低群青→中朱→中高粉→高檸檬）與筆的彎度，一支活的鬃毛筆從海報上那張嘴裡出發；句子之間停下來就收筆、偶爾在筆尖落一隻鳥。唱完即得一張自己的波蘭式海報（分數、FNV-1a 代號、PNG）。字幕擦色以 Web Animations 實作、`currentTime` 由聲卡時鐘寫入。不允許麥克風時，同一支筆由「按住唱」的合成人聲驅動。
